# Nexora 大数据量页面参考

本参考将《前端大数据量展示与交互设计规范》提炼为 Nexora 前端实现规则，并结合配置备份中心的实际场景校准。适用于设备、备份批次、任务、日志、告警、拓扑和配置正文等持续增长的数据页面。

## 选择展示模式

1. 先判断数据规模、增长速度、层级关系和用户任务，再选择组件。
2. 使用表格进行字段比较、排序、批量操作和精确定位；使用卡片展示摘要、健康度和状态；使用树或树表表达父子层级；使用时间线表达事件先后；使用代码查看器展示配置正文。
3. 列表只返回摘要字段。配置正文、命令输出、日志正文、完整接口/路由/邻居数据必须由详情接口按需加载。
4. 数据超过 500 条时，必须使用服务端搜索、服务端筛选和分页/游标；不得先拉取全量数据再由前端分页或虚拟化。
5. 数据超过 5000 条时，先要求用户选择 Site、区域、机房、设备组、状态或输入关键词，再发起查询。

## 配置备份中心约束

1. 使用“备份批次/日期 → Site → 设备结果”的业务层级，但同一层级只呈现一次：顶部已有 Site 选择器时，选中单个 Site 后隐藏重复的 Site 汇总卡片和表格分组标题；选择“全部 Site”时再显示 Site 汇总和分组标题。
2. 概览先展示批次级和 Site 级摘要：总设备、成功、失败、未知、跳过、最近批次和异常数量。Site 标签必须读取 CMDB 的 `site_name`，再回退 `site_code`，最后才使用历史兼容字段；禁止把内部 ID 当作用户名称。
3. 点击有失败或未知结果的 Site 时，直接进入该 Site 的异常筛选；不要让用户在全量设备表中手动翻找。
4. 详情默认每页 20 条，可选 10/20/50/100；接口必须返回 `total`、`page`、`page_size`。设备名、管理 IP、平台等搜索条件必须提交后端。
5. 详情提供常用状态快捷筛选：全部、异常、失败、未知、成功、跳过；同时提供关键词搜索和“一键重置”。无结果时明确提示当前筛选条件没有匹配设备。
6. Site、状态、关键词和分页必须组合查询。切换 Site 或状态时重置到第 1 页；不要在切换后继续展示上一个筛选条件的结果。
7. Site 下的设备结果应直接打开该设备的备份详情/配置正文；不要再维护一个与 Site 入口重复的“设备明细”主视图。
8. 日期聚合使用有限时间窗口（例如近 7/30/90 天）和紧凑列表，最多展示少量日期行；不要按日期无限铺卡片。底部批次历史使用固定高度、粘性表头和分页，避免把历史记录撑满页面。
9. 详情弹窗首屏只加载批次/Site/状态汇总和极少量元数据，状态筛选项直接显示数量；用户点击状态后才请求设备结果。弹窗和结果区使用固定最大高度与内部滚动，避免设备数量改变页面整体高度。

## 筛选与搜索

1. 顶部保留高频条件：关键词、Site、状态、时间范围、搜索和重置；低频条件放到高级筛选区域。
2. 搜索框明确提示字段，例如“设备名称或 IP”，允许按回车或点击搜索执行；不要每输入一个字符都请求后端。
3. 显示当前结果数量、当前筛选条件和无结果状态；提供清除单个条件和全部重置。
4. 快速切换条件时取消旧请求，避免旧响应覆盖新筛选结果。

## 异步请求与状态

1. 为详情查询保存 `AbortController`；开始新查询前取消旧查询，关闭弹窗时也取消未完成请求。
2. 仅当前请求可以结束 loading 状态或写入结果；被取消的请求不得弹出错误提示。
3. 区分首次加载、筛选加载、分页加载、空数据、无搜索结果、请求失败和重试状态；不要只显示全屏旋转图标。
4. 视图切换应保留 Site、状态、关键词、排序和每页数量；结果接口返回的数据必须对应当前查询条件。

## 接口契约

大数据列表接口至少支持：

```text
page / page_size
keyword 或 search
业务筛选条件（site、status 等）
```

后端应限制最大 `page_size`，只查询当前页所需字段，避免 N+1 查询，并为常用筛选字段建立索引。列表接口不得返回配置正文等大字段；详情接口应独立返回正文或完整日志。

## 验收清单

- [ ] 首屏没有默认加载全量设备或大字段
- [ ] Site 名称来自 CMDB 默认名称，不显示内部 ID
- [ ] Site、状态、关键词可以组合筛选
- [ ] 选中单个 Site 时没有重复的 Site 汇总/分组标题
- [ ] 异常 Site 可以一键定位到失败和未知设备
- [ ] 搜索由后端执行，支持设备名和 IP
- [ ] 分页默认 20，最大值受接口限制
- [ ] 切换筛选会取消旧请求并重置页码
- [ ] 显示总数、无结果、加载失败和重试状态
- [ ] 详情正文和命令输出按需加载
