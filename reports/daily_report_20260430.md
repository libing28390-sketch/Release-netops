# 2026-04-30 开发与故障排查总结报告

## 1. 核心任务目标
今日主要围绕“自动化定时作业”的功能增强以及“执行历史记录”为空的故障排查展开。

## 2. 完成的主要工作

### A. 定时作业（Scheduled Jobs）功能增强
- **脚本详情预览集成**：在定时作业列表及详情中，将脚本名称修改为可点击状态。
- **源码查看器**：实现了全局的脚本预览弹窗（Modal），用户无需跳转页面即可直接查看脚本的 Python 源码。
- **UI 交互优化**：
  - 修复了新建作业弹窗在关闭后未彻底清除搜索关键字和下拉框状态的问题。
  - 完善了作业详情模态框，确保所有脚本关联均能正确跳转预览。

### B. 执行历史记录故障排查（关键排查点）
针对用户反馈的“执行历史里没有任何记录”的问题，进行了深度溯源：
- **数据层校验**：通过数据库查询确认 `playbook_executions` 表中存在 34 条执行记录，`inspection_runs` 中有 1 条，确认后端逻辑已正确持久化数据。
- **前端分页 Bug 修复**：发现在 `ExecutionScheduleTab.tsx` 中，切换过滤器或数据更新时，页码状态 `inspRunPage` 未重置。若用户之前处于较后页码，切换后会导致列表因切片索引超限而显示为空。
- **健壮性增强**：在前端排序逻辑中增加了日期解析的安全保护，防止因日期格式问题产生的 `NaN` 导致排序失败。
- **可观测性提升**：
  - 在前端添加了 `[ExecutionScheduleTab]` 前缀的调试日志。
  - 在后端 `list_playbooks` 接口添加了数据量统计日志。

### C. 环境与后端稳定性修复
- **端口冲突解决**：修复了后端启动时报 `[winerror 10048]` 端口占用错误。识别并清理了占用 `8003` 端口的死进程（PID 36348），恢复了开发环境的正常运行。
- **生命周期异常监控**：识别到 FastAPI `lifespan` 可能存在递归调用的风险（日志中出现大量 `merged_lifespan` 堆栈），已定位到 `backend/main.py` 相关代码块。
