## 执行规则

1. 每项任务必须以当前代码和可复现证据为依据，不把设计建议直接当作缺陷事实。
2. 每完成一项，同步更新状态、验证结果和 `docs/EXECUTION_LOG.md`。
3. 涉及持久化的变更只采用 PostgreSQL 方案；SQLite 仅用于现有测试兼容，不新增 MySQL 路径。
4. 浏览器验证和截图必须来自实际运行环境；受阻项如实记录，不伪造。
