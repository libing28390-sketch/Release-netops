## 4. 整改结论

### 4.1 标签管理

标签定义接口已返回逐标签分配数，统计接口已补齐总数、已使用、未使用和已标记设备数。页面已改为左侧分类导航、紧凑列表、搜索、使用状态/启用状态组合筛选和清晰的统计卡片。

### 4.2 IPAM

- 利用率口径排除 IPv4 `/31`、`/32`、IPv6 `/127`、`/128` 和容器前缀，并向页面返回口径说明；
- Prefix 页面明确中文状态、容量分母、分类、生命周期和来源；
- IP 地址页提供可搜索的层级 Prefix 选择，并将 `/32` 主机路由与容量网段分开；
- 对账接口返回设备名称、来源、置信度和风险，页面使用“标准登记”语义；
- 无历史样本时显示真实空状态，不伪造趋势。

### 4.3 网络总览与监控

无采集证据、空值和采集失败均归为未知，不再显示正常；未配置与无邻居使用中性色；设备风扇、电源等字段的 `0`、`null` 和空值不再被乐观解释。页面保留来源、采集时间和空状态说明。

### 4.4 PAM 与凭据轮换

会话审计补齐查询筛选、详情、录像/回放、终止、完成时间、风险呈现和 CSV 导出。凭据轮换移除重复统计，区分未配置状态，提供目标筛选、单台轮换、批量轮换和进度轮询。凭据解析修复双账号资产被旧通用凭据覆盖的问题；普通账号轮换不会覆盖管理员凭据。

### 4.5 Change Center

新增多厂商命令静态防护、不可逆命令阻断、高风险审批升级、审批快照哈希、审批后变更检测、PostgreSQL 实施阶段 MFA、一次性执行令牌元数据和敏感审计字段过滤。旧 SQLite 隔离测试仅保留兼容路径，实际 PostgreSQL 运行环境始终启用 MFA 门禁。

### 4.6 NCM

配置快照新增原始/规范化哈希、行数、段数、完整性、生命周期、规范化器版本、采集时间和任务 ID。备份内容会执行完整性判断和哈希校验；恢复计划校验设备归属、快照完整性、变更工单、MFA、预备份和回滚计时，完整配置恢复不允许直接下发。

NCM 说明书中的 MySQL 方案未采用。运行环境已实测为 PostgreSQL 18.4，数据库 `netops`，9 个新增快照字段已全部落库。

### 4.7 Smart NPA

已删除固定 IP 与伪造诊断报告分支。诊断以真实采集证据输出 `UNKNOWN/CONFLICT`，补齐正向/回程路径、逐跳入/出接口、ACL 方向与证据分类、来源/时间/缺口、证据不足置信度封顶和整改复测信息。无 CEF、BGP、HA、ACL 或性能数据时不再乐观判定正常。

### 4.8 全模块文档与页面验收

按实际侧栏生成 11 份模块 README、62 份功能介绍和 62 份使用指南，共 136 份模块文档。使用真实本地运行环境登录并逐页验证 62 个子页面，生成 62 张对应截图；最终未发现登录页误截、应用错误、未完成加载或页面级横向溢出。
