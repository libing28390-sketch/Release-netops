# Grafana 看板 V2 配色与生成更新计划

## 任务目标

以 `nexora-grafana-dashboard-skill-v2.zip` 中的 V2 Skill 和 12 份优化 Dashboard JSON 为标准，完整更新项目 Grafana Skill，并把 V2 面板展示配置纳入可重复的生成流程。

## 现状与约束

- 旧项目 Skill 的 Inbound 蓝、Outbound 绿与 V2 规范冲突；以 V2 为准，旧视觉要求不再生效。
- 保留项目特有的 Grafana 12.1.0、VictoriaMetrics UID、指标语义、查询安全和生成器约束。
- ZIP 的优化 JSON 与原 Dashboard 的数据/查询结构一致，视觉调整集中在 `fieldConfig`。
- 保留工作区内其他未提交的用户改动，不操作运行中的 Grafana。

## 实施范围

- 以 V2 规则重写 `.agents/skills/netops-grafana-dashboards/SKILL.md`，并保留兼容的 NetOps 技术规范。
- 更新 `monitoring/grafana/generate_dashboards.py`：采用 V2 默认语义颜色、Stat No Data 灰色映射，并加载 UID/Panel ID 匹配的展示配置。
- 新增 `monitoring/grafana/dashboard_presentation_v2.json`，保存 12 个 Dashboard、253 个面板的 V2 `fieldConfig`。
- 重新生成 `monitoring/grafana/dashboards/` 中的 12 个 JSON。

## 实施步骤

1. 检查工作区状态和完整生成目标清单，确认只触碰本任务范围。
2. 从 V2 优化 JSON 提取全量面板 `fieldConfig`，以 Dashboard UID、Panel ID、标题和类型索引。
3. 在生成器中严格校验 12 个 UID、全部 Panel ID、标题和类型，再应用 V2 展示配置；任何结构不匹配都显式失败。
4. 以 V2 完整规范更新专项 Skill；明确 V2 是视觉基准，同时保留项目数据/查询契约。
5. 运行生成器并逐份核对全部 12 个输出。

## 验证计划

- 编译 Python 生成器并运行生成器。
- 解析 12 个输出 JSON，与 ZIP 中对应 V2 JSON 做完整结构比较。
- 对比 HEAD 和生成结果，确认 `fieldConfig` 之外的 UID、Panel ID、Datasource、Queries/Targets、变量、Transformations、Links、统计口径及布局均未改变。
- 检查所有 Stat 的 `null` / `nan` 映射为 Muted Gray、V2 语义配色和 Skill 元数据。
- 执行 `git diff --check` 并复核最终文件清单。
- 不运行无关业务回归，不部署或写入运行中的 Grafana。
