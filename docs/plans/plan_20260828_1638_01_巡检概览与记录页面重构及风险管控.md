# 实施计划：巡检概览与记录页面重构及风险管控

## 1. 任务目标与背景

根据业务生产运维要求，针对巡检模块进行系统性重构与风险收敛：
1. **风险控制**：彻底移除 `/automation/records` 与 `/automation/inspections` 中的“立即巡检全部”无脑高危按钮，巡检必须通过「定时作业按设备类别错峰执行」或「受控单批次执行」。
2. **页面解耦与去重**：
   - `/automation/inspections`（巡检概览）：定位为**健康大盘与趋势分析**（全网健康打分、24h/7d 健康趋势图、高风险异常设备雷达、最近 5 次巡检概况）。
   - `/automation/records`（巡检记录）：定位为**审计流水与报告中心**（移除顶部重复的大看板，专注于批次流水、单设备检查明细及 Excel/PDF/HTML 报告导出）。
3. **设备类别驱动的巡检指标套件**：
   - 在定时作业（`JobModal.tsx`）中提供基于设备大类的「预设巡检套件」（网络设备标准套件、主机服务器套件、智能自适应套件、专属脚本），解决指标过多打开卡顿与跨设备类型指标混淆的问题。
