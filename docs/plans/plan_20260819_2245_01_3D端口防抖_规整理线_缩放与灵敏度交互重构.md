# Implementation Plan - 3D端口防抖、垂直规整走线、平滑缩放与点击灵敏度重构

## 用户痛点与缺陷深度诊断

1. **端口间隙悬浮导致屏幕抖动与频繁刷新 (Oscillating Render Loop)**：
   - **根本原因**：端口卡片使用了 `scale-110` 放大特效且未固定 HUD 容器高度，当鼠标在两个端口中间的间隙移动时，触发了 `onMouseEnter`（尺寸变大） -> `onMouseLeave`（尺寸恢复） -> 布局回流挤压鼠标位置 -> 再次触发 `onMouseEnter` 的高频无限震荡重渲染死循环；
   - **修复方案**：
     - 彻底去除布局破坏性的 `scale-110`，改为无回流的 `ring-2 ring-cyan-400` / `brightness-125` 高亮；
     - 固定 Tooltip 与 HUD 详情卡片的尺寸与内边距，杜绝任何 DOM 回流尺寸抖动；
     - 采用稳定持久的选中/悬浮状态记忆，在端口缝隙间移动时不重置渲染。
2. **按需跳线杂乱不规整、标签重叠 (Unorganized Cable Geometry & Tag Clutter)**：
   - **根本原因**：之前曲线直接在空中自由弯曲，没有按照数据中心真实理线槽路径铺设；
   - **修复方案**：
     - 严格按照 **机架垂直理线槽（Vertical Cable Organizer Raceway, $X = -1.85, Z = 1.65$）** 构建标准化 5 点规整走线：
       `端口引出 -> 90°平滑转入侧边理线架 -> 沿理线架垂直降落/上升 -> 90°水平引出 -> 接入目标端口`；
     - 限制按需模式下只显示当前选中设备的整洁走线，仅在主干处呈现 1 个高对比度发光 3D 标牌，杜绝空中杂乱与标牌重叠。
3. **放大缩小不方便 (Inconvenient Zooming)**：
   - **修复方案**：
     - 在顶部浮动控制岛直接提供专用的 **`[ + 放大 ]`** 与 **`[ - 缩小 ]`** 快捷按钮；
     - 优化 OrbitControls 的滚轮缩放平滑度（`zoomSpeed = 1.4`, `dampingFactor = 0.12`）。
4. **选择设备鼠标操作不灵敏 (Insensitive Device Raycasting)**：
   - **根本原因**：`RackDeviceItem` 与 `ProceduralChassis` 两层组件同时在 `useFrame` 中独立计算 Z 轴抽拉，导致碰撞体包围盒在抽拉瞬间与射线检测发生冲突；且缺少全尺寸前向碰撞层；
   - **修复方案**：
     - 统一下沉 Z 轴抽拉动画至单层管理；
     - 在每个设备正面添加一层隐形的大尺寸交互碰撞体（Hitbox Plane），并在鼠标移入时即刻设置指针 `cursor: pointer`，实现 100% 灵敏秒选。
