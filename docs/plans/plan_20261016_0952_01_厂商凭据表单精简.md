# 厂商凭据表单精简计划

## 任务目标

- 资产表单只在 Cisco 网络平台显示 Enable Secret，并在切换到非 Cisco 平台时清除隐藏的 Enable 密码草稿。
- 凭据中心新建通用凭据时默认隐藏 Enable 密码；仅当用户明确勾选“这组凭据用于 Cisco 设备”后才展开该字段。
- 精简资产新增表单的首屏信息，把网络接入、位置、保修及低频元数据收进可展开的“更多信息”，保留所有已有字段与保存行为。

## 现状与问题

- 生产凭据中心新建 `ssh_password` 记录时直接显示 Enable 密码，容易让用户误以为普通服务器或所有网络设备都需要此字段。
- 资产表单已有 Cisco 平台条件，但切换平台后需确保隐藏字段不被继续提交。
- 资产新增表单一次展开 Web、设备属性、认证、网络、位置和保修等大量选填字段，首屏密度高、滚动距离长。
- 工作树中存在此前资产、凭据和 Web 入口等未提交修改；本次在这些修改上增量实现，不覆盖无关内容。

## 影响范围与拟修改文件

- `src/pages/AssetManagement/components/AssetModal.tsx`：Cisco Enable 字段保护、表单分组折叠和密度调整。
- `src/pages/AssetManagement/components/AssetModal.test.tsx`、`src/pages/AssetManagement/index.test.tsx`：覆盖 Cisco/非 Cisco 字段显示与 payload 行为。
- `src/pages/CmdbManagementTab.tsx`：新增凭据默认隐藏 Enable 密码并提供 Cisco 显式展开选项。
- 视测试需要新增凭据表单组件测试；不修改后端凭据 API 合约。
- 本计划及配套 walkthrough。

## 实施步骤

1. 复核平台与凭据字段的现有绑定；以 Cisco 平台为唯一资产侧展示条件，切换到非 Cisco 时清空 Enable 密码状态和提交值。
2. 为凭据中心新建流程添加默认关闭的 Cisco Enable 密码选项；只有 CLI 凭据类型可以启用，取消时清空草稿；编辑已有 Enable 密码时保留可管理能力。
3. 把资产创建中的次要网络/位置/保修/标签细节收纳到“更多信息”，让身份、管理地址和凭据路径更突出，并保证折叠前后的表单值都进入既有保存流程。
4. 运行相关 Vitest、TypeScript lint 和前端构建；在浏览器核验资产新建和凭据新建两种路径，确认非 Cisco 默认不出现 Enable 字段、Cisco 显式启用后出现。

- 凭据中心新建 SSH 密码/密钥时增加默认未勾选的 Cisco Enable 密码选项；勾选后才显示 Enable 密码，其他类型会清除该选项及草稿。已有凭据的 Enable 字段仍可编辑。
- 资产保存时只有 Cisco 网络平台会提交 `enable_password`。

## 风险与回滚思路

- 折叠只改变展示，不删除或重置其他可编辑表单值；回滚 UI 即可恢复全部字段常驻呈现。
- Enable 密码按密码秘密字段处理；折叠/关闭时清空非 Cisco 草稿，空值不会覆盖凭据库中已有密码。
- 若生产页面异常，可将 `/root/asset-credential-ui-20261016/originals/` 中备份的前端文件恢复到 `/data/nexora-automation` 对应路径，重建镜像并仅重启 `netops` 服务。
