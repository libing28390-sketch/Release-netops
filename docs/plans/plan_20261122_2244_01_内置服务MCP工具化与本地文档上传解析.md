# 实施计划：内置服务 MCP 工具化、动态 `/` 目录与本地文档上传解析

- 创建时间：2026-11-22 22:44
- 目标仓库：`D:\netops\netsops-main`

## 1. 任务目标
1. **内置服务 MCP 工具化**：将 Nexora 内置的只读运维/AI 服务统一注册为标准 MCP Tool（`name`、`slash_command`、`title`、`description`、`inputSchema`、`category`、`risk_level`），并通过 `GET /api/ai/assistant/tools` 与标准 MCP JSON-RPC 端点 `POST /api/ai/assistant/mcp`（`initialize` / `tools/list` / `tools/call`）对外提供服务。
2. **Copilot `/` 快捷指令动态化**：前端从 `/api/ai/assistant/tools` 动态加载可用服务列表，输入 `/` 时自动展示后端注册的全部工具与参数提示（请求失败时回退默认列表）。
3. **本地 Word / Excel / PDF 上传与解析**：支持在 Copilot 输入框中直接选择 `.docx` / `.xlsx` / `.pdf` / `.txt` / `.md` / `.csv` / `.log` / `.json` 文件，后端纯本地解析文本并执行现有 AI 安全预检/脱敏，前端展示附件标签并在发送时随当前轮次上下文提交。

## 2. 现状与问题
- `backend/ai/tools/read_only_tools.py` 已有只读工具实现，但未统一暴露为 MCP 工具目录，也未向前端 `/` 菜单下发。
- `CopilotComposer.tsx` 的 `/` 指令此前为前端硬编码列表，后端新增能力无法自动呈现。
- Copilot 输入框尚无文件上传入口，无法直接解析 Word / Excel / PDF。

## 3. 影响范围与拟修改文件
- 新增：`backend/ai/mcp/__init__.py`、`backend/ai/mcp/registry.py`（MCP 工具注册表与执行调度）。
- 新增：`backend/ai/services/document_parser.py`（本地 `.docx` / `.xlsx` / `.pdf` / 纯文本安全解析与截断）。
- 修改：`backend/ai/api/assistant.py`（新增 `GET /tools`、`POST /mcp`、`POST /attachments/parse`）。
- 修改：`src/api/ai.ts`（新增 `CopilotToolDefinition`、`getCopilotTools`、`parseCopilotAttachment`）。
- 修改：`src/pages/ai/Copilot/CopilotComposer.tsx`（动态 `/` 菜单 + 文件上传按钮与附件标签）。
- 修改：`src/pages/ai/Copilot/AssistantTab.tsx`（加载工具列表、接入附件上传回调）。

## 4. 实施步骤
1. 检查并确认 `.venv` 中 `python-docx` / `openpyxl` / `pypdf` 可用性（缺失时提供清晰降级提示或按需安装）。
2. 实现 `backend/ai/services/document_parser.py` 本地文件解析（限制单文件大小 <= 10MB、限制提取字符数、自动脱敏）。
3. 实现 `backend/ai/mcp/registry.py`（注册内置只读工具与斜杠指令映射，实现 `list_mcp_tools()` 与 `call_mcp_tool()`）。
4. 在 `backend/ai/api/assistant.py` 暴露 `GET /tools`、`POST /mcp`、`POST /attachments/parse`。
5. 在 `src/api/ai.ts`、`CopilotComposer.tsx`、`AssistantTab.tsx` 接入动态 `/` 目录和文件上传交互。
6. 运行后端单元测试、前端 `npm run lint`、Copilot `vitest` 和 `npm run build`。

## 5. 验证计划
- 后端：`py_compile` + `pytest` 验证 MCP `tools/list`、`tools/call`、`/tools` 接口及文档解析接口（`.txt`/`.docx`/`.xlsx`/`.pdf` 边界与超大文件拦截）。
- 前端：`npm run lint`、`npx vitest run src/pages/ai/Copilot`、`npm run build`。

## 6. 风险与回滚思路
- **安全风险**：MCP `tools/call` 仅暴露白名单只读工具，强制经过 `require_ai_permission` 鉴权与 `sanitize_data` 脱敏；文档上传限制扩展名白名单与 10MB 上限，并强制经过 `ai_security_gateway` 预检。
- **回滚**：所有新增端点均为增量路由，前端工具列表拉取失败自动回退本地默认指令，不影响原有对话主链路。
