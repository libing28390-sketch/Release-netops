# 实施计划：首页 Three.js 3D 视觉增强与 MFA 找回密码逻辑修复

## 1. 任务背景与目标

1. **首页 3D 视觉增强**：充分利用项目已集成的 Three.js / WebGL 生态，为系统首页（`HomePage.tsx`）构建富有未来感、高科技感与沉浸式交互的 3D 赛博网络数字孪生视觉（`ThreeCyberNetwork`），提升全网资产、监控与自动化平台的视觉品质与品牌质感，同时确保 60FPS 流畅度与低功耗。
2. **MFA 认证找回密码逻辑排查与修复**：彻底排查并修复通过 MFA 身份验证器找回密码时的 30 秒 TOTP 动态码时效过期竞态问题、步骤 2 缺失前置核验、错误信息未汉化等问题，构建稳定顺畅的找回密码闭环。

---

## 2. 问题深度剖析

### 2.1 MFA 找回密码逻辑问题
1. **30秒时效过期竞态 (Core Flaw)**：
   - TOTP 动态码每 30 秒滚动一次。
   - 原逻辑在步骤 2（输入 MFA 动态码）未向后端请求核验，直接跳转到步骤 3 让用户填写符合强密码规则（≥10位、大写、小写、数字、特殊字符）的新密码与确认密码。
   - 用户填写完两次密码并点击“重置密码”时往往已经过去 30~50 秒，步骤 2 的动态码已在服务端失效，后端返回 `400 "Invalid account or MFA code"`，导致重置失败。
2. **步骤 2 缺乏前置校验与即时反馈**：
   - 用户名未开启 MFA 或输错动态码时，步骤 2 无法及时感知，直到步骤 3 提交后才报错。
3. **报错信息未本地化**：
   - 密码强度不合规或验证码错误时返回的英文报错直接抛给前端用户，体验不佳。

### 2.2 首页 3D 视觉现状
- 依赖项中已有 `three`、`@react-three/fiber`、`@react-three/drei`，但 `HomePage.tsx` 仍采用传统静态 2D 平铺卡片，缺乏网络运维控制台应有的全网互联、动态脉冲与全局掌控感。

---

## 3. 拟修改与新增文件

1. **后端 API & 服务层**：
   - `backend/api/users.py`：
     - 新增 `/api/forgot-password/verify-mfa` 与 `/api/forgot-password/verify-code` 预检与凭证签发接口。
     - 引入短期（5~10分钟）安全重置令牌 `reset_ticket`（HMAC 签名，绑定用户名与过期时间）。
     - 优化 `forgot_password_mfa_reset` 与 `forgot_password_reset` 接口，支持凭证重置与多语言错误返回。
     - 优化密码强度校验提示，支持清晰中文/多语言错误原因。
2. **前端找回密码交互**：
   - `src/components/ForgotPasswordModal.tsx`：
     - 步骤 2 增加即时验证逻辑，调用后端验证接口并获取 `reset_ticket`，通过后进入步骤 3。
     - 步骤 3 携带 `reset_ticket` 提交改密，消除 30 秒 TOTP 时效竞态。
     - 增加密码强度实时校验与规则提示，提升改密成功率。
   - `src/i18n.tsx`：补充与完善 MFA 找回密码、密码强度要求及验证提示字典。
3. **前端 3D 首页组件**：
   - `src/components/home/ThreeCyberNetwork.tsx` [NEW]：
     - 基于 Three.js 构建的高性能 3D 赛博网络视界（粒子流、发光拓扑节点群、流动数据弧线、鼠标平滑视差响应）。
     - 支持明暗主题自适应、健康状态流光联动、窗口 Resize 响应、低功耗离屏休眠。
   - `src/pages/HomePage.tsx`：
     - 集成 `ThreeCyberNetwork` 英雄区，重构首页视觉层级、玻璃拟态卡片与动态状态展示。
   - `src/components/LoginScreen.tsx`：
     - 协同优化登录页对 MFA 错误与找回密码弹窗的平滑联动。

## 4. 实施步骤

1. **第一阶段：后端重置逻辑与凭证机制改造**
   - 在 `backend/api/users.py` 中实现安全的 `_generate_reset_ticket(username)` 与 `_verify_reset_ticket(ticket, username)`。
   - 实现 `/api/forgot-password/verify-mfa`：校验用户 MFA 启用状态与 TOTP 动态码，成功则返回有效时间为 10 分钟的 `reset_ticket`。
   - 实现/更新重置接口：允许通过 `reset_ticket` 或兼容参数重置密码并清除锁定状态。
   - 优化报错文案，提供精准的用户可读提示。
2. **第二阶段：前端 `ForgotPasswordModal` 闭环重构**
   - 步骤 2 绑定即时核验与加载态；
   - 步骤 3 接入实时强密码检测并使用 `reset_ticket` 完成安全重置；
   - 补充 `src/i18n.tsx` 对应词条。
3. **第三阶段：Three.js 3D 赛博网络组件与首页设计**
   - 编写 `src/components/home/ThreeCyberNetwork.tsx`，实现粒子光晕、球体拓扑网格、动态弧线光流与鼠标互动；
   - 在 `src/pages/HomePage.tsx` 中嵌入 3D 模块，优化全屏排版与卡片微光样式；
   - 验证深色/浅色模式下的色彩对比度与可读性。
4. **第四阶段：质量门禁与回归验证**
   - 运行单元测试验证 MFA 找回密码与登录鉴权接口；
   - 运行 `npm run lint` 与 `npm run build` 确保 TypeScript 类型与生产打包无误；
   - 验证 3D 组件在不同分辨率与主题下的渲染性能。
