# 工作台登录操作布局优化

状态：已完成；本次修改保留在本地工作区。

## 目标

优化操作工作台 ALL 视图表格右侧区域，解决“登录方式”标题与控件错位，以及窗口需要横向滚动才能找到登录按钮的问题。

## 现状与原因

- ALL 表格内联最小宽度为 1720px，普通桌面窗口也会出现横向滚动。
- 登录方式选择器与登录操作按钮放在同一列，列标题居中而控件从左侧排列，阅读对齐不清楚。
- 该组合区域固定占 420px，进一步挤压设备信息列。

## 方案

1. 将“登录方式”和“登录操作”拆分为独立列。
2. 将 ALL 表格宽度改为容器宽度，设定紧凑的列宽和单元格间距，桌面窗口不再因 1720px 硬编码产生无意义溢出。
3. 将右侧登录方式和操作列设为粘性列；窄窗口查看设备信息时，登录入口仍停留在可视区域。
4. SSH 设备默认优先选择 Web SSH，用户手动切换的方式继续保留。
5. 只调整 `AccessCenterTab` 的 ALL 视图，不改变 SSH、RDP、VNC、WEB 分类页及登录调用行为。

## 修改范围

- `src/pages/AccessCenterTab.tsx`
- `src/index.css`
- 本计划和对应 walkthrough

## 验收

- 登录按钮与“登录操作”标题对应，右侧两列在横向滚动时保持可见。
- 现有方法选择仍控制对应的 SSH/RDP/VNC/HTTP/HTTPS 登录入口。
- SSH 设备默认方式是 Web SSH；用户可切换到 SSH 终端，设备没有 Web SSH 时回退到可用入口。
