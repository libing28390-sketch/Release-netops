# 实施计划：网段前缀与接口 IP 独立导出脚本

以后针对任务生成的任何实施计划，必须保存在工作区的 `docs/plans/` 目录下。

## 1. 任务目标
编写一个独立的 Python 脚本 `scripts/export_network_prefixes_and_ips.py`，支持：
1. 联网/直连从网络设备（或系统已有数据库/凭据）通过 SSH 采集接口 IP 地址信息。
2. 自动根据接口 IP 及子网掩码生成网段前缀 (CIDR)。
3. 根据接口名称和特征自动归断网络类型（管理网、用户网、设备互联、Loopback 等）。
4. 导出包含 `Subnet_Prefixes`（网段前缀汇总）和 `Device_Interfaces`（设备接口 IP 明细）两个工作表的精美 Excel 表格。

## 2. 现状与问题
- 目前系统前端有 IPAM 前缀与接口信息，但缺少一个轻量级、可独立运行的 Python 导出工具。
- 用户希望剥离 SNMP 监控指标（CPU/内存/流量等），只保留纯 SSH 接口 IP 与网段前缀信息。
