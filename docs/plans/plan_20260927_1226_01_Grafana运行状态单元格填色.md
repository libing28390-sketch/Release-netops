# Grafana 运行状态单元格填色

## 任务目标

在 `04 接口流量与健康（Interface Traffic & Health）` 仪表盘的“运行状态”表格中，将 `Up` 显示为绿色底色，将 `down` 显示为红色底色。

## 现状与问题

该面板已把 IF-MIB 状态值映射为 `Up`/`down`，并配置绿色/红色映射色；当前表格单元格模式为彩色文字，截图中只显示红色文字，没有填充背景。

## 影响范围

- Grafana 仪表盘生成器及其生成的接口仪表盘 JSON。
- 不改采集、PromQL、状态语义或实时 Grafana 实例。

## 拟修改文件

- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-interface.json`（生成产物）
- 本计划及对应 walkthrough 文档。

## 实施步骤

1. 让表格面板可选择映射色的背景填充模式，保留其它调用点的既有彩色文字行为。
2. 为 04 仪表盘“接口运行状态”面板单独启用彩色背景单元格。
3. 运行生成器，检查完整输出范围和生成差异。

## 验证计划

- 解析受影响的 dashboard JSON，检查运行状态字段映射和单元格模式。
- 检查 `git diff --check` 与完整差异。
- 不连接或修改 live Grafana；UI 实际渲染无法在本地源文件检查中确认。

## 风险与回滚

- 若 Grafana 12.1.0 的 live 渲染与预期不同，可将该表格字段恢复为文本着色模式。
- 生成器会重写 9 个 dashboard JSON，执行前已确认目标列表，并在生成后检查所有输出差异。
