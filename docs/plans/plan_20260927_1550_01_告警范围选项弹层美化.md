# 告警范围选项弹层美化

## 任务目标

优化告警规则编辑器中站点/角色候选项的展示，替换浏览器原生 datalist 弹层。候选列表应与输入框同宽、信息层级清楚，键盘和鼠标操作直观，保留自由输入和现有匹配语义。

## 现状与问题

- 站点和角色筛选使用原生 `<datalist>`，弹出层宽度、字号、选项布局由浏览器决定，难以匹配应用样式。
- 设备数量在原生候选项中显示不稳定，截图里候选弹层明显窄于输入框，名称与数量的层级不清楚。
- 组合范围的站点、角色、类型和平台字段也复用了原生 datalist，外观与主表单不一致。

## 影响范围

- 告警规则编辑器内站点、角色及组合条件的候选项交互和样式。
- 不改变告警范围 API、保存字段、模糊/精确匹配或运行时目标语义。

## 拟修改文件

- `src/pages/AlertRulesTab.tsx`
- 本计划及对应 walkthrough。

## 实施步骤

1. 新增局部可复用的范围候选输入组件，按当前输入过滤租户目录选项。
2. 用同宽自定义弹层展示候选值和设备数，添加选中态、空结果态和轻量键盘导航；保留用户自由输入。
3. 站点、角色以及组合范围中的站点、角色、类型、平台字段统一使用该组件，移除对应 datalist。
4. 运行前端 lint 和生产构建，检查差异并记录未做的浏览器联调。

## 验证计划

- `npm run lint`
- Vite production build 使用临时输出目录，避免覆盖工作区已有 `dist`。
- `git diff --check`

## 风险与回滚思路

- 候选选择只写入原输入值，不改 API 和数据模型；回滚 UI 组件即可恢复原有 datalist 交互。
- 手动输入仍允许保存，因此候选项只提供引导，不会改变已有精确/模糊匹配行为。
