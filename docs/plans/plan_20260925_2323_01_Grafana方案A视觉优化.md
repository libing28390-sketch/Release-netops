## 风险与回滚思路

- `ifLastChange` 是 TimeTicks；Last Change 转换需要与同设备 `sysUpTime` 对齐，并处理 SNMP TimeTicks 回绕/设备重启。
- Last Change 面板依赖 `sysUpTime`；标准基线同时收集 system 与 interface 模块。只启用自定义 interface-only collection plan 时，该面板可能无数据。
- Flap 计数来自采样到的 `ifOperStatus` 变化，分辨率受 30–60 秒抓取间隔限制；不会声称捕获抓取之间的瞬时抖动。
- per-interface metric relabel 配置随 CMDB 接口数增长；需要按角色/阈值 profile 合并正则规则并保留 regex 转义，避免按接口创建重复 SNMP scrape。
- 04 的多接口 Gauge 保持平台默认 60/75/90 阈值；接口详情页在单接口上下文使用 CMDB 实际阈值计算动态状态，容量表仍显示每个接口的配置阈值。
- Dashboard JSON 结构校验不能代替 Grafana 12.1.0 的真实渲染验收；本次不在线部署。
- migration 只加带默认值的 profile 字段；回滚保留用户填写的 profile 数据，避免自动删列造成信息丢失。代码/配置回滚时恢复生成器、catalog、compiler 和看板 JSON。
