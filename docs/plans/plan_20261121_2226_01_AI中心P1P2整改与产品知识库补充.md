## 1. 任务目标

1. **P1 核心业务闭环**：彻底打通 Copilot 流式引用与反馈、IP/MAC/自然语言查询 SQL 化、模型路由优先级与 N+1 优化、Agent 注册表配置加载与线程池超时修复、Prompt 动态按场景/厂商解析、知识库文件上传解析分块闭环与版本契约修复、产品目录自定义型号 `vendor_id` 与 `kb_product_alias` 别名闭环。
2. **P2 前端页面美化与交互补齐**：全面优化 AI 中心各页面交互体验与视觉呈现（深色模式兼容、表单字段补齐、可视化检索沙箱、成本与预算仪表盘、安全网关策略编辑器与 Dry-Run 展示、变更治理设备选择器、消除原生 `alert()` 与死按钮）。
3. **产品知识库补充**：在保持现有目录契约测试 100% 通过的前提下，丰富主流网络厂商（华为、H3C、思科、锐捷等）企业级交换机/路由器/防火墙产品型号、软件版本与别名知识库。
4. **自检验证与交付**：通过隔离 PostgreSQL 后端回归测试、PostgreSQL-only 扫描、`npm run lint`、`npm run build`，归档 `walkthrough_*.md`，全部完成后按用户明确指令触发系统关机。

1. **阶段 A（P1 后端核心闭环）**：
   - 修复 Copilot 流式引用持久化、SSE 返回数据库消息 ID、`conversation_service` 状态字段保留、`ip_troubleshooting` / `mac_troubleshooting` / `natural_query` SQL 化；
   - 修复 `LLMGateway` 路由优先级（`scene_route` 优先于 `user_default_model`）、`models.py` 消除 N+1 ACL 查询并新增删除场景路由接口、`model_health.py` 默认保留 90 天；
