# 接口采集联动 VLAN

- 目标：手动 CMDB 接口采集在同一 SSH 会话采集 VLAN，采集后 VLAN 页面可读取快照。
- 现状：CMDB 手动入口误用调度策略的 vlan 开关；当前设备默认均关闭，VLAN 快照为空。
- 范围：仅 CMDB CLI 采集服务及其回归测试；不修改监控、全局采集策略、解析模板。
- 拟修改文件：backend/services/cmdb_cli_collection_service.py、backend/services/read_only_collection_adapter.py、backend/tests/vendor_audit/test_cmdb_cli_collection.py。
- 二次门控：通用 operational_data_service 还会按策略过滤 VLAN；通过适配器透传已有 policy_override_categories 参数，仅手动 CMDB 调用覆盖 vlan。
- 步骤：修正手动入口 VLAN 联动条件；覆盖默认关闭策略和 VLAN-only 调用；验证实际采集及页面。
- 验证：聚焦 pytest、PostgreSQL-only 扫描、浏览器采集及列表检查。
- 风险与回滚：新增同会话 VLAN 只读命令；失败保留旧成功快照并返回错误。回滚本次条件变更即可。
