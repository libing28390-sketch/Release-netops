# 告警中心表格宽度修复计划

## 目标

在浏览器缩放 100% 时，让告警中心表格中的站点、级别、状态、责任人等值保持完整可读，避免逐字换行造成行高拥挤。

## 现状与范围

- 告警表格列数较多，浏览器自动布局会压缩部分列。
- 表格已有横向滚动容器，可在总宽度超过可视区域时查看剩余列。
- 修改范围限定在 `src/pages/AlertDeskTab.tsx`，为关键列设置合理的最小宽度并禁止短值换行。

## 实施步骤

1. 为告警表格设置适当的最小宽度，避免浏览器将所有列压进视口。
2. 为站点、级别、状态、责任人、发生时间和持续时间设置最小列宽及不换行样式。
3. 对告警标题、信息和主机等列设置可用宽度约束，使横向滚动时仍保持层次清晰。

## 验收

- `npm run lint` 通过。
- 检查变更差异，确认改动仅影响告警中心表格布局。
- 不运行测试或构建；本次只调整现有页面样式，避免覆盖工作区已有的 `dist/` 改动。

## 风险与回退

- 表格总宽度增加后，较窄视口需要横向滚动；该行为由现有滚动容器承载。
- 如列宽不合适，可只调整本页列宽类名并重新执行 lint。
