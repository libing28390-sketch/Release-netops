# 拓扑链路可见度与分组示意

## 目标

恢复选中设备没有物理上联时完整拓扑中链路的正常对比度；让正式页面的「上联分组」回到 Demo 的分层图、组卡片连线和右侧上联路径呈现。

## 现状

完整拓扑根据“有设备被选中”进入聚焦态。被选设备无相邻链路时，所有其他链路仍被压到低透明度。正式上联分组当前使用逐层卡片列表，缺少 Demo 的核心到汇聚、汇聚到上联组以及接入组到无线区域的连接示意图。

## 影响范围

仅修改 `src/components/TopologyGraph.tsx` 的聚焦判断和非焦点链路透明度，及 `src/components/TopologyUplinkGroups.tsx`、`src/components/TopologyUplinkGroups.css` 的上联分组示意图与物理上联路径。设备、链路仍使用页面筛选后的数据和现有自定义图标。

## 实施

- 以实际存在的选中链路判断是否聚焦，使无连接设备被选中后保留正常链路对比度。
- 将未聚焦链路透明度提高到可辨识的次级状态。
- 按 Demo 重构上联分组画布。核心、汇聚、边缘、接入分组、AP 和控制器显示在对应区域。
- 根据筛选后的已确认物理链路画出层间连接，选中设备的路径高亮。
- 右侧设备详情展示每一条实际确认的物理上联和端口。保留未知上联、空态与响应式布局。
- 按画布可用高度同步缩放各层位置和 SVG 坐标；无线分组展示实际 AP 名称，避免线条被纵向拉伸或 AP 被隐藏在空白组中。

## 验收

检查无上联控制器被选中时完整拓扑链路仍清晰。浏览器中对照 Demo 检查层级、分组、连线、双上联和无线设备布局；并确认画布高度变化不会拉伸 SVG 连线。

## 回滚

只需回退组件和样式中的链路聚焦、分组视图改动，不涉及接口、数据库或已保存布局。
