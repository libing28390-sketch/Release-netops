# 实施计划：优化配置差异对比视图布局与全屏阅读体验

- **任务目标**: 解决配置差异对比窗口（`/config/diff`）垂直高度受限、可视代码行数过少的问题，提供全屏/最大化模式、统计指标卡片折叠、字号调节、自动换行及侧边栏折叠等全方位阅读优化。
- **创建时间**: 2026-08-18 14:15

---

## 1. 现状与问题分析

1. **现状**:
   - 配置差异对比页面在展示 Diff 视图时，顶部常驻展示了巨幅概览、6 个大尺寸指标卡片及对象标签列表，占用了屏幕 60% 以上的垂直高度；
   - 底层容器使用了 `overflow-auto` 嵌套导致内部代码区域无法自适应伸展到底部，用户在标准 1080p 屏幕上只能看到 6~8 行配置代码，体验局促；
   - 缺少全屏查看、字号调整、长行换行及变更目录折叠功能。
2. **改进目标**:
   - **全屏/最大化沉浸对比模式**：提供一键全屏切换（支持 Esc 退出），拉满整个视口，查看代码行数增加 300% 以上；
   - **指标面板一键折叠/展开**：6 个大卡片支持一键折叠为单行精简徽章，节省 >120px 垂直高度；
   - **动态弹性高度容器**：去除多余的嵌套滚动，让 Diff 容器完全占据 `flex-1 min-h-0` 的全部剩余空间；
   - **视图个性化工具**：提供字号缩放 (A- / A / A+)、长行自动折行 (Wrap) 及变更目录侧边栏显隐切换。
