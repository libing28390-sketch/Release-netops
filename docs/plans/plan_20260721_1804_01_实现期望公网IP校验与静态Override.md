# 完善企业级公网IP校验与静态Override 实施计划

为了解决前一版本实现中，真实检测与人工配置结果混淆、缺乏连续确认导致偶发网络异常误报、配置格式错误缺乏启动校验以及健康状态强制绑定等问题，本方案将对互联网出口可用性拨测中的公网 IP 校验与静态 Override 机制进行重构与完善。

## 1. 拟解决的问题与优化点

1. **公网 IP 区分来源与可信度**：历史快照和事件表中增加 `public_ip_source` 与 `public_ip_verified` 字段，并在检测中返回 `confidence`（高/中/低）及成功源计数，区分 `detected`、`static_override`、`cached` 和 `unknown` 等四种来源。
2. **离线与期望 IP 优先级解耦**：当配置 `STATIC_EGRESS_IP` 后，直接跳过在线检测，且不执行 expected IP 漂移比对（直接将来源置为 `static_override`、认证为 `False`）。
3. **健康状态与连通性解耦**：
   - 互联网出口状态裂变为 `connectivity_status`（连通性状态）与 `overall_status`（总体状态）。
   - 提供环境配置选项控制是否降级总体健康度（`OUTBOUND_PROBE_EGRESS_IP_MISMATCH_AFFECT_HEALTH`）。
4. **防止环境变量格式错误静默失效**：服务启动或初始化时完成严格的 IP/CIDR 校验，遇格式错误输出明示 ERROR 日志，并在系统日志/运行状态中公开，防止静默失效。
5. **连续确认防抖**：必须连续 2 次检测到相同非预期 IP 才确认发生漂移、产生告警和进行状态降级，避免外网探测源的偶发波动误报。
6. **IPv6 双栈匹配适配**：规范化所有输入规则，增加 IPv6 规范匹配与混合匹配测试。
