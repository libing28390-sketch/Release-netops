# 路由上下文设备搜索

## 目标与现状

设备上下文映射页目前使用原生设备下拉框，选项虽显示名称和管理 IP，但大量设备时只能滚动查找。需要支持输入名称或 IP 筛选后选择。

## 影响范围

- `src/pages/IPVlan/DeviceRoutingContextTab.tsx`：将设备选择改为可搜索的可访问组合框。
- `src/pages/IPVlan/DeviceRoutingContextTab.test.tsx`：调整既有设备选择 helper 以适配组合框。
- 不修改 API、设备列表加载、映射查询与保存契约。

## 实施步骤

1. 提供按设备名称、ID、管理 IP 和 IP 字段不区分大小写的子串筛选；空查询默认不展开全量设备列表。
2. 只有输入搜索词或主动按键操作后显示选项；支持鼠标、上下箭头、Enter 和 Escape。
3. 删除选择框右侧重复说明，保留加载、禁用、无匹配和选中状态。
4. 更新现有 UI 测试交互以匹配新选择器，不新增测试用例。

## 验证计划

- 静态检查组件状态、设备搜索字段、ARIA 引用和既有测试调用。
- 本轮不运行测试、构建或浏览器交互；用户未要求验证。

## 风险与回滚

只替换设备选择控件，筛选结果仍使用设备 ID 驱动现有映射查询。可回滚页面控件和对应测试 helper，不触及数据或 API。
