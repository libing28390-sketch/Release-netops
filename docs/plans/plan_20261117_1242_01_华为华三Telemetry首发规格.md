# 华为华三 Telemetry 首发规格计划

- 目标：按用户授权查询华为、华三中国官网，将首发协议、候选设备/版本、指标路径证据和前后端开发契约具体化。其余采用已建议的独立采集器、首期配额、监控指标、资产入口及设备变更边界。
- 现状：整改书已覆盖容量和12项开发闭环；尚无网络流式Telemetry业务实现；用户确认厂商以Huawei/H3C为主，未提供具体在网型号。禁止使用skills。
- 范围：官方资料与现有代码只读研究、文档规格；不连接设备、不修改生产配置，不把文档支持当成已完成设备验收。
- 拟修改：本计划、官网支持矩阵与实施规格、对应walkthrough、原整改书的决策更新。
- 步骤：核实产品版本/协议/限制；收敛首发适配器；确定模型、API和前端入口；形成实施文件边界和验收条件。
- 分工：主Agent负责H3C中文官网、当前代码复用及规格集成；huawei_official执行者只读华为中国官网证据，不写文件、不创建下级Agent。
- 验证：逐条链接/标题/型号/版本核对；未知明确标注；文档一致性和diff检查；不运行业务回归。
- 风险与回滚：官网可能要求登录才能下载版本proto/YANG，设备实际支持需验收；只新增文档，无业务回滚。
