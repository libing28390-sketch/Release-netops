# 拓扑隐藏合成端口标签

## 任务目标

拓扑画布不显示采集链路中生成的 `Port-数字` 占位端口名，同时保留真实接口名、拓扑连线和底层发现数据。

## 现状与问题

`backend/services/snmp_service.py` 在 SNMP 的 LLDP 本地端口号无法映射到 `lldpLocPortId` 或 IF-MIB `ifName` 时，生成 `Port-{loc_port_num}`；CDP 路径也会在缺少 `ifName` 映射时生成 `Port-{if_idx}`。拓扑服务把该字段作为端口端点持久化，`TopologyGraph` 又将端点字段直接绘制为画布标签，导致图中出现没有运维意义的 `Port-2`、`Port-3` 等文本。

## 影响范围

- 仅修改拓扑画布端口名称的展示。
- 不改 SNMP/CDP 采集、邻居识别、接口关联、链路持久化或图数据契约。
- 真实接口名及物理链路继续显示。

## 拟修改文件

- `src/components/TopologyGraph.tsx`
- 对应 `docs/walkthrough/` 记录

## 实施步骤

1. 在拓扑图共用接口标签格式化入口识别严格匹配 `Port-数字` 的合成占位名。
2. 画布端口标签、标题和悬浮信息不显示该占位名；真实接口名不变。
3. 检查变更 diff，运行前端 lint，并把生产构建输出到临时目录以保留现有 `dist/`。

## 验证计划

- 运行 `npm run lint` 和输出到临时目录的 Vite 生产构建。
- 静态检查处理范围只匹配 `Port-数字`，不匹配 `Port-channel` 等真实接口名称。
- 不改采集和持久化数据，避免影响链路合并和接口关联。

## 风险与回滚思路

若现场确有真实物理接口名恰好为 `Port-数字`，该名称也会在拓扑画布中隐藏；回滚方式是撤销该展示过滤。数据库中的原始值和链路数据均不受影响。
