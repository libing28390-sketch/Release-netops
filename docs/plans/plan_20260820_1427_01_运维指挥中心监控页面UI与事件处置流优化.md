# 实施计划 - 运维指挥中心监控页面 UI 与事件处置流优化

## 1. 任务目标
针对运维指挥中心（`MonitoringCenter.tsx`，路由 `/monitor/telemetry`）进行 UI 降噪与监控事件处置流优化：
- **状态卡片 Bento 化**：统一 4 联指标卡为现代 Bento Grid，移除生硬的左侧刺眼粗红/黄竖线与混杂底色；
- **顶栏控件聚合**：整合 30s 自动轮询、时钟与立即刷新微胶囊，收敛操作按钮层级；
- **活跃事件处置流卡片重塑**：将刺眼的满屏黄色告警卡片重构为白底高对比度现代 NOC 告警处置卡，清晰呈现等级标签与处置入口；
- **平台自监控区优化**：重构微型监控指标栅格，提升信息质感。
