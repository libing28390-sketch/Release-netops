# 实现期望公网IP校验与静态Override 实施计划

为了满足企业级部署对固定公网静态 IP 比对及离线生产网 Override 的需求，本方案在 `.env` 中引入了两个公网 IP 检测的高级控制配置。

## 问题描述与需求分析

1. **期望静态 IP 校验**：大多数公司拥有固定的公网静态 IP 或 IP 地址段。系统需要具备“出口漂移自动告警”能力，即通过定期探测真实公网 IP，验证其是否仍在预期的公司出口 IP 段内；若发生漂移（如自动切换到备份无线网卡或不相干网络），触发降级告警。
2. **多 IP 与网段支持**：允许企业配置多个逗号分隔的 IP（如 `202.96.128.8,210.22.84.5`）或 CIDR 网段（如 `202.96.128.0/29`），支持出口负载均衡及 NAT 地址池轮询。
3. **离线 Override 模式**：对于纯局域网隔离的无外网环境，系统无法向 `ipify.org` 发起 HTTP 请求，需直接提供静态 IP 劫持展示，避免页面报错。

## 拟修改文件

* [outbound_probe_service.py](file:///d:/nexora/nexora-private/backend/services/outbound_probe_service.py)
  - 实现 `_check_ip_matches_expected` 辅助函数，使用 Python `ipaddress` 库进行多值匹配和网络包含校验。
  - 在 `detect_egress_ip` 中检查 `OUTBOUND_PROBE_STATIC_EGRESS_IP` 环境变量，如果配置，直接返回该静态 IP。
  - 在 `_record_egress_event` 记录出口快照时，若配置了 `expected_ip_raw`，比较当前真实 IP，如果不符合期望，则设置 `public_ip_changed = True`。
  - 在 `run_outbound_probe_once` 中，若 `public_ip_changed` 为 True，将原为 `healthy` 的运行状态降级（`degraded`），并附带详细的中文化警告日志，作为告警源。
