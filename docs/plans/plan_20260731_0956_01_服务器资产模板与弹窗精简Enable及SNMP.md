# 实施计划 - 服务器资产录入弹窗与 Excel 模板精简 Enable 密码及 SNMP 采集项

## 1. 任务目标
1. 在前端资产新增/编辑弹窗 (`AssetModal.tsx`) 中，当资产类型为“服务器” (`asset_type === 'server'`) 时，精简隐藏不属于服务器特性的“Enable 密码”和“SNMP 社区名/端口/凭据”采集域。
2. 在“服务器模板”的 Excel 导出的静态与动态模板文件 (`public/templates/asset_import_template.xlsx` & `index.tsx`) 中，彻底移除 `Enable密码`、`SNMP社区名`、`SNMP端口` 表头与数据列。

---

## 2. 根因分析
1. 服务器（Linux / Windows / ESXi / CentOS 等）运维与口令管理采用标准用户与 root/sudo 特权账号机制，不存在网络设备的 Enable 模式（`enable_password`）。
2. 服务器资产的数据采集与上收通常不依赖传统网络设备级别的 SNMP 团体字配置，原“服务器模板”中包含 `Enable密码` 与 `SNMP社区名/端口` 会给填报用户带来混淆。

### 5.2 手动功能验证
1. 打开 `/assets/dashboard`，点击“新增资产”弹窗：
   - 切换为“服务器”类型，确认 SNMP 区域和 Enable 密码自动隐藏。
   - 切换为“网络设备”类型，确认网络设备的 SNMP 区域和 Enable 密码（若为 Cisco）正常显示。
2. 点击“下载模板”获得 `资产导入模板.xlsx`：
   - 查看“服务器模板”工作表，确认列头已去除 `SNMP社区名`、`SNMP端口` 和 `Enable密码`。
   - 查看“网络设备模板”工作表，确认网络设备保留必要的 SNMP 和 Enable 字段。
