# Implementation Plan - 3D机柜工业级真实感与运维交互终极重构 (3D Rack Twin Industrial Realism & Ops Overhaul)

## 核心设计哲学 (Design Manifesto)

> **“第一眼像真的，第二眼看得懂，第三步能操作，第四步能排障。”**
> **“70% 工业真实 + 20% 运维信息 + 10% 科技感。任何一个视觉元素，如果不能增强‘位置识别、状态识别、设备识别、操作反馈’四者之一，就不要加。”**

## 拟重构与升级模块清单

### 1. 严格的真实机柜比例与工业金属质感
- **比例标准**：
  - 1U = 0.4445 (44.45mm)
  - 42U 有效高度 = 18.669 (1866.9mm)
  - 机柜宽度 = 6.0 (600mm，约 13.5U)
  - 机柜深度 = 10.0 (1000mm，约 22.5U)
  - 19 英寸内导轨宽度 = 4.826 (482.6mm)
- **材质色彩**：
  - 移除满屏纯蓝/赛博朋克特效，改用**深炭灰/枪灰冷轧钢金属** (`#1c2430` ~ `#283344`，金属度 0.65，粗糙度 0.45)。
  - **柔和冷白顶棚与自然补光**：主光使用柔和冷白光（`#f8fafc`），配合浅灰蓝环境光，真实呈现冷轧钢拉丝与倒角反光。

### 2. 正面与背面的真实物理差异
- **前面板 (Front Faceplate)**：
  - 交换机：RJ45/SFP+ 阵列、挂耳螺丝、小铭牌、精准小型 LED 状态灯。
  - 服务器：热插拔 2.5/3.5 寸硬盘仓抽拉格栅、电源小灯。
  - 防火墙/路由器：简洁面板、Console/MGMT、业务标签。
  - 配线架/挡板：空位挡板与理线梳。
- **后面板 (Rear Faceplate)**：
  - 双冗余 PSU 交流电源模块（带电源插座、提手、散热孔与小指示灯）。
  - 双排风扇模块（进风/出风蜂窝格栅）。
  - 后部 MGMT/Console 维护端口与接地铜螺栓。

### 3. 精准克制的状态指示灯与选中微动拉出 (Pull-Out)
- **状态灯**：
  - 正常 (Healthy)：原材质 + 小型绿色点光源指示灯 (`#22c55e`)
  - 警告 (Warning)：原材质 + 橙色指示灯 (`#f59e0b`) + 极微弱边缘橙光
  - 严重 (Critical)：原材质 + 红色指示灯 (`#ef4444`) + 克制呼吸
  - 离线 (Offline)：整机饱和度降低至 50% + 灰色指示灯 (`#64748b`)
  - 未知 (Unknown)：原材质 + 灰白指示灯 (`#94a3b8`)
- **选中交互**：
  - 选中设备**向前微拉出 6cm** (`z + 0.6` Three.js 单位)，体现工业抽拉滑轨质感。
  - 其他未选中设备亮度轻微降低至 75%，选中设备加细线轮廓边框。
  - 自动平滑聚焦。

### 4. 文字克制与信息分级 (3D 负责定位，Drawer 负责排障)
- **3D 表面**：只保留大号清晰的设备名称（如 `CORE-SW01`）与型号（如 `CE6885`），绝不在 3D 贴图中硬塞 CPU/内存/功耗等数据。
- **Hover 浮动 Tooltip**：紧凑 4 行卡片（设备名、型号、U位区间、健康状态、管理 IP）。
- **右侧专业运维 Drawer**：
  - 设备身份与硬件规格
  - 实时健康遥测（CPU、内存、温度、电源）
  - 关联网络设备与端口情况
  - 一键快捷跳转按钮：**[资产档案] [监控中心] [接口查询] [配置备份] [Web SSH]**

### 5. 空 U 位与真实机柜层次
- 42U 中未安装设备的空间不再是空洞盲区，而是清晰呈现左右立柱导轨刻线与三方孔。
- 鼠标悬停空 U 位时，高亮显示该 U 槽并提示：`U18 (空闲 · 1U)`。

### 6. 搜索设备自动飞镜头聚焦
- 顶部搜索框支持按设备名、IP、型号模糊搜索，选择后相机平滑飞至目标设备前方微俯视角并触发拉出高亮。
