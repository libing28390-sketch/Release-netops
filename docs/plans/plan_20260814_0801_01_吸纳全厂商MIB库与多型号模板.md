# 吸纳全厂商 MIB 知识库与多型号指标模板实施方案

## 1. 任务背景与目标

依据“模式一：资产吸纳模式”，将开源生态（如 LibreNMS / RFC / 厂商公开标准）经过工业级验证的核心 MIB 库与多厂商 OID 规则，完整移植并内置到 Nexora 系统中，无需额外引入 PHP/MySQL 依赖，零部署成本即可实现：
1. **全厂商核心 MIB 库开箱即用**：覆盖 Standard RFC（1213/IF/HOST-RESOURCES/ENTITY/SENSOR）、Cisco、Huawei、H3C、Arista、Ruijie、Juniper、Fortinet 等主流网络厂商。
2. **海量主流型号模板中心**：内置 15+ 款核心交换机/路由器/防火墙的完整采集指标（CPU、内存、存储、温度、风扇、电源、IF-MIB 流量）。
3. **一键同步与更新内置 MIB 库**：支持在界面一键更新和同步最新的内置全厂商 MIB 知识库。

---

## 2. 详细落地规划

### 2.1 扩充内置 MIB 种子集 (`snmp_preset_service.py`)
* **Standard RFC 规范**：
  * `RFC1213-MIB` (MIB-II)
  * `IF-MIB` (RFC 2863 接口与 64位 HC 计数器)
  * `HOST-RESOURCES-MIB` (RFC 2790 CPU/存储)
  * `ENTITY-MIB` (RFC 4133 / RFC 2737 硬件实体)
  * `ENTITY-SENSOR-MIB` (RFC 3433 传感器)
* **Cisco (思科)**：
  * `CISCO-PROCESS-MIB` (CPU 5s/1m/5m)
  * `CISCO-MEMORY-POOL-MIB` (内存 Used/Free)
  * `CISCO-ENHANCED-MEMPOOL-MIB` (IOS-XE 64位内存)
  * `CISCO-ENVMON-MIB` (温度/风扇/电源)
* **Huawei (华为)**：
  * `HUAWEI-ENTITY-EXTENT-MIB` (VRP CPU/内存/温度/风扇/电源)
* **H3C (新华三)**：
  * `HH3C-ENTITY-EXT-MIB` (Comware V7/V5 CPU/内存/温度/风扇)
* **Arista (阿里斯塔)**：
  * `ARISTA-SW-MIB` (EOS 硬件监控)
* **Ruijie (锐捷)**：
  * `RUIJIE-DEVICE-MIB` (RGOS CPU/内存/温度)
* **Juniper (瞻博)**：
  * `JUNIPER-OPERATING-MIB` (Junos CPU/内存/温度)
* **Fortinet (飞塔)**：
  * `FORTINET-FORTIGATE-MIB` (FortiGate CPU/内存/会话)

### 2.2 扩充官方主流型号指标模板 (`OFFICIAL_MODEL_PRESETS`)
* Cisco：Catalyst 9300, Catalyst 3850, Catalyst 2960, Nexus 9000, ISR 4000
* Huawei：S5700, S6700, CE6800, CE12800, AR6100
* H3C：S5130, S5500, S6800, S10500
* Arista：7050X, 7280R
* Ruijie：RG-S5750, RG-S6220
* Juniper：EX4300, QFX5100
* Fortinet：FortiGate-100F

### 2.3 API 与 UI 增强
* 新增 `POST /api/platform-registry/mibs/reset-builtin`，支持一键重置/初始化内置全厂商 MIB。
* 前端 `MibUploadModal.tsx` 增加 `【一键同步内置全厂商 MIB 库】` 按钮。
