## 目标

依据用户提供的 530×790 截图，改善资产新增/编辑弹窗在窄视口下的可读性和操作流：清楚区分基础身份信息、连接与凭据、SNMP/库存扩展信息；让字段标签、输入和状态足够易读；优化手动凭据与已存凭据的模式切换；保持滚动内容与固定操作区的关系清楚。

## 已知现状与契约

- 当前弹窗固定 `600px` 宽，主体表单大量使用两列网格和 8–10px 辅助字号；在窄视口中字段与凭据面板显得拥挤。
- 主机名输入把“批量导入时通过 SNMP 同步”放在 placeholder，截图中看起来像字段内容，且缺少主机名示例。
- 可选资产详情默认折叠；网络设备包含厂商/平台、Web 管理、双账户 PAM 和可选 SNMP 设置。
- 保存、凭据绑定、密码掩码、编辑保护、Cisco Enable Secret、生产状态和待投产校验均须保持原行为。
- 只优化 Assets 新增/编辑弹窗，不代表 `/assets/dashboard` 整页或其余子路由已浏览器验收。

## 修改边界

- 可修改：`src/pages/AssetManagement/components/AssetModal.tsx`、`src/pages/AssetManagement/components/AssetModal.test.tsx`。
- 由主 Agent 维护本计划、walkthrough 和 `page-coverage.md`。
- 不修改共享控件、全局 tokens、API/schema、资产字段、请求参数、校验、安全或权限逻辑；不调用浏览器/computer-use 工具。

## 实施步骤

1. 复用现有 `FormSection`、`FormActionBar`、密码输入、主题 tokens 与本地字段组件；按视口宽度折叠为单列或两列，提升标签和辅助文字字号。
2. 将说明性文本移出 placeholder，整理基础字段顺序和分组；扩大桌面弹窗宽度，同时保留窄视口边距、内部滚动和固定底部操作区。
3. 明确凭据模式的选中状态、可访问语义和内容分组；为可选详情、Web 管理入口、模式切换保留清晰键盘/焦点反馈。
4. 扩展有行为意义的组件测试，验证凭据模式切换与原有安全/校验状态；运行聚焦测试、lint、隔离构建及 diff/doc 检查。
5. 记录未执行的浏览器视觉验收；不把 jsdom 或静态类名测试称为视觉验收。

## 验收与风险

- 窄视口下字段内容不挤成双列，主机名输入示例可辨识，文字遵循现有 11/12px 语义尺度。
- 桌面仍有效利用宽度；固定保存/取消区可见，表单主体独立滚动。
- 既有字段值、厂商平台联动、凭据模式切换、掩码、表单校验、编辑和生产状态确认保持不变。
- 当前不运行浏览器工具，视口截图和真实键盘走查待后续允许的验收方式完成。
