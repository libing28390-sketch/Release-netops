# 登录粒子鼠标互动

## 任务目标
恢复减少动态效果设置下由用户鼠标触发的粒子互动。
## 现状与问题
浏览器 prefers-reduced-motion 为 true。当前 animate、syncAnimation 与 onPointerMove 全部禁用动画及鼠标互动；本地页面有粒子但不跟随鼠标。GLSL 编译错误猜测已排除。
## 影响范围与拟修改文件
仅 src/components/home/loginParticleRenderer.ts；不改鉴权与 API。主 Agent 完成此单文件局部改动。
## 实施步骤
减少动态设置下保持默认静态帧，鼠标进入后启动互动，离开或失焦恢复静态。
## 验证计划
npm run lint；隔离目录 Vite build；浏览器确认减少动态设置仍开启且鼠标互动恢复。
## 风险与回滚
无 WebGL 浮点能力的现有静态回退保留。回滚本文件改动即可。
