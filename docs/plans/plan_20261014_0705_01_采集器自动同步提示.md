# 采集器自动同步提示

## 任务目标

在采集器详情中明确显示后台会自动编译和发布，并呈现最近配置发布状态和时间，避免用户误以为容器启动后必须点击“编译、发布”。

## 现状与问题

- 线上启动日志显示自动同步正常运行：首轮生成 0 assignments；后续后台生成 30 assignments 的 v2 和 v3。v3 于 2026-10-13 22:57:32（Asia/Shanghai）在用户点击前自动同步完成。日志没有证明 0→30 是设备状态变化还是资产导入造成，也不能证明全部资产均已导入。
- 启动后自动同步、设备状态变化后触发同步和 5 分钟周期复查均已实现。
- 采集器 API 已返回 last_config_status、last_config_version、last_config_applied_at。详情目前仅展示在线状态、类型和版本，未说明自动同步，也未展示发布状态和时间。
