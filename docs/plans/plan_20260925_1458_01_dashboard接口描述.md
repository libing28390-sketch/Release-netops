# Dashboard 接口描述数据修正计划

## 任务目标
修正 Grafana 网络接口 dashboard 表格中“接口描述”字段实际没有从 `ifDescr` 指标获取、导致显示异常的问题。

## 现状/问题
`nexora-network-interface.json` 的组织变换配置包含 `ifDescr` 列名映射，但相关 PromQL 只关联 `ifName`。JSON 由 `monitoring/grafana/generate_dashboards.py` 生成，需要以生成器为准修改。

## 影响范围
仅影响接口流量 dashboard 的表格数据查询及其生成配置，不改 API、数据库或设备侧数据。

## 拟修改文件
- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-interface.json`（生成产物）
- `docs/plans/plan_20260925_1458_01_dashboard接口描述.md`
- `docs/walkthrough/walkthrough_20260925_1458_01_dashboard接口描述.md`

## 实施步骤
1. 检查接口指标的标签来源与 dashboard 查询。
2. 更新生成器，使目标表格查询把 `ifDescr` 标签按设备及 `ifIndex` 关联，同时保留 `ifName`。
3. 重新生成并检查 JSON 内容及差异。

## 验证计划
解析 JSON；运行 dashboard 生成器；确认接口表格 PromQL 包含 `ifDescr` 关联，且 JSON 可复现生成结果。按项目规则不运行无关业务测试。

## 风险与回滚思路
PromQL 标签连接若遇到缺少 `ifDescr` 的设备可能导致行缺失，需保留既有 `ifName` 查询结果并尽可能使用兼容回退。回滚时恢复生成器和 dashboard JSON 的本次差异即可。
