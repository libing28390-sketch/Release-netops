# 发现终端采集更新闭环

## 目标与现状

处理首次小时任务空等、手动 FDB CLI 回退、手动/自动重复运行、投影等待和页面不刷新。用户要求删除覆盖状态横幅；保留行级待确认状态。保留其他用户改动。

## 文件与步骤

- main.py：首次任务在启动30秒后执行，后续仍每小时。
- ip_locator_service.py：手动全量与自动共用 SNMP-only 周期函数和数据库续租锁；完成后直接投影，空表按小时重试。
- api/ip_locator.py：手动 ARP 成功后投影。
- DiscoveredEndpointsTab.tsx：删除覆盖横幅，提供刷新及可见页面每分钟读取数据库。
- 聚焦回归、TypeScript检查、隔离构建；归档走查。

## 风险与回滚

保持原始时间与快照；失败保留旧数据。立即投影会增加每轮一次数据库查询。周期读取页面不访问设备。回滚这些调用与调度即可；不更改设备配置，不部署或重启。
