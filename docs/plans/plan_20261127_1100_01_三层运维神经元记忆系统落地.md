# 实施计划：三层运维神经元记忆系统落地（短期滚动记忆 + 情景案例 + 长期实体联想图谱）

- **创建时间**：2026-11-27 11:00
- **目标仓库**：`D:\netops\netsops-main`

## 1. 任务目标
基于现有 PostgreSQL（不引入额外图数据库中间件），为 Nexora AI Copilot 构建可控、可审计、可强化/衰减的 **三层运维神经元记忆系统（Ops Neural Memory Graph）**：
1. **短期工作记忆（Working Memory）**：长对话超过 12 轮滑动窗口时，自动将滑出窗口的早期关键实体（设备、IP、机柜、站点、关键结论）压缩为紧凑滚动摘要（Rolling Summary），确保 100 轮对话仍记得前期重点且输入 Token 受控。
2. **情景排障案例记忆（Episodic Memory）**：沉淀跨会话排障闭环根因经验（带时间衰减权重与召回/人工点赞强化机制）。
3. **长期语义与实体联想图谱（Long-Term Semantic & Synapse Graph）**：存储企业隐性运维常识（变更窗口、双核心互备关系、团队输出偏好）及实体关联边（`ha_peer_of`、`same_rack_as`、`resolved_by` 等），通过 2 跳扩散激活（Spreading Activation）自动联想相关设备与历史案例。

## 2. 安全与数据边界红线
- **严禁存密钥**：写入长期记忆前强制执行 `redact_secrets` 与敏感词拦截，拒绝存储明文密码、私钥、SNMP community 或 Token。
- **严禁固化瞬时状态**：长期记忆仅存静态/半静态经验、拓扑关系与历史闭环案例；当前告警数、端口 UP/DOWN、PAM 登录次数等实时运行状态仍严格由 12 模块只读工具实时查询 PostgreSQL。
- **完全透明可删改**：提供 `/api/ai/assistant/memories` 列表、新增、强化（点赞）与删除接口，杜绝黑盒记忆污染。

## 3. 拟修改与新增文件
- `backend/core/config.py`：新增开关 `AI_NEURAL_MEMORY_ENABLED: bool = True`。
- `backend/ai/services/memory_graph.py`（**新增**）：PostgreSQL `ai_memory_nodes` / `ai_memory_edges` 幂等建表、写入脱敏校验、时间衰减 + 赫布强化（Hebbian Reinforcement）、2 跳扩散激活检索（`activate_memories`）、以及 0-Token 早期对话实体滚动摘要提取（`build_rolling_summary`）。
- `backend/ai/services/copilot_tools.py`：新增 `query_or_remember_ops_memory` 工具（支持模型召回或按用户要求记住长期运维常识/排障案例），并在系统提示词说明记忆边界。
- `backend/ai/services/assistant.py`：在 `_select_agentic_history` 接入滑出窗口的短期滚动摘要；在 `_run_agentic_chat` / `_run_agentic_chat_stream` 每次对话前自动执行 2 跳神经元记忆激活并注入精简记忆片段（≤ 450 字符）。
- `backend/ai/api/assistant.py`：新增 `/memories` 只读列表、创建、强化与删除接口。
- `backend/tests/ai/test_neural_memory_graph.py`（**新增**）：覆盖短期滚动摘要、长期语义/情景记忆写入、2 跳实体突触扩散激活、权重强化与时间衰减、以及密钥拦截红线测试。
