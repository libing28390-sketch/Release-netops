# 拓扑默认 Site 卡片视图

## 任务目标
用户打开 `/monitor/topology` 时，默认按 Site 分组，以卡片形式展示不同 Site，并可点击卡片进入对应站点拓扑。

## 现状/问题
`TopologyPage` 已包含 Site 总览卡片和站点详情画布切换，但 `canvasView` 初始值为 `site`，首次进入显示设备拓扑，Site 卡片需要手动切换才能看到。

## 影响范围
- 前端拓扑监控页面的初始展示状态。
- 不涉及 API、数据模型、后端或拓扑关系计算。

## 拟修改文件
- `src/pages/TopologyPage.tsx`
- `docs/plans/plan_20260930_1552_01_拓扑默认Site卡片视图.md`
- `docs/walkthrough/walkthrough_20260930_1552_01_拓扑默认Site卡片视图.md`

## 实施步骤
1. 将拓扑页面初始画布视图设为 Site 总览。
2. 保持现有卡片点击进入站点拓扑和顶部视图切换行为。
3. 检查差异与工作树，按用户要求不主动运行测试。

## 验证计划
- 检查变更 diff，确认只有初始视图状态改变且现有卡片交互保留。
- 不运行测试或构建，除非用户后续要求。

## 风险与回滚思路
风险较低，仅改变页面初次挂载时的视图。若行为不符合预期，将初始状态恢复为 `site`。
