# 拓扑默认 Site 卡片视图

## 任务目标
用户打开 `/monitor/topology` 时，默认按 Site 分组，以卡片形式展示不同 Site，并可点击卡片进入对应站点拓扑。移除画布右上角重复的“Site 总览 / 设备拓扑”切换按钮。

## 现状/问题
`TopologyPage` 已包含 Site 总览卡片和站点拓扑画布，初始值已设为 `overview`。画布右上角的双按钮与现有 Site 筛选器和卡片入口功能重复；选择“全部站点”应返回卡片总览。

## 影响范围
- 前端拓扑监控页面的初始展示状态。
- 不涉及 API、数据模型、后端或拓扑关系计算。

- `docs/plans/plan_20260930_1552_01_拓扑默认Site卡片视图.md`

## 实施步骤
1. 保持拓扑页面初始画布视图为 Site 总览。
2. 移除画布右上角“Site 总览 / 设备拓扑”双按钮。
3. Site 卡片点击进入该站点拓扑；Site 筛选选择“全部站点”返回卡片总览。
4. 检查差异，并构建到临时目录确认前端产物包含新交互且不覆盖现有 dist 数据。

## 验证计划
- `git diff --check`。
- 使用 Vite 将前端构建到独立临时目录，不清理现有 `dist` 内容。

## 风险与回滚思路
风险较低，仅调整拓扑页面入口和视图切换控件。若行为不符合预期，恢复原有双按钮及其视图状态处理。
