# 资产表单闪烁与凭据提示精简计划

## 目标

- 从资产新增/编辑界面移除 SSH 算法策略下拉和说明，保留 `auto` 默认值及既有数据兼容。
- 排查资产新增表单的连续闪烁反馈，移除不必要的弹窗和加载动效。
- 让 Cisco Enable 密码选项在 Cisco 设备表单前部可见，并确保非 Cisco 不显示。
- 简化凭据新增表单中 Cisco Enable 密码的提示。
- 完成回归验证，并在目标页面确认表现；不提交、不 push。

## 结论与实现

- 未发现资产弹窗被循环挂载、关闭或反复重置的状态循环。代码中的弹窗入场淡入/缩放和查找状态旋转图标会增加跳动感；已移除资产弹窗入场动画与旋转效果。连续闪烁在原页面静止截图中未能复现，因此不能把它归因为持续重渲染循环。
- Cisco Enable 密码开关移到平台和连接方式下方；选择 Cisco 网络设备时可直接看到，勾选后显示密码输入框。非 Cisco 切换会隐藏并清空 Enable 密码草稿。
- Cisco Enable 不出现的根因也已定位：新建网络设备时平台状态为空，但原生下拉把第一项 Cisco IOS 显示成默认值；表单实际没有 Cisco 平台值，故 Enable 判定为隐藏。现增加“请选择厂商或平台…”占位项，选 Cisco 厂商时自动选中 Cisco IOS 并显示 Enable。
- 站点下拉选项只显示 `site_name`；站点 ID 继续作为选项值用于保存关联。
- 移除 SSH 算法策略控件及解释文案；API 字段和既有值兼容保留，新建继续使用 `auto`。
- 凭据新增复选框使用“包含 Cisco Enable 密码”，勾选后显示“仅适用于 Cisco 设备”。
