# H3C 无线 AP 离线统计与排序看板

## 任务目标

修复 AP 离线后纳管总数减少、离线数不增加的问题；将 AP 离线状态显示为红色；提供按关联终端数和在线/运行时长排序的 AP Top 20，并在主机 `192.168.204.128` 上验证完成后再推送到 `main`。

## 现状与证据

- AC_11 CLI 报告 AP 总数 2、已连接 1：AP_12 为 `I`（Idle），AP_13 为 `R/M`（Run/Master）。
- 完整 H3C AP MIB 当前只返回 AP_13；数据库保留 AP_12 的身份，但旧的逐行 SNMP 轮询计划会把“完整快照未上报”覆盖成无效/空值，导致指标导出和 Grafana 清单只剩 AP_13。
- 看板已具备 AP 状态、关联客户端 Top、Radio 利用率等指标；离线 AP 阈值在 1 台时仍是橙色，且 AP Top 表需要明确按 AP 汇总排序。
- H3C `hh3cDot11APSysUpTime2` 可按现有 AP 状态表身份索引读到 TimeTicks；现场 AP_13 返回 `4:51:37`，AP_12 返回 0。Cisco `cLLwappUpTime` 明确定义为 AP 加入控制器的时长。Huawei 的在线时长字段在本地固定 MIB 中未说明单位，不能据此换算天数。

## 影响范围

- 后端 SNMP 硬件库存状态持久化和 H3C/Cisco 无线 MIB 适配。
- 无线专网 Grafana 生成器、V2 展示配置和生成后的 dashboard JSON。

- 本次不执行 AC 配置命令；SNMP 仅做只读读取。若主机服务健康或指标异常，使用远端备份恢复对应文件并重新构建/启动服务；Grafana JSON 也可从本次主机备份恢复。
