# IP 地址表格文字对比度

## 目标与现状
用户指出 IP 地址分配管理页表格文字太浅，字段难以辨认。提供的 1920×930 截图显示表头、时间标签、主机名、关联设备、资产信息、MAC 和备注大量使用 Tailwind `gray-400/500`，小号文字在白色表面上对比不足。

## 影响范围
- `src/pages/IPVlan/IPAddressTab.tsx`：只提高 IP 地址列表表头、次级说明及普通数据字段的文字对比，优先使用现有主题语义色，保留状态色、布局、尺寸、排序、链接和操作行为。
- 不改公共 token、共享表格样式、数据/API、筛选或业务语义。

## 实施步骤
1. 以用户截图为基线，定位当前表格中的低对比文字色。
2. 将普通字段和表头改为主题适配的可读颜色，次级说明提高到可辨认等级；确认状态 badge 仍用语义色。
3. 运行前端类型检查、隔离生产构建和差异空白检查；未能进行浏览器截图时说明验证边界。

## 验证计划
- `npm run lint`
- `npx vite build --outDir .codex-build-validation-endpoints-20261029/dist`
- `git diff --check`

## 风险与回滚
只改页面局部文字颜色类名；回滚可恢复该文件的原类名，不涉及数据、接口或共享主题 token。
