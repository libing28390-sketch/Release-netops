- 目标与现状：有无线控制器的小站点，有线设备偏在角色色带左侧。接入组标题只有上联设备名称，容易和接入成员混淆。
- 范围：调整 `src/utils/topologyRoleLayout.ts`、`src/components/TopologyGraph.tsx` 的自动布局与共享尺寸，以及 `src/components/TopologyUplinkGroups.tsx`、对应 CSS 的布局与标识。
- 步骤：让无线控制区靠近有线设备的右边界，减少无效留白。分组图区在容器内居中，明确标出上联和接入设备。
- 验证：检查少量有线设备加一个控制器的布局，以及现有密集角色布局和接入分组场景。执行前端类型检查与隔离构建。
- 风险与回滚：关注无线控制区和有线图标间距。回退前端改动即可恢复原布局。
