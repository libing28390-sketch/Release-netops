# 实施计划：定时作业 UI 风格极简化重塑与无用项清理

## 1. 任务目标与背景

根据用户反馈与截图指示：
1. **移除红框内的无用项**：
   - 彻底移除 `手动自定义`（Manual Custom）选项及下方的原生 `net_cisco_cpu` 多行文本输入框；
   - 精简智能巡检套件选项为高价值的核心方案（智能自适应 / 网络设备深度套件 / 服务器主机套件 / 关联巡检脚本）。
2. **彻底重塑 UI 风格（去除层层嵌套的大灰框）**：
   - 摒弃“灰底套白底套灰底”的沉重多层嵌套风格；
   - 采用系统统一的**现代化轻量企业级设计语言**（纯净白底、精致细边框 `border-slate-200/70`、柔和微渐变、精致内联胶囊 Pill 控制器、优雅的排版与呼吸动效）；
   - 去除生硬的编号方块，采用轻盈精致的分区标题与视觉分隔；
   - 左右范围与实时匹配看板采用一体化设计，视觉轻盈现代、极度清爽。
