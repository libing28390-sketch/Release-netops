# SNMP 模板编辑界面极简重构（对标 Zabbix）实施计划

## 任务背景与现状问题
当前 SNMP 型号模板编辑弹窗（`MetricProfileEditor.tsx` / `LiveWalkInspector.tsx`）存在严重的信息过载问题：
1. **视觉层次杂乱**：测试工具箱（SNMPWALK 实时探测）作为大块卡片强行插入在厂商输入与指标列表正中间，割裂了表单填写流程。
2. **指标表格过宽过重**：每行指标把采集方式、OID、源字段、结果类型、单位、高级计算（scale/offset/aggregation/状态码）全部平铺展开，信息密度过大。
3. **接口模板过于繁琐**：平铺了 8 个 OID 输入框，而 99% 的设备均遵循 RFC 标准 IF-MIB。
4. **冗余提示文字泛滥**：各区域有大量长篇解释说明文字，缺乏现代监控系统的干练质感。

---

## 改造目标（对标 Zabbix 优雅精简哲学）

参考 Zabbix 的 Template / Item 表单设计：
1. **核心表单极致简洁**：
   - 顶部：厂商（Vendor）+ 型号（Model）+ 快速套用推荐预置（如有）。
   - 中部指标列表（Items）：
     - 清爽的精简列表：【指标名称】、【OID 输入框（带快速拾取与测试图标）】、【模式/单位小徽标】、【⚙️ 高级选项（折叠）】、【删除】。
     - 默认收起 scale、offset、aggregation 等复杂计算参数，按需展开。
2. **测试与 SNMPWALK 工具“按需调用”（On-Demand Tool）**：
   - 将笨重的主屏常驻测试卡片，改为顶部/侧边 **「🔍 实时探测与 Walk 工具」** 折叠面板或按需展开抽屉；
   - 默认隐藏，用户需要现场调试设备时点击展开，既不占主表单空间，又能随手使用。
3. **接口模板（IF-MIB）一键化与极简化**：
   - 默认为轻量卡片：一个简洁的 Switch 开关 **「启用接口流量监控（默认标准 IF-MIB / 64位计数器）」**；
   - 仅当勾选“自定义私有接口 OID”时才展开详细字段，大幅减少页面噪点。
4. **文案降噪**：全面剔除无意义的解释性长句，界面干净利落。

---

## 拟修改文件

- `src/components/SnmpMib/components/MetricProfileEditor.tsx`：重构弹窗整体布局，精简头部与接口卡片，收纳探测工具。
- `src/components/SnmpMib/components/MetricRowItem.tsx`：重构指标项为清爽行结构，高级选项采用折叠 Popover / Accordion。
- `src/components/SnmpMib/components/InterfaceConfigSection.tsx`：简化接口模板为开关+摘要模式，私有 OID 折叠展开。
- `src/components/SnmpMib/components/LiveWalkInspector.tsx`：改造为紧凑型按需展开的调试抽屉/折叠卡片。
