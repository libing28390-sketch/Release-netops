# 资产列表字段自选展示计划

## 任务目标

调整 `/assets/dashboard`、网络设备和服务器列表：默认只展示高频关键字段，保留常用操作入口，并提供勾选项让用户按需展开其他字段，减少默认横向滚动。

## 现状与问题

用户反馈资产总览默认展示全部字段，导致操作列需要横向滑动才能看到；网络设备和服务器列表也有同类问题。当前需先确认三个列表的组件边界、字段定义及已有列配置交互，再确定默认字段集合。

## 影响范围

- 仅影响资产总览、网络设备、服务器列表的列可见性和对应前端交互。
- 不改 API 数据契约、导出字段语义、后端数据或共享表格全局样式。

## 拟修改文件

- `src/pages/AssetManagementTab.tsx` 或资产总览实际页面组件。
- `src/pages/InventoryDevicesTab.tsx`、`src/pages/InventoryServersTab.tsx` 或其对应列表组件。
- 相关类型、页面局部列选择组件及聚焦测试（若已有测试结构适用）。
- `docs/plans/plan_20261008_0910_01_资产列表字段自选展示.md`
- `docs/walkthrough/walkthrough_20261008_0910_01_资产列表字段自选展示.md`

## 实施步骤

1. 追踪三个列表的路由、组件和列定义，检查是否已有可复用的列显隐模式。
2. 默认字段：资产总览显示设备、资产类型、状态和管理 IP；网络设备显示名称、管理 IP、在线状态和健康状态；服务器显示主机名、管理 IP 和状态。操作列保持可达，其他字段通过复选项按需显示。
3. 保留现有筛选、分页、导出和行操作行为；必要时增加局部回归验证。
4. 运行前端 lint、生产构建和适用的聚焦测试，记录实际结果。

## 验证计划

- `npm run lint`
- 使用仓库外的隔离输出目录运行 Vite 生产构建，避免覆盖已有构建产物。
- 对已改动的列选择/列表组件运行相关前端测试；若缺乏可验证列显示的测试，再按现有测试模式补充最小回归检查。
- 检查缩窄视口下默认关键列与操作列可见，勾选后其他列可显示。

## 风险与回滚思路

默认列调整可能改变用户原有的表格视图习惯；通过明确的字段勾选恢复完整列可降低影响。若交互有问题，可撤回各列表的默认显隐状态与列选择控件，数据和 API 均不变。
