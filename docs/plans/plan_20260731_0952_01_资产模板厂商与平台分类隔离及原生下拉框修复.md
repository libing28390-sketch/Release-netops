# 实施计划 - 资产模板厂商/平台分类隔离及原生 Excel 下拉菜单修复

## 1. 任务目标
1. 解决资产导入模版 (`asset_import_template.xlsx`) 中“服务器模板”与“网络设备模板”数据验证下拉菜单中厂商与平台相互混杂（例如服务器模板包含思科/华为/迪普，网络设备模板包含戴尔/惠普）的问题。
2. 实现【厂商】与【平台】在服务器和网络设备模板中的彻底分类隔开：
   - **服务器模板**：厂商仅包含服务器品牌（戴尔、惠普、联想、浪潮、通用服务器等）；平台仅包含服务器操作系统（Linux、Ubuntu、Windows Server、ESXi 等）。
   - **网络设备模板**：厂商仅包含网络/安全设备品牌（思科、华为、华三、迪普、锐捷、迈普、中兴等）；平台仅包含网络操作系统（思科 IOS、DPTech Conplat (Switch)、DPTech Conplat FW (Firewall)、华为 VRP、华三 Comware、锐捷 RGOS 等）。
3. 使用 `openpyxl` 重新生成带有美观且精准原生 Excel 数据验证下拉框（`DataValidation`）的静态模版文件 `public/templates/asset_import_template.xlsx`。

---

## 2. 根因分析
1. 原先模板文件在配置 Data Validation 下拉数据源时使用了全量不加区分的厂商和平台集合，导致服务器厂商与网络设备厂商混在一起。
2. 前端 JS `xlsx` 库导出时丢掉了原生 `<dataValidation>` 属性，之前文件为老脚本遗留产物。

## 4. 实施步骤

1. **编写 openpyxl 模版生成 Python 脚本**：
   - 构建 `sheet1: 填写说明`。
   - 构建 `sheet2: 服务器模板`：应用服务器专用的厂商下拉源（`戴尔,惠普,联想,浪潮,华为,通用服务器`）与服务器专用平台下拉源。
   - 构建 `sheet3: 网络设备模板`：应用网络/安全专用的厂商下拉源（`思科,华为,华三,迪普,锐捷,迈普,中兴,阿里斯塔,瞻博,飞塔,帕洛阿尔托`）与网络专用的平台下拉源（含 `DPTech Conplat (Switch)` 与 `DPTech Conplat FW (Firewall)`）。
   - 构建 `sheet4: 参数可选值参考`：清晰分类展示服务器与网络设备的标准参数对照。
   - 导出写覆盖 `public/templates/asset_import_template.xlsx`。

2. **更新前端动态生成代码**（`src/pages/AssetManagement/index.tsx`）：
   - 在 JS 动态生成逻辑中同步隔开服务器厂商/平台与网络设备厂商/平台的参考及选项。

### 5.2 手动功能验证
1. 打开资产管理，点击“下载模板”获得 `资产导入模板.xlsx`。
2. 在 Excel 中切换至“服务器模板”工作表：
   - 选中 D 列（厂商），展开下拉菜单，确认**仅包含服务器厂商**（戴尔、惠普、联想、浪潮等），绝不包含思科、华三、迪普等网络厂商。
   - 选中 F 列（平台），展开下拉菜单，确认**仅包含服务器操作系统**。
3. 切换至“网络设备模板”工作表：
   - 选中 D 列（厂商），展开下拉菜单，确认**仅包含网络设备厂商**（包含迪普），绝不包含戴尔、惠普、联想等服务器厂商。
   - 选中 F 列（平台），展开下拉菜单，确认包含 `DPTech Conplat (Switch)` 与 `DPTech Conplat FW (Firewall)` 等网络平台。
