# 实施计划：拓扑全厂商聚合口适配与右侧面板下线

## 1. 任务背景与目标
1. **拓扑图全厂商聚合口 (LAG) 识别与展示适配**：
   - 各网络设备厂商聚合口命名差异巨大：
     - 华三 (H3C): `Link-Aggregation`, `Bridge-Aggregation`, `Route-Aggregation`, `BAGG`, `RAGG`
     - 华为 (Huawei): `Eth-Trunk`, `Trunk`
     - 思科 (Cisco): `Port-channel`, `Portchannel`, `Bundle-Ether`, `Po`, `BE`
     - 锐捷 (Ruijie): `AggregatePort`, `Ag`
     - 瞻博 (Juniper): `Aggregated-Ethernet`, `ae`
     - 迪普/山石/Linux: `Aggregate`, `aggr`, `bond`, `team`
   - 原代码中正则仅覆盖了少数思科与华三变体，缺失 `Link-Aggregation`、`Eth-Trunk`、`AggregatePort`、`ae`、`bond` 等，导致多厂商拓扑推导与连线标签展示出现割裂与未识别。
   - 目标：前后端全链路打通全厂商聚合口规范化匹配、拓扑推导及画布精炼标签展示。
2. **下线拓扑图右侧详情抽屉面板**：
   - 根据用户确认，彻底移除 `/monitor/topology` 右侧的详情抽屉面板（`TopologyInspectorPanel`），消除空间挤占与信息冗余，让拓扑画布享有全屏 100% 空间，更加纯粹清爽。
3. **解答 `/monitor/modules` 采集模块定位与厂商完整度**：
   - 向用户清晰说明该模块在系统中的作用、当前 5 套内置模板的原因以及后续演进建议。
