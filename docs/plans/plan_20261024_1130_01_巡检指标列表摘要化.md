# 巡检指标列表摘要化

## 目标与现状

巡检指标表把状态型指标的完整判定规则重复铺在“警告阈值”和“严重阈值”两列，导致单行高度过大、首屏可读指标变少；同时默认选中了英文名、OID、绑定脚本、描述等低频字段，横向信息过载。数值阈值本身简洁；主要需要收敛状态规则长段说明和默认列数。

## 影响范围

- 调整 `src/pages/InspectionItemsTab.tsx` 的只读列表呈现、默认列预设、旧列偏好迁移与已有展开详情。
- 状态规则在表格中显示一句摘要，完整解释通过悬停提示和展开详情查看。
- 编辑模式仍显示完整规则，方便理解编辑项的含义。
- 默认显示中文名称、分类、厂商、检查 Key、采集方式、告警规则、严重规则和操作；英文名、解析类型、单位、绑定脚本、OID、描述通过列设置按需显示。
- 对旧的默认列选择迁移到精简预设；已有自定义列选择予以保留。
- 保留阈值计算语义、API、统计卡片、筛选、列设置、分页和默认每页 10 条。

## 实施步骤

1. 为状态型指标生成简短的告警/严重级别摘要，覆盖普通文本状态及风扇/电源组件状态。
2. 列表状态单元格限制为单行摘要；完整规则保留在悬停提示、可访问文本及展开详情中。
3. 将“信息型、不参与阈值判定”在列表中压缩为短标签，并保留完整提示。
4. 精简默认列，并在升级列配置键时识别旧默认集合；只迁移旧默认，保留用户自定义列选择。
5. 浏览器检查默认列、指标行高度和可扫读性，确认编辑状态规则没有被压缩。
6. 运行 TypeScript 检查、隔离 Vite 构建和差异格式检查。

## 验证计划

- 浏览器检查 `/automation/metrics` 的状态型与数值型指标、悬停提示及展开详情。
- 浏览器确认英文名及低频技术字段默认隐藏、分页仍为每页 10 条。
- `npm run lint`
- 在临时目录执行 Vite production build。
- `git diff --check` 检查本次涉及的页面与文档。

## 风险与回滚

- 列表摘要会省略状态匹配的细节；完整判定文本仍可悬停或展开查看。
- 旧的默认列集合会被迁移到新预设；用户自行定制过的列仍保留。需要回滚列行为时恢复旧 storage key 和默认列定义即可。
- 如需回滚摘要显示，恢复状态规则单元格的完整说明文本和信息型阈值原文即可。
