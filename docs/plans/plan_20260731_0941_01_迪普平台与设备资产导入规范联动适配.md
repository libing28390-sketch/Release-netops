# 实施计划 - 迪普 (DPTech) 平台与设备资产录入/导入规范联动适配

## 1. 任务目标
1. 解决资产管理与设备录入/编辑弹窗中选中“迪普 (DPTech)”厂商时，操作平台未适配或未区分交换机与防火墙的问题。
2. 支持并规范化迪普两大平台：
   - 迪普交换机平台：`dptech_conplat` (`DPTech Conplat (Switch)`)
   - 迪普防火墙平台：`dptech_conplat_fw` (`DPTech Conplat FW (Firewall)`)
3. 同步更新资产批量导入（Excel/CSV）模板规范、字段说明、校验字典、下载示例以及后端的平台规范化与 TextFSM 驱动映射。

---

## 2. 现状与影响范围

### 2.1 现状分析
1. 前端 `src/pages/AssetManagement/constants.ts` 中的 `VENDOR_PLATFORMS` 字典遗漏了 `DPtech` / `DPTech` 选项，导致前端选择迪普厂商时平台下拉框无法正确关联对应的平台。
2. 后端 `backend/core/platform_utils.py` 与 `backend/api/assets.py` 原先仅硬编码了历史的 `dptech_ios` 或通用备选，未区分交换机 (`dptech_conplat`) 与防火墙 (`dptech_conplat_fw`)。
3. 资产导入导出规范文档及示例模板未更新对迪普厂商（交换机/防火墙）的取值说明。

## 4. 实施步骤

### 阶段一：前端厂商与平台字典扩展及资产录入联动
1. **修改 `src/pages/AssetManagement/constants.ts`**：
   - 在 `VENDOR_PLATFORMS` 中增加 `DPtech` 与 `DPTech` 的平台配置：
     - `dptech_conplat`: `DPTech Conplat (Switch)`
     - `dptech_conplat_fw`: `DPTech Conplat FW (Firewall)`
   - 在 `IMPORT_VALUE_MAP.vendor` 中补充迪普的别名映射：`'迪普'`, `'迪普科技'`, `'DPTech'`, `'dptech'`。
   - 在 `IMPORT_VALUE_MAP.platform` 中补充迪普两类平台的名称映射（包含中文与标准 Key）。
2. **修改 `src/types.ts` & `src/components/DeviceFormModal.tsx`**：
   - 补充 `dptech_conplat` 和 `dptech_conplat_fw` 的 Display Name 映射。
3. **优化 `src/pages/AssetManagement/components/AssetModal.tsx`**：
   - 支持根据厂商（迪普/DPTech）和设备分类/角色（交换机/防火墙）智能推导默认平台为 `dptech_conplat` 或 `dptech_conplat_fw`。

### 阶段二：更新资产导入模板与规范说明
1. **修改 `src/pages/AssetManagement/index.tsx`**：
   - 更新资产导入模版规范说明弹窗与规则说明表格，补充迪普厂商（`DPtech`）及平台（`dptech_conplat` / `dptech_conplat_fw`）的填报规则。
   - 更新下载的 Excel/CSV 资产导入示例模版数据，新增迪普交换机与防火墙的示例行。

### 阶段三：后端平台规范化与 TextFSM 解析引擎联动
1. **修改 `backend/core/platform_utils.py`**：
   - 更新 `normalize_device_platform`，识别 `dptech_conplat` 与 `dptech_conplat_fw`。
   - 若厂商为迪普 (`dptech`) 且平台为空时，根据角色或类型自动映射到 `dptech_conplat_fw`（防火墙）或 `dptech_conplat`（交换机）。
2. **修改 `backend/api/assets.py`**：
   - 更新 `_platform_from_vendor` 内部推导逻辑，匹配 `dptech_conplat` / `dptech_conplat_fw`。
3. **修改 `backend/core/textfsm.py`**：
   - 在 `TEXTFSM_PLATFORM_MAP` 和 `_COMPATIBLE_PLATFORMS` 中将 `dptech_conplat` 与 `dptech_conplat_fw` 注册并映射至迪普 TextFSM 模板库。

## 5. 验证计划

- 运行 pytest 校验多厂商与迪普平台 TextFSM 模板及规范化测试：

- 运行前端代码与类型检查：
  `npm run lint`

### 5.2 手动功能验证
1. 打开资产管理新增/编辑资产弹窗 (`/assets/dashboard`)：
   - 厂商选择“迪普 (DPtech)”，检查平台下拉框是否正确展示 `DPTech Conplat (Switch)` 与 `DPTech Conplat FW (Firewall)` 选项。
   - 选择交换机或防火墙，验证能否正确保存并提交到数据库。
2. 验证模版下载与导入规范：
   - 点击“下载导入模板”，检查模板中关于迪普厂商及 `dptech_conplat` / `dptech_conplat_fw` 的填报说明。
   - 导入包含迪普交换机与防火墙的数据，验证解析入库后的厂商与平台字段是否完全一致。
