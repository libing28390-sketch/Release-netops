# 服务器远程桌面资产导入模板

## 任务目标

在资产导入模板中加入服务器 RDP/VNC 配置字段，并让导入流程把配置写入现有远程桌面配置表，使新导入服务器无需逐台打开资产编辑器补录配置。

## 现状与问题

- 资产导入模板当前只有“网络设备”“服务器”“管理入口”等工作表，没有 RDP/VNC 配置输入表。
- RDP/VNC 配置保存在 `asset_remote_desktop_profiles`，属于资产与协议的独立配置，不是 `physical_assets` 的普通字段。
- 现有 Excel 解析仅处理资产表和 SSH/NETCONF/HTTP/HTTPS 管理入口；即使模板出现 RDP/VNC 列，当前导入接口也不会保存它们。
- 远程桌面凭据通过凭据库 ID 绑定；模板不应收集明文密码。

## 影响范围

- `public/templates/asset_import_template.xlsx`：增加“远程桌面”工作表及 RDP/VNC 输入字段。
- `src/pages/AssetManagement/index.tsx`：同步浏览器兜底模板、说明和工作表解析流程。
- `src/pages/AssetManagement/importUtils.ts`：解析、校验远程桌面行并关联同一批次中的服务器资产。
- `backend/api/assets.py`：扩展导入契约，并在资产行事务中保存远程桌面配置及审计摘要。
- `docs/plans/` 与 `docs/walkthrough/`：维护配对的实施记录。

## 拟修改文件

除上述文件外，不改数据库 schema、远程桌面 API、Guacamole 连接逻辑或其他导入工作流。已有资产的重复行继续遵循导入时跳过、不更新的既有规则。

## 实施步骤

1. 按既有模板风格增加独立“远程桌面”工作表，一行代表一个资产的一种协议；同一服务器可分别填写 RDP 与 VNC。沿用其它工作表的“资产编号”“主机名”表头，标明必填字段，并提供与服务器示例资产关联的 RDP/VNC 示例行。
2. 暴露协议、启用状态、端口、RDP 域、RDP 安全模式、可选 RDP 证书 SHA-256 指纹、剪贴板开关和配置名称；导入时沿用资产凭据，不在远程桌面工作表重复填写凭据 ID。
3. 更新前端兜底模板和导入解析，校验资产关联键、协议、端口、RDP 安全模式、RDP 指纹格式及重复协议行；VNC 忽略 RDP 专属字段。
4. 后端在每条资产导入的同一数据库事务/保存点中复用 `save_asset_profile` 校验并保存 profile；失败时整条资产行按现有导入语义回滚。
5. 保持服务端动态 SNMP 凭据模板生成及已有 Excel 工作表、命名范围、下拉项不变。

## 验证计划

- 使用 Artifact Tool 检查并渲染原模板，再渲染新增工作表，核对字段、示例和布局。
- 导出后检查原模板工作表、命名范围及服务端 `openpyxl` 加载/更新 SNMP 下拉的兼容性。
- 静态检查前端和后端字段契约及差异。遵照当前任务范围，不运行自动化测试。

## 风险与回滚

- 资产工作表引用的凭据 ID 无效或角色不匹配时，对应资产行导入失败，不会保存半个资产或半个远程桌面配置。
- 旧模板仍可导入，远程桌面工作表为可选项。
- 若模板导出导致原有下拉、命名范围或格式丢失，恢复模板工作簿并改用可保留其原生功能的方式编辑；后端配置保存可通过回退该导入扩展撤销。
