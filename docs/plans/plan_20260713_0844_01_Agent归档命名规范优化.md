# Agent 归档命名规范优化计划

## 任务目标

优化 `.agents/AGENTS.md` 中 plans 与 walkthrough 的归档命名规则，为后续文件名增加时间戳和序号，使历史记录按文件名即可排序、查找和配对。

## 现状/问题

- 当前计划文件格式为 `plan_[任务名].md`，完成记录为 `walkthrough_[任务名].md`。
- 文件名缺少创建时间和序号，任务多了以后同名/近似任务容易混淆，无法直接按时间线查看。

## 影响范围

- `.agents/AGENTS.md`
- 后续新增的 `docs/plans/` 与 `docs/walkthrough/` 归档文件。

## 拟修改文件

- `.agents/AGENTS.md`
- `docs/plans/plan_20260713_0844_01_Agent归档命名规范优化.md`
- `docs/walkthrough/walkthrough_20260713_0844_01_Agent归档命名规范优化.md`

## 实施步骤

1. 将计划文件命名升级为 `plan_YYYYMMDD_HHMM_NN_任务名.md`。
2. 将完成记录命名升级为 `walkthrough_YYYYMMDD_HHMM_NN_任务名.md`。
3. 明确 `YYYYMMDD_HHMM` 使用当前工作区时区时间。
4. 明确 `NN` 为同一分钟内的两位序号，从 `01` 开始。
5. 保留同一任务 plan/walkthrough 使用相同时间戳、序号、任务名后缀的配对要求。

## 验证计划

- 检索 `.agents/AGENTS.md` 中新格式是否写入。
- 人工检查规则是否包含时间戳、序号、配对和旧文件兼容说明。

## 风险与回滚思路

- 风险：历史旧文件不会自动重命名，短期内目录中会同时存在新旧命名。
- 回滚：还原 `.agents/AGENTS.md` 中第 1 节命名规则即可。
