# 对齐 Grafana 仪表盘完整性测试并打通 CI 发布流水线实施计划

## 1. 任务背景与现状
- **问题根因**：在清理重复的 Grafana 预置文件时，`monitoring/grafana/dashboards/` 下旧版未带前缀的旧仪表盘（如 `network-device.json`、`network-wireless.json` 等）被删除，统一保留规范的 `nexora-*.json` 仪表盘。
- **CI 中断影响**：GitHub Actions 流水线中单元测试 `backend/tests/monitoring/test_domestic_and_wireless_monitoring.py::test_dashboards_suite_completeness` 因仍检测旧文件名而断言失败（`network-device.json missing`），导致 CI 中断，发布任务未执行，`libing28390-sketch/Release-netops` 仓库未能同步最新的代码与镜像构建，宿主机执行 `git pull` 仍停留在旧提交。

## 2. 拟修改范围与文件
- `backend/tests/monitoring/test_domestic_and_wireless_monitoring.py`：更新 `expected_files` 为全部现存的标准 `nexora-*.json` 仪表盘套件。

## 3. 实施步骤
1. 修改 `test_domestic_and_wireless_monitoring.py` 中的 `expected_files` 列表，包含：
   - `nexora-network-overview.json`
   - `nexora-network-device.json`
   - `nexora-network-wireless.json`
   - `nexora-network-interface.json`
   - `nexora-monitoring-health.json`
   - `nexora-network-outbound.json`
   - `nexora-linux-metrics.json`
   - `nexora-windows-metrics.json`
2. 本地执行 pytest 验证测试全部通过。
3. 按照规范创建修复记录 `docs/fixes/fix_20260920_1428_01_对齐Grafana仪表盘测试并打通CI发布.md` 与验证走查文档 `docs/walkthrough/walkthrough_20260920_1428_01_对齐Grafana仪表盘测试并打通CI发布.md`。
4. 提交 Git 并推送到 `main` 分支，触发 GitHub Actions 构建并自动发布到 `Release-netops`。

## 4. 验证计划
- 单元测试：`backend/tests/monitoring/test_domestic_and_wireless_monitoring.py` 5/5 全部 PASSED。
