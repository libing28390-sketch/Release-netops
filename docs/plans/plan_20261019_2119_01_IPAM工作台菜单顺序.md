# IPAM 工作台菜单顺序调整计划

## 任务目标

将“IP 定位”放到 IPAM 工作台子菜单首位，使侧栏顺序与进入 IPAM 后默认打开的功能一致。

## 现状与问题

`src/components/AppSidebar/navConfig.ts` 当前将“利用率”排在“IP 定位”之前，而 `/ipam` 默认重定向到 `/ipam/locate`，导致菜单首项与默认页面不一致。

## 影响范围

仅调整 IPAM 工作台侧栏子项的显示顺序，不改路由、默认页或其他菜单。

## 拟修改文件

- `src/components/AppSidebar/navConfig.ts`
- `docs/walkthrough/walkthrough_20261019_2119_01_IPAM工作台菜单顺序.md`

## 实施步骤

1. 将“IP 定位”调整到 IPAM 工作台子菜单第一项。
2. 保持“利用率”和“IP 对账”的现有路由、标签与功能不变。
3. 运行前端 TypeScript 检查及 diff 格式检查。

## 验证计划

- `npm run lint`
- `git diff --check`
- 检查菜单配置顺序以及 `/ipam` 默认路由仍指向 `/ipam/locate`。

## 风险与回滚思路

此变更仅涉及数组展示顺序，风险低。需要回滚时将 `navConfig.ts` 中三项恢复原顺序即可。
