# 登录后页面尺寸跳变整改计划

## 任务目标

减轻用户登录成功时页面闪动和轻微放大的视觉跳变。

## 现状与问题

登录页根容器使用 Tailwind `w-screen`，对应 `100vw`；登录后的主应用壳使用常规块级宽度填满父容器。视口宽度与容器可用宽度不一致时，认证状态切换可能造成轻微横向尺寸变化。

## 影响范围

仅调整登录页根容器的宽度约束，不改变登录请求、路由或认证状态行为。

## 拟修改文件

- `src/components/LoginScreen.tsx`
- 本计划及配套 walkthrough 文档

## 实施步骤

1. 将登录页根容器从视口宽度约束改为父容器宽度约束，使其与主应用壳一致。
2. 保留现有高度、内边距、背景与表单布局。
3. 审查差异，确认仅涉及登录页尺寸行为。

## 验证计划

- 静态检查修改位置与 JSX。
- 不运行测试或构建；登录布局变更按用户现场观察确认。

## 风险与回滚思路

风险限于极窄视口下的横向布局。若页面宽度异常，可将该容器类名还原为 `w-screen`。
