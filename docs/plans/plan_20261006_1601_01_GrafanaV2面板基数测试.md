# Grafana V2 面板基数测试修正计划

## 目标
修复全量 Actions 中因新增无线看板面板而失效的 V2 面板总数和统计卡数量断言，并推送测试修正到 `main`。

## 现状与根因
- Actions 全量测试 2,872 passed、1 skipped，失败 2 项。
- 新增 4 个无线面板后，面板总数为 257，统计卡为 92；V2 presentation 测试仍冻结在 253 和 90。
- 同一测试还冻结 row 数和非 row 数，需要一并核对更新，避免修完前两个断言后继续失败。

## 影响范围
- 预计修改：`backend/tests/monitoring/test_grafana_v2_presentation.py` 中面板总数、row、非 row 与统计卡基数。
- 按仓库规范新增本任务计划、walkthrough 和 Git fix 记录。
- 不改业务代码、dashboard 定义、CI workflow 或用户已有工作区文件。

## 实施与验证
1. 搜索所有与 Grafana 全局 panel/stat 基数有关的硬编码断言，确认遗漏项。
2. 更新断言至当前完整目录基数：257 panels、54 rows、203 non-row panels、92 stat panels。
3. 运行 V2 presentation 测试和 dashboard 查询目录测试，再运行 `git diff --check`。
4. 检查并提交仅包含测试与本任务记录的改动，推送至 `main`。

## 风险与回滚
该改动只更新已核对的测试期望值，不影响运行时面板或采集逻辑。若面板目录核对发现实际集合不匹配，应先定位生成器差异，不得仅放宽断言。回滚本次测试与记录提交即可。
