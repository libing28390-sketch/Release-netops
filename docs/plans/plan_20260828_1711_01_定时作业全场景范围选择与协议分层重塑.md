# 实施计划：定时作业全场景范围选择与协议分层重塑

## 1. 任务目标与背景

针对定时作业系统（`/automation/scheduled-jobs`）进行深度体验重塑与业务逻辑升级：
1. **解除 NSOT 事实库的强制范围锁定**：
   - 彻底解除 NSOT 只能选全部设备的限制，支持按站点（Site）、角色（Role）、标签（Tag）、复合资产（Composite）、IP 清单进行多数据中心分批错峰采集。
2. **CMDB 智能联动下拉（告别手输过滤）**：
   - 按站点（`site`）与按角色（`role`）筛选时，自动从 CMDB 数据中提取已建站点与角色，提供带数量统计的智能下拉选择，杜绝输入错字。
3. **IP 范围轻量化紧凑收敛**：
   - 优化 IP 输入与已选列表展现，避免长列表纵向撑爆页面。
4. **脚本执行模式的资产大类与协议通道分层**：
   - 结构化拆分为：目标资产类别（网络设备 / 服务器） $\rightarrow$ 协议驱动通道（SSH-CLI / SNMP / Shell） $\rightarrow$ 联动过滤脚本列表。
5. **右侧实时匹配看板与调度排版对齐**：
   - 精简设备列表占位，强化平台统计与在线状态，使整个弹窗比例协调，无需长篇滚动。
