# 远程桌面默认启用

状态：已完成并按用户授权部署到 `192.168.204.128`。

## 目标

移除 `NETOPS_REMOTE_DESKTOP_ENABLED` 功能开关，使 Nexora 的 RDP/VNC 入口和 Guacamole 网关随标准 Docker 部署默认启用。

## 现状与问题

- 后端通过 `NETOPS_REMOTE_DESKTOP_ENABLED` 拒绝远程桌面接口；目标服务器 `.env` 当前值为 `0`，导致工作台打开时批量读取 RDP/VNC 配置返回 503。
- Guacamole 与 guacd 使用 Compose `remote-desktop` profile，部署脚本按同一开关决定是否启动服务和生成 Guacamole JSON 密钥。
- 访问工作台会加载远程桌面配置，因此关闭开关会在普通页面上显示远程桌面错误。

## 影响范围

- 后端远程桌面 profile、会话创建及 WebSocket 接口。
- Docker Compose 服务默认启动行为、Docker 部署脚本和 `.env.example`。
- Docker 部署说明及现有远程桌面部署契约测试。
- 用户已授权将本次变更部署到 `192.168.204.128`；部署前备份服务器配置和本次会覆盖的文件。

- 对应 walkthrough 文档

## 实施步骤

1. 移除后端远程桌面功能开关检查，保留现有登录鉴权、资产范围、MFA、审计和 Guacamole 会话校验。
2. 移除 Compose 服务 profile 与环境开关引用，让 Guacamole/guacd 纳入标准服务；部署脚本始终管理这两个服务，并为未配置或无效的 Guacamole JSON 密钥生成独立随机值。
3. 删除 `.env.example` 中的开关并更新 Docker 部署说明和部署契约测试。
4. 检查最终差异并运行受影响的 Docker 部署契约验证。
5. 备份服务器 `.env`、Compose、部署脚本和后端路由；同步本次相关文件，初始化 Guacamole 密钥，重建后端并启动 Guacamole/guacd。
6. 如现有共享静态资源卷存在旧版 owner，先保存 owner 清单，再将卷 owner 规范到运行时 `netops` UID，避免非 root 启动脚本不能更新旧文件元数据。
7. 检查容器状态、密钥格式（不输出密钥）、旧开关清理和浏览器工作台页面。

## 验证计划

- 运行 `backend/tests/release/test_deploy_docker_remote_desktop_contract.py`，验证服务默认纳入部署、服务网络和录像卷边界、密钥生成及 `.env` 行尾兼容。
- 运行 `backend/tests/pam/test_remote_desktop_enablement.py`，验证历史 `.env` 中即使残留旧值 `0`，后端接口也不再拒绝 RDP/VNC 配置读取。
- 检查仓库有效部署配置不再引用 `NETOPS_REMOTE_DESKTOP_ENABLED` 或 `remote_desktop_is_enabled`。
- 手工审查后端仍保留认证、授权、MFA 和审计门控。
- 部署后检查 `nexora-netops`、`nexora-guacamole`、`nexora-guacd` 状态，并在浏览器确认工作台远程桌面配置读取不再返回 503。
- 检查共享前端资源卷没有 root 所有的静态文件，后端容器健康。

## 实施结果

- 聚焦测试：4 passed；部署脚本差异检查通过。
- 服务器备份：`/root/nexora-remote-desktop-default-20261016-1213/pre-change.tar.gz`。
- 服务器旧开关已从 `.env` 移除；Guacamole JSON 密钥初始化有效，密钥值未输出。
- Compose 配置验证通过；`nexora-netops` 与 `nexora-guacd` healthy，`nexora-guacamole` 正常运行。
- 容器内 `/api/health/live` 与 Guacamole `/guacamole/` 均返回 200；浏览器登录后的工作台正常显示资产列表，后端 profiles 接口返回 200。
- 修复共享静态资源卷中 root/UID 1000 混合 owner 引起的复制错误：先保存旧 owner 清单，再将该卷文件 owner 统一为 UID/GID 1000，未改文件内容。
- 未向具体设备创建 RDP/VNC 会话；没有提交或推送代码。

## 风险与回滚

- 默认启动 Guacamole/guacd 会增加两个容器、镜像下载与资源占用；是否能连接具体资产仍取决于资产侧 RDP/VNC 服务、网络放行和凭据配置。
- Guacamole JSON 密钥必须与两个服务配置保持一致；部署脚本应保留已有有效密钥，只为缺失或无效值生成密钥。
- 目标机的前端静态资源卷混有 root 和 UID 1000 文件；已记录原始 owner 路径清单，以便回滚此 metadata-only 修正。
- 用户已明确授权启动远程桌面网关。部署会启动新的远程接入通道，并在旧 `.env` 中删除该开关行。
- 如需回滚，从本次服务器备份恢复代码、Compose、部署脚本和 `.env`，随后按旧部署方式恢复 `NETOPS_REMOTE_DESKTOP_ENABLED=0` 并停止 Guacamole/guacd；保留数据库和录像卷，不执行 `docker compose down -v`。
