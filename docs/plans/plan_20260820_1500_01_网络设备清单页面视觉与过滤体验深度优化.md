# 网络设备清单页面视觉与过滤体验深度优化计划

## 1. 任务目标
对 `/assets/network-devices`（网络设备清单页面，即 `InventoryDevicesTab.tsx`）进行深度视觉与交互重构，使其与 `/assets/dashboard` 保持一致的高级 SaaS Bento Grid 设计语言，并统一 KPI 卡片与表格数据过滤的精准对齐。

## 2. 现状与存在问题
1. **视觉割裂**：顶部仅有简易的纯文字微标签（`QuickTag`），缺少与资产管理大盘统一的 4 联 Bento KPI 状态概览卡片；
2. **搜索与工具栏简陋**：筛选下拉框与搜索框缺乏现代容器化封装与重置状态指示；
3. **统计与过滤口径需对齐**：
   - 告警统计之前仅在当前分页 `inventoryRows` 内计算，当设备分页加载时计算不准确；
   - 过滤与快捷卡片点击联动缺少清晰的选中态高亮与动态条数提示；
4. **批量操作交互待升级**：批量操作栏缺少平滑的滑入指示与状态反馈。

## 3. 优化与实施步骤

### 3.1 顶部 4 联 Bento 状态卡片升级
- 将现有的简陋 `QuickTag` 升级为 4 联 Bento Grid 卡片：
  - **离线设备 (Offline)**：红色调微徽章 + 粗体 Mono 数值 + 进度条 + 点击过滤；
  - **告警设备 (Alerts / Warning)**：橙黄色调微徽章 + 粗体 Mono 数值 + 进度条 + 点击过滤；
  - **维护/待投产 (Maintenance / Staging)**：蓝色调微徽章 + 粗体 Mono 数值 + 进度条 + 点击过滤；
  - **运行正常 (Healthy / Online)**：翡翠绿微徽章 + 粗体 Mono 数值 + 进度条 + 点击过滤；
- 卡片支持点击高亮与再次点击取消过滤。

### 3.2 工具栏与高级筛选 Bento 容器化
- 搜索框与筛选选择器（平台、角色、状态、生命周期、标签）封装在圆角 Bento 卡片中；
- 增加当前筛选条件计数与高亮状态；
- 当有任何筛选（包括 KPI 卡片、搜索、下拉框、标签）激活时，显示一键 **「重置筛选」** 按钮；
- 工具栏右侧动态展示匹配的实际条数（`共 N 台设备`）。

### 3.3 批量操作栏微交互优化
- 选中多台设备时，工具栏下方优雅滑出批量操作胶囊栏（批量连通性检查、批量配置、批量打标签、清除选择）。

### 3.4 空态与分页优化
- 表格数据过滤为空时，展示图文提示并提供一键「重置所有筛选」按钮；
- 底部集成 `<Pagination />`，保持完整分页与条数切换支持。

## 4. 验证计划
1. 执行 `npm run build` 确保 TypeScript 检查与生产构建 0 错误；
2. 验证多厂商设备（Cisco, Huawei, H3C 等）筛选、状态卡片联动、标签过滤以及批量操作逻辑正常工作。
