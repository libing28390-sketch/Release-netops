### 2.2 核心架构结论：“双擎协同”才是行业最佳实践

- **“全部迁移到 Grafana”并不是最完美的，而且违背了软件工程的分层原则**：
  - **Grafana 的定位是【时序数据消费者与观测面 (Observability)】**：它的强项是千亿级时序指标的高性能渲染、多维 PromQL 聚合、灵活透视、时空下钻与沉浸式大屏；
  - **Nexora 的定位是【网络自动化控制面与运维工作台 (Control Plane & Operation Center)】**：它的核心价值是设备资产权威源 (CMDB)、SNMP 自动编译引擎、故障自愈 Playbook 编排、特权凭据安全治理 (PAM) 以及网络物理拓扑推导。
- **最完美的形态是“双擎协同、各司其职、无缝打通”**：
  1. 将所有**时序图表与指标监控**彻底托付给 Grafana + VictoriaMetrics；
  2. 将所有**配置管理、采集编排、自动化自愈与交互式拓扑**保留在 Nexora 控制面；
  3. 并在 Nexora 各模块中设立“📊 Grafana 专属大盘”一键直达入口，形成极致流畅的运维体验。

## 3. 表格导出功能原理与实现方案

### 3.1 Grafana 原生表格导出能力
- **Grafana 原生完全支持导出表格**：
  - 路径：任意面板右上角菜单 `...` -> `Inspect` -> `Data` -> 点击 `Download CSV`。
  - 支持“应用转换后的列名”与“带单位格式化”。
  - 但在内嵌 Kiosk 模式下，面板顶部的菜单栏默认被隐藏或极难寻找；且原生导出缺乏针对中文 Excel 的 UTF-8 BOM 优化。

### 3.2 Nexora 内置一键导出实现方案
1. **在 `GrafanaDashboardPage.tsx` 顶部工具栏增加“📥 导出表格数据 (Export Table)”操作按钮**。
2. **实现沉浸式导出模态框 (`ExportTableModal`)**：
   - 自动识别当前所处的大盘，列出该大盘支持导出的表格清单：
     - **04 接口流量**：《端口带宽利用率 Top 20》、《端口错误与丢弃排行 Top 20》
     - **05 采集健康**：《SNMP 慢采集耗时排行》、《探针健康与存活清单》
     - **06 互联网出口**：《出口链路实时流量表》、《WAN 链路丢包诊断表》
     - **01 网络总览**：《全网核心节点负荷概览表》
     - **07 服务器监控**：《主机 CPU Load 与内存使用排行》、《磁盘使用率告警表》
   - **一键下载标准 CSV**：
     - 前端封装导出生成器，注入 `\uFEFF` (UTF-8 BOM)，用 Windows Excel / WPS / Numbers 打开中文 100% 正常；
     - 自动剔除内部无用字段（`asset_id`、`job`、`__name__`），输出排版规范的字段（设备名称、管理 IP、端口号、指标数值、时间戳）；
   - **附带“Grafana 原生高级导出指引”**：
     - 为高级运维人员提供在 Grafana 独立全屏界面下导出任意自定义指标的快捷操作图文说明。
