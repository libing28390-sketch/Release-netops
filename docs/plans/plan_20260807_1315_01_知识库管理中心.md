# Plan: Nexora 专属企业网络知识库中心与 RAG 数据底座重构

## 任务目标
将知识库从原有的“提示词附属工具”全面提升重构为独立、规范的 **企业网络知识管理中心 + RAG 数据底座**。支持区分厂商资料、企业 SOP 与系统示例知识（Sample），建立完善的 Metadata 元数据标记、7 步索引状态可视化与独立导航。

---

## 核心重构要点

### 1. 知识来源类型解耦 (Knowledge Source Type)
在后端 `ai_knowledge_base` / `ai_document` 数据表及前端 Schema 中新增 `knowledge_source_type` 字段：
- `official_vendor`: 厂商官方资料 (Cisco, Huawei, H3C, ZTE, Maipu, Ruijie, DPtech)
- `internal_sop`: 企业内部 SOP
- `internal_standard`: 企业内部规范
- `case`: 历史故障案例
- `user_document`: 用户上传资料
- `sample`: 系统示例知识（明确标识为 Sample，提供一键“清空示例”按钮）
- `ai_generated`: AI 生成知识

### 2. 独立导航模块拆离 (Independent Navigation)
在 AI 中心主导航 (`AiCenterPage.tsx`) 中，将“知识库管理”彻底拆离为独立的一级 Tab：
`Provider 供应商` | `Model & 路由` | `Prompt 提示词` | `AI Copilot` | `Agent 注册表` | `知识库管理` | `AI 变更治理` | `Token 统计审计`

### 3. 知识管理中心三块结构 (3-Block Knowledge Hub Layout)
构建 `KnowledgeManagementTab.tsx` 组件：
- **头部数据大盘**：文档总数、Chunk 切片数、涵盖厂商数、Ready 索引数。
- **三大分类卡片**：
  1. 🏢 **厂商官方知识** (Cisco, Huawei, H3C, ZTE, Maipu, Ruijie, DPtech)
  2. 🔒 **企业私有知识** (网络 SOP, 变更规范, 故障案例, 巡检规范)
  3. 🧪 **系统示例知识 (Sample)** (带“一键清空示例”/“一键导入示例”按钮)
- **规范导入与 7 步索引可视化 (7-Step Indexing Pipeline)**：
  展现：`✓ 文件解析 → ✓ 文档结构识别 → ✓ Metadata 提取 → ✓ 智能分块 → ✓ Embedding → ✓ 向量索引 → ✓ 全文索引`
- **声明 Banner**：明确说明“知识库文档仅作为 RAG 检索依据，系统不会因为导入文档而修改模型本身”。
