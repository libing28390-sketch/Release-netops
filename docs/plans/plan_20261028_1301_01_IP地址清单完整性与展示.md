# IP 地址清单完整性与展示

- 目标：解释并修复站点网段数与地址展示的差异，清晰显示站点、设备报告网络和采集时间。
- 现状：只读数据库核对到 WH-DC-01 有15个已纳管前缀、0条手工IP地址，旧IPAM API只返回2条虚拟前缀网关。成功代次CMDB快照另有33条带掩码接口IP、聚合19个报告CIDR；它们均未落入现有15个前缀。
- 范围：IPAM地址服务与 IPAddressTab，使用成功代次的CMDB接口快照只读投影，不写共享 interfaces/ip_inventory、不修改监控或解析模板。
- 实施：source=interface_cli单独呈现；站点按资产/设备归属解析，观察CIDR和采集时间单独显示；快照缺VRF时保留为待匹配观察行，不自动创建或关联前缀；优化表格关键列和时间展示。
- 验证：PostgreSQL隔离IPAM测试、TypeScript源码检查、PostgreSQL-only策略扫描、前端聚焦测试及隔离构建；浏览器验收检查当前所连API是否已加载新代码。
- 风险与回滚：现有接口快照无VRF字段，不能安全挂入VRF前缀；观察行只读且来源明确。回滚本次IPAM API投影和页面改动即可。
