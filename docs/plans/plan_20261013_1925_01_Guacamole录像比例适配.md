# Guacamole RDP/VNC 录像画面比例适配

## 任务目标
改善 RDP 与 VNC 会话录像的回放画幅，保留桌面原始宽高比，并让旧 4:3 录像可按需放大查看。

## 问题与判断
用户截图中的 RDP 录像源为 1024×768（4:3），被等比完整放入宽屏播放器后两侧留黑边。既有 VNC 录像源和新 VNC 实测录像均为 1920×1080（16:9）。已录制文件保留原始尺寸，播放器提供完整适配与按宽度放大两种查看方式。

## 实施内容
1. RDP 初始分辨率明确请求 1920×1080，保留 resize-method=display-update。
2. RDP/VNC 客户端优先协商 16:9 显示尺寸，上限 1920×1080。
3. 录像播放器显示源宽高及比例，并提供完整适配和按播放器宽度放大；按宽度模式等比缩放，内容超高时可纵向滚动。
4. 运行定向测试与发布门禁，部署到 Ubuntu 后实测 RDP/VNC 录像源尺寸和缩放方式。

## 风险与回滚
新会话的实际画幅最终由目标服务端接受的尺寸决定。历史录像不会重新编码；旧 4:3 RDP 录像使用播放器按宽度放大模式查看时可能出现纵向滚动。回滚时撤销初始宽高请求和播放器调整后重新部署。
