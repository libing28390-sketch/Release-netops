# 登录粒子与切换体验

## 目标与现状
- 将现有登录背景的稀疏网络几何改为 Antigravity 风格的微粒子场，具有带惯性的鼠标跟随圆环、细微扰动和呼吸变化。
- 排查并消除登录后页面突然放大的体验问题。官网公开脚本确认采用 Three.js、自定义 shader 和平滑追随；本项目已有 Three.js。

## 影响范围与文件归属
- 主 Agent：`src/components/home/ThreeCyberNetwork.tsx`、`src/components/home/loginParticleRenderer.ts`，统一集成、记录和验证；Luna 负责独立 shader 初稿（`loginParticleShaders.ts`），最终模拟参数由主 Agent 对照官网修正。
- Luna frontend_worker：登录后布局与首页动画，边界为 `src/components/AppLayout.tsx`、`src/pages/HomePage.tsx`、`src/components/AppMainContent.tsx`；跨边界根因先报告。
- 保留现有用户内部协作材料及全部历史构建产物。认证、MFA、验证码、API 契约不变。

## 实施步骤
1. 读取当前登录页/布局和样式，检查浏览器基线及入口动画。
2. 使用现有 Three.js 以 GPU shader 绘制细小胶囊粒子；实现帧率无关的圆环追随、局部扰动和原位微动。用户反馈第一版屏幕空间密集粒子环与官网差别明显，撤换该实现，改为泊松采样 + 透视粒子场 + GPU 双缓冲状态模拟，按官网真实密度、粒径、蓝红黄色团、双环形状与缓动机制复核。
3. 修复登录后几何缩放的实际来源；不更改用户浏览器缩放。
4. 检查事件、动画帧及 GPU 资源清理，支持减少动画、后台暂停、窄屏和无 WebGL 降级。

## 验证计划
- 相同代码状态的公共检查仅运行一次：`npm run lint`、隔离输出目录的 Vite 生产构建；用户反馈导致实现替换后，对最终状态补做类型检查、受影响测试及构建。
- 浏览器：相同桌面视口下查看改前/改后粒子场、鼠标交互、表单操作；390×844 检查溢出；登录入口几何变化复核。
- 不将模拟会话组件验证写成真实认证成功。若缺少可用登录会话，记录验证边界。

## 风险与回滚
- 高 DPI 或低端设备 GPU 压力：限制像素比和粒子数，减少动画时静态绘制，页面隐藏暂停。
- Three.js 初始化失败时保留可用登录表单。回滚限定本次代码文件与记录，不覆盖现有用户修改。
