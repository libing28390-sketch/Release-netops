# Windows 资产远程桌面配置与访问表显示优化

## 目标
只在 Windows 服务器资产中展示 RDP/VNC 配置；在 Access Center 中显示 RDP/VNC 各自的目标端口，并把 RDP 的普通、管理员和服务管理操作排在同一行。

## 现状
- AssetModal 在所有编辑资产中渲染 RDP/VNC 配置区。
- Access Center RDP/VNC 分类的端口列复用 management_port，LEERBON 因而显示 22，而 RDP profile 配置端口为 3389。
- RDP 的服务管理按钮另起一行，造成操作列高度增加。

## 实施
- 以资产类型 server 且平台为 windows 或 windows_server 判断 Windows 机器；仅在该条件下显示配置区和新资产提示。
- RDP/VNC 分类显示各自已启用 profile 的端口，其他分类继续显示 management_port。
- RDP 普通、管理员和服务管理按钮使用单行不换行布局。
- 保留现有 profile 读写 API 与保存流程。
