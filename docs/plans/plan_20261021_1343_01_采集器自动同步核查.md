# 采集器自动同步核查

- 目标：只读核实 192.168.204.128 的自动编译、发布、配置加载与页面采集状态。
- 问题：docker logs 无自动同步匹配记录；另一台不可访问主机在手动发布后出现 53/204 正常、151 异常。
- 范围：本机 SSH、已打开浏览器、源代码与应用日志；另一台主机仅依据截图，不推断现场根因。
- 拟修改文件：仅此计划与对应 walkthrough，不修改业务、运行配置或设备。
- 步骤：查自动同步调用链、文件日志、数据库配置版本、vmagent targets、浏览器展示。
- 验证：比对版本、目标数量、错误与周期日志；不触发同步、重启或设备配置变更。
- 分工：主 Agent 负责现场与报告；此前 device_metrics_diagnosis 子 Agent 仅审查设备指标链代码，未改文件。
- 风险与回滚：只读检查，不需要部署回滚；禁止记录凭据。
- 后续核查：对比自动 UNCHANGED/APPLIED 跳过分支与手动发布，隔离模拟运行目录缺失、数据库仍为 APPLIED，以及发布失败的返回状态；不接触真实数据库。
