# 平台绑定权限与提示

## 目标与现状
明确首次绑定、原绑定保存、管理员替换/解绑的权限边界。后端已校验 Administrator force，但前端未接入角色，依赖列表快照判断并原样展示英文错误。

## 影响范围与拟修改文件
前端平台绑定组件、角色传递调用方、共用错误提示 helper，以及后端普通编辑清除绑定的绕过入口与相关测试；不变更数据库或放宽专用接口授权契约。
主 Agent 负责方案、共用 helper、集成验证及归档。frontend_worker 负责 BatchPlatformBindingModal、DeviceDetailModal、InventoryDevicesTab、AppMainContent、AppModals 及对应组件测试。互不覆盖文件。

## 实施步骤
1. 传入真实当前角色，未取得角色时不赋予管理员权限。
2. 非管理员阻止替换/解绑及版本不匹配覆盖；管理员保留显式确认和 force。
3. 不依赖缺失绑定快照自动提升权限，绑定冲突提示刷新数据后重试；无静默 force 重试。
4. 将已知后端绑定错误映射为清晰中英文提示，保留其他错误信息。
5. 验证角色、force、确认取消、首次绑定和过期数据冲突。

## 验证计划
相关 Vitest 组件/helper 测试；npm run lint；隔离输出目录生产构建。后端无改动不触发数据库或全量业务回归。

## 风险与回滚
后端仍为授权最终边界；force 不跳过厂商、平台及版本校验。真实部署与设备不操作。回滚本次前端改动即可。保留 dist/index.html 与现有用户变更。

## 排查后补充范围
普通设备更新的 _resolve_platform_binding(clear_existing=True) 可清除已有 Profile，绕过专用解绑授权。补充后端约束：已有绑定不能通过普通编辑替换或清除，必须走管理员 force 的专用接口；首次绑定与原绑定保存仍可用。backend_worker 仅负责 backend/api/devices.py 中 helper 与 backend/tests/platform_registry/test_device_platform_binding.py。后端验证使用受控测试 PostgreSQL，运行 PostgreSQL-only 扫描。

## 集成补充
主 Agent 另负责 DeviceFormModal.tsx/test 与 useDeviceFormActions.ts/test：普通编辑已有绑定只读，使用当前编辑设备的原绑定快照；结构化409提示不能渲染为 [object Object]。AppModals prop 接线仍由 frontend_worker 负责。
后端选定验证：test_device_platform_binding.py 与 test_platform_identification.py，创建 nexora_pytest_platform_binding_* 临时源库后使用共享 PostgreSQL fixture，执行完删除临时源库。

## 用户后续补充：SNMP失败与拓扑
同时排查拓扑 discovery 的 SNMP LLDP 路径、SSH CLI fallback、快照失败栅栏及 run 状态/UI 数据读取。调用链确认：常规 SNMP walk 异常会进入 SSH CLI fallback，失败设备不会删除最后一次有效 LLDP observation；但 `resolve_collector_credentials()` 在共享凭据解析时会先将 `snmp_port` 转为整数，拓扑 `_get_device()` 又在开始采集前调用该解析器，因此格式错误的 SNMP 端口会在 fallback 之前打断设备发现。`_collect_device_observations()` 也在 SNMP try 之外转换端口。

拓扑修复范围：调整 `backend/services/topology_service.py` 与 `backend/services/snmp_service.py`。不把坏端口静默改成 161；隔离 SNMP 配置解析错误，让仍可用的 SSH/CLI LLDP 路径继续工作。SNMP MIB walk 发生部分/全部错误时，不发布可能不完整的邻居快照；继续 CLI fallback。若 CLI fallback 也失败，保留设备级失败状态和旧拓扑证据，并给出不含凭据的诊断信息。拓扑代码由主 Agent 负责方案，backend_worker 仅负责 topology_service.py；主 Agent 集成 SNMP collector 错误处理。

验证范围：绑定后端的 PostgreSQL 回归（已完成）与前端组件回归（已完成）；TypeScript 检查、隔离目录生产构建；拓扑改动进行 Python 编译与 diff 检查，不连接真实设备或部署。拓扑回归测试因当前执行约束未新增或运行。
