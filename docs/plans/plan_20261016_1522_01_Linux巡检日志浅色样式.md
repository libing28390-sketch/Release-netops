# Linux 巡检日志浅色样式

## 任务目标

将自动化执行历史详情中的 Linux 巡检日志改为白色背景和黑色等宽文字，保持可读性；日志区域不显示健康评分。

## 现状与问题

- Playbook 设备输出面板固定使用深色终端配色，错误输出还会整块染成红色，Linux 巡检的长文本不易阅读。
- Linux 检查结果应展示原始日志和状态信息，不需要额外评分。
- 内置 Linux 脚本末尾仍打印“综合健康评级”，与用户希望去掉评分的要求不符。

## 影响范围

- 执行历史详情中 Linux 服务器的 Playbook 输出区域。
- 内置 `insp_linux_full` 脚本的汇总输出。
- 其他平台的终端样式与输出操作保持现状。

## 拟修改文件

- `src/pages/ExecutionSchedule/components/ExecutionDetail.tsx`
- `backend/database/seed.py`
- `docs/walkthrough/walkthrough_20261016_1522_01_Linux巡检日志浅色样式.md`

## 实施步骤

1. 根据当前设备的平台/资产类型识别 Linux 服务器输出。
2. 只为该输出区域应用浅色背景、黑色文字和适合长日志阅读的间距；保留折叠、复制、下载。
3. 从内置 Linux 巡检脚本汇总中删除综合健康评级，保留错误/警告数量与原始指标。
4. 确认日志展示中没有健康评分，并运行适用的前端静态检查与构建。

## 验证计划

- `git diff --check`
- `npm run lint`
- 使用隔离输出目录运行 Vite 构建。
- 本轮不运行测试、不操作设备、不部署。

## 风险与回滚思路

- 样式判断依赖设备 `platform` 或 `asset_type`；无法识别为 Linux 的设备沿用原主题。
- 如出现样式回归，只需回滚本组件内新增的浅色主题分支。
