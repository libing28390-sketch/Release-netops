# 拓扑身份冲突诊断与可视化

## 目标

在同一轮发现中汇总 SNMP 与 SSH/CLI LLDP 证据，并使用资产管理 IP 与设备本轮自身采到的接口 IP 确认对端身份，再统一生成链路。名称、端口等字段可跨协议补齐；冲突 IP 不静默覆盖，不通过主机名猜测地址归属。画布每台纳管资产只显示一个图标。

## 现状与问题

- 当前拓扑匹配器优先使用能命中的唯一管理 IP，但当 LLDP 给出的 IP 在 CMDB 中没有命中时，仍会回退到主机名/序列号；已有测试把这个回退写成预期。
- 当前浏览器页面的失败详情藏在节点无障碍/悬浮信息中，画布只显示 `!` 和未匹配节点 `?`。
- 现场 LLDP 邻居报告 `10.254.100.5`、`10.254.100.4` 等地址；对应 CMDB 资产管理地址是 `10.254.0.2`、`10.254.0.1`。当前存储的主机名也没有包含已确认的 S6850 名称映射，因此系统不能从现有 CMDB 身份字段证明它们是同一资产。
- SNMP LLDP 若只返回部分 MIB 数据但已有可用邻居，当前采集器会提前返回，不继续采集 SSH/CLI；最终拓扑因此可能使用残缺 IP/名称信息并保留旧快照。
- 资产导入只有在 SNMP 成功读取 `sysName` 后才同步设备主机名；SNMP 失败时保留导入时的主机名/管理 IP。当前 schema 没有独立设备别名字段。

## 影响范围

- 后端 SNMP/CLI 采集汇总、LLDP 邻居到 CMDB 资产的身份匹配及未匹配邻居投影。
- 完整/partial 采集快照的生命周期，避免一侧可完整采集时把 partial SNMP 结果直接当作最终图谱。
- 前端拓扑页的发现异常和未匹配邻居诊断摘要。
- 拓扑链路证据状态：双向确认、单侧证据、邻居不一致和过期，并与设备采集健康分开展示。
- 后端拓扑匹配回归测试、前端相关 lint/build 验证。

## 文件边界

- 主 Agent：`backend/services/topology_service.py`、`backend/api/topology.py`（仅链路证据字段）、`src/hooks/useTopology.ts`、`src/types.ts`、拓扑测试、本计划与 walkthrough。
- 前端子 Agent：仅 `src/components/TopologyGraph.tsx` 和 `src/components/TopologyInspectorPanel.tsx`，依据明确的链路证据状态字段更新样式和详情；不得更改设备图标、布局或身份匹配逻辑。

## 实施步骤

1. 收紧匹配规则：存在 LLDP 管理 IP 且没有唯一 CMDB IP 命中时，不允许主机名/序列号回退；缺失 LLDP IP 时保留既有名称/序列号识别。
2. SNMP 有邻居时也在 SSH 凭据可用的情况下采集 CLI LLDP；按本端端口、对端身份和规范化端口合并同一邻居，互补缺失字段，冲突 IP 保留为独立证据。
3. 至少一侧给出完整采集结果时，使用两侧汇总结果替换当前快照；两侧都 partial 时保留 partial 状态，不把不完整结果标成完整快照。
4. 在未匹配邻居投影中暴露稳定的匹配原因代码和方法；拓扑页默认只显示异常数量和归类原因，逐台详情折叠展示。未匹配 LLDP 邻居留在诊断清单中，不作为额外设备图标画入画布；画布设备数等于纳管资产数。
5. 为每条 LLDP 链路汇总双端观测方向及两端最近的完整采集快照：互相发现为双向确认；只有一侧证据且另一端快照未成功为单侧证据；两端快照均完整但互相未发现为邻居不一致；过期证据单独标为过期。未匹配邻居由于没有可验证的 CMDB 对端采集状态，保守标为单侧证据。
6. 画布只用两种线型表达 LLDP 证据：双向确认用实线，其余未达到双向确认的可绘制链路统一用虚线。不按链路类型增加额外线型，不在每条边上重复贴状态标签或绘制方向箭头；端口和协议细节在点击链路后查看。链路两端必须都是纳管设备，未匹配邻居不生成额外图标。
7. 覆盖 partial SNMP + SSH 成功、SSH 失败、跨协议字段补齐、IP 冲突保留及四种链路状态；运行 focused pytest、npm lint/build、PostgreSQL-only policy 与 diff 检查，并更新 walkthrough。

## 风险与回滚思路

- 双协议与本机接口 IP 采集增加只读请求；协议失败会隔离，不能把超时截断地址表或远端/gateway 字段作为本机归属。完整的独立 IP-MIB 表可提供对应地址事实。
- 本轮之外的接口地址不参与匹配；重复 IP、缺少本轮归属证据仍保持待确认。不会用历史邻居补出不存在的本轮关系。
- 回滚新增本机 IP 收集、最终匹配及缓存强制刷新接入即可；不回滚用户要求的 8 图标与双向实线/单向虚线规则。
- 现场仅重新执行已授权的拓扑发现，替换观测与派生链路；不改 CMDB 管理 IP、名称、凭据或设备配置，不硬编码设备映射。
