# 资产管理页面深度视觉与体验优化实施计划

## 1. 任务目标
深度重构与优化资产管理主页面（`/assets/dashboard` -> [src/pages/AssetManagement/index.tsx](file:///d:/nexora/nexora-private/src/pages/AssetManagement/index.tsx)）：
- 消除顶部 4 块大面积纯色高饱和刺眼卡片，重塑为现代 SaaS Bento 风格仪表盘；
- 重构表格顶部操作栏与筛选工具栏，胶囊化主操作按钮（新增资产、批量操作、展示列、导入导出）；
- 升级表格单元格渲染（状态微胶囊、Mono 字体排版、操作按钮组）；
- 在表格底部集成标准分页组件 [Pagination.tsx](file:///d:/nexora/nexora-private/src/components/Pagination.tsx)，支持多页码跳转与每页条数切换。

## 2. 现状与痛点
1. **顶部卡片过亮刺眼**：P1 严重故障、P2 重要问题、P3 需要关注、正常等 4 个卡片采用全屏大面积纯红/纯橙/纯黄/纯绿高饱和渐变，视觉压迫感重且信息层级不明显；
2. **工具栏控件粗糙**：按钮和输入框尺寸较小，部分控件样式未统一到系统 SaaS Bento 风格；
3. **表格缺少分页控件**：资产列表虽有服务端分页支持，但页面底部未渲染分页条，影响多页浏览体验。

## 3. 拟修改文件

## 4. 实施步骤
1. **顶部 4 联 Bento 状态卡片重构**：
   - 将实色大色块改为白底/深灰底 Bento 容器 + 细致的微状态灯/胶囊徽章；
   - 展现大号 Mono 指标数值与流体微进度指示；
   - 支持点击卡片进行多状态联动过滤与高亮激活框。
2. **操作工具栏与高级筛选重塑**：
   - 蓝色主操作胶囊（新增资产）、优雅批量操作栏、展示列下拉配置、导出/导入按钮组；
   - 搜索输入框、类型/状态/标签/高级筛选下拉框圆角优化。
3. **表格单元格与操作组优化**：
   - 表头与行排版优化、在线状态微胶囊、投产状态徽章、操作列图标美化。
4. **集成标准分页组件**：
   - 引入 [Pagination.tsx](file:///d:/nexora/nexora-private/src/components/Pagination.tsx) 并在表格底栏渲染。
5. **质量门禁与验证**：
   - 执行 `npm run build` 确保生产构建与类型检查通过。
