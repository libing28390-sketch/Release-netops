# 移除知识库管理页面左侧目录树实施计划

## 任务目标
优化知识库管理界面（`src/pages/ai/Knowledge/KnowledgeManagementTab.tsx`），移除左侧 25% 占位的遗留物理目录树，将文档列表、多维元数据过滤与管理表格扩展为 100% 全宽现代表格，提升文档可读性与操作体验。

## 现状与分析
1. **现状**：
   - 知识库页面目前采用两栏布局（`grid-cols-4`），左侧占用 1 列用于展示虚拟目录树（`01_product`, `02_commands` 等）；
   - 右侧仅有 3 列，导致核心文档表格在展示“文档标题、厂商、系列、分类、分块数、索引状态、操作”时产生挤压和换行；
2. **架构合理性**：
   - 在 Nexora Knowledge Engine V2 体系中，文档的分类、检索与防幻觉对账全部由文档本身的 **YAML Front Matter 元数据** 与顶部的 **【官方/企业知识分区】** 以及 **产品层级 Facet 过滤** 驱动；
   - 移除左侧物理目录树后，页面将全面转向基于元数据（Metadata-Driven）的现代资产/知识库管理模式。

## 拟修改文件
- `src/pages/ai/Knowledge/KnowledgeManagementTab.tsx`：
  - 移除左侧两栏布局中的目录树侧边栏；
  - 将文档管理区调整为全宽（`w-full`）；
  - 优化搜索提示词和数量统计文案；
  - 保留并凸显顶部的【官方/企业知识分区卡片】与【产品层级 Facet 过滤】；
  - 清理未使用的辅助组件和状态。

## 验证计划
1. 运行 `npm run lint` (`tsc --noEmit`) 确保类型与构建 100% 通过；
2. 运行 `npm run test:frontend` 验证前端单测套件；
3. 生成 walkthrough 文档。
