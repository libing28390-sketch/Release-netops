# Nexora 互联网出口监控 P2 故障关联与容量分析任务清单

> 文档状态：`implemented_pending_external_acceptance`  
> 编制日期：2026-08-02  
> 前置门禁：P1 综合验收 `WAN-P1-012` 必须为 `done`  
> 原则：第一阶段使用确定性规则和证据链，不引入不可解释的自动结论  
> 状态口径：`pending`、`in_progress`、`blocked`、`done`

## 1. P2 目标

P2 将链路指标、探测结果、告警事件和历史统计组合为可解释的诊断与容量证据，回答：

- 是出口设备/接口故障，还是外部单目标故障；
- 是带宽拥塞，还是 DNS、路径或目标服务异常；
- 主备链路是否发生切换；
- 当前流量是否显著偏离历史基线；
- 是否存在需要评估扩容的持续性证据；
- 管理人员能否在一个驾驶舱查看风险、趋势和建议。

## 3. 探测绑定任务

### 3.1 数据模型

- [ ] 建立 `wan_probe_bindings` 或等价模型。
- [ ] 字段包含链路、探测目标、路由模式、来源 IP、优先级和启用状态。
- [ ] 同一链路和探测目标组合唯一。
- [ ] 删除链路或探测目标时定义保留/级联策略。
- [ ] 绑定变更写 before/after 审计。
- [ ] 不在绑定表保存凭据或敏感网络配置。

### 3.2 API 与 UI

- [ ] 查看单链路已绑定探测目标。
- [ ] 新增、修改、删除和批量绑定。
- [ ] 校验探测目标存在且启用。
- [ ] 校验来源 IP 和路由模式。
- [ ] 绑定测试只执行授权的只读探测。
- [ ] UI 支持按站点、链路和探测类型筛选。
- [ ] Viewer 只读，Operator 可管理绑定。

### 3.3 证据边界

- [ ] 默认路由探测不能伪装成指定出口探测。
- [ ] 无法证明实际出口时，关联结果标记“证据不足”。
- [ ] 多出口环境记录来源 IP、出口公网 IP 或其他可验证路由证据。
- [ ] 探测失败和采集失败分别保留原始事实。

## 4. 关联事件与规则引擎

### 4.1 事件模型

- [ ] 建立关联事件、证据项和时间线模型。
- [ ] 关联事件包含 `root_cause_code`、`correlation_group`、严重级别、状态和置信度。
- [ ] 每个结论保存使用的规则版本。
- [ ] 每条证据保存来源类型、来源 ID、时间、指标和值。
- [ ] 事件支持触发、更新、恢复、确认和关闭。
- [ ] 重新计算不会重复创建同一活动关联事件。
- [ ] 原始告警和探测结果保持不可变引用。

### 4.2 出口设备/接口故障

- [ ] 多个绑定探测目标连续失败。
- [ ] 同时存在设备不可达、接口 Down 或采集失败证据。
- [ ] 区分设备故障、接口故障和证据不足。
- [ ] 设备不可达时抑制每接口重复根因事件。
- [ ] 接口恢复且探测恢复后关闭关联事件。
- [ ] 单个目标失败不得判定出口故障。

### 4.3 出口拥塞

- [ ] 多个绑定目标时延同时升高。
- [ ] 出口利用率持续高于85%。
- [ ] 丢弃持续增加作为增强证据。
- [ ] 使用同一时间窗口对齐探测、利用率和丢弃。
- [ ] 只有高利用率但无体验劣化时输出“高负载”，不直接判定拥塞。
- [ ] 只有探测变慢但利用率正常时保留路径/目标异常候选。

### 4.4 单目标和 DNS 异常

- [ ] 单个目标失败且其他目标正常时识别单目标异常。
- [ ] DNS 目标失败但 IP 连通性正常时识别 DNS 异常候选。
- [ ] HTTP 失败但 TCP 正常时保留应用层异常证据。
- [ ] 国内与国际目标分组分别计算影响范围。
- [ ] 目标恢复后关闭对应关联事件。

## 5. 主备切换识别

- [ ] 读取线路组成员和 primary/backup 角色。
- [ ] 主链路 Down 或不可用作为第一证据。
- [ ] 备用链路流量显著上升作为第二证据。
- [ ] 绑定探测出口变化作为可选增强证据。
- [ ] 只有备用链路有少量待机流量时不判定切换。
- [ ] 记录切换开始、确认、恢复和持续时间。
- [ ] 记录切换前后公网出口 IP（如可验证）。
- [ ] 多厂商接口名称使用共享 canonicalizer，不按显示名比较。
- [ ] Cisco、Huawei、H3C 至少各有一组主备测试夹具。

## 6. 历史基线和突变检测

### 6.1 基线模型

- [ ] 使用小时或日聚合建立基线，不扫描长期分钟原始表。
- [ ] 基线至少按链路、方向、星期和小时分桶。
- [ ] 保存样本数、中位数、P95、离散度和更新时间。
- [ ] 节假日和维护窗口样本可排除或单独标记。
- [ ] 采集失败和质量异常样本不参与基线。
- [ ] 新链路在样本不足时显示“基线未建立”。
- [ ] 基线任务幂等并支持指定范围重算。

### 6.2 突增和突降

- [ ] 当前值显著超过同时间段基线时识别突增。
- [ ] 工作时段显著低于基线时识别突降。
- [ ] 接口 Down、维护窗口和采集失败时抑制突降告警。
- [ ] 阈值同时考虑绝对差值和相对偏差。
- [ ] 保留当前值、基线值、偏差、窗口和样本数。
- [ ] 恢复到正常区间后关闭事件。
- [ ] 规则版本和参数变化写审计。

## 7. 容量证据和建议

### 7.1 指标

- [ ] 近7天、30天和90天的上/下行 P95。
- [ ] 月度峰值和最大利用率。
- [ ] 高于70%、85%、95%的累计时长。
- [ ] 链路可用率和采集成功率。
- [ ] 高负载期间的丢弃、错误和探测时延。
- [ ] 工作日/周末和业务时段差异。
- [ ] 运营商和线路组对比。

### 7.2 建议规则

- [ ] 月度 P95 利用率达到70%时输出关注证据。
- [ ] 高于85%的累计时长超过配置值时输出持续高负载证据。
- [ ] 高负载同时存在丢弃和时延升高时提高建议优先级。
- [ ] 采集成功率不足时不得给出确定性容量建议。
- [ ] 签约带宽近期变更时标记统计口径变化。
- [ ] 建议措辞使用“建议评估”，不得自动输出“必须扩容”。
- [ ] 每条建议显示数据范围、指标值、阈值和证据链接。
- [ ] 支持“观察、计划评估、已处理、不适用”处置状态。

## 8. 管理驾驶舱

### 8.1 总览

- [ ] 当前链路健康和服务可用性。
- [ ] 活动根因事件和影响范围。
- [ ] 高负载、拥塞、设备/接口故障分类。
- [ ] 近30天 P95 和容量风险。
- [ ] 主备切换次数和持续时间。
- [ ] 站点、运营商和线路组对比。
- [ ] 容量建议状态。

### 8.2 交互与大数据策略

- [ ] 首屏只加载聚合摘要。
- [ ] 站点、运营商、时间范围和风险级别由服务端筛选。
- [ ] 事件列表默认分页20。
- [ ] 详情、证据时间线和历史图表按需加载。
- [ ] 快速切换筛选时取消旧请求。
- [ ] 图表只加载用户选择的少量链路。
- [ ] 超过500条事件使用服务端搜索和分页。
- [ ] 导出使用异步任务，不在浏览器拼接全量数据。

### 8.3 行动入口

- [ ] 从根因事件跳转到链路详情。
- [ ] 从容量建议跳转到证据时间范围。
- [ ] 从单目标异常跳转到探测目标详情。
- [ ] 从主备切换跳转到线路组时间线。
- [ ] 处置、确认和备注均受权限控制并写审计。

## 9. 权限、审计和安全

- [ ] `wan.correlation.view` 查看关联结论。
- [ ] `wan.binding.manage` 管理探测绑定。
- [ ] `wan.baseline.manage` 管理基线参数。
- [ ] `wan.capacity.review` 处置容量建议。
- [ ] `wan.dashboard.export` 导出驾驶舱数据。
- [ ] 所有规则、阈值、绑定和处置操作记录 before/after。
- [ ] API 不返回 SNMP community、SSH 凭据、令牌或敏感路由配置。
- [ ] 关联引擎只消费授权范围内的站点和链路数据。

## 10. P2 测试矩阵

### 10.1 绑定和关联

- [ ] 绑定 CRUD、唯一约束和权限。
- [ ] 默认路由证据不足。
- [ ] 多目标失败 + 接口 Down → 出口接口故障。
- [ ] 多目标失败 + 设备不可达 → 出口设备故障。
- [ ] 多目标变慢 + 高利用率 + 丢弃 → 拥塞。
- [ ] 单目标失败 + 其他正常 → 单目标异常。
- [ ] DNS 失败 + IP 连通正常 → DNS 异常候选。
- [ ] 恢复、复发和事件去重。
- [ ] 时间窗口错位不得产生错误关联。

### 10.2 主备和基线

- [ ] 主链路 Down + 备用流量上升 → 切换。
- [ ] 备用待机少量流量不判定切换。
- [ ] 主链路恢复后的切回记录。
- [ ] 基线样本不足。
- [ ] 正常周期波动。
- [ ] 流量突增和突降。
- [ ] 维护窗口、接口 Down 和采集失败抑制突降。

### 10.3 容量和驾驶舱

- [ ] P95 高但采集成功率低时不给确定建议。
- [ ] 持续高负载但无体验劣化时只标记高负载。
- [ ] 高负载、丢弃和时延同时发生时提高建议级别。
- [ ] 签约带宽变更后的统计口径。
- [ ] 驾驶舱组合筛选、分页和按需加载。
- [ ] 导出权限、审计和异步任务。
- [ ] 中文、英文、空数据、证据不足和窄屏状态。
