# 实施计划：自动化快捷操作路由与导航规范化 (/automation/quick-ops)

## 1. 任务目标与背景

用户反馈 `http://192.168.56.1:5400/automation/tasks` 的 URL 与其实际业务定位不符（该页面核心功能是**设备快捷查询与自定义命令执行**，应为“快捷操作”）。

### 目标：
1. **URL 路由规范化**：将旧路由 `/automation/tasks` 正式重命名为 `/automation/quick-ops`；
2. **侧边栏与面包屑文案对齐**：侧边栏由“自动化任务”更新为“快捷操作” (Quick Operations)；
3. **页面标题对齐**：控制台顶部更新为“快捷操作控制台” (Quick Operations Console)；
4. **向后兼容与重定向**：在全局路由分发中，对访问旧路径 `/automation/tasks` 或 `/automation/execute` 的用户自动无缝重定向至 `/automation/quick-ops`，保证书签与现有链接不失效。
