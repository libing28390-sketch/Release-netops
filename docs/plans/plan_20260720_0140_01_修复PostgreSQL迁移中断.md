# 修复 PostgreSQL 迁移中断

## 任务目标

修复新部署 PostgreSQL 只执行到 migration 18，导致 topology aggregation 和 interface identity 字段未创建的问题。

## 根因

`m0019_site_timestamps` 对基线中的 TEXT 时间字段使用了 PostgreSQL timestamp 值进行 `COALESCE`，迁移 19 失败后，迁移框架停止执行后续迁移。

## 修改方案

- 保持站点时间字段的 TEXT 契约。
- PostgreSQL 回填时使用 `CURRENT_TIMESTAMP::text`。
- 不删除或重建已有数据，修复后由启动迁移自动从 19 继续执行到 23。

## 验证计划

- 迁移测试和 Python 编译检查。
- 新部署启动后确认 `schema_migrations` 包含 1～23。
- 手动执行拓扑发现，确认 `managed_links` 大于 0。

## 回滚

回退应用版本即可；本次只修正失败迁移 SQL，不删除数据或字段。
