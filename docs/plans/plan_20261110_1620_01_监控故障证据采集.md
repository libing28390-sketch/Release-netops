# 监控故障证据采集

- 目标：提供 Linux Docker 部署的一键只读诊断脚本，定位批量导入后监控数据中断。
- 现状：未访问故障服务器；当前仓库使用 vmagent/VictoriaMetrics，并可启用 LibreNMS。
- 范围与文件：仅新增 output/collect_netops_monitoring.py 和对应 walkthrough；保留现有所有改动。
- 步骤：采集主机资源、容器精简状态、限量日志、目标状态、存储查询、两次队列指标，输出私有目录和压缩包。
- 接口：Python 3 标准库调用 Docker CLI；只使用 inspect/ps/stats/logs 和容器内只读 GET/df/ls，不访问设备。
- 验证：Python 编译、CLI 帮助、模拟 Docker 完整运行、凭据脱敏与命令失败/超时验证。按 netops-quality-gate 选择脚本相关检查，不运行无关业务回归。
- 风险：自动脱敏无法覆盖任意日志格式，输出仍包含内部地址；回传前复核。依赖缺失或服务不可用记录错误继续；不采集环境变量、完整配置和数据库内容。
- 回滚：删除本次新增脚本即可，无生产状态修改。采集结果由用户自行保留或删除。
