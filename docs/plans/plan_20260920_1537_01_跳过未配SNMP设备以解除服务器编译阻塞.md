# 跳过未配 SNMP 凭证设备以解除监控编译阻塞实施计划

## 1. 任务背景与现状
- **问题根因**：
  在宿主机执行 `sync_all_monitoring_collectors()` 时报错：
  `services.monitoring_compiler.CompileError: AUTH_NOT_CONFIGURED: asset=asset-5c788264d2fc`。
  因为 CMDB 中存在未配置 SNMP 凭证的设备（或服务器被当成网络设备混入 SNMP 列表），`build_assignments` 对其校验失败直接抛出异常中断了整个编译事务。
- **级联影响**：
  由于 SNMP 编译阶段异常退出，后续的服务器 targets 生成（`render_server_targets`）以及发布操作（`publish_collector`）全部被腰斩，导致 `linux_targets.yml` 一直处于初始空列表 `[]`，vmagent 无法抓取 Linux 服务器。

## 2. 拟修改范围与文件
- `backend/api/monitoring_v1.py`：在 `_load_compile_inputs` 中进行过滤：
  1. 排除服务器角色（`role='server'`），服务器专由 `server_sql` 处理；
  2. 对网络设备，若未绑定 SNMP 凭证且无法解析 community，则跳过其进入 SNMP 采集编译列表并记录日志，避免阻塞整体编译与服务器 targets 的发布。

## 3. 实施步骤
1. 修改 `_load_compile_inputs`，过滤未配置 SNMP 的设备与服务器。
2. 运行本地自动化测试验证。
3. 编写走查文档与修复记录，提交并推送到远端 `main` 分支。

## 4. 验证计划
- 运行 `pytest backend/tests/monitoring/test_monitoring_v1_compiler.py` 和 `test_domestic_and_wireless_monitoring.py` 确保测试全部通过。
