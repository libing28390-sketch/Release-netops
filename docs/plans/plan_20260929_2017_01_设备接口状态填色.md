# 设备接口状态填色

## 任务目标

将 `02 网络设备详情` 的“设备端口实时状态清单”运行状态单元格改为状态色背景：Up 为绿色，down 为红色。

## 现状 / 问题

当前值映射已把 Up/down 映射为绿色/红色，但表格使用 `color-text`，只给文字着色，没有按用户截图填充单元格背景。

## 影响范围

只调整设备详情看板的状态列显示模式，不修改 PromQL、状态映射和接口状态采集逻辑；保留本工作区已有的筛选器与布局改动。

## 拟修改文件

- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-device.json`（生成器输出）
- 对应 `docs/walkthrough/` 完成记录

## 实施步骤

1. 将设备端口状态表的映射单元格模式设为 `color-background`。
2. 运行看板生成器并审查全部输出差异，确认不改动其他 dashboard。
3. 编译生成器、解析全部看板 JSON、核对 Up/down 映射和背景填充配置，并运行 `git diff --check`。

## 验证计划

- `python -m py_compile monitoring/grafana/generate_dashboards.py`
- 运行生成器；解析全部 dashboard JSON 并检查目标面板背景模式与状态映射。
- `git diff --check`

## 风险与回滚思路

此变更只影响显示样式，状态值仍按 IF-MIB `ifOperStatus` 映射。若背景显示不符合目标 Grafana 版本，可把该表格的 `mapped_cell_mode` 恢复为 `color-text` 并重新生成 JSON。
