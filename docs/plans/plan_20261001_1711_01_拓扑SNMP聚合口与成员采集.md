# 拓扑 SNMP 聚合口与成员采集

## 任务目标

恢复 SNMP 优先发现中的聚合口名称和成员端口信息，保留 8 台纳管设备的 8 个图标。完整 SNMP LLDP 成功时不执行任何 CLI；双向/单侧 LLDP 证据继续分别使用实线/虚线。

## 现状与证据

- 上轮 SNMP 成功提前返回后，发现入口跳过了仅支持 CLI 的 `_sync_aggregation_inventory`；当前站点接口表没有父子聚合关系，画布显示 17 条物理链路。
- 只读 SNMP 验证：标准 `dot3adAggPortAttachedAggID` 表将 S6850-1 的 ifIndex 50–53 关联到 5130（Bridge-Aggregation12），S6850-3 的 ifIndex 2–5 关联到 5129（Route-Aggregation34）。ifType=161，ifStack 在两台设备上为空。
- 不通过并行链路数量猜测聚合关系，必须使用设备实际报告的接口和成员关联。

## 影响范围和拟修改文件

- 新建 `backend/services/topology_snmp_aggregation_service.py`：有界、只读 SNMP 聚合快照。
- 新建 `backend/services/topology_aggregation_inventory_service.py`：成功快照的原子持久化；`backend/services/topology_service.py` 负责发现入口集成、成员方向及元数据。
- 新建针对 SNMP 聚合采集/持久化/折叠的测试；按需更新受影响的 discovery mock。
- `src/components/TopologyGraph.tsx`：成员列表加入现有链路 tooltip，直接悬停聚合线即可查看，避免端口标签被隐藏时找不到详情。
- 主 Agent 同步调整图和 TopologyPage 的计数文案为“链路”，避免把折叠后的 11 条画布链路误称为 11 个物理连接。

## 分工与共享文件

- 主 Agent：方案、真实只读证据、topology_service.py 集成及持久化、综合验证、归档。
- backend_worker aggregation_inventory_trace：先追踪现有父子接口与折叠契约，随后独占新 SNMP collector 及其采集单测；不修改共享 service。
- frontend_worker aggregation_ui_trace：核对 API 到画布及成员详情，仅修改 TopologyGraph.tsx 的现有 tooltip；不运行公共构建，不改其它文件。
- 所有执行者保留现有未提交变更，不继续创建子 Agent。

## 实施步骤

1. 确认两端实际 SNMP 聚合表、接口名、状态及索引；明确完整、空、缺失和失败快照语义。
2. 采集标准 LAG 成员关联，必要时使用明确的 IF-MIB 聚合堆叠关系；保留原始名称，使用统一 canonicalizer 匹配接口。
3. 仅完整有效快照更新父子关系；截断、超时、无法解析或未支持的表不能清空库存。有效快照移除已不属于聚合的旧成员。
4. 在 SNMP-only 路径集成聚合同步；CLI 回退路径保留原有能力。辅助聚合失败不损坏 LLDP，也不暗中登录 SSH。
5. 两端成员关联齐全时折叠为聚合链路，API 保留成员端口、带宽及确认信息。

## 验证计划

- Collector mock：真实 H3C 样本、Cisco/Huawei 名称、零关联、空/不支持、错误、截断、孤立索引和冲突证据。
- 隔离 PostgreSQL：父子写入、canonical alias 幂等性、成员删除、失败快照不写入、generation 竞争与现有 LLDP 折叠。
- Discovery：完整 SNMP 不执行 CLI、SNMP LAG 数据写入及成员详情；现有 SNMP/CLI 回退测试。
- 本机设备只读采集验证两组各 4 个成员；若实际 discovery 验证，核对 8 节点、9 物理链路+2 聚合链路、17 个物理连接及 0 CLI。
- Python 编译、PostgreSQL-only policy scanner、git diff --check、npm run lint 及聚合相关前端测试。tooltip 文案拼接不影响打包/路由，不重复生产构建。

## 风险与回滚

- 不同 SNMP agent 未必支持相同 LAG 表：明确报告 unavailable，保留 LLDP 物理链路而不猜测父子关系。
- 仅成功、完整、有来源证据的快照可替换库存；使用事务及当前设备/generation 校验避免旧任务覆盖新任务。
- 无迁移、不变更设备配置；可回退本次 collector 和集成，现有资产、LLDP 及之前用户变更保留。
