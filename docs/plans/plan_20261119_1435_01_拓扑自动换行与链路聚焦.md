# 拓扑自动换行与链路聚焦

50 台设备的拓扑在每行上限为 60 时变得过宽，适应全图会把设备名缩得太小。选中设备时多条上联难以追踪。

- `src/utils/topologyRoleLayout.ts` 按视口宽度、设备名称和每行上限计算换行，依据实际物理上联组合排列接入设备，保留无线分区。由布局执行者负责并补充回归测试。
- `src/components/TopologyGraph.tsx` 接入视口布局，保留手工坐标和上限，首次加载旧布局时重新计算视野。明确适应全图与 100% 缩放，选中设备后突出关联链路。主执行者负责。
- 使用布局和导出测试、类型检查，以及包含 50 台设备和双上联的浏览器样本验证。
- 如需回滚，撤回布局与渲染改动。保留既有存储键和手工坐标。

用户补充希望在正式站点页面找到 Demo 的「上联分组」。新增 `src/components/TopologyUplinkGroups.tsx`，由分组视图执行者负责，使用正式站点的设备和链路。主执行者在 `src/pages/TopologyPage.tsx` 接入切换、选中状态和全屏控制，并验证两种视图。
