# 巡检阈值规则详情弹窗

## 任务目标

巡检指标主表保留精简的关键列；通过操作列的眼睛按钮打开详情弹窗，查看指标规则、采集信息与指令。保留现有编辑能力和每页 10 条的默认分页。

## 现状与问题

- 告警规则和严重规则内容较长，直接放在表格列中会挤占空间。
- 指标详情需要一个明确入口，用户不应依赖点击整行来发现详情。
- 详情查看、阈值修改、脚本/OID 信息需要各自清楚，同时不丢失既有编辑功能。

## 影响范围

- 修改 `src/pages/InspectionItemsTab.tsx`：操作列增加详情入口，使用项目现有弹窗壳展示完整信息。
- 保留主表默认可见列、筛选、导出、接口与分页契约；默认每页仍为 10 条。
- 详情支持复制 OID/采集指令，并能从详情进入现有编辑状态。
- 保留数值阈值与状态期望值编辑、大小写分类映射和 CLI 选项显示。

## 实施步骤

1. 通过眼睛按钮打开详情弹窗；取消整行点击展开详情的交互。
2. 在弹窗集中展示基础属性、告警/严重告警规则、说明、OID/采集指令、更新时间和指标 ID。
3. 支持复制 OID/采集指令、Esc/遮罩关闭、键盘焦点限制与关闭后焦点返回。
4. 详情中的“编辑指标”继续进入现有行编辑流程；取消/保存后收起编辑详情。
5. 运行 TypeScript 检查、隔离 Vite 生产构建和差异检查；尝试页面交互验证并如实记录运行环境边界。

## 验证计划

- 眼睛按钮可打开详情；规则、脚本/OID 和复制操作可用；Esc 与关闭按钮可关闭。
- 从弹窗进入编辑后，基础字段和阈值控件仍可编辑；取消不保存。
- `npm run lint`
- 在临时目录运行 Vite production build。
- `git diff --check`。

## 风险与回滚

- 弹窗只改变详情呈现入口，不改变巡检规则的计算和服务端数据契约。
- 若键盘焦点或弹窗内容布局出现问题，可恢复行详情入口，保留阈值规则本身。
