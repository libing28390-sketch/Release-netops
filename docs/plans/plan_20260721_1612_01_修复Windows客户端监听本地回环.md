# 修复Windows客户端监听本地回环 实施计划

为了解决 Windows 客户端打包/安装运行后，FastAPI 后端仅监听 `127.0.0.1` 导致外部或其他网卡 IP 无法访问的问题，本方案拟将启动绑定地址调整为 `0.0.0.0`。

## 问题描述与根因分析

* **现象**：在 Windows 客户端运行期间，FastAPI 服务正常启动在端口 `5010`，但该服务只允许本地回环 `127.0.0.1` 访问。从局域网内其他设备访问该服务器的 IP 地址（如 `192.168.42.1:5010`）时会被拒绝连接。
* **根因**：在 [desktop_tray.py](file:///d:/nexora/nexora-private/desktop/desktop_tray.py) 中，由 PySide6 Agent 启动后端 FastAPI 子进程时，其传递给 `uvicorn` 的命令行参数为 `--host 127.0.0.1`，这限制了服务仅能绑定在本地回环网卡上。

## 拟修改文件

* [desktop_tray.py](file:///d:/nexora/nexora-private/desktop/desktop_tray.py)
  - 将启动子进程的 `--host` 参数从 `127.0.0.1` 修改为 `0.0.0.0`，从而绑定在本机的所有 IPv4 地址上。

## 验证计划

1. 检查代码的格式与编译是否无误。
2. 启动 Windows 客户端后，验证其后端除了能通过 `127.0.0.1:5010` 访问外，还可以使用本机其他的物理 IP 地址（如 `192.168.42.1:5010`）访问，证明多网卡监听已生效。
