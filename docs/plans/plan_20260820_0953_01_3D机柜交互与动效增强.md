# 3D 机柜交互与动效增强实施计划

## 任务目标
为 3D 孪生机柜引入生产力操作闭环与真实机房动态视觉效果，实现：
1. **双击设备平滑对焦特写（Double-Click to Focus）**
2. **设备状态指示灯呼吸与闪烁动效（Live LED Breathing/Blinking）**
3. **3D 空 U 位悬停光框与点击直接上架（3D Slot Interactivity & Install）**
4. **机柜内顶置冷光探照灯带与立体内饰（Interior Top Lighting Strip）**

## 现状与需求分析
- **现状**：
  - 3D 视图下只能看不能做空间上架，安装设备需要切回 2D 或手动在输入框计算 U 位；
  - 3D 设备模型指示灯为静态固定发光值，缺乏真实机房运转感；
  - 点击设备只弹出右侧抽屉，视角不发生变化，查看 1U/2U 设备的端口和细节需要手动多次缩放和平移；
  - 机柜内部顶部缺少结构光，暗部层次仍可进一步丰富。

## 拟修改文件清单
1. `src/pages/RackManagement/Rack3D/CameraController.tsx`：
   - 支持聚焦指定设备（Focus on Device Target）及双击平滑推进特写视角。
2. `src/pages/RackManagement/Rack3D/models/SwitchFaceplate.tsx` 与 `RackDeviceItem.tsx`：
   - 增加基于 `useFrame` 的 GPU 着色指示灯呼吸（Healthy 心跳呼吸）、快闪（Warning 警示闪烁）、频闪（Critical 故障告警）动效；
   - 支持双击设备事件触发视角聚焦。
3. `src/pages/RackManagement/Rack3D/RackFrame.tsx`：
   - 增加机柜内顶部冰蓝冷光 LED 泛光灯带模型与下探点光源；
   - 增加 3D 空 U 位悬停高亮指示框（Slot Hover Box）及点击事件。
4. `src/pages/RackManagement/Rack3D/RackScene.tsx`：
   - 接收并连接空 U 位点击、设备双击聚焦、对焦重置状态。
5. `src/pages/RackManagement/Rack3D/index.tsx`：
   - 工具栏增加“特写设备”提示与“重置全景”快捷联动，对接 `onInstallAtU` 属性。
6. `src/pages/RackManagement/index.tsx`：
   - 将 `openInstallDeviceAtU` 传递至 3D 容器，实现 3D 点击空位一键弹出安装弹窗。

## 实施步骤
1. **阶段 1：3D 内部冷光照明带与空 U 位悬停交互**
   - 在 `RackFrame.tsx` 增加顶部内嵌 LED 发光条与射灯；
   - 在未占用 U 位生成轻量交互感应区域，鼠标悬停时展示虚影高亮框与 U 位提示，点击触发 `onEmptySlotClick(u)`。
2. **阶段 2：设备指示灯动态呼吸与闪烁**
   - 在 `SwitchFaceplate.tsx` 及 `RackDeviceItem.tsx` 中使用 `useFrame` 对 PWR/SYS LED 发光强度应用正弦/脉冲动效。
3. **阶段 3：双击平滑推进特写视角**
   - 在 `CameraController.tsx` 中增加设备聚焦状态；
   - 在 `RackDeviceItem.tsx` 绑定 `onDoubleClick`，平滑推进到距设备 7 单位的最佳特写观察点。
4. **阶段 4：前后端与页面联动验证**
   - 确保 3D 点击空 U 位与 2D 点击空 U 位统一唤起 `openInstallDeviceAtU`；
   - 运行 `npm run lint` 与 `npm run build` 进行代码质量与打包验证。
