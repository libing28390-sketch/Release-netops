# 登录失败友好中文提示与锁定预警找回引导实施计划

## 任务目标
优化平台首页（`http://192.168.56.1:5400/`）登录认证失败与账号安全防护体验：
1. **中文错误提示**：去除原本的英文错误提示（如 `Invalid credentials`），统一返回友好中文提示；
2. **连续失败 3 次锁定预警**：连续输错 3 次及以上时，明确提示“连续失败超过 10 次将锁定账号（当前已失败 X 次，剩余 Y 次）”；
3. **锁定状态提示**：超过 10 次被锁定后，提示锁定倒计时及联系管理员/重置方式；
4. **找回密码全链路引导**：在错误提示内直连【找回密码】弹窗，并在找回密码弹窗中提供多渠道（通知渠道、MFA、管理员重置）的完整中文指引。

---

## 拟修改文件
1. `backend/api/users.py`：后端登录失败次数阈值规范化为 10 次，返回结构化中文提示（含失败次数、剩余次数、锁定秒数）。
2. `src/hooks/useAuth.ts`：前端登录异常响应处理与英文兜底本地化。
3. `src/components/LoginScreen.tsx`：登录错误提示框 UI 增强（支持失败次数预警、锁定高亮以及一键唤起找回密码弹窗）。
4. `src/components/ForgotPasswordModal.tsx` & `src/i18n.tsx`：找回密码说明与多方式重置引导完善。

---

## 实施步骤
1. 修改 `backend/api/users.py`：
   - 将 `_MAX_LOGIN_ATTEMPTS` 设为 10；
   - 登录失败时，若失败次数 < 3，返回“用户名或密码错误，请重新输入”；
   - 若 3 <= 失败次数 < 10，返回详细预警提示：“用户名或密码错误。连续失败超过 10 次将锁定账号（当前已失败 X 次，剩余 Y 次）。如忘记密码请点击【找回密码】或联系管理员”；
   - 若已达 10 次被锁定，返回 HTTP 429 并提示：“密码错误次数过多，账号已被锁定。请在 Z 秒后再试，或联系系统管理员重置密码”。
2. 修改 `src/hooks/useAuth.ts`：
   - 解析后端返回的结构化 `detail`，确保全中文呈现。
3. 修改 `src/components/LoginScreen.tsx`：
   - 优化错误提示区域，增加直接点击唤起 `ForgotPasswordModal` 的快捷交互。
4. 构建与验证：
   - 运行 `npm run build` 验证前端；
   - 模拟多次密码错误，验证 1 次错误、3 次错误、10 次锁定的提示与找回密码弹窗交互。
