# 修复 CMDB 凭据导入 Excel 模板标题行纹理网格异常

## 1. 任务目标
修复 `http://192.168.56.1:5400/cmdb/credentials` 页面中“模板下载”导出的 `.xlsx` 文件在 Excel 中打开时，表头行（A1:F1）出现网格状点状/纹理遮罩导致文字无法看清的问题。

## 2. 现状与根因分析
- **问题现象**：用户在下载凭据导入模板后，用 Microsoft Excel 打开时，表头（凭据名称、类型、用户名等）填充背景显示为网格密集的灰色/黑色点阵（dither pattern），白色文字被黑点网格覆盖极难识别。
- **技术根因**：
  1. `backend/api/credentials.py` 原先采用手工拼接底层 Zip + OpenXML XML 字符串的方式构建 Excel，在定义样式表 (`styles.xml`) 时与 Microsoft Excel 内部样式映射逻辑存在兼容性偏差。
  2. 后端开发服务在 PID 11212 驻留运行，重载时复用了旧服务，未及时加载修改后的 Python 代码。

## 3. 拟修改文件
1. `backend/api/credentials.py` [MODIFY]
   - 重构 `_build_credential_import_template()`，全面采用 Python 标准 Excel 库 `openpyxl` 进行表头填充（`FF007D9D` 纯色）、加粗白色字体（`FFFFFFFF`）、冻结首行 (`freeze_panes="A2"`) 和下拉校验（DataValidation）构建。
2. `backend/tests/configuration/test_credential_import_template.py` [MODIFY]
   - 使用 `openpyxl` 校验导出的 Excel 工作薄 Sheet 页、表头名称、背景填充类型 (`solid`)、字体颜色和冻结窗口属性。

## 4. 实施步骤
1. 将 `backend/api/credentials.py` 中模板生成逻辑重构为 `openpyxl` 方式。
2. 终止后台驻留的旧服务进程，确保前端访问拉取最新的 openpyxl 模板。
3. 运行 `pytest backend/tests/configuration/test_credential_import_template.py` 验证测试通过。
4. 更新 `docs/walkthrough/walkthrough_20260806_2214_01_修复凭据导入模板Excel样式.md`。

## 5. 风险与回滚
- **风险**：低。openpyxl 属于标准已安装依赖，导出的工作薄在 Microsoft Excel / WPS / LibreOffice 中具备最高兼容性。
- **回滚思路**：可直接还原 `credentials.py` 和测试文件。
