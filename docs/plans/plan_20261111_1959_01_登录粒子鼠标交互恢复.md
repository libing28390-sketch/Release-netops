# 登录页粒子鼠标交互恢复计划

## 目标

恢复登录页背景粒子随鼠标移动的动态效果，并保留系统减少动态效果偏好下的行为。

## 现状与问题

登录页的粒子渲染器仅在支持 `EXT_color_buffer_float` 时持续启动模拟动画。不支持该扩展时，旧实现只渲染静态粒子。补上回退动画后，鼠标移入账号/密码框仍会让粒子环落在登录卡片下面，白色卡片和输入框遮住了可见变化。

## 影响范围

只调整登录页卡片标记与粒子指针映射。保留浮点颜色缓冲设备上的 GPU 模拟路径、页面隐藏与 WebGL 上下文丢失处理；系统减少动态效果偏好仍允许鼠标指向时的显式交互。

## 拟修改文件

- `src/components/home/loginParticleRenderer.ts`
- `src/components/home/loginParticleShaders.ts`
- `src/components/LoginScreen.tsx`

## 实施步骤

1. 为缺少浮点颜色缓冲扩展的浏览器增加顶点着色器回退动画，用鼠标驱动的环形中心计算粒子位移和亮度。
2. 不再因缺少扩展而停掉动画帧；减少动态效果偏好下仍只在鼠标进入页面时启动回退动画。
3. 标记登录卡片；指针位于卡片内时，将粒子响应映射到最近的可视卡片外沿，避免效果被卡片和输入框遮挡。
4. 鼠标离开或浏览器失焦时，保持当前减少动态效果策略并清理动画帧。

## 验证计划

1. 运行 `npm run lint` 与 `npm run build`。
2. 在本地未登录页面的背景、用户名、密码及浏览器自动填充浮层间移动鼠标，确认粒子响应始终可见；静止指针后检查环境动画；检查控制台无着色器报错。
3. 检查工作区差异，确认只改动登录粒子文件与本任务计划、走查文档。

## 风险与回滚

顶点着色器回退效果会与浮点模拟路径略有差异。若出现着色器编译错误或视觉异常，可回滚两个粒子渲染文件；主 GPU 模拟路径与减少动态效果偏好逻辑应保持可用。
