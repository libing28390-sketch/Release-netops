# S3 连通提示

## 任务目标

说明 `Environment` 存储项的用途，并调整对象存储测试成功提示，准确描述当前检查范围。

## 现状与问题

- 对象存储页同时显示数据库存储配置和由 `.env` 派生的 `Environment` 配置。
- S3 健康检查只执行 Bucket 列表查询，当前成功文案容易被理解为已经验证真实对象的写入和读取。

## 影响范围

- 对象存储管理页测试连接成功提示的中英文文案。
- `Environment` 的回退和兼容用途通过交付说明解释，不改变存储路由或数据。

## 拟修改文件

- `src/pages/StorageManagementPage.tsx`
- `docs/walkthrough/walkthrough_20260925_2329_01_S3连通提示.md`

## 实施步骤

1. 为配置编辑弹窗和已保存配置的连接测试统一使用准确的成功提示。
2. 保留现有失败消息和存储行为。
3. 运行前端 lint 检查并记录结果。

## 验证计划

- `npm run lint`
- 静态检查两个连接测试成功状态均调用同一条本地化消息。

## 风险与回滚思路

- 改动仅涉及测试结果提示文案；如需回滚，恢复页面原有成功消息即可。
