# 实施计划：平台动作统一凭据解析

## 任务目标

修复平台绑定设备在拓扑发现和 Playbook 平台动作中出现 SSH 用户名/密码认证失败的问题，并建立连接凭据解析规范，避免后续连接路径绕过凭据中心。

## 根因

平台绑定设备的拓扑路径改为调用 `execute_platform_action()` 后，该服务重新查询 `devices.*` 并直接创建驱动。设备绑定共享凭据中心时，`devices.password` 可能为空，导致驱动收到空密码；资产字段和凭据中心中的有效凭据没有被重新解析。

## 实施范围

- 在 `execute_platform_action()` 创建 driver 前调用 `resolve_collector_credentials(device, ssh_role="normal")`。
- 保持普通账号作为拓扑、巡检和只读采集的默认角色。
- 增加 mock driver 回归测试，验证解析后的账号密码覆盖设备原始字段。
- 新增设备凭据与连接边界代码规范文档。

## 验证计划

- 平台平台注册隔离测试及消费者路径测试。
- Python 编译检查、TypeScript lint 和差异空白检查。
- 不执行真实设备配置变更；最终由用户在拓扑页面发起一次只读发现验证。

## 回滚方案

若出现兼容性问题，回滚本次 `execute_platform_action()` 凭据注入和对应测试/规范文档；不修改数据库数据，不改变凭据绑定关系。
