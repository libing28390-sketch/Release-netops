# 机柜 3D 渲染与 2D/3D 拖拽缩放体验优化实施计划

## 任务目标
解决用户换电脑测试时发现的 3D 机柜发黑看不清问题，并彻底优化 2D/3D 模式下的缩放、顶部与底部设备拖拽和视角观察体验。

## 现状与根因分析
1. **3D 机柜发黑看不清**：
   - [RackFrame.tsx](file:///d:/nexora/nexora-private/src/pages/RackManagement/Rack3D/RackFrame.tsx) 中立柱、导轨、顶盖、底座的 `MeshStandardMaterial` 设置了过高的金属度（`metalness = 0.7~0.85`）与暗颜色 `#1e293b`；
   - 场景中无环境反射贴图（IBL），导致高金属度材质漫反射削减 80%~85% 且反射不到外部环境，呈现 RGB 6~10 的死黑状态；
   - 高对比度屏幕（MacBook Retina、OLED、标准 Gamma 2.2 屏幕）具有更严格的黑位压制（Black Crush），使机柜彻底融进 `#090d16` 暗黑背景。
2. **2D 拖拽与缩放体验差（顶部/底部难拖拉）**：
   - 缩放状态（`rackScale < 1`）下，`RackElevation` 在 `handleDragMove` 中直接用视口像素计算 U 位，未除以缩放比例 `currentScale`，导致拖拽目标点严重漂移错位；
   - 100% 原始大小时，机柜全高 1008px 产生滚动条，拖拽靠近上下边缘时缺少自动滚屏（Auto-Scroll），无法跨屏将顶部设备拖到底部；
   - 缺少免拖拽的“快捷修改 U 位”入口。
3. **3D 视角放大时顶部/底部出界**：
   - 3D `OrbitControls` 焦点锁定在机柜几何中心（21U），放大后顶部（U35-U42）和底部（U1-U10）被裁剪出视口；缺少顶部/底部快速对焦预设。

## 影响范围与拟修改文件
1. `src/pages/RackManagement/Rack3D/RackFrame.tsx`：重构机柜外框、立柱、导轨材质（降低金属度，提高粗糙度和工业冷灰对比度），增加高光边缘轮廓线。
2. `src/pages/RackManagement/Rack3D/RackScene.tsx`：优化多方向摄影棚光照与背部轮廓光（Rim Light），提升暗部通透度。
3. `src/pages/RackManagement/Rack3D/CameraController.tsx` 与 `src/pages/RackManagement/Rack3D/index.tsx`：增加顶部聚焦（Top Focus）与底部聚焦（Bottom Focus）视角预设按钮。
4. `src/pages/RackManagement/components/RackElevation.tsx`：
   - 引入 Scale-Aware 缩放坐标换算，修复拖拽判定；
   - 增加拖拽边缘自动滚屏（Auto-Scroll）；
   - 支持点击空 U 位直接触发快速安装。
5. `src/pages/RackManagement/index.tsx`：
   - 传递 `rackScale` 与滚动容器 Ref 给 `RackElevation`；
   - 在右侧设备详情抽屉中新增“直接调整起始 U 位”快捷控件（输入框 / 步进器 / 冲突校验）。

## 实施步骤
1. **阶段 1：3D 机柜视觉重构**
   - 优化 `RackFrame.tsx` 材质：立柱、顶底座、导轨的 `metalness` 降至 `0.2 ~ 0.25`，基础色调整为工业冷钢灰 `#334155` / `#475569`；
   - 为立柱外框增加 `EdgesGeometry` 轮廓高光线；
   - 在 `RackScene.tsx` 调整摄影棚灯光与背部轮廓补光。
2. **阶段 2：3D 视角与顶部/底部聚焦**
   - 在 `CameraController.tsx` 增加 `focus_top`（聚焦 38U）和 `focus_bottom`（聚焦 5U）预设；
   - 在 `Rack3D/index.tsx` 控制栏中增加对应的快捷视角按钮。
3. **阶段 3：2D 拖拽与 Scale-Aware 修复**
   - 修改 `RackElevation.tsx`，在 `handleDragMove` 中依据 `rackRect.height / (totalU * U_PX)` 准确归一化计算 `relY`；
   - 加入边缘滚动监听逻辑（当 pointer 距离容器顶部或底部 < 50px 时触发自动滚动）；
   - 支持空 U 位点击安装。
4. **阶段 4：设备抽屉免拖拽快捷改 U 位**
   - 在 `RackManagement/index.tsx` 设备抽屉中增加 U 位微调与直接修改功能。
5. **阶段 5：质量门禁与验证**
   - 运行 `npm run lint` 和 `npm run build` 进行前端构建与类型校验；
   - 验证 2D 拖拽、缩放、3D 视觉和多屏幕兼容性。

## 验证计划
- 运行 `npm run lint` 验证无 TypeScript 报错。
- 运行 `npm run build` 验证生产打包成功。
- 在 2D 模式下测试 `100%`、`适应屏幕 (例如 60%)` 下从顶部（U42）拖拽到机柜底部（U1）的准确定位与自动滚动。
- 在 3D 模式下验证机柜框架、立柱与导轨在不同背景与角度下的清晰立体轮廓。
