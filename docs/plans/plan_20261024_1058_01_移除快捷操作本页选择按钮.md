# 移除快捷操作本页选择按钮

## 目标与现状

快捷操作页筛选工具栏包含“选择本页在线设备”按钮。用户要求移除该按钮，并指出之前没有此项。当前按钮只调用 `AutomationExecuteTab` 内的 `handleSelectAllOnline`，没有其他页面使用。

## 影响范围

- 从 `DeviceSelectionStep` 移除该按钮和紧邻的竖向分隔线，保留厂商筛选和视图切换。
- 删除只服务于该按钮的组件属性、父组件处理函数及测试夹具中的失效属性。
- 保留表格分页、批量选择能力、筛选、列表布局和已完成的留白修正。

## 拟修改文件

- `src/pages/AutomationExecute/components/DeviceSelectionStep.tsx`
- `src/pages/AutomationExecute/index.tsx`
- `src/pages/AutomationExecute/components/DeviceSelectionStep.test.tsx`

## 实施步骤

1. 移除按钮及其相邻分隔线。
2. 删除不再被调用的 `handleSelectAllOnline` 处理函数及组件 prop。
3. 从组件测试夹具删除失效 prop。
4. 浏览器确认按钮消失、筛选与视图切换仍在原位，并运行 TypeScript 检查和隔离前端构建。

## 验证计划

- 浏览器检查 `/automation/quick-ops` 工具栏和表格留白布局。
- `npm run lint`
- 在 `%TEMP%` 独立目录运行 Vite production build。
- `git diff --check`

## 风险与回滚

- 移除该选择入口后，用户仍可使用行复选框进行单台/多台选择；不改批量选择状态逻辑。
- 回滚时恢复按钮、对应 prop 和处理函数即可。
