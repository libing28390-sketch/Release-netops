# 拓扑 Site 总览留白优化

## 任务目标
改善 `/monitor/topology` 的 Site 卡片总览布局，减少截图中卡片周边和下方的大面积留白，让内容更充分利用可用空间。

## 现状/问题
Site 总览容器和两站点卡片网格都限制了最大宽度，画布又沿用设备拓扑详情的大高度，少量 Site 卡片下方出现大片空白。

## 影响范围
- 前端拓扑页面 Site 总览卡片样式与画布高度。
- 不涉及 API、数据模型、拓扑关系计算或设备操作。

## 拟修改文件
- `src/pages/TopologyPage.tsx`
- `docs/plans/plan_20260930_1704_01_拓扑Site总览留白优化.md`
- `docs/walkthrough/walkthrough_20260930_1704_01_拓扑Site总览留白优化.md`
- `docs/fixes/fix_20260930_1711_01_拓扑Site总览留白优化.md`

## 实施步骤
1. 扩展 Site 总览内容宽度，让两站点卡片铺满画布。
2. 根据 Site 数量采用响应式卡片列数，并强化状态和指标层级。
3. 按视图类型调整画布高度：卡片总览使用紧凑高度，设备拓扑保留大画布。
4. 执行 TypeScript 检查和前端生产构建，检查差异并保留已有本地构建数据。

## 验证计划
- `npm run lint`
- Vite 前端生产构建到独立临时目录。
- `git diff --check`

## 风险与回滚思路
风险集中在不同窗口高度和 Site 数量下的布局。卡片区域保留内部滚动，设备拓扑继续使用原有画布高度；如出现布局问题，可分别回滚卡片网格和 overview 高度样式。
