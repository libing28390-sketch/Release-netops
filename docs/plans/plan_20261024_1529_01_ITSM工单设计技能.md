# ITSM 工单设计技能

## 任务目标

新增 Nexora 项目级 ITSM 设计 skill，结合 PeopleCert 公开资料和当前工单、审批、监控、自动化流程提供可复用设计指导。

## 现状与问题

项目已有 PAM 变更执行 skill，尚缺统一的工单产品设计指导。现有变更工单能力和新增 ITSM 建议需要明确区分。

## 影响范围与拟修改文件

- 新增 `.agents/skills/netops-itsm-design/SKILL.md`、`agents/openai.yaml` 和 `references/nexora-workflows.md`。
- 在 `.agents/AGENTS.md` 的 skills 路由中登记。
- 新增对应计划、walkthrough；保留已有前端 skill 修改。

## 实施步骤

1. 核对 skill-creator 规范和 PeopleCert 官方公开资料。
2. 编写工单分类、职责、审批、自动化关联和简洁 UI 指导，标明建议与已实现能力。
3. 登记项目路由并检查元数据、引用路径和 skill 格式。

## 验证计划

运行 skill-creator 的 quick_validate，解析 UI YAML，检查相对引用、路由登记和差异。仅变更指令文件，不执行业务测试或前端构建。

## 风险与回滚

指导内容不是官方认证或生产授权；实际业务改动遵循对应专业 skill。回滚仅删除本次新技能并撤销路由条目。
