# 修复链路聚合识别与拓扑采集说明实施计划

## 1. 任务目标
针对用户反馈的前端流水线说明、链路聚合显示与识别缺陷：
1. **修复 LLDP 端口 ID 与描述倒置问题**：解决因为端口描述包含 `GE1/0/1` 导致 `remote_port` 被识别为 `TO-S6850-4-GE1/0/1`，从而导致 `Route-Aggregation34` 聚合口折叠失败并显示 4 条重复平行散线的问题。
2. **消除聚合链路标签重复堆叠显示**：修复 `TopologyGraph.tsx` 中当双端聚合口名称相同时（如 `BAGG12 · 4×10G`）在中心垂直重叠渲染两个相同徽标的问题，合并为单个清晰居中的聚合标签。
3. **修复流水线状态统计包含失效观察数据**：在 `get_topology_generation_status` 中过滤 `is_active = 1` 与 `status <> 'stale'`，消除页面顶部流显示“未匹配证据: 19”的虚假数字。
4. **优化前端拓扑采集逻辑文案与步骤说明**：更新流水线卡片文案为“SNMP优先免密只读采集”，准确说明底层工作机制。

---

## 2. 现状与根因分析

### 2.1 链路聚合识别失败（S6850-3 与 S6850-4 的 Route-Aggregation34）
- 数据库 `interfaces` 表中已成功录入 S6850-3 和 S6850-4 的 `Route-Aggregation34`（包含 `GE1/0/1 ~ 4` 成员）。
- 但在 `backend/services/snmp_service.py` 的 `collect_snmp_lldp_neighbors` 中，代码错误地优先使用了 `lldpRemPortDesc`（接口描述 `TO-S6850-4-GE1/0/1`），而弃用了标准的 `lldpRemPortId`（真实接口名 `GigabitEthernet1/0/1`）。
- 导致邻居证据中的对端端口为 `TO-S6850-4-GE1/0/1`，在聚合匹配字典中找不到对应接口，聚合折叠逻辑中断，退化为 4 条散线。

### 2.2 聚合链路中心双重标签重叠
- 在 `TopologyGraph.tsx` 中，`getPortLabelAnchor` 对聚合链路将两端标签的锚点均计算在连线中心点（`(source.x + target.x) / 2`），仅靠 `perp * 13` 微小位移区分。
- 当两端聚合名称均为 `BAGG12` 时，画布在中央渲染了两个内容完全一致的 `BAGG12 · 4×10G`，重叠显示给用户造成“有两条重叠连线”的错觉。

### 2.3 流水线卡片与未匹配证据统计
- `TopologyPage.tsx` 中的流水线步骤文案仍为旧版单一的“只读采集 LLDP”。
- `get_topology_generation_status` 在统计 `unmatched_observations` 时没有过滤 `is_active=1`，导致上一轮测试残存的 19 条失效观察被统计并显示在前端警示栏中。

## 3. 拟修改文件与实施步骤

### 3.1 后端 SNMP 邻居端口提取优化与接口描述防倒置 (`backend/services/snmp_service.py`)
- 修改 `collect_snmp_lldp_neighbors`：优先使用标准 IEEE 802.1AB `lldpRemPortId`，杜绝用户配置的接口描述（如 `TO-S6850-4-GE1/0/1`）覆盖真实端口 ID，保证两端端口均规范化为标准端口（如 `gi1/0/1`），从而让 `Route-Aggregation34` 聚合口成功折叠。

### 3.2 拓扑发现轻量化与去除复杂协议推导 (`backend/services/topology_service.py`)
- 在 `discover_device_neighbors` 中移除无条件 SSH 会话建立与 `collect_protocol_evidence`（去除 OSPF、ISIS、BGP、路由表、接口描述、STP 等 6 大复杂 CLI 命令的调用）。
- 严格遵循“SNMP 优先免密只读采集，仅在 SNMP 无邻居时回退至 CLI LLDP”的精简原则，避免对设备发起大量 CLI 查询。
- 在 `get_topology_generation_status` 中为 `observation_metrics` 查询增加 `WHERE COALESCE(o.is_active, 1) = 1 AND COALESCE(o.status, 'active') <> 'stale'`，消除“未匹配证据: 19”的陈旧残留。
- 清理已存的历史 `interface_description` 协议观察数据，彻底消除因接口描述导致的紫色重复链路。

### 3.3 前端画布聚合标签去重 (`src/components/TopologyGraph.tsx`)
- 在 `TopologyGraph.tsx` 中，对聚合链路若双端标签一致（如 `BAGG12 · 4×10G`），隐藏 target 端标签，并将 source 端居中精确贴合线缆中心，消除重叠双徽标。

### 3.4 前端流水线说明与步骤文案优化 (`src/pages/TopologyPage.tsx`)
- 更新流水线标题、步骤（`只读采集 xDP/LLDP (SNMP优先)`、`合并双向证据与链路聚合`）及运行说明文案。

### 3.5 数据重算与链路刷新
- 运行链路重新计算，使得 `Route-Aggregation34` 成功折叠为单条聚合链路。
