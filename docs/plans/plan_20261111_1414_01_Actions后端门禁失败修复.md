# GitHub Actions 后端门禁失败修复计划

## 目标

修复提交 `03bea6c223f2677c487cc031a76647bf51b00eb0` 的 Actions run #774 中后端 pytest release gate 的 11 个失败项，并以同一修复提交的 CI 结果确认回归通过。

## 现状与问题

Actions 后端门禁结果为 11 failed、4134 passed、2 skipped。复核调用链后，11 项均由旧测试契约/夹具未跟上已实现的接口与数据模型导致：IP 定位 mock 未接受新增 VLAN 参数，导致测试把身份读取异常吞成“证据不足”后误触发 LLDP（2 项）；直接调用 FastAPI 路由的测试未显式传入 `endpoint_class='all'`（1 项）；站点权限测试 mock 未接受新增 `visible_scopes` 参数（1 项）；IPAM inventory 轻量 PostgreSQL schema 缺少 `address_space_id`/`sites.tenant_id`，且 legacy-only 测试未隔离 current-only observation 查询（1 项）；CMDB CLI 期望值未包含新加入的上下文元数据（6 项）。

## 影响范围

只修正测试调用契约、测试 schema 和过期的期望值；生产业务代码保持不变，不放宽生产断言、不跳过失败测试、不修改现场数据库或设备配置。无地址空间归属的 legacy 发现缓存仍按现行逻辑排除，不从站点/IP 推断地址空间。
