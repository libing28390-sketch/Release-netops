# 模板自动带出与必填标记修复计划

## 任务目标

让“管理入口”工作表的资产编号和主机名从“网络设备”和“服务器”工作表自动读取，减少重复填写；结合现有资产管理字段，在两张资产表表头用红色 `*` 清楚标明必填字段。

## 现状/问题

- 当前管理入口的资产编号和主机名仍是普通输入单元格，容易与资产表不一致。
- 新模板虽然已拆分资产表，但必填字段没有统一的可视标记。
- 表头增加标记后，导入解析必须继续识别带 `*` 的表头，同时旧模板仍要兼容。

## 影响范围

资产导入模板下载、Excel 公式联动、资产表头展示和前端导入表头规范化；不修改数据库或已有资产数据。

## 拟修改文件

- `src/pages/AssetManagement/index.tsx`：兜底模板分表、自动带出公式说明和星号表头。
- `src/pages/AssetManagement/importUtils.ts`：工作表类型识别与带星号表头规范化。
- `src/pages/AssetManagement/importUtils.test.ts`：覆盖分表识别、SSH 单行和星号表头。
- `public/templates/asset_import_template.xlsx`：静态模板公式、10 列管理入口和红色必填标记。
- `docs/walkthrough/`：记录验证证据。

## 实施步骤

1. 在管理入口 A/B 列写入堆叠读取两张资产表 B/C 列的 Excel 公式，并保留示例缓存值。
2. 在网络设备和服务器表头追加 `*`，将必填单元格设置为红色，补充条件必填说明。
3. 让导入器去除表头尾部星号后再映射字段，保留旧版统一资产表和旧管理入口表头兼容。
4. 重新生成并渲染静态 XLSX，检查公式缓存、数据验证和可读性。

## 验证计划

- `npm run test:frontend -- --run src/pages/AssetManagement/importUtils.test.ts`
- `npm run lint`
- `npm run build`
- 只读检查静态模板的工作表、公式、必填星号颜色和下拉规则
- 使用旧版思科资产工作簿做离线解析回归

## 风险与回滚思路

公式依赖固定的两张中文/英文工作表名称和连续资产行；用户增删资产后由 Excel 重算。旧模板使用旧表名和无星号表头，解析器继续兼容。失败时可回退模板和纯前端解析改动，不涉及数据回滚。
