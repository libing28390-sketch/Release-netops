# 桌面端 Codex 风格界面优化计划

## 任务目标

审查 `desktop/` 下 NetOps.exe 图形化管理器的界面实现，并将主界面视觉调整为更接近 Codex 的简洁、克制、低噪风格。

## 现状/问题

- 图形界面主要由 `desktop/desktop_tray.py` 中的 PySide6 窗口、内嵌 QSS 和页面布局构成。
- 当前界面存在高饱和青蓝色、厚重阴影、大字号状态文本、过宽侧栏、卡片层级偏重等问题。
- `desktop/desktop_settings.ini` 默认 `dark_mode=false`，启动后优先展示当前较弱的浅色主题。

## 影响范围

- 桌面端 Agent 管理器主窗口视觉样式。
- 仪表盘、服务管理、日志、设置和关于页面的全局主题观感。
- 不改变后端启动、停止、诊断、日志读取、系统信息和托盘功能逻辑。

## 拟修改文件

- `desktop/desktop_tray.py`
- `desktop/desktop_settings.ini`
- `docs/plans/plan_20260713_0858_01_桌面端Codex风格界面优化.md`
- `docs/walkthrough/walkthrough_20260713_0858_01_桌面端Codex风格界面优化.md`

## 实施步骤

1. 调整全局 QSS：背景、侧栏、卡片、按钮、输入框、日志区域、菜单和滚动条。
2. 降低阴影、边框、圆角和状态色强度，避免视觉噪声。
3. 缩窄侧栏并调整主窗口默认尺寸与页面边距。
4. 改善仪表盘状态文本字号和间距，使信息层级更克制。
5. 将默认主题改为暗色模式，贴近 Codex 桌面视觉基调。
6. 运行 Python 语法检查验证桌面端文件可解析。

## 验证计划

- `.\.venv\Scripts\python.exe -m py_compile desktop/desktop_tray.py`
- 人工检查关键样式片段是否更新为低饱和 Codex 风格。

## 风险与回滚思路

- 风险：QSS 调整可能影响局部控件可读性，需要后续打开 exe 实机查看细节。
- 回滚：还原 `desktop/desktop_tray.py` 与 `desktop/desktop_settings.ini` 的视觉相关修改即可。
