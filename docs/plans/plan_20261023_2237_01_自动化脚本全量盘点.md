# 自动化脚本全量盘点

## 目标与现状

用户要求全量梳理自动化脚本。提供的链接文字为 scheduled-jobs，实际 href 为 /automation/scripts；以脚本管理为主，覆盖关联的 Playbook、快速执行、版本与定时任务。

## 影响范围与文件边界

只读检查当前浏览器页面和相关源码，不执行脚本或真实设备操作。主 Agent 仅维护本计划和对应 walkthrough；不修改业务代码和现有用户变更。

## 分工

- 主 Agent：页面实际数据、前端入口与工作流、汇总报告及结论。
- 后端执行者：api/automation.py、services/automation_service.py、api/scheduled_jobs.py、services/scheduler_service.py 及直接依赖，检查脚本 CRUD、执行和任务关联；只读。
- 目录执行者：database/schema.py 的脚本种子、api/playbooks/、playbook 版本相关服务，盘点脚本目录与 Playbook 区别、平台与生命周期；只读。
- 共享文件及交接：计划和 walkthrough 由主 Agent 独占；执行者不创建文档。

## 步骤

1. 核对路由、页面和当前完整脚本列表。
2. 按名称、类型、分类、平台、状态、参数及用途形成清单。
3. 追踪脚本与 Playbook、执行、历史、定时任务的关系。
4. 记录已证实的问题、重复项和后续整理建议，区分代码事实与运行证据。

## 验证范围

浏览器只读查看列表、筛选与详情；源码阅读及静态统计。无需运行业务测试、构建、脚本预演或设备命令。

## 风险与回滚

避免读取或记录真实凭据；不点击执行、审批、发布、保存、删除。仅新增盘点文档，无运行时回滚操作。
