# 公共表格默认分页调整

## 任务目标

将使用共享 `Pagination` 组件的表格和列表，其默认每页条数从 20 调整为 10。

## 现状与问题

- `src/components/Pagination.tsx` 未传 `itemsPerPage` 时默认已经是 10。
- 多个页面以受控状态向该组件传入 `useState(20)` 或固定值 20，因此实际首次显示仍为 20 条。

## 影响范围

- 只调整共享分页组件调用方的初始每页条数；保留用户可选的 20、50、100 条选项。
- 不调整导出拉取、下拉选项预加载等非表格分页请求的批量大小。
- 不改变 API 分页契约及用户主动选择其他每页条数后的行为。

## 拟修改文件

- `src/pages/` 中使用共享 `Pagination` 且初始每页条数为 20 的页面/组件。
- `src/components/` 中同类分页调用方。
- 本计划及对应 walkthrough。

## 实施步骤

1. 枚举共享 `Pagination` 的调用位置与对应受控 page-size 初始值。
2. 将 20 条默认值改为 10；校正不能选择低于 20 的特例约束，使 10 条可生效。
3. 静态复查差异，确保只影响表格/列表默认分页，不改批量导出或预加载大小。

## 验证计划

- 使用 `rg` 复查共享分页调用方的 20 条初始值和特例下限。
- 检查变更差异与空白格式；不运行测试或构建。

## 风险与回滚思路

- 页面首次显示行数减少，但用户仍可通过分页选择器切换到其他条数。
- 如需回滚，可将本次调用方初始 page-size 值恢复为原值；无需数据库或 API 变更。
