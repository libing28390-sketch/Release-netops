# 机柜列表站点标签单行布局

- 创建时间：2026-10-21 11:21（工作区时区）
- 状态：已实施并完成自动化验证；浏览器目视验收待补

## 目标

修正 `/cmdb/racks` 左侧机柜卡片中站点名称在窄卡片内被挤压成多行的问题，同时让其他元信息保持可读且不撑宽卡片。

## 现状与根因

用户截图显示站点标签如 `WH-DC-02` 被拆成多行。卡片把站点、楼层、机柜类型、U 数和尺寸放在一条不换行的 Flex 行里；站点标签默认允许收缩并按标点断行，窄内容区因而把标签撑高。

## 影响范围

- 仅修改 `src/pages/RackManagement/index.tsx` 中机柜卡片的站点与元信息行。
- 保留站点名称解析、筛选、机柜选中和操作行为，不改 API 或数据契约。

## 实施步骤

1. 复用已解析的站点名称，避免 JSX 中重复查找。
2. 允许元信息项按整项换行；站点标签限制最大宽度、保持单行并在超长时省略，悬停标题保留完整名称。
3. 运行站点标签与 Rack ViewModel 聚焦测试、TypeScript 检查、隔离 Vite 构建和差异空白检查。

## 风险与回滚

长站点名称会在卡片中省略，完整内容保留在 `title` 和无障碍文本中。若信息行布局不佳，可回退该 JSX 行的 flex-wrap 与标签类；业务逻辑不受影响。
