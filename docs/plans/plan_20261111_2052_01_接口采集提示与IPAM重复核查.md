# 任务目标
修复 CMDB 接口采集结束提示常驻；解释 VRF 维护及全局路由表填写方式；排查 IPAM 相同 IP 重复展示。

## 现状与影响范围
接口任务结束写入 notice，没有清理或关闭入口；终态详情应继续可查。用户截图显示同站点同 IP/MAC 多行，需区分作用域与来源后判断原因。

## 拟修改文件与分工
- 主 Agent：src/pages/CmdbManagementTab.tsx、对应测试及统一计划/验证记录。
- 只读子 Agent：核对 VRF 契约；另一只读子 Agent：追踪 IPAM 重复来源。子 Agent 均不修改文件。
- IPAM 是否需要代码修改，由证据确定并更新本计划。
- 已确认 IP 地址页状态枚举落后于后端（scope_pending/matched），且接口所有者误标为接入设备。主 Agent 同步修改 src/pages/IPVlan/IPAddressTab.tsx 及 IPAddressTab.edit.test.ts，补齐真实状态和采集设备文案，不自动合并或写入台账。

## 实施步骤
1. 检查接口启动、轮询、终态、提示与详情链路。
2. 为接口通知增加自动消失及手动关闭；终态详情可手动关闭，保留失败诊断。
3. 核查 VRF 与 IPAM 列表/写入的实际契约。

## 验证计划
接口页面及进度组件定向 Vitest、npm run lint、独立目录 Vite build；如可用，浏览器验证，不发起真实设备采集。

## 风险与回滚
不变更设备配置、数据库数据或部署。保留已有未提交改动。若新增提示计时器必须清理，防止旧提示计时器误清新提示。回滚仅撤销本任务代码。
