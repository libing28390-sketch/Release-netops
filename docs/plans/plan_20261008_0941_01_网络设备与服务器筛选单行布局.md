# 资产管理、网络设备与服务器工具栏单行布局

- 创建时间：2026-10-08 09:41（Asia/Shanghai）
- 目标：让资产管理、网络设备和服务器页面的搜索、筛选、列设置及主要操作在桌面宽度下收拢到单行，沿用资产管理工具栏的紧凑间距和视觉层级。
- 现状：资产管理把“资产台账/操作”和筛选分成两行；网络设备的列设置及刷新位于页面标题栏；服务器的快捷状态筛选及刷新分开放置。
- 范围：`src/pages/AssetManagement/index.tsx`、`src/pages/InventoryDevicesTab.tsx`、`src/pages/InventoryServersTab.tsx`。
- 约束：不改变搜索、筛选、分页、列设置和快捷状态筛选的行为；窄屏保留可用的换行/滚动空间，不压缩到不可操作。
- 实施步骤：
  1. 移除资产管理的“资产台账”标签行，将原有操作并入搜索和筛选工具栏。
  2. 将网络设备和服务器的搜索、筛选、刷新、列设置和快捷状态筛选收拢到紧凑工具栏。
  3. 将刷新操作改为仅显示图标并保留可访问名称、加载动画和禁用状态。
  4. 在窄屏上允许工具栏适配换行，避免控件横向溢出。
- 验收：运行 `npm run lint` 与前端构建；在浏览器检查网络设备和服务器页面的宽屏单行排列及窄屏可用性。
- 风险：低；仅调整布局类名与容器结构，不涉及数据或交互逻辑。
