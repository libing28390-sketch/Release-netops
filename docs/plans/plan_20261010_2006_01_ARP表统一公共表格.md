# ARP 表统一公共表格

## 目标

将“IP 定位 > ARP 表”的列表改为使用项目公共 DataTable 的标准语义结构和样式，保留当前搜索、点击定位、导出、分页及表格滚动行为。

## 现状与问题

ARP 视图虽然调用了 `DataTable`，但传入 `unstyled`，并将 `thead`、`tbody`、行和单元格改成 `block/grid` 布局。结果绕开了公共表格的表头、行高、单元格间距和 hover 样式，截图中仍是页面自绘列表。

## 影响范围

- 前端 ARP 表视图；不改采集 API、过滤规则或数据类型。
- 只改 ARP 表格对应的 `src/pages/IPLocatorPage.tsx` 区域，保留该文件中其他已有工作区修改。

## 拟修改文件

- `src/pages/IPLocatorPage.tsx`
- 本计划和对应 walkthrough。

## 实施步骤

1. 去除 `DataTable` 的 `unstyled`，让公共组件应用 `.nx-data-table` 基础样式。
2. 把 ARP 表恢复成标准 `<table>/<thead>/<tbody>/<tr>/<th>/<td>` 结构；移除 block/grid 模拟表格布局。
3. 适度设置列宽和单元格文本截断，维持窄视口横向滚动；保留完整过滤结果导出、整行定位和公共 `Pagination`。
4. 静态检查改动和 TypeScript/JSX 结构；根据验证规则不运行测试，除非用户要求。

## 验证计划

- 检查最终 ARP 区域确认 `DataTable` 使用默认公共样式，且没有 `block/grid` 伪表格布局。
- 执行 `git diff --check`。
- 不触发采集，不修改或部署服务器。

## 风险与回滚

- 表格列宽与滚动手感可能随视口变化；通过表格最小宽度和标题文本截断维持可读性。
- 若公共样式与当前视口不兼容，可仅回退此 ARP 表格片段，搜索、采集状态和数据请求不受影响。
