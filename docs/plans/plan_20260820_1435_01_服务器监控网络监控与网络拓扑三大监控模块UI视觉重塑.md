# 服务器监控、网络监控与网络拓扑三大监控模块 UI 视觉重塑实施计划

## 1. 任务目标
重构并深度优化系统监控中心三大核心业务页面：
- **服务器监控** (`/monitor/servers` -> [ServerMonitoring.tsx](file:///d:/nexora/nexora-private/src/components/ServerMonitoring.tsx))
- **网络监控** (`/monitor/networks` -> [NetworkMonitoring.tsx](file:///d:/nexora/nexora-private/src/components/NetworkMonitoring.tsx))
- **网络拓扑** (`/monitor/topology` -> [TopologyPage.tsx](file:///d:/nexora/nexora-private/src/pages/TopologyPage.tsx))

将原有粗糙的传统控制台样式全面升级为现代 SaaS 风格的高级 Bento 仪表盘质感，优化数据层级、消除高饱和刺眼色块、增加交互细节与状态微胶囊。

## 2. 现状与痛点
1. **服务器监控**：指标展示形式单调，缺少现代化流体微进度条，卡片布局层次不够鲜明；
2. **网络监控**：采集状态与微观诊断面板采用大面积纯绿背景色块，高饱和度刺眼且信息噪点多；
3. **网络拓扑**：发现任务进度条粗笨，指标条与工具栏控件样式割裂，未采用统一的微胶囊与 SaaS 边框设计。

## 4. 实施步骤
1. **服务器监控重塑**：Header 控件胶囊化（时间范围分段控制 + 刷新轮询）、左侧列表现代化、4 联 Bento 核心指标卡升级、渐变面积图美化。
2. **网络监控重构**：消除大面积纯绿背景、5 联微型硬件快照 Bento 化、接口流量表 UP 状态微胶囊化、告警时间线现代徽章。
3. **网络拓扑优化**：Header 发现与导出按钮升级、LLDP 6 阶段流水线微卡化、发现任务执行进度条升级、统计指标栏与筛选工具栏 Bento 整合。
4. **质量验证**：执行 `npm run build` 确保 TypeScript 类型与 Rollup 生产构建零报错。
