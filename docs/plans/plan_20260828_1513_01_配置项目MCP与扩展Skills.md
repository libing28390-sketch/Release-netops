# 实施计划 - 配置项目 MCP 服务与扩展专业领域 Skills

针对 Nexora NetOps 项目的技术栈与复杂业务子系统（PostgreSQL、FastAPI、多厂商驱动、AI 知识库、拓扑图谱、SNMP 监控、PAM 堡垒机），配置 Model Context Protocol (MCP) 并补充 5 个细分领域的 Skills 体系。

## 1. 目标与背景

当前项目已有 6 个基础技能（后端、前端、数据库迁移、网络驱动、质量门禁、发布打包），但在以下高复杂度领域缺乏针对性的约束规范与专用上下文指导：
1. **AI 知识库与 RAG 检索管线**（Security Vault 脱敏、pgvector/trgm 混合检索、Provider 熔断限流）
2. **网络拓扑与图谱计算引擎**（LLDP/CDP 归一化、LAG 汇聚、STP 环路推导、Canvas/SVG 渲染性能）
3. **监控遥测、出向探针与告警流转**（64位 MIB 计数器溢出处理、SSRF 防御探针、维护期抑制、多通道通知）
4. **特权访问 PAM、Web 终端与变更工单**（WebSocket 终端录像审计、密码轮转、危险命令拦截、工单状态机）
5. **TextFSM 模板工程与多厂商解析沙箱**（模板状态机、正则规范、多厂商 fixture 验证）

同时，配置 `.agents/mcp_config.json` 引入 PostgreSQL、Docker、Browser、Git 等 MCP 服务，赋予 Agent 直接探查数据库、容器状态及执行无头测试的外部能力。

## 3. 实施步骤

1. **创建 `.agents/mcp_config.json`**：配置标准 Stdio 形式的 MCP Servers（Postgres、Docker、Browser/Puppeteer、GitHub）。
2. **编写 5 个领域的 `SKILL.md`**：
   - 明确每个 Skill 的工作流 (Workflow)、核心约束 (Conventions / Safety Gate)、代码路径边界 (Boundaries) 以及验证方式 (Verification)。
   - 严格融入项目现有代码规范（如 PostgreSQL 绑定、Security Vault 脱敏、`hp_comware` 规范化、安全 HTTP 探针等）。
3. **更新 `.agents/AGENTS.md`**：完善 Skills 路由表与跨 Agent 协作指引。
4. **验证与交付**：检查 JSON 语法、Markdown 格式、目录结构以及 Skill 元数据 frontmatter 正确性。

---

## 4. 验证计划

- 验证所有 `SKILL.md` 的 YAML Frontmatter（`name` 和 `description`）格式标准有效。
- 验证 `.agents/mcp_config.json` JSON 语法合法。
- 验证 `.agents/AGENTS.md` 路由表与实际 Skill 目录 100% 一致。
