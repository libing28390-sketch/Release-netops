# 审核人指派弹窗

## 目标与现状

脚本提交审核时，“指派审核人”弹窗中的搜索结果使用绝对定位，脱离弹窗正常布局，打开结果后会覆盖“发送审核申请”按钮。弹窗在窄视口下也缺少最大高度与内部滚动约束。

## 影响范围

- 仅调整 `src/pages/ScriptManagementTab.tsx` 的审核人指派弹窗。
- 搜索结果改为正常文档流，随结果列表扩展弹窗内容并将操作按钮推至其后；弹窗增加窄屏高度约束和内部滚动。
- 保持审核人搜索、选择、关闭与提交行为，不触碰审核 API 或脚本数据。

## 实施步骤

1. 去掉装饰图标和说明文案，保留标题、搜索、结果、提交、取消这五个必要内容。
2. 将审核结果从绝对定位覆盖层改为有最大高度的内嵌列表；保持无结果提示和滚动。
3. 为弹窗增加最大视口高度与内部滚动约束。
4. 用浏览器复现搜索 `lisan`，确认结果项、发送按钮、取消按钮无重叠；检查窄视口布局。
5. 运行 TypeScript 检查、隔离 Vite 构建与差异格式检查。

## 验证计划

- 浏览器打开 `/automation/scripts` 的脚本审核弹窗，搜索并选择审核人；不发送真实审核申请。
- `npm run lint`
- 在 `%TEMP%` 独立目录执行 Vite production build。
- `git diff --check`

## 风险与回滚

- 此改动只影响弹窗排版；选中审核人仍通过原有状态写入，提交仍走原有处理函数。
- 回滚时恢复原弹窗与审核人结果列表 JSX 即可。
