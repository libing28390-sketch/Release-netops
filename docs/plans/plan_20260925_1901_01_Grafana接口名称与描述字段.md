# Grafana 接口名称与描述字段修正计划

## 任务目标
让“接口全称”显示 SNMP `ifName`，让“接口描述”显示 SNMP `ifDescr`，避免当前语义映射到 `ifAlias`。

## 现状/问题
接口流量 Dashboard 的生成器曾将 `ifAlias` 当作接口描述。用户确认描述字段应对应 IF-MIB 的 `ifDescr`。SNMP Exporter 已采集 `ifDescr`，并在接口计数器上提供该标签。

## 影响范围
接口流量与健康 Dashboard 的表格查询、字段映射及其生成产物；不涉及 API、数据库或设备写操作。

## 拟修改文件
- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-interface.json`
- 本计划及对应 walkthrough

## 实施步骤
1. 将接口元数据关联和聚合标签由 `ifAlias` 改为 `ifDescr`，保留 `ifName` 作为接口全称。
2. 仅重新生成接口 Dashboard JSON。
3. 检查表格 PromQL、列名映射、JSON 可解析及差异范围。

## 验证计划
调用生成器的接口 Dashboard 构建函数生成目标 JSON；验证 JSON 可解析，接口表格使用 `ifDescr` 且 `ifName` 仍单独保留；执行 `git diff --check`。

## 风险与回滚思路
设备未返回 `ifDescr` 时描述可能为空。回滚时恢复生成器与接口 Dashboard JSON 的本次差异。
