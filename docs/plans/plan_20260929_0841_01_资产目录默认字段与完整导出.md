# 资产目录默认字段与完整导出实施计划

## 任务目标

调整 `/assets/dashboard`：页面表格固定显示既有默认字段，不允许通过列选择加入可选字段；表格导出始终包含资产完整字段集合。

## 现状/问题

`src/pages/AssetManagement/index.tsx` 从 localStorage 恢复展示列偏好，并提供“展示列”菜单；导出数据也复用当前可见列，因此屏幕字段和下载字段相互耦合。

## 影响范围

仅影响资产目录页面的表格列呈现及该表格的导出字段。筛选、分页、资产操作和其他页面不在本次范围内。

## 拟修改文件

- `src/pages/AssetManagement/index.tsx`
- `docs/plans/plan_20260929_0841_01_资产目录默认字段与完整导出.md`
- `docs/walkthrough/walkthrough_20260929_0841_01_资产目录默认字段与完整导出.md`

## 实施步骤

1. 以 `DEFAULT_ASSET_COLUMNS` 作为唯一的表格可见列来源。
2. 移除列选择菜单、展示列本地持久化状态及相关辅助逻辑。
3. 将导出列固定为 `ASSET_COLUMN_DEFS` 的完整定义，保留当前过滤条件和全量分页拉取行为。
4. 进行针对性静态检查/构建，并记录实现及验证结果。

## 验证计划

- 检查变更 diff，确认表格只映射默认列，导出映射全部列。
- 运行前端 lint 或项目已有的针对性类型/构建检查；不启动会触发后台同步的全栈服务。

## 风险与回滚思路

- 风险：历史浏览器中保存的自定义列偏好不再生效；这是固定默认展示的预期行为。
- 风险：导出新增字段后，工作簿列数增加至完整字段集合；这是用户要求的预期行为。
- 回滚：恢复本次对资产目录组件的变更即可；不涉及数据迁移或持久化数据写入。
