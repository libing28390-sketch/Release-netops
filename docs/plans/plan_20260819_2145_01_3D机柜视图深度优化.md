# Implementation Plan - 3D 机柜孪生深度渲染与交互优化 (3D Rack Twin V1 Polishing)

## 任务目标与根因分析

### 现状与根因分析
1. **WebGL 兼容性与上下文释放**：
   - 初始探测函数 `isWebGLAvailable` 和 `getGPUSummary` 创建了临时 WebGL 上下文但未显式调用 `loseContext()`，在某些显卡/软件渲染模式下占用了浏览器受限的 WebGL 上下文槽位。
   - `Canvas` 的 `powerPreference` 设为 `high-performance` 在无独立显卡或集成显卡/软件光栅化模式下易触发上下文丢失。
2. **Troika Font / 3D Text 瓶颈**：
   - `RackFrame.tsx` 中为每个 U 位生成了 42 个独立的 `@react-three/drei` `<Text>` 组件，导致触发 42 次异步字体请求与 SDF 着色器编译，在无外网或低端 GPU 环境下可能发生白屏或加载阻塞。
3. **CameraController 轨道控制冲突**：
   - `CameraController` 未正确绑定 `OrbitControls` 的实际引用，导致相机 Lerp 过渡标志位 `isTransitioning` 无法正常结束，锁死了相机的交互旋转。
4. **模型细节与工业质感需要升级**：
   - 机柜立柱缺少真实的 EIA-310-D 方形安装孔（Cage Nut Holes）与刻度。
   - 设备面板缺少高保真机架挂耳（Mounting Ears）、驱动器托架把手、SFP 端口与动态告警呼吸灯。

## 优化方案与实施步骤

### 1. WebGL 鲁棒性与上下文管理
- 修改 [`src/pages/RackManagement/Rack3D/utils/webgl.ts`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/utils/webgl.ts)：探测完成后立即通过 `WEBGL_lose_context` 释放临时上下文。
- 修改 [`src/pages/RackManagement/Rack3D/RackScene.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/RackScene.tsx)：调整 `powerPreference: 'default'`，添加 `webglcontextlost` 事件监听与自动恢复，优化 Canvas 渲染配置。

### 2. 程序化立柱导轨纹理（彻底替代 42 个 3D Text）
- 在 [`src/pages/RackManagement/Rack3D/utils/textures.ts`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/utils/textures.ts) 中增加 `getRackRailTexture(totalU)`：
  - 绘制工业冷轧钢背景与拉丝高光。
  - 精确绘制每个 U 位的 3 个 EIA-310-D 方孔与 U 刻度数字（U1 到 U42），每 5U 重点亮蓝标识。
- 在 [`src/pages/RackManagement/Rack3D/RackFrame.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/RackFrame.tsx) 中将左右前后 4 根立柱及安装导轨直接映射该高清纹理，0 额外字体请求、0 异步卡顿、1 次合批渲染。

### 3. 重构相机平滑过渡与控制器协同
- 重构 [`src/pages/RackManagement/Rack3D/CameraController.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/CameraController.tsx)：
  - 将 `OrbitControls` 实例引用通过 `ref` 传入并双向同步。
  - 在用户鼠标按下拖拽时立即解除过渡动画锁定，确保 100% 丝滑无阻滞。
  - 预设视角（正面、背面、45°等轴、俯视、重置）平滑过渡，并在选中设备时聚焦到该设备中心。

### 4. 极致工业质感模型重构
- [`ProceduralChassis.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/models/ProceduralChassis.tsx)：深炭灰拉丝冷轧钢，加入顶部散热格栅纹理、边框光晕以及金属螺丝细节。
- [`SwitchFaceplate.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/models/SwitchFaceplate.tsx)：精细化 RJ45/SFP+ 阵列、高光金属挂耳、厂商名牌、状态指示灯（Critical/Warning 呼吸闪烁）。
- [`ServerFaceplate.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/models/ServerFaceplate.tsx)：自适应 1U/2U/4U 硬盘仓位矩阵（带抽拉把手与指示灯）、电源按钮。
- [`GenericFaceplate.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/models/GenericFaceplate.tsx)：防火墙、路由器、PDU 与理线架专用面板。
