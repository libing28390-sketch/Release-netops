# 资产管理与网络设备增加“全部”总览卡片与全量联动优化计划

## 1. 任务目标
为 **资产管理**（`/assets/dashboard`）与 **网络设备清单**（`/assets/network-devices`）页面的顶部 Bento KPI 卡片组增加首位的 **「全部」总览卡片**，让用户在筛选后能清晰直观地一键切换回“全部”视图，并确保底栏分页总数与当前过滤视图精确联动。

## 2. 现状分析
1. **缺少显式的「全部」总览卡片**：
   - 顶部目前只有 4 联严重程度/状态卡片（P1 离线/严重、P2 告警/重要、P3 维护/临期、正常）；
   - 当用户点击某个卡片进入过滤后，虽然可以再次点击卡片或点击“重置筛选”，但界面缺少直观的“全部”总览入口与选中态标识；
2. **底栏分页总数未与前端过滤联动**：
   - 过滤后表格显示少量匹配行，但底栏 Pagination 依然展示全量总数（如 8 条），产生视觉错位。

## 3. 优化方案

### 3.1 升级为 5 联 Bento KPI 卡片（增加「全部」卡片）
在 `/assets/dashboard` 和 `/assets/network-devices` 统一配置 5 联卡片网格（`grid-cols-2 md:grid-cols-3 lg:grid-cols-5`）：
1. **「全部」总览**（`filterVal: 'all'`）：展示全部资产/设备总数（100%），默认高亮选中；
2. **「P1 · 严重/离线」**（`filterVal: 'critical'` / `'offline'`）；
3. **「P2 · 告警/异常」**（`filterVal: 'major'` / `'warning'`）；
4. **「P3 · 临期/待投产/维护」**（`filterVal: 'warning'` / `'staging_maintenance'`）；
5. **「正常 · 运行正常」**（`filterVal: 'healthy'`）；

- **高亮逻辑**：
  - 未选择任何状态卡片时，**「全部」卡片处于高亮激活态**；
  - 选择具体状态卡片时，对应卡片高亮；
  - 点击「全部」卡片或再次点击当前卡片，立即恢复全量展示并高亮「全部」卡片。

### 3.2 底栏分页总数与条数精准联动
- 将底栏 `<Pagination totalItems={...} />` 的总数设置为当前过滤视图下的实际条数（`severityFilter !== 'all' ? displayAssets.length : total` / `quickFilter !== 'all' ? displayRows.length : inventoryTotal`）。

## 4. 涉及文件

- `src/pages/InventoryDevicesTab.tsx`
