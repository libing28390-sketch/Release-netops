# 实施计划 - 运营总览仪表盘前端视觉与监控指标层级重塑

## 1. 任务目标
针对运营总览仪表盘（`DashboardTab.tsx`）进行专家级的前端视觉与网络监控业务重塑：
- **降噪减负**：整合顶部杂乱的操作按钮，规范颜色语义，杜绝全屏“泛红狼来了”；
- **标准化指标卡（Bento KPI Grid）**：统一指标卡结构与宿主机资源胶囊条，消灭空洞卡片；
- **行动闭环告警条（Actionable Incident Stream）**：将告警信息升级为带有严重度标签与快捷跳转的行动流；
- **高坪效多厂商与角色矩阵（Fleet Matrix）**：优化单一环形图，增强网络拓扑角色与厂商分布信息密度。

---

## 2. 拟修改文件
- `src/pages/DashboardTab.tsx`：重构整个仪表盘组件的 JSX 排版与交互样式。

---

## 3. 实施步骤
1. **重构顶部 Hero 栏**：整合定时刷新微胶囊、健康度标签与主次操作按钮；
2. **重构 5 联 KPI 指标卡**：
   - 资产总数（对齐实际设备与资产联动展示）；
   - 在线节点（微进度条 + 占比）；
   - 合规率（柔和语义配色，未检测显示友好提示）；
   - 24H 自动化（作业总数与 100% 成功率）；
   - 宿主机资源（水平胶囊微图，清晰呈现 CPU/MEM/DISK）。
3. **重构当前告警行动条**：增强视觉轻盈感与告警级别标签；
4. **重构趋势图与平台分布**：优化图表渐变色、图例胶囊与平台厂商矩阵；
5. **验证构建**：运行 `npm run build` 确保无编译报错，并通过浏览器走查。
