# 资产录入必填标识

## 目标与现状
明确资产编号、管理 IP 的必填规则；主机名、整机 SN、型号选填。当前新增窗口仅要求主机名或资产编号至少一项，管理 IP 未标必填，导入模板存在说明和星号不一致。检查资产导入识别的 SNMP 行数边界，避免将超过 200 行的实体表误当成完整结果。

## 影响范围及文件边界
前端 AssetManagement 录入、导入预检和下载模板；后端调整模板输出，并让已有“管理 IP 作为临时主机名”规则覆盖服务器导入，避免前端允许留空后后端拒绝。不扩大其它资产 API 必填契约或新增 SN 采集功能。使用 netops-frontend、netops-backend 与 netops-quality-gate 方法。只读审查子 Agent 负责定位既有导入/SNMP 路径；模板执行 Agent 负责 assets.py、静态模板与相关配置测试；主 Agent 负责前端、SNMP回归测试及集成。

## 步骤
1. 确认当前导入、模板和 SNMP 识别链路，区分选填与已支持的自动采集。
2. 新增页面与表格导入清楚标记必填字段并执行一致的前端预检；保留既有凭据、生命周期和厂商平台校验。
3. 更新实际下载的 Excel 模板及回退说明，避免不支持的自动补齐承诺。
4. 运行相关前端测试、类型检查和模板/SNMP 行数边界聚焦测试，记录浏览器与真实设备验证边界。

## 风险与回滚
必填规则限制新录入，不阻塞历史资产编辑。SNMP 失败不能影响手工填写选填字段的能力，不用前 200 行结果推断机箱身份。保留所有既有未提交变更；回滚仅撤销本轮页面/模板改动。
