# 列表工具栏与操作样式统一

## 任务目标
统一共享表格选中与悬停颜色，并逐页复查自动化导航下的列表布局、主操作强调色和创建按钮文案；根据页面反馈减少巡检指标页的重复边框/徽标，并修正资产管理工具栏两端布局。

## 现状与问题
自动化导航包含多种列表和执行页面，之前只统一了资产管理与定时作业工具栏，执行计划、巡检、执行历史、脚本及模板等页面仍有各自的新增入口、青色强调和状态样式。共享表格普通选中底色已调淡，但选中行悬停反馈太弱。巡检指标页统计卡片、筛选胶囊和计数徽标过多；资产管理页右侧控件组被总数标签的自动左外边距挤开，没有整体靠右。用户要求创建按钮文案统一为“新建”、强调色统一为标准蓝，并清理重复的视觉边框。

## 影响范围
- 自动化导航下相关页面（快捷操作、计划、执行历史、巡检、定时作业、指标、TextFSM、脚本、NSOT、场景与 Playbook）的列表布局、主操作、状态徽标和强调色；仅修改与列表统一要求相关的表面。
- `.nx-data-table` 选中行使用浅标准蓝，选中行悬停时提供清晰可见的较深蓝底，并保留柔和的左侧标记。
- 公共 `ListToolbar` 增加可选左侧主操作槽，不传入该槽的页面保持现有布局。
- 公共 `DataTable` 单元格默认不折行，防止缩放后名称、厂商和状态被压成多行；需要折行的单元格显式加 `nx-data-table-cell--wrap`。
- 资产管理和所有适用的自动化列表：左侧放“新建”，搜索、筛选/分类、列设置及其他列表控件靠右；页面宽度不足时允许响应式换行。
- 巡检指标页统计概览压成单行摘要；分类/采集方式改用轻量标签样式，移除重复边框、投影和数字胶囊。
- 创建按钮文案统一为“新建”，自动化列表中的待执行和主强调色统一为标准蓝；成功、失败和风险等语义色按状态保留。

## 实施步骤
1. 调淡共享表格浅色/深色主题选中行及悬停颜色，并弱化左侧标记。
2. 为公共 `ListToolbar` 添加可选左侧操作槽与右侧控件组。
3. 将自动化导航各适用列表的创建入口放入左侧操作槽，统一文案为“新建”；搜索、筛选、分类、列设置等控件靠右。
4. 将自动化列表待执行徽标及主强调色统一为标准蓝，保留成功/失败等语义色，并让选中行 hover 有足够对比度。
5. 移除资产管理工具栏总数标签的 `ml-auto`，让右侧操作组整体向右对齐；保留分页数据总数。
6. 精简巡检指标页统计和筛选层次，保留全部分类、计数、采集方式、平台筛选及清除筛选交互。
7. 在公共表格样式中默认保持单元格单行，并提供显式折行修饰类；检查 NSOT 与现有表格的横向滚动。
8. 保留表单取消和原有数据操作流程，检查全部路由覆盖与差异并记录验证结果。

## 验证计划
- 执行 `npm run lint` 检查 TypeScript。
- 使用独立临时输出目录运行 Vite 生产构建，避免覆盖仓库已有 `dist` 内容。
- 执行 `git diff --check`。
- 不运行测试套件；未覆盖页面的浏览器视觉验收需记录为未执行。

## 风险与回滚思路
共享选中/hover 样式会影响所有带选中属性的 `.nx-data-table`。左侧主操作槽只在有主创建入口的列表显式启用。若布局、颜色或表单取消入口不符合预期，可回退对应页面和公共组件改动；其他 `ListToolbar` 页面默认布局不变。
