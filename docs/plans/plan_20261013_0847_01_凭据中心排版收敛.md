# 凭据中心排版收敛计划

> 创建时间：2026-10-13 08:47（Asia/Shanghai）
> 范围：收敛凭据中心的标题、工具栏和凭据列表宽度

## 1. 目标

改善 `/cmdb/credentials` 在宽屏下横向信息过散、搜索框与操作按钮分离、表格导出入口重复的问题。让页面标题明确指向设备凭据；搜索与新建/导入/导出并入同一操作栏；列表采用受限宽度和明确列比例，设备绑定信息按列宽自然换行。保持凭据数据、搜索、导入导出、绑定管理、编辑删除与权限逻辑不变。

## 2. 现状与证据

- 页面由 `src/pages/CmdbManagementTab.tsx` 的 `credentials` 分支承载。
- PageHero 当前展示通用的 CMDB 标题，凭据列表搜索框出现在单独的 `extras` 行。
- 管理表格铺满可用宽度，浏览器自动分配列宽；设备列获得大量剩余空间，实际设备标签只占其中一部分。
- PageHero 已有完整的凭据导出入口，表格“操作”表头还重复渲染通用导出菜单。
- 当前工作区包含此前对该组件的刷新按钮移除及接口采集完成态处理，需保留这些修改。

## 3. 修改范围

- `src/pages/CmdbManagementTab.tsx`：凭据专属 PageHero 文案/图标、搜索工具栏位置、凭据列表最大宽度和列宽、凭据行紧凑间距、重复导出入口。
- 本计划及对应 walkthrough。

不改后端 API、数据库、凭据值、权限、刷新按钮移除和接口采集任务逻辑。

## 4. 实施步骤

1. 仅在凭据页使用更具体的标题和凭据图标。
2. 将凭据搜索控件放入 PageHero 操作栏，与新建和导入/导出控件并列；其他 CMDB 页继续使用原有搜索布局。
3. 限制凭据列表容器最大宽度，使用固定布局和明确列比例，减少宽屏下的列间空白；保留小屏横向滚动。
4. 移除凭据表头重复的导出菜单；顶部导出入口仍可用。
5. 运行 TypeScript 检查和差异检查，更新 walkthrough。

## 5. 验收标准

- 凭据页标题清楚表达设备访问凭据管理。
- 桌面布局中搜索与主要操作处于同一行，窄屏能够换行且不遮挡。
- 列表在宽屏上不再铺满整块内容区；凭据名称、类型、用户名、角色和关联设备宽度有明确控制，长设备绑定可换行或按需展开。
- 页面只有一个导出入口；导入模板、导入、导出、编辑、删除及设备绑定操作保持可用。
- 其他 CMDB 页行为不变；保留此前已修改的 CMDB 刷新与接口采集逻辑。

## 6. 验证计划

- `npm run lint`（`tsc --noEmit`）和 `git diff --check`。
- 不新增或运行测试；不运行会覆盖工作区现有 `dist/` 的生产构建。
- 使用源码差异和响应式类名检查确认只影响凭据页；部署环境中的视觉效果由用户更新后复核。

## 7. 风险与回滚

- 表格列宽调整可能使特别长的凭据名或设备标签换行；通过截断/提示和设备绑定现有展开机制避免内容丢失。
- 回滚只需恢复本次凭据页 JSX 与样式类；没有数据库或服务端数据迁移。
