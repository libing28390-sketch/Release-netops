# 实施计划：站点总览卡片移除分页

## 任务目标
优化 `/monitor/topology` 的“先看故障域，再进入站点拓扑”站点总览：保留摘要卡片交互，移除站点分页，让所有站点直接可见。

## 现状与问题
站点总览已经采用卡片，但将列表切成每页 20 个，并在卡片下方显示分页控件。用户希望卡片式总览一次呈现，减少翻页操作。

## 影响范围
仅 `TopologySiteOverview` 的前端展示与状态；继续使用既有服务端站点摘要数据、卡片点击进入拓扑、空态和跨站连接摘要，不改拓扑 API 或图布局。

## 拟修改文件
- `src/pages/TopologyPage.tsx`

## 实施步骤
1. 删除站点页码、页大小、切页逻辑和分页组件。
2. 让全部站点直接渲染为卡片；依据站点总数选择居中、限宽或响应式多列栅格。
3. 运行前端类型检查、站点摘要相关单测和生产构建，审查与同文件现有改动的差异。

## 验证计划
- `npm run lint`
- `npm run test:frontend -- --run src/utils/topologySiteOverview.test.ts`
- `npm run build -- --outDir <临时目录>`
- `git diff --check`

## 风险与回滚
站点数量很多时会一次渲染所有摘要卡片；站点总量通常较小，容器保留内部滚动，卡片只含摘要字段。回滚只需恢复 `TopologySiteOverview` 片段。
