# Git 忽略规则补充临时目录与编辑器缓存

## 1. 任务目标
在 `.gitignore` 中完善临时文件与编辑器临时目录的忽略配置，确保 `.tmp/` 目录及其下生成的临时文件（如质量检查生成物、Codex 编辑临时物等）以及 `*.tmp` 临时文件被 Git 正确忽略，防止因误执行 `git add .` 将无关临时内容上传至远程仓库。

## 2. 现状与问题分析
- 当前根目录存在 `.tmp/` 目录（包含 quality-gate-dist 等数百个中间生成文件），在 `git status` 中显示为未跟踪 `?? .tmp/`。
- 现有 `.gitignore` 中配置了 `tmp/` 和 `.codex-tmp/`，但缺少带前导点的 `.tmp/` 以及通配 `*.tmp`。
- Git 规则中，`tmp/` 无法匹配 `.tmp/`，导致 Codex 编辑或质量门禁产生的临时内容暴露在暂存风险中。

## 3. 影响范围
- `.gitignore`
- Git 跟踪状态（`.tmp/` 及其子目录/子文件变更为 ignored）

## 4. 拟修改文件
- [`.gitignore`](file:///d:/nexora/nexora-private/.gitignore)

## 5. 实施步骤
1. 修改 [`.gitignore`](file:///d:/nexora/nexora-private/.gitignore)，在临时文件区域加入 `.tmp/` 与 `*.tmp`，并在 Codex 区域确保除配置文件外的临时输出被忽略。
2. 执行 `git status` 与 `git check-ignore` 验证 `.tmp/` 及其子文件是否已完全被忽略。
3. 产出验证与走查报告 [walkthrough_20260918_1218_01_Git忽略规则补充临时目录与编辑器缓存.md](file:///d:/nexora/nexora-private/docs/walkthrough/walkthrough_20260918_1218_01_Git忽略规则补充临时目录与编辑器缓存.md)。

## 6. 验证计划
- 运行 `git check-ignore -v .tmp/ .tmp/quality-gate-dist/data/geo/districts/CN.json`，确保规则命中 `.gitignore`。
- 运行 `git status --short`，验证 `.tmp/` 不再出现在未跟踪文件列表中。

## 7. 风险与回滚思路
- 风险评估：仅修改 `.gitignore` 补充临时忽略项，不影响现有已追踪的代码与配置。
- 回滚策略：若出现误忽略问题，可通过 `git checkout -- .gitignore` 快速恢复。
