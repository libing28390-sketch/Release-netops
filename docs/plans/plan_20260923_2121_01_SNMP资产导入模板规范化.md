# SNMP 资产导入模板规范化计划

## 目标

让资产导入模板明确表达 SNMP 凭据列接受的内容，并在登录后下载的模板中动态提供凭据中心现有 SNMPv2 凭据下拉项；同步静态模板与前端后备模板。

## 现状与问题

- 实际下载的 XLSX 使用通用列名“SNMP凭据（推荐）”，没有凭据版本说明或环境专属的动态凭据下拉列表。
- 示例数据填入 `snmp-ro`，且普通/特权绑定列含 `user-h3c`、`admin-h3c` 占位名；这些名称在凭据中心不存在时会导致导入失败。
- 前端生成的后备模板也使用同一通用列名，填写说明没有说明必须使用凭据中心中的准确 SNMPv2 凭据名称。
- 当前资产导入契约只支持 SNMPv2；模板应明确说明这一点，并允许留空继续使用资产本地 Community。

## 影响范围

- 受 Operator 鉴权的资产导入模板下载端点，从凭据中心读取 SNMPv2 名称并生成动态 Excel 下拉列表。
- 静态资产导入工作簿中的网络设备表头、示例行及填写说明。
- 前端生成的后备模板和表头别名映射、对应单元测试。

## 实施步骤

1. 检视现有静态工作簿的结构、表头、示例值、格式和填写说明。
2. 将网络设备表头改为清楚标示 SNMPv2 与凭据名称的选填字段，清空示例行中的虚构 SNMP 凭据名，并补充凭据名称校验、占位名处理、社区名处理、SNMPv2 限制及重复资产跳过说明。
3. 增加 Operator 鉴权的动态模板端点，把已有 SNMPv2 凭据名称写入隐藏选项表并通过命名区域提供下拉列表；无凭据时仍返回可用模板。
4. 调整前端优先请求动态模板，失败时保留静态文件和浏览器模板后备；同步后备模板、表头映射和旧列名兼容。
5. 增加动态模板的有凭据与无凭据测试，检查静态及后备模板内容，并运行针对性验证。

## 验证计划

- 使用工作区表格运行时导入、检查并导出修改后的 XLSX；渲染并查看网络设备和填写说明工作表。
- 后端测试验证只有 SNMPv2 凭据名称进入下拉列表，SNMPv3/SSH 名称不进入；无 SNMPv2 凭据时端点仍返回可用模板。
- 重新读取保存后的工作簿，确认工作表顺序、既有下拉校验及其他结构仍在，网络设备 SNMP 示例值为空且填写说明完整。
- 运行 `npm run test:frontend -- --run src/pages/AssetManagement/constants.test.ts src/pages/AssetManagement/importUtils.test.ts` 和 `npm run lint`。
- 将 Vite 构建输出写入临时目录，确认静态模板被原样打包。

## 风险与回滚

- 静态模板本身不含环境专属凭据名单；需要由登录后下载端点按当前凭据中心数据生成下拉列表。
- 保留旧表头别名，避免已有用户模板失效。
- 如需回滚，仅恢复本计划列出的应用文件；保留工作区中与本任务无关的拓扑未提交变更。
