# 移除网络设备新增功能

## 任务目标

从 `/assets/network-devices` 移除“添加设备”入口，并清除只供该入口使用的创建弹窗、提交逻辑和属性传递；保留资产台账的新增资产流程及网络设备编辑能力。

## 现状与问题

网络设备页通过 `setShowAddModal` 打开全局 `DeviceFormModal` 的新增模式。该模式只在此页面入口调用，造成设备创建和资产台账创建路径并存。

## 影响范围

- 网络设备页的顶部操作区与页面属性。
- 首页“添加网络设备”快捷入口的目标路由。
- Inventory context 到网络设备页的新增状态传递。
- 全局设备表单弹窗的新增模式与新增设备提交处理。
- 新增设备专属状态、生命周期确认分支和相关测试。

## 拟修改文件

- `src/pages/InventoryDevicesTab.tsx`
- `src/pages/HomePage.tsx`
- `src/components/AppMainContent.tsx`
- `src/contexts/AppDomainContext.tsx`
- `src/App.tsx`
- `src/components/modals/AppModals.tsx`
- `src/components/DeviceFormModal.tsx`
- `src/hooks/useDeviceFormActions.ts`
- 相关前端测试文件

## 实施步骤

1. 移除网络设备页按钮及 `setShowAddModal` 属性传递，并将首页新增快捷入口指向资产台账。
2. 删除全局新增设备弹窗、hook 中 POST `/api/devices` 的新增处理，以及仅用于新增的表单状态。
3. 将仍用于编辑设备的表单弹窗与生命周期确认收窄为编辑流程。
4. 更新受影响测试并检查代码库中不再存在旧新增设备入口引用。

## 验证计划

- 运行 `DeviceFormModal` 与 `useDeviceFormActions` 相关 Vitest 测试。
- 运行前端 lint / 类型检查和生产构建。
- 浏览器确认 `/assets/network-devices` 不再展示“添加设备”，资产台账的“新增资产”仍可用。
- 运行 `git diff --check`。

## 风险与回滚思路

共享设备新增弹窗将完全移除；编辑流程和资产台账自己的新增资产流程应保持可用。若验证发现编辑流程受到影响，可回滚对应弹窗编辑模式收窄和 hook 状态清理，同时保留移除网络设备页入口的改动。
