# 资产导入进度提示样式调整计划

## 任务目标

优化资产管理页面批量导入期间的提示条，降低高饱和蓝色和整句粗体带来的压迫感，并让进行中的状态更直观。

## 现状与问题

导入状态复用资产页的通用反馈提示。信息态采用亮蓝背景、边框和深蓝粗体，导入时显示信息图标，视觉上较重，状态含义也不够明确。

## 影响范围

仅影响资产管理页的信息提示样式；成功、警告、错误提示及导入接口行为保持不变。

## 拟修改文件

- `src/pages/AssetManagement/index.tsx`
- 本计划及配套 walkthrough 文档

## 实施步骤

1. 将导入提示拆成导入行数主文案和自动显示说明。
2. 为导入中的信息提示使用柔和的中性色背景、较轻的字重和旋转状态图标，并设置礼貌的辅助技术播报语义。
3. 保留其他反馈类型现有颜色和行为，并检查最终差异未覆盖已有资产管理改动。

## 验证计划

- 静态检查 JSX 条件分支和 Tailwind 类名。
- 按用户要求避免运行测试或构建；通过差异审查确认变更范围。

## 风险与回滚思路

风险限于视觉呈现。若样式不符合预期，可仅还原该提示 JSX 区块，不影响导入流程。
