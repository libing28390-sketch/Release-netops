# CI 收集阶段数据库初始化修复计划

## 目标

修复 GitHub Actions 后端 pytest 收集阶段因 telemetry 模块导入时查询 `alert_rules` 而失败的问题，并将修复合入 1.0.8 发布标签。

## 根因

`background_monitor_service.py` 在模块导入末尾调用 `_init_telemetry_state()`；pytest 收集测试模块时数据库 schema fixture 尚未执行，导致 `alert_rules` 不存在。

## 修改与验证

- 移除模块级初始化调用。
- 在 `backend/main.py` 的数据库 `init_db()` 完成后、启动 telemetry loop 前调用初始化。
- 运行模块编译、定向测试和发布合同检查；推送修复提交并更新 `v1.0.8` 标签。
