# 实施计划 - VLAN 清单 UI 视觉重塑与现代化微交互

针对 `/cmdb/vlans` 页面进行全面的视觉重塑与体验优化，提升企业级网络中台与 CMDB 资产资产全景图的现代化美感和专业度。

## 1. 目标与设计规范

1. **KPI 汇总卡片重塑**：
   - 将原先扁平单调的 5 个数据方块重构为具科技感、层次分明的高级玻璃质感（Glassmorphism）统计卡片；
   - 增加主题渐变光条、语义化图标（`Layers`, `Radio`, `Activity`, `Hash`, `AlertCircle`）、大字号 Mono 指标以及状态微标签。
2. **左侧资产分类树优化**：
   - 优化边框、毛玻璃背景、层级缩进引导线与激活态高亮；
   - 修复乱码文案为标准中文 `全部资产`。
3. **VLAN 清单主表格重塑**：
   - VLAN 标头：采用科技蓝紫渐变徽章（Cyan Mono Pill）展现 `VLAN {id}`；
   - 网络与网关列：采用清晰的网段代码卡片（Prefix Code Box）、带状态指示图标的网关设备和 SVI 接口标签；
   - 终端定位列：突出展示终端数量徽章，结构化呈现终端 IP 与 MAC 芯片标签；
   - 业务状态列：优化已关联业务/待补业务的状态芯片，结构化展示部门、负责人与业务等级；
   - 展开明细区：重构为模块化暗调/极简卡片面板，提升 ARP/MAC 终端明细与端口分布的可读性。
