# 机柜站点显示名称修正计划

## 任务目标

让机柜管理列表和机柜视图中的站点标识显示站点名称，特别是默认站点应显示其名称，而不是内部站点代码。

## 现状与证据

- `RackManagement/index.tsx` 的 `siteLabel` 先返回 `site_code`，所以默认站点的内部代码会覆盖可读名称。
- 后端机柜摘要已按站点名称生成 `site_label`；前端列表忽略该优先级，再次按代码优先解析。
- 默认站点记录可同时包含内部代码（如 `default_site`）和供用户识别的 `site_name`。

## 影响范围与修改文件

- 新增机柜站点名称解析 helper 和单元测试。
- 更新 `src/pages/RackManagement/index.tsx` 的站点展示解析。
- 本计划和对应 walkthrough。

## 实施步骤

1. 抽出可测试的站点名称解析函数。
2. 按站点显示名称、机柜 API 返回名称、站点代码、数据中心标签的顺序回退。
3. 列表和依赖 `siteLabel` 的机柜视图统一使用该 helper。
4. 运行目标测试、前端 lint，并在目标机页面复核默认站点显示。

## 验证计划

- `npm run test:frontend -- src/pages/RackManagement/siteLabel.test.ts`。
- `npm run lint`。
- 目标机重新构建/启动 NetOps 后核对机柜站点名称。

## 风险与回滚

- 只改变站点标签的显示优先级，不修改机柜记录、站点关联或筛选数据。
- 若站点名称为空，继续回退到站点代码、数据中心标签或站点 ID。
- 可通过回滚前端 helper 和调用点恢复原显示。
