# IPAM P4-P5 非 VRF 范围推进

## 任务目标

按用户要求继续 IPAM P4、P5 整改，当前先跳过需要创建、确认或迁移 VRF 的工作。推进所有不依赖 VRF 归属决定的代码审查、当前台账证据整理与 P5 逐项验收；不推断 Global/VRF，不修改应用数据库、生产数据库或历史观察快照。

## 现状与问题

- P1-P3 当前实现及聚焦自动化回归已收口；完整 A01-A36 逐项证据映射仍未完成。
- 当前只读基线为 60 条正式 Prefix：5 条已映射到现存 VRF address-space，55 条待确认；26 组跨 WH-DC-01/WH-DC-02 的重复 CIDR仍待人工裁决。
- 用户要求 VRF 先跳过；该要求不等于授权把无 VRF 前缀默认映射到 Global。
- 最近增加的批量地址空间预览目前仅能把待归属 Prefix 一批映射到同一目标，已归属 Prefix 和重复 CIDR 会整体阻断。
- A31 首轮路由审查确认，Prefix/IP 库列表、候选、聚合、地址空间目标预览和部分建议读取缺少完整对象授权范围。主要非 VRF 后端路径已修复并加入隔离回归；浏览器导出和完整角色/动作矩阵仍待验收。
