# 设备与接口看板参考样式计划

## 任务目标

参考用户提供的 Grafana 图片，改善 Nexora 设备详情与接口流量看板的可读性和热点定位效率；新增面板必须使用当前采集链路实际提供、语义明确的指标。

## 现状与问题

- 02 网络设备详情已有 CPU、内存、温度统计卡和趋势，但统计卡用文字数字呈现，不够直观；设备详情还有端口状态和接口流量趋势。
- 04 接口流量与健康已有接口流量趋势、当前/峰值/P95 利用率表、配置带宽表和利用率 Top20 表格仪表；缺少直观看当前入向/出向速率热点的排行视图。
- 当前 Grafana datasource 是 VictoriaMetrics。光模块收发光功率目前由设备 CLI/TextFSM 采集并存入业务数据库，SNMP exporter 没有 Rx/Tx 光功率指标。
- 已核对 LibreNMS 的 `resources/definitions/os_discovery/comware.yaml`：当前 Comware 传感器定义包含风扇、电源等，但没有 H3C 光模块 Rx/Tx 功率发现配置。H3C 厂商 MIB 确实定义了相关 OID，但不满足“LibreNMS 已有对应 MIB/OID 才接入”的门槛；因此本次不添加 SNMP 光模块指标或 Grafana 光模块面板，也不改用 CLI 路径。
- H3C SNMP 有 Flash 总容量/空闲容量和实体 MAC 数量指标，但 MAC 数量没有可用于全设备表项使用率的可靠统一分母；不把计数伪装成利用率，也不把 H3C 专有数据混成通用设备指标。
- 工作树已有 `handoff.md`、Linux 图例及 01 总览硬件覆盖/链路筛选变更；生成器会重写 9 份 JSON，需保留并确认本次预期只增改相关文件。

## 影响范围

- 02 网络设备详情：将选定设备 CPU、内存当前值改为 Gauge，并保留温度统计和趋势/接口状态；明确 Gauge 表示多实体采样中的设备最大值，避免平均值掩盖热点。温度卡使用中性呈现，不对不同厂商套用同一阈值。
- 04 接口流量与健康：增加过去 5 分钟平均入向、出向接口速率 Top10 横向 Bar gauge，以 `rate()` 后的 IF-MIB 速率排序；保留现有利用率表格仪表，因为它同时提供接口身份、阈值和详情跳转。普通速率数据不做 Heatmap。
- 暂不新增光模块 SNMP/CLI 指标与面板；不把 H3C MAC 项数展示为使用率。
- 不触碰运行中 Grafana provisioning、真实设备或采集配置，不改变既有 01/07 看板变更。

## 实施步骤

1. 使用设备筛选后的最大 CPU/内存指标值配置 Gauge，明确 `0–100%` 范围和无数据文案。
2. 为 04 看板增加即时查询的入向/出向 Top10 Bar gauge，保留站点、设备、接口名称标签并配置 bps 单位和方向色。
3. 在对应设备/接口区段放置新面板，调整网格位置并检查无重叠。
4. 根据 LibreNMS 当前 Comware 发现定义核对光模块支持情况，暂缓引入未被其现行定义采用的 H3C 专有光模块 OID。
5. 运行生成器、Python 编译、全部 JSON 结构与面板位置验证、PromQL/数据源配置审阅及 `git diff --check`。

## 验证计划

- `python monitoring/grafana/generate_dashboards.py`

- 解析全部 dashboard JSON，检查唯一 panel ID、网格不重叠、目标 datasource UID、Gauge/Bargauge 单位/界限/即时查询。
- 检查新流量排行使用 `rate()` 后再乘 8，方向筛选保留 `ifName`，PromQL 标签与 exporter IF-MIB 定义一致。

- 运行中的 Grafana 仅进行只读核验；源码生成的 JSON 不部署，故不以当前页面状态冒充本次改动已上线。

## 风险与回滚思路

- 部分厂商/设备可能没有 CPU、内存或带宽速率指标，Grafana 应继续显示“数据暂不可用”，不能用零值伪造正常状态。
- 设备 CPU/内存按最大实体采样呈现会突出热点组件，不等于整机平均负载；说明中明确此含义。
- Bar gauge 只呈现当前采样时刻 Top10，历史变化仍看流量趋势；利用率继续用接口表格仪表并保留配置阈值上下文。
- LibreNMS 的当前 Comware 定义未接入 H3C 收发光 OID；只有后续 LibreNMS 定义或项目指标采集契约确认支持后，才考虑加入统一 SNMP 展示。
- 回滚时恢复 02 原 CPU/内存统计卡配置与 04 原面板布局，再运行生成器。

## 实施结果

- 已完成 02 Gauge 和 04 双向速率 Top10 的源文件修改与 JSON 生成。
- 运行中的 Grafana 仍显示旧面板，需由后续部署/重载流程应用生成物；本任务未写入或部署运行实例。
- 光模块 SNMP 未接入：LibreNMS 的当前 Comware 发现定义不含 H3C 收发光项，标准 `mibs/h3c` 目标路径下也未找到该 MIB。虽然 H3C 厂商 MIB 有定义，本次遵从“LibreNMS 无对应项则暂不添加”的要求。
