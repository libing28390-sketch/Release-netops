# 快捷操作设备列表留白

## 目标与现状

用户在 `http://192.168.56.1:5400/automation/quick-ops` 截图中看到列表底部留白过大。截图视口约为 1920×928，设备页显示 10 行（总计221台、23页）；表格内容结束后至分页栏之间约有3行高度的空白。

源码调用链为 `/automation/quick-ops` → `AutomationExecuteTab` → `DeviceSelectionStep`。右侧列表使用 `flex-1 min-h-0 overflow-auto` 填满可用高度，分页栏固定在列表区域下方。设备页大小应继续固定为10；完整10行时将表格包裹容器和表格本身撑满列表区域，让浏览器把多余高度分配给现有数据行，消除表格末行到分页栏之间的空白。少于10行时保持原有自然行高，避免少量结果被拉伸。

## 影响范围

- 仅在快捷操作列表完整显示10行时让现有表格行填充可用列表区域；保留页面结构、分页大小、筛选和底部操作栏。
- 修改 `src/pages/AutomationExecute/components/DeviceSelectionStep.tsx`，只对完整10行列表启用表格填充。
- 修改 `src/index.css` 增加该表格自身导出包装层的作用域高度规则，不改共享布局或全局表格样式。
- 保留设备接口分页契约、筛选/选择逻辑、分页组件、底部操作栏与移动视口内部滚动。
- 不调整共享布局组件、不改后端接口或数据库。

## 实施步骤

1. 保持快捷操作设备页大小为10，在完整页的表格容器、导出包装层和表格上启用满高样式。
2. 在浏览器确认数据行填充列表区域、没有行截断或新增滚动，分页、底部操作栏位置保持不变。
3. 运行 TypeScript 检查、隔离 Vite 构建和差异格式检查。

## 验证计划

- `npm run lint`
- 使用 `%TEMP%` 下独立目录运行 Vite production build，避免覆盖已有 `dist`。
- `git diff --check`
- 浏览器对照用户截图；若本地页面服务不可用，记录该限制并以源代码布局与构建结果说明。

## 风险与回滚

- 增高的是完整页的现有表格行，设备每页数量和分页语义不变；少于10行不做拉伸，视口低于表格最小内容高度时仍由现有列表滚动容器承接。
- 回滚时移除包裹容器和表格的 `h-full` 样式即可。
