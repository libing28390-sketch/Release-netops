# TextFSM 文件名列换行

## 目标与现状

TextFSM 模板列表在100%缩放时，较长文件名伸出“文件名”列并覆盖“厂商”列。该单元格有断词类，但共享 `.nx-data-table tbody td` 的 `white-space: nowrap` 优先级更高，导致实际仍不换行。

## 影响范围

- 仅修改 `src/pages/TextFSMTemplatesTab.tsx` 的文件名单元格，启用已有 `nx-data-table-cell--wrap` 换行约定。
- 保留表格列宽、排序、分页、导出、筛选和其他列行为。
- 不修改共享表格样式，避免影响其他页面。

## 实施步骤

1. 在文件名单元格增加已有换行类，使全局 nowrap 规则不再覆盖该列。
2. 在用户截图相同的100%缩放/窗口尺寸复核长文件名与厂商列不重叠。
3. 运行 TypeScript 检查、隔离 Vite 构建和差异格式检查。

## 验证计划

- 浏览器复核 TextFSM 页面100%缩放下文件名换行、首两列可读性和横向滚动。
- `npm run lint`
- 在 `%TEMP%` 独立目录执行 Vite production build。
- `git diff --check`

## 风险与回滚

- 换行会让特别长的文件名占用多行；其余列和表格宽度不变。
- 回滚时移除文件名单元格的换行类即可。
