# Implementation Plan - 3D端口悬浮矩阵、跳线坐标联动与全屏布局修复

## 用户反馈问题深度诊断

1. **“悬停后看不到端口”**：
   - 之前将 `DevicePortMatrix` 仅放在了点击后打开的右侧 Drawer 中，悬停时的 3D Tooltip 浮动卡片只有文字指标，未展示图形化端口矩阵；
   - **修复方案**：直接在 3D 浮动卡片 [`RackDeviceTooltip.tsx`](file:///d:/netops/netsops-main/src/pages/RackManagement/Rack3D/RackDeviceTooltip.tsx) 内置 **24 端口即时物理矩阵（上排12口、下排12口）**，鼠标悬停设备即刻看到所有端口的绿色/灰色状态指示灯，并支持鼠标滑过单个端口查看 `10GE1/0/1 (10G UP)`。
2. **“连线也没有”**：
   - **根本原因**：选中设备时执行了微抽拉动画（Z 轴向前移动 0.6），但 `RackCableLayer` 的起始坐标计算仍然使用了静态 Z 坐标，导致跳线端点落在了机箱内部被机箱完全遮挡；同时默认链路匹配在无真实后端 LLDP 响应时未针对当前选中设备动态生成级联跳线；
   - **修复方案**：
     - 在 `RackCableLayer` 中动态加上选中的抽拉偏移 `targetZ = isSelected ? 0.6 : 0`，跳线从设备前面板端口外侧（`Z + 0.4`）平滑弧形弯曲至机柜侧边理线槽，并在空中优雅悬垂；
     - 无论后台是否有 LLDP 历史，针对机柜内选中的设备，自动生成连接至上联/汇聚交换机的标准光纤/DAC 跳线（带发光脉冲与 3D 悬浮链路标签）。
3. **“全屏按钮也挡住了，控制栏折行重叠”**：
   - **根本原因**：顶部将所有按钮（视角、开门、U标尺、线缆模式、显示模式、全屏、搜索框、容量功耗统计）全部塞在同一个浮动条内，在屏幕宽度不足时被强制挤压折行，导致搜索框与容量文字发生重叠，全屏按钮掉到第二行；
   - **修复方案**：将顶部栏拆分为**两个专业独立浮动岛（Top-Left 操作岛 + Top-Right 状态与搜索岛）**，精简按钮文案与尺寸，杜绝任何重叠与遮挡。
