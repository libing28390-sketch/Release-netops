# Plan: Nexora RAG 统一中间格式 (Normalized Markdown) 与智能解析管道重构

## 任务目标
将知识库解析层升级为 **统一中间格式 (Normalized Markdown + Metadata JSON)** 架构。实现任意原始文档 (PDF/DOCX/HTML/CHM/TXT/MD) 先标准化转换为 Markdown 与结构化 JSON，再基于 Heading 标题与命令语法树进行智能切片 (Smart Chunking)。

---

## 核心架构要点

### 1. 统一中间格式管道 (Normalized Middle Format Architecture)
```text
原始文件 (PDF/DOCX/HTML/CHM/TXT/MD)
      │
      ▼
Document Parser 解析转换
      │
      ▼
标准化中间格式 (Normalized Markdown + Metadata JSON)
      │
      ▼
Heading & Command-Aware 智能切片 (Smart Chunking)
      │
      ▼
Embedding 向量化 + 全文索引 (FTS)
```

### 2. 后端数据持久化扩展 (`knowledge_service.py`)
- 支持 `normalized_content` 字段存储转换后的标准 Markdown 正文。
- 采用 Heading / 命令块感知的 `smart_chunk_markdown()` 函数：
  优先按 Markdown 标题 (`#`, `##`, `###`) 与 CLI 代码块进行完整结构切片，确保命令描述、参数语法、回显示例与故障建议完整保留在单个 Chunk 中。

### 3. 前端 UI 格式优先级指南与管道可视化 ([KnowledgeManagementTab.tsx](file:///d:/nexora/nexora-private/src/pages/ai/Knowledge/KnowledgeManagementTab.tsx))
- **格式优先级提示 Badge**：
  - 🟢 **最佳**：Markdown (`.md`), HTML (`.html`), TXT (`.txt`), JSON (`.json`)
  - 🟢 **推荐**：DOCX (`.docx`), CSV/XLSX (`.csv`, `.xlsx`)
  - 🟡 **支持**：文本型 PDF (`.pdf`), CHM (`.chm`)
  - 🔴 **不推荐**：扫描型 PDF / 图片 (提示字符混淆风险)
- **标准化管道 Stepper**：
  展示 `✓ 原始文件解包 → ✓ 标准化转码 Markdown → ✓ Heading/CLI 结构识别 → ✓ Metadata 提取 → ✓ Smart Chunking → ✓ Embedding 向量化`
