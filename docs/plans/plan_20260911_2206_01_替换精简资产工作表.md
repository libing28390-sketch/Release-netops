# 替换精简资产工作表计划

## 任务目标

使用用户提供的 `资产导入模板_精简修正版.xlsx` 中“网络设备”和“服务器”两张工作表替换当前模板对应工作表，保持其它工作表内容不变；在这两张表上恢复可用的厂商→平台下拉，并保留红色 `*` 必填标记。

## 现状/问题

- 当前模板资产表头仍沿用上一版完整字段，与用户指定的精简表头不一致。
- 厂商/平台校验公式依赖 `Vendor_*`、`Platform_*` 命名区域，但当前下载文件的工作簿定义名称已丢失，Excel 无法展开下拉。
- 拆分后的网络设备/服务器列位不同，旧版统一资产表的生命周期、功能、区域、端口和 U 高度校验仍指向旧列。
- 管理入口已由公式自动带出资产编号和主机名，不能因替换资产表而失效。
- 预铺 2000 行公式/校验使空白区域被 Excel 视为已使用，需要清理显示范围。

## 影响范围

仅修改静态模板的两张资产工作表和前端兜底模板的对应定义；不改管理入口、说明、参数参考、下拉选项或数据库数据。

## 拟修改文件

- `public/templates/asset_import_template.xlsx`：复制用户附件的两张资产表内容与样式，补平台校验及红色必填标记。
- `src/pages/AssetManagement/index.tsx`：让兜底模板使用同样的网络设备/服务器表头契约。
- `src/pages/AssetManagement/importUtils.ts`、`importUtils.test.ts`：保持表头和旧模板解析兼容，补必要回归测试。
- `docs/walkthrough/`：记录替换范围和验证证据。

## 实施步骤

1. 只读渲染并读取用户两张资产表，记录表头、样式和校验范围。
2. 从当前静态模板复制其它工作表，从用户附件复制网络设备/服务器工作表。
3. 在两张资产表的厂商和平台列设置基于当前“下拉选项”工作表及 46 个命名区域的动态校验；网络设备固定走网络厂商/平台，服务器固定走服务器厂商/平台，并追加红色 `*` 到必填表头。
4. 按两张精简表的实际列位重建生命周期、功能、区域、SNMP 端口和 U 高度校验，避免校验落到备注或密码列。
5. 删除资产表和管理入口的空白预铺行，只保留必要示例和联动行，避免模板出现 2000 行空数据。
6. 检查管理入口 A/B 公式仍引用两张资产表的 B/C 列，验证旧版思科工作簿导入兼容。

## 验证计划

- `npm run test:frontend -- --run src/pages/AssetManagement/importUtils.test.ts`
- `npm run lint`
- `npm run build`
- 对比替换前后其它工作表内容和表头
- 检查两张资产表的厂商/平台校验公式、命名区域、红色星号和管理入口公式缓存
- 对比用户上传的 `(7)` 与修复副本，确认除 `workbook.xml` 和两张资产表校验 XML 外其它工作簿部件未改变

## 风险与回滚思路

用户附件的两张资产表作为模板来源，可能包含历史示例数据；仅复制表格结构与示例，不读取或输出敏感凭据。其它工作表保留当前版本。若验证失败，可恢复替换前的静态 XLSX，不影响源附件和数据库。
