# 实施计划 - 个人设置 UI 双栏布局与视觉体验重塑

重构 Nexora NetOps 的个人设置弹窗 ([ProfileModal.tsx](file:///d:/nexora/nexora-private/src/components/ProfileModal.tsx))，消除重复横幅套娃问题，升级为现代中后台经典的“左侧身份名片与导航 + 右侧独立设置面板”双栏架构，提升视觉质感与操作体验。

## 1. 目标与现状问题

### 现状问题：
1. **多重横幅冗余**：顶部标题、右上角 Badge、步骤条、蓝色提示栏和卡片连续 4 次出现“基本资料/头像”，占用过多垂直空间。
2. **向导式设计不匹配设置心智**：线性数字向导（1->2->3->4）给用户造成必须按部就班的误导，而非按需切换设置项。
3. **头像选择器排版失衡**：12 个预设头像采用 5 列排布导致末行孤立留白（5+5+2），缺少卡片收纳与动效。
4. **只读字段与可编辑表单混杂**：用户名、角色与姓名/手机/邮箱平铺排布，缺乏身份归属感。

### 优化目标：
- 采用 **Master-Detail 双栏结构**：左侧展示身份名片与纵向功能 Tab；右侧专注呈现对应表单。
- 预设头像优化为 **6 列 × 2 行** 对称排列，增加 Cyan 选中呼吸环与悬浮动效。
- 表单输入框增加语义化图标前缀（`UserRound`, `Phone`, `Mail`, `Lock`）与现代 Focus 光晕。
- 保留并无缝兼容所有既有业务逻辑（密码修改校验、MFA 二次认证流程、固定 PIN、告警渠道 Webhook、终端 Agent/客户端配置）。

## 3. 实施步骤

1. **结构重塑**：
   - 移除原有多层级提示条与横向数字向导，替换为左侧侧边栏（个人卡片 + 4 个功能 Tab）与右侧主内容区。
2. **Tab 1: 基本资料重构**：
   - 个性头像卡片：当前头像 + 上传/重置按钮 + 6x2 对称预设网格（带选中呼吸环与悬浮动效）。
   - 联系方式卡片：真实姓名、手机号、邮箱带图标前缀与 Focus 光晕。
3. **Tab 2: 登录安全重构**：
   - 密码修改卡片（当前密码、新密码、确认新密码及实时一致性校验）。
   - 管理员特权固定 PIN 码卡片（保持现有权限逻辑）。
   - MFA 双因子认证卡片（未启用引导、扫码绑定 TOTP、已启用状态与密码验证关闭）。
4. **Tab 3: 告警通知重构**：
   - 飞书、钉钉、企业微信机器人渠道卡片，支持 Webhook、密钥输入、测试发送与权限隔离。
5. **Tab 4: 终端工具重构**：
   - 自动识别当前工作站操作系统（Windows / Ubuntu）。
   - Windows 终端程序选择（Xshell / PuTTY / SecureCRT / MobaXterm）与路径下拉预设。
   - Terminal Agent 下载卡片。
6. **质量验证**：
   - 运行 TypeScript 类型检查 (`npm run lint`)。
   - 验证明亮模式（Light）与暗黑模式（Dark）下的对比度、边框与文本可读性。
