# IPAM 共用工作流面板移除计划

## 任务目标

从 IPAM 的所有子菜单中移除顶部重复出现的“CMDB / IPAM 企业工作流”面板，并清理不再使用的面板组件。

## 现状与问题

- `IPAMManagementTab` 在渲染具体子页面前统一挂载 `EnterpriseWorkflowPanel`，所以 Prefix、IP 地址、地址池、VIP、DHCP、利用率、对账页面都会出现该面板。
- 面板折叠状态下仍会初始化 CMDB、IPAM 和对账 hooks；截图中展开后还出现了 `Not Found` 错误。
- 各 IPAM 子菜单本身已有独立页面和操作，不需要在每页重复展示该工作流。

## 影响范围

- 仅移除 IPAM 共用页面壳中的工作流面板，以及面板文件本身。
- 保留 IPAM 所有子页面、路由、侧栏导航、API 和独立业务能力。

## 拟修改文件

- `src/pages/IPAMManagementTab.tsx`
- 删除 `src/pages/IPVlan/components/EnterpriseWorkflowPanel.tsx`
- `docs/walkthrough/walkthrough_20261010_1120_01_IPAM共用工作流面板移除.md`

## 实施步骤

1. 从 IPAM 共用页面壳移除面板 import 和 JSX。
2. 确认没有其他使用者后删除工作流组件文件。
3. 运行 TypeScript lint，确认共用入口的类型和 JSX 正常；该修改不变更路由或构建配置，不生成新的构建产物。

## 验证计划

- `rg` 确认组件和标题不再被引用。
- `npm run lint`。
- 检查最终差异及 `git diff --check`。

## 风险与回滚思路

- 移除该组件会让其中的站点初始化、快速分配、对账处置与资产投产入口不再从 IPAM 通用顶栏访问；这些功能有独立 IPAM/CMDB 页面或流程，用户明确要求不在各子菜单重复显示。
- 若后续需要其中某个业务流程，应以独立页面或明确入口重新设计，不恢复全子菜单通用面板。
- 回滚时恢复共用入口引用和组件文件即可；不涉及后端或数据变更。
