# 任务目标

继续打磨 `/cmdb/racks` 的 3D 机柜孪生视图，使设备状态灯、端口灯和机柜细节更接近真实网络设备，同时保持现有 CMDB 与监控数据契约不变。

# 现状/问题

- 当前 3D 视图能展示设备堆叠和基础状态，但设备前面板的电源/告警/链路指示不够真实，端口区域缺少清晰的逐端口灯效与层次。
- 选中设备后的视觉重点需要与 Inspector、拉出观察状态协调，避免灯效被遮挡或状态语义冲突。
- 复核发现数据库已有匹配的 LLDP `topology_observations`，但兼容 `topology_links` 读模型可能暂时为空；同时聚合链路父接口名不能直接作为物理端口坐标。
- Windows WatchFiles 会监测 `backend/tests`，测试文件变更可能触发 Uvicorn 在 PostgreSQL 初始化期间重启。

# 影响范围

- 前端 3D 机柜渲染组件、设备面板与端口可视化样式。
- 前端展示层、拓扑链路归一化与后端只读拓扑读模型回退；不修改数据库结构、不执行真实设备配置变更。

# 拟修改文件

- 先定位 `src` 中 `/cmdb/racks` 路由及 3D 机柜组件；只修改与该视图直接相关的 TSX/CSS/类型文件。
- 如需新增纯展示 helper，放在现有机柜领域目录内，避免引入新的 UI 框架或状态库。
- `backend/api/topology.py`、`backend/services/topology_service.py` 负责 LLDP 物理链路回退与接口运行态合并；`backend/main.py` 仅调整开发重载排除目录。

# 实施步骤

1. 追踪路由、3D 视口、设备模型、端口/状态数据和样式调用链。
2. 设计并实现与真实交换机面板一致的灯效层：系统/电源/告警灯、端口链路灯、暗态与可辨识的常亮/闪烁节奏。
3. 将已验证 LLDP 聚合链路展开为物理成员端点；优先使用接口 `oper_status` 为线缆和聚合成员着色，缺少证据时保持未知态。
4. 去除机柜 3D 默认伪造预览线，修正选中设备近景与 Inspector 改变尺寸时的镜头抢占。
5. 在浏览器验证正面、45°、选中设备、拉出观察和 Inspector 同时打开时的可读性。

# 本轮补充（线路可辨识度）

- 目标：在不引入彩虹色和大面积标签的前提下，区分同一机柜中的多条 LLDP/LAG 线路。
- 方案：保留介质色（光纤青色、铜缆黄色），为同一端点组建立确定性的微型线束通道偏移；LAG 成员以轻量分层呈现并显示 `LAG n/m`；悬停时增强目标线、压低其余线路；近景标签使用短接口名并避免裁切。
- 验收：全线视图不出现不可辨识的同色重叠；选中设备可看出成员顺序；不影响端口精准落点和 LLDP 状态。
- 追加问题：修正 S6800 族原生 `XGE/FGE/FortyGigE` 端口号被错误截断为 48 的坐标归一化，并加入 49/53/54 分离回归测试。
- 追加问题：QSFP 源 GLB 的实心 cage/slot/lane 叠层在前端读作保护盖，且公共线束曾穿过端口排；改为保留标签/anchor、叠加开放式 QSFP 组件，并把公共水平段下移到面板 clearance 之外。
- 追加问题：已插入模块仍缺少“线缆进入 receptacle”的连续视觉；端点前移到模块面，增加窄型 boot/应力释放，并按 S6800/S6850 资产端口布局将无显式介质的 1–48 号 SFP 识别为光纤。
- 追加问题：SFP 光纤端点需要与双 LC 孔一一对应；在单 boot 之后拆出两根并行纤芯，铜缆/DAC 保持单端点形状。
- 追加问题：近景跨 U 位链路的下落过渡仍在设备前平面；将过渡点和公共水平段切到面板后方深度，并降低光纤线径，保留端口短引可见。
- 追加问题：全线视图中公共汇线槽贴在前立柱内侧，远端设备的线路会被立柱深度挡掉；将槽位移到立柱外侧（`trunkX≈-2.72`），并在设备边框下沿保留 `0.10` 间隙。机柜顶盖/状态条仅关闭深度写入，确保 U41/U42 设备和端点可见。

# 风险与回滚思路

- 风险主要是 Canvas/WebGL 渲染性能、不同视口下灯效重叠和遥测未知态被误读。
- 保留现有数据映射和组件边界；如视觉效果退化，可按文件级 diff 回退新增灯效层，不触及 CMDB 数据。
