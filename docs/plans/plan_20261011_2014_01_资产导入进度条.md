# 资产导入提示增加进度指示

## 任务目标

在资产批量导入提示中增加清晰的进度视觉反馈，让用户知道导入仍在进行。

## 现状与问题

导入提示目前展示“正在导入 N 行”和辅助说明，但没有进度视觉元素。后端按行提交数据，不过 HTTP 导入接口只在整批结束后返回汇总结果；前端定时刷新列表只能刷新当前筛选结果，不能可靠地作为整批进度百分比。

## 影响范围

只调整资产管理导入中的提示 UI，不改变导入请求、逐行提交或 SNMP 后台处理行为。

## 拟修改文件

- `src/pages/AssetManagement/index.tsx`
- 本计划及配套 walkthrough 文档

## 实施步骤

1. 在导入进行中状态的提示内加入无百分比的动画进度条。
2. 保持现有导入文案、辅助说明和结束结果通知；按明暗主题适配。
3. 检查 JSX 和差异，确认非导入通知不显示进度条。

## 验证计划

- 静态检查导入进度 UI 的条件渲染、无障碍状态和主题样式。
- 不运行测试或构建；除非用户要求，不对 221 台设备重新执行导入。

## 风险与回滚思路

进度条只表达任务仍在进行，不显示虚假的百分比或行数。若动画影响现有通知布局，可移除进度条元素而保留现有状态文案。
