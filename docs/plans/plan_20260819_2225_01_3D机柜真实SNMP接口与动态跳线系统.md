# Implementation Plan - 3D机柜真实SNMP接口遥测与动态3D跳线追踪系统

## 用户需求与目标

1. **真实 SNMP 接口状态与矩阵**：
   - 彻底打破以往 3D 界面“只有纯贴图外观”的局限，联动后端 `IF-MIB` 真实接口遥测（`/api/devices/{id}/interfaces` 与 `/api/topology/links`）；
   - 在设备详情抽屉与 3D 悬浮面板中提供真实的 24/48 端口矩阵，展示真实物理端口状态（Up/Down）、协商速率、实时进出流量以及 LLDP 邻居对端。
2. **机柜内/跨设备动态 3D 真实跳线追踪 (Dynamic 3D Cable Routing)**：
   - 基于网络拓扑链路数据，在 3D 空间中真实生成机柜垂直理线槽走线的 **3D 贝塞尔曲线跳线管（CatmullRomCurve3 TubeGeometry）**；
   - 支持光纤（湖蓝/橙色）、DAC 高速铜缆（深灰带橙色拉手）、Cat6 网线（深蓝）；
   - 支持 3 种线缆模式：`[ 选中按需点亮 (推荐) | 全部走线 | 隐藏线缆 ]`；
   - 选中设备时，跳线发光并悬浮展示链路详情标牌：`10GE1/0/1 ⇄ 10GE1/0/24 (10G DAC · UP)`。
