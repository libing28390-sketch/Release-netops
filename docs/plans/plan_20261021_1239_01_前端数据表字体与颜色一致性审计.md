# 前端数据表字体与颜色一致性审计

- 创建时间：2026-10-21 12:39（工作区时区）
- 状态：全站普通业务表格已对齐资产管理表格基准，NSOT 标签填充样式、浏览器复核与最终质量门禁均已完成

## 目标

以 `/assets/dashboard` 的资产表作为全站数据表视觉基准，统一表格字体、字号层次和中性文本颜色；保留语义状态颜色，并修整用户指出的 `/automation/nsot`。

## 现状与审计结论

- Nexora 共享规则已将大多数业务表格正文设为 13px、表头 12px；紧凑表格正文 12px、表头 11px，浅色/深色主题使用语义色变量。直接写在 `td`/`th` 上的部分小字号会被共享规则覆盖。
- 实际字号异常主要出现在单元格内部嵌套文本、状态徽标和几个页面自建控件：NSOT 目录说明与 ID、巡检项目录字段、IPAM 利用率/徽标、WAN 专线辅助信息及跨页关键状态徽标。
- 静态清点 `src/` 中 64 个非测试 TSX 表格标记来源（含共享封装和业务页面），覆盖 `/monitor/*`、`/access/*`、`/alerts/*`、`/assets/*`、`/cmdb/*`、`/ipam/*`、`/automation/*`、配置、工单、管理和 AI 页面；终端/命令输出类表格不套用普通业务表格字级结论。

## 影响范围

- 修改 `src/pages/NSOTCollectionOperations.tsx` 与 `src/pages/NSOTCollectionOperations.test.tsx`：改进表头、主数据/辅助信息字号和主题色，为表格加可访问名称，缩小不必要的最小宽度。
- 修改 `src/pages/InspectionItemsTab.tsx`、`src/pages/IPVlan/index.tsx`、`src/pages/IPVlan/IPPoolTab.tsx`、`src/components/wan-circuits/WanCircuitTable.tsx`：修正被审计确认的小字号普通业务值和关键徽标。
- 修改告警桌面/历史/规则/维护、巡检记录、网络监控、执行详情、PAM 审计和定时作业中的关键状态徽标；统一至少 11px。
- 不改变 API、数据契约、列语义、筛选、分页、权限、危险操作或数据导出范围；不做无差别的全站字号覆盖。

## 实施步骤

1. 盘点共享 `DataTable` 与原生表格样式来源，完成 64 个业务表格 TSX 来源的静态审查并区分终端/命令输出例外。
2. 以资产表的正文 13px、表头 12px、主标识 12px 加粗、圆角状态标签 10px 为标准；NSOT 使用共享表格基线，取消偏离该基线的局部字号覆盖。
3. 在所有普通业务表格中统一圆角状态标签的字级，同时保留厂商/状态等已有语义前景色；终端和命令输出表格继续例外。
4. 运行受影响页面测试、TypeScript 检查、隔离生产构建和差异检查；在浏览器对比资产表与 NSOT 实际效果。

## 验证计划

- 聚焦运行 NSOT、日期时间选择器、告警桌面、定时作业、WAN 专线和 IPAM 相关前端测试。
- `npm run lint`
- 新建隔离构建目录运行 `npx vite build --outDir <fresh-validation-dir>`
- `git diff --check`
- 分开记录自动化验证和浏览器目视验证；未触达的其他页面只报告源码审计，不声称逐页浏览器验收。

## 风险与回滚思路

调整嵌套文字可能改变少数字段的换行或表格宽度；NSOT 表格继续保留容器内横向滚动，长值保留 title 可查看完整内容。若布局密度退化，可逐页回退本轮样式类，不改变数据契约与操作流程。
