- **归档目录**：`docs/plans/`

## 1. 任务目标

1. **官方预置模板在主列表中直接展示**：
   - 在 `/management/snmp-metric-templates` 模板管理主列表中集成展示官方主流预置模板库（Cisco、Huawei、H3C、Arista、Ruijie、Juniper、Fortinet 等）；
   - 提供直观的 Tab 切换（【全部模板】/【自定义型号模板】/【官方预置模板库】）或状态过滤，使运维人员无需打开弹窗即可总览所有内置预置。
2. **支持“一键复制并自定义”（Clone / Duplicate & Edit）**：
   - **对官方预置**：提供“📋 复制并自定义”按钮，点击后直接将该预置的所有 OID、公式、高级参数及 17 项接口流量配置完整载入编辑面板，用户仅需微调型号名或参数即可一键保存为正式自定义模板。
   - **对自定义模板**：在操作列增加“📋 复制”按钮，便于运维人员将已调优好的型号模板（如 `S5700-28P`）一键克隆并修改为相近型号（如 `S5700-52P`），极大降低重复配置成本。

## 3. 实施步骤

1. **模板列表 Tab 与数据融合**：
   - 在 `MetricOidProfilesModal.tsx` 中同时获取已保存的型号模板与官方预置模板库；
   - 在 `MetricProfileList.tsx` 顶部提供快速 Tab 分组，并在列表清晰标识【官方预置】与【自定义型号】。
2. **一键复制（Clone）功能实现**：
   - 实现 `onCloneProfile(profile)`：读取已有自定义模板，深拷贝 OID/计算规则/接口配置，将型号名称设为 `${profile.model} (副本)` 或原名，打开编辑器，用户一键保存即可新增；
   - 实现 `onClonePreset(preset)`：读取官方预置模板，将指标/接口配置全部映射到编辑表单，自动填入厂商与型号，用户可直接保存或微调后保存。
3. **类型检查与测试覆盖**：
   - 增加关于克隆和预置列表融合的单元测试；
   - 运行 `npx tsc --noEmit` 和 `npx vitest run src/components/SnmpMib/` 验证。
