# 维护期创建与列表视觉优化

## 目标
重新组织维护期创建弹窗和已创建维护窗列表，提高层级、空间效率及状态/范围可读性；保留所有 API、校验、筛选、取消/删除确认和中英文行为。

## 现状与范围
用户反馈首轮版式与告警区其他页面不一致，并明确要求使用公共组件。对照 `AlertDeskTab` 与组件地图后，维护期列表和弹窗统一复用告警区页面骨架、表单组件及设计 token。

## 实施步骤
1. 对照给定截图、当前组件和现有维护期结果状态，整理创建流程与信息优先级。
2. 改善表单弹窗尺寸与分组：模式、范围、维护时间、原因、联系人、持久操作栏；让移动端滚动可用。
3. 改善结果列表中的名称、范围摘要、时间区间、状态和操作列；保留分页/搜索/筛选及行详情入口。
4. 保留行为契约，做本地浏览器视觉检查；按指令限制不运行自动化测试或构建。

## 影响文件
- src/pages/AlertMaintenanceTab.tsx
- docs/plans 与对应 docs/walkthrough 记录

## 实施与验证结果
- 列表工具栏复用 `ListToolbar`、`ListSearchInput`，并保持 `PageHero`、`alertPanelClass`、`DataTable`、`Pagination` 结构，与 `AlertDeskTab` 一致。
- 表格与分页使用完整面板宽度；操作列与告警中心相同，使用 `TableActionCell` 和无额外边框的 `ActionIconGroup`，行/表头间距统一为 `px-5`。
- 按用户字段要求拆为 8 列：维护期、描述、执行目标、开始时间、结束时间、状态、创建人、操作；搜索提示同步使用描述和执行目标术语。
- 创建、资源选择和详情弹窗复用 `FormDialogShell`；表单分组和字段复用 `FormSection`、`TextField`、`SelectField` 与 `ActionButton`。
- 浏览器检查了维护期列表，并打开表单确认名称、规则、时段、原因、联系人和操作按钮。空白弹窗已关闭，未创建维护期。浏览器截图 API 捕获表单时超时，因此只保存最终列表截图；表单结构以可访问性树和源码复核。
- 响应式断点通过源码检查，未实测窄屏视口。
- 未运行测试、lint 或 build；未部署。
- 截图：`docs/walkthrough/maintenance-window-list-component-aligned-20261102.png`。
