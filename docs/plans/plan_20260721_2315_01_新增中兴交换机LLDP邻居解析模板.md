# 新增中兴交换机 LLDP 邻居解析模板与 Playbook 命令修正

为中兴交换机（平台为 `zte_zxros`）新增 LLDP 邻居解析模板 `zte_zxros_show_lldp_neighbor_brief.textfsm`，并在后台对折行 Port ID 进行预处理合并。同时修正前端自动化任务（Playbook）中，中兴设备的邻居查询命令为 `show lldp neighbor brief`。

## User Review Required

> [!IMPORTANT]
> 1. 中兴交换机的 `show lldp neighbor brief` 输出中，当 `Port ID` （对端端口名）过长时，会折行输出。为了保证 TextFSM 的行匹配正确性，我们将在后端 `smart_parse_cli` 预处理流程中，对符合中兴折行特征的邻居记录行进行向上合并。
> 2. 我们将为 `zte_zxros` 提供专用的 TextFSM 模板，放置在 `data/textfsm_templates/zte_zxros_show_lldp_neighbor_brief.textfsm`。
