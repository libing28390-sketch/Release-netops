# 拓扑有线无线筛选

- 目标与现状：目前设备角色可单选，缺少按有线、无线或全部设备查看的入口。
- 范围：`TopologyPage.tsx` 增加筛选，`topologyDevices.ts` 投影设备和链路，`TopologyGraph.tsx` 隔离筛选后的临时布局，`TopologyUplinkGroups.tsx` 明确筛选后链路空态。
- 实施：沿用拓扑角色，AP 和控制器归为无线。仅绘制当前设备之间的链路，画布、站点总览和统计共用数据。
- 验证：三种模式的设备、链路、空态以及切回全部后的布局；运行前端类型检查与临时目录构建。
- 风险与回滚：核对已有布局持久化和现有筛选的组合效果，回退前端改动即可恢复。
