# 资产列表默认列调整实施计划

## 任务目标

让资产台账和网络设备列表首次展示及“恢复默认列”与用户截图中的勾选项一致；服务器列表首次展示及“恢复默认列”中勾选全部可用字段；从资产列表展示中移除“SSH算法策略”，从网络设备列表及其导出列中移除 CPU、内存。

## 现状与问题

资产台账的默认列与用户当前勾选项不同，且列选择器仍包含 SSH 算法策略。网络设备列表也需要以截图中的勾选项为默认值，CPU 和内存不再作为列表/导出列展示。服务器可选字段较少，用户希望默认全选。三个列表都在浏览器本地存储列偏好，因此默认升级还需兼容旧版自动保存值，同时保留用户自定义选择。

## 影响范围

- 资产管理页的默认列、列选择器及列表单元格渲染。
- 网络设备页的默认列、偏好加载、列选择器、表格和可见列导出。
- 服务器列表默认列及偏好加载。
- 对应前端单元测试。
- 不改变资产编辑、导入校验中的 SSH 算法策略字段，也不改变 SNMP CPU/内存采集或设备详情内容。

## 实施步骤

1. 将资产截图勾选项设为资产台账默认列；迁移旧版自动保存的默认组合，保留与旧默认不同的用户自定义设置。
2. 从资产台账列定义和单元格渲染中移除 SSH 算法策略；保留资产编辑和导入使用的字段契约。
3. 将网络设备截图勾选项设为默认列：设备名称、资产编号、管理 IP、设备类别、角色、厂商、型号、标签、在线状态、健康状态和操作。
4. 从网络设备列类型、列设置、表格和表格导出中移除 CPU、内存；迁移旧版默认列值并保留其他用户自定义列。
5. 将服务器列设置的所有现有选项设为默认勾选；自动保存旧默认配置时迁移为全选，自定义配置继续生效。
6. 更新测试，验证三张截图对应的默认项、旧配置迁移、操作列，以及已移除的列不再展示或导出。

- 检查差异：`git diff --check`

## 风险与回滚思路

风险限于列表列的初始显示偏好。已有用户保存的自定义列配置继续生效；历史配置中的 SSH 算法列及 CPU/内存偏好会因列定义移除而被忽略。若默认字段有误，可恢复对应默认常量和迁移逻辑，用户自定义配置仍可保留。
