# 自动化列表与时间选择器字级优化

- 创建时间：2026-10-21 12:20（工作区时区）
- 状态：已实施并通过自动化验证；浏览器目视验收待补

## 目标

根据用户提供的三张截图，提升快捷操作设备表、执行计划列表和共享日期时间选择器的文字可读性与操作空间，不改变筛选、分页、计划状态或时间值语义。

## 现状与问题

- 快捷操作设备列表的表头、类型、厂商、状态等字段使用 9–11px 字号。
- 执行计划表的列名、辅助信息、状态和时间也偏小，关键时间值仅 11px。
- 共享 `DateTimePicker` 的星期、日期、时间列和“现在/清除/确认”使用 9–11px 字号；日期按钮为 26px 高，时间步进为 24px，点击区域偏紧。

## 影响范围

- `src/pages/AutomationExecute/components/DeviceSelectionStep.tsx`
- `src/pages/ExecutionSchedule/index.tsx` 的时间范围工具栏
- `src/pages/ExecutionSchedule/components/ScheduleList.tsx`
- `src/components/DateTimePicker.tsx` 及其现有调用方

不调整 API、时间格式、分页/筛选行为、危险操作、权限或其他列表布局。保留 `DeviceSelectionStep.tsx` 中已有的未提交交互改动。

## 实施步骤

1. 增大设备表与计划表的列名、主要数据和辅助数据字号，并同步提升时间范围与重置控件字号，保持紧凑的行密度。
2. 增加日期、时间选项及底部操作的字号与命中区域，适度加宽选择器，并限制宽度/高度以适应视口。
3. 运行聚焦前端测试、TypeScript 检查、隔离生产构建和 `git diff --check`。

## 风险与回滚

共享日期选择器的尺寸调整会影响多个现有表单，但不改变时间值和选中逻辑。若弹层在窄视口或被嵌套容器使用时遮挡内容，可回退选择器的尺寸/定位改动；列表字号可独立回退。
