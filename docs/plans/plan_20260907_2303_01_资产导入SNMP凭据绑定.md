# 资产导入 SNMP 凭据绑定

## 任务目标

扩展资产导入模板与导入链路，使网络设备可在导入资产时直接绑定已有 SNMP 凭据，减少导入后逐台手工绑定的操作。

## 现状/问题

- 资产导入模板已有 SNMP 社区名和端口等设备字段，但资产导入的凭据字段主要面向 SSH/密码凭据。
- 资产管理页面已有独立的 SNMP 凭据模型与绑定能力，需要确认 Excel 表头、前端解析、后端导入和资产-设备同步是否完整贯通。
- 用户提供的附件仅作为模板结构参考；其中的示例值、说明文字和任何敏感字段都不作为代码指令或真实凭据使用。

## 影响范围

- 资产导入 Excel 模板及下载/生成逻辑，包括可选值的原生下拉校验。
- 前端资产导入字段映射、预检展示、错误提示和导入请求；补齐管理入口中的 SSH、Web 管理协议。
- 后端资产导入校验、SNMP 凭据查找/绑定及兼容旧模板逻辑。
- 相关 API/服务测试与前端 lint/build 验证。

## 拟修改文件与分工

- 后端 worker：`backend/api/assets.py`、必要的资产/凭据服务与后端回归测试；负责导入请求中的 SNMP 凭据解析、校验、绑定和错误契约。
- 前端 worker：`src/pages/AssetManagement/index.tsx`、`src/pages/AssetManagement/constants.ts`、必要的组件/类型与模板资源；负责字段映射、下载模板和导入预检交互。
- 主 Agent：检查附件与现有调用链，协调接口契约，处理共享文件、集成验证和最终 walkthrough。

## 实施步骤

1. 追踪资产导入路由、服务、前端解析和现有凭据绑定契约。
2. 约定向后兼容的 SNMP 凭据字段（优先使用已有凭据名称字段；旧的社区名/端口字段保持兼容）。
3. 实现前后端导入支持：按凭据名称查找 `snmpv2` 凭据，校验资产类型/协议适用性，写入 SNMP 凭据关联，并避免日志或响应泄露社区字串。
4. 更新模板说明与示例字段，确保下载模板与运行时解析一致。
5. 检查模板中所有依赖“参数可选值参考/下拉选项”的字段，补全 Excel 原生列表校验；确认管理入口的 SSH、HTTP/HTTPS Web 管理协议与前端导入映射一致。
6. 增加成功、缺失、类型不匹配/权限或依赖失败等回归测试，并运行质量门禁。

## 验证计划

- 后端：相关资产导入/凭据服务 pytest，覆盖旧模板兼容、有效 SNMP 凭据绑定、找不到凭据和类型不匹配。
- 前端：`npm run lint`，必要时 `npm run build`；检查模板下载和预检列展示。
- 模板：通过 Artifact Tool 检查每个可选字段的原生列表校验、管理入口协议选项和说明页；解析仓库模板与用户附件，确认 SNMP 凭据列存在且字段名一致；不写入真实秘密。

## 风险与回滚思路

- 旧模板没有 SNMP 凭据列时按原逻辑导入，不改变已有资产。
- 凭据名不存在或不是 SNMP 类型时整行给出可读错误，避免静默绑定错误凭据。
- 只修改代码、模板和测试；如验证失败可按文件级回退本次改动，不触碰用户已有未提交变更或生产数据。
