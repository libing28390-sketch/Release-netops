# 实施计划：双轨混合路由（轨道 A 极简 0-Token 事实快道 + 轨道 B 原生 LLM 推理）

- **创建时间**：2026-11-27 12:23
- **目标仓库**：`D:\netops\netsops-main`
- **背景来源**：单句纯查数（`查一下我们有多少台设备`）进入 LLM 工具循环消耗了 3,578 Input Tokens / 20 秒，应由本地 PostgreSQL 0-Token 极简秒回，同时保留复杂分析/多意图/追问走原生 LLM 推理。

## 1. 任务目标
在 `AI_COPILOT_AGENTIC_CHAT_ENABLED=True` 模式下实现干净的 **双轨混合路由**：
- **轨道 A（0-Token 极简事实快道，< 0.1 秒）**：仅匹配短句（≤ 36 字）、单一客观事实（查总数/分布、查是非/状态、查单设备档案/机柜/登录/漂移/合规、查告警/站点/凭据/待审批工单/IPAM/总览、以及显式 `/slash`），返回精炼直答（如设备总数+厂商/类型/站点 4 行分布，不吐八股大表），并正常写入会话历史供下一轮 LLM 承接。
- **轨道 B（原生 LLM 推理 + 0-Token 预取证 + 神经元记忆）**：凡含推理/原因/建议/割接/对比/命令/知识库/总结/记住、复合多意图（`顺便 / 另外 / 并且 / 多问号`）或长句（> 36 字），一律交由 LLM 推理。

## 2. 拟修改文件
- `backend/ai/services/module_bus.py`：新增 `_query_device_count_summary(query, entities)`，返回极简 4 行设备数量与厂商/类型/站点分布摘要（0 Token）。
- `backend/ai/services/local_router.py`：在 Agentic 模式下启用严格的 Track A 准入守卫（排除推理/多意图/长句，放行单一客观事实与 `device_count_summary`）。
- `backend/ai/services/assistant.py`：在 `chat()` 与 `_chat_stream_impl()` 中先尝试 Track A 快速路由，命中即 0-Token 直出，未命中则无缝进入 `_run_agentic_chat` / `_run_agentic_chat_stream`。
- `backend/tests/ai/test_copilot_agentic_tools.py`：补充双轨分流回归测试（验证 `查一下我们有多少台设备` 0-Token 秒回，而割接/原因/对比/命令/记住均走 LLM）。

## 3. 验证计划
