# Plan — AI 中心 7 大功能模块左侧导航与全量验证

## 任务目标
1. 将 AI 中心的 7 大功能模块重构下沉至左侧 Sidebar 主导航栏中：
   - Provider 供应商 (`/ai/providers`)
   - Model 与路由 (`/ai/models`)
   - Prompt 提示词中心 (`/ai/prompts`)
   - AI Copilot 对话 (`/ai/copilot`)
   - Agent & Tool 注册表 (`/ai/agents`)
   - AI 变更治理门禁 (`/ai/governance`)
   - Token 统计与审计 (`/ai/usage`)
2. 支持刷新和直接访问各子路由（支持原生 `/ai/center` 及各子路由全量跳转与高亮选中）。
3. 逐一验证 7 大功能模块的前后端连通性与核心业务逻辑，确保每个模块无报错、能够正确响应数据。

## 影响范围与修改文件
- `src/components/AppSidebar/navConfig.ts`: 替换 `ai-center-group` 下的单节点为 7 个子导航节点。
- `src/components/AppSidebar/index.tsx`: 在 `iconMap` 和 `lucide-react` 导入中补充 `Cpu`, `MessageSquare`, `Wrench` 等所需图标。
- `src/utils/routeContext.ts`: 补充 `/ai/providers`, `/ai/models`, `/ai/prompts`, `/ai/copilot`, `/ai/agents`, `/ai/governance`, `/ai/usage` 的路由解析逻辑。
- `src/components/AppMainContent.tsx`: 支持匹配所有 `/ai/*` 路由并联动激活对应的 `AiCenterPage` 子页签。
- `src/pages/ai/AiCenterPage.tsx`: 支持根据路由与 props 动态同步 `activeTab`，切换页签时更新浏览器 URL。

## 实施步骤
1. **修改导航与图标**：
   - 在 `AppSidebar/index.tsx` 的 `iconMap` 中增加 `Cpu`, `MessageSquare`, `Wrench` 等图标映射。
   - 在 `navConfig.ts` 中配置 7 个子导航节点。
2. **更新路由与主内容渲染**：
   - 更新 `routeContext.ts` 支持解析 `/ai/providers`, `/ai/models`, `/ai/prompts`, `/ai/copilot`, `/ai/agents`, `/ai/governance`, `/ai/usage`。
   - 在 `AppMainContent.tsx` 中响应所有 `ai-` 相关的 `activeTab`。
3. **改造 AiCenterPage**：
   - 监听外部传入的 `activeSubTab` 或 `useLocation`，实现点击顶部 Tab 实时更新 URL 路由，点击左侧菜单实时同步 Tab。
4. **7 大模块全量验证**：
   - 运行 pytest 针对后端 `backend/ai/` 接口进行单元测试。
   - 运行 `npm run build` 验证前端代码无类型与编译错误。
   - 验证 Provider/Model/Prompt/Copilot/Agents/Governance/Usage 各页面的 API 连通性。

## 验证计划
- **自动化测试**：运行 `pytest backend/tests/test_ai_center.py`（若有）或测试后端路由。
- **构建测试**：运行 `npm run build` 确保 TypeScript 编译通过。
