# 实施计划：执行流水历史 (Execution History) UI 现代化重塑与操作栏重构

## 1. 任务目标与背景

用户反馈 `http://192.168.56.1:5400/automation/history` 界面视觉欠佳，**特别是每行末尾的操作栏堆叠了 4 个雷同的灰色文件图标（HTML/PDF/Excel/JSON），既拥挤混乱又影响美观**。

### 重塑目标：
1. **重构操作栏（Actions Column）**：
   - 彻底废除 5 个图标平铺挤在一起的做法；
   - 重构为现代化企业级双组件：
     - **【👁️ 查看详情】核心操作按钮**：清爽高质感的 Cyan 按钮，点击直接打开详细执行轨迹；
     - **【📥 导出报告 ▾】智能下拉菜单**：点击展开精致的导出选项面板，清晰列出「📕 导出 PDF」、「📊 导出 Excel」、「🌐 导出 HTML」、「📦 导出 JSON」。
2. **重塑顶部工具栏与实时搜索**：
   - 增加即时搜索框（按任务名称、执行人快速过滤流水）；
   - 现代化 Segmented Switcher 过滤执行类型（全部 / 手动 / 计划 / 定时作业）。
3. **表格视觉与状态微交互提升**：
   - 统一使用现代轻量级设计规范（纯净白底、细边框 `border-slate-200`、呼吸状态指示灯、清晰的字阶对比与对齐）。
