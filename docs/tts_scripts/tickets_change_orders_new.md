# 🎙️ 工单管理 · 新建工单 功能演示与配音脚本

> **模块名称 (Module)**: 工单管理 (CHANGE ORDERS & TICKETS)
> **功能名称 (Feature)**: 新建工单 (Create New Change Order)
> **视频分镜预估时长**: 45-50秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
在规范的网络运维流程中，任何配置变更都必须有据可查、合规流转。新建工单模块为您提供了极为严密又顺畅的录入入口。    支持‘场景化模板’和‘手工输入命令’双重模式，一键关联目标设备，并支持智能的窗口防冲突机制。    在新建工单表单中，您只需填写标题、计划执行时间段，系统即会根据所选场景自动渲染出需要执行的安全命令序列。    严密的‘申请人不能是初审或终审人’等风控审计逻辑内置其中，从源头封堵网络变更违规行为。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 导航点击进入‘新建工单’，在工单标题中键入‘核心汇聚网络路由防环路调整’，优先级选择‘高 (High)’。  
2. 在执行方式中选择‘场景化模板模式’，在场景下拉框选中‘交换机安全端口割接下发’，并在下方填入所关联的核心网络设备 IP 与端口变量。  
3. 点击下方的‘生成预览指令 (Render Preview)’按钮，页面立即显示渲染出的标准命令列表，随后点击右侧的‘申请初审’按钮提交流程。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
