# 🎙️ 工单管理 · 组内待办 功能演示与配音脚本

> **模块名称 (Module)**: 工单管理 (CHANGE ORDERS & TICKETS)
> **功能名称 (Feature)**: 组内待办 (Group Tasks Queue)
> **视频分镜预估时长**: 30-35秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
在大型团队的日常割接和审批流转中，往往有部分工单分配给了特定的运维角色组，处于无人接单的状态。组内待办页面是整个运维组的公共待抢队列单。    所有属于当前登录用户权限组下的公共待办工单都会汇总在此。    组内成员可以根据当前的工作负荷，一键认领工单并将处理人更改为自己，或是将工单指派给组内其他空闲的同事，彻底避免公共任务被遗漏的尴尬局面。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 点击打开‘组内待办’，列表中展示两条状态为‘终审中’且当前处理人为空的团队公共工单。  
2. 点击第一条工单，展示其被分配至所属的‘Final-Approvers-Group’组标签。  
3. 鼠标悬停在操作列的‘指派/认领 (Claim Job)’图标上并点击，工单处理人立即更改为当前用户并自动归入个人待办，展示清晰的认领变化。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
