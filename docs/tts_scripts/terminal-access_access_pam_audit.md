# 🎙️ 终端接入 · 受控审计 功能演示与配音脚本

> **模块名称 (Module)**: 终端接入 (TERMINAL ACCESS)
> **功能名称 (Feature)**: 受控审计 (PAM Audit & Session Replay)
> **视频分镜预估时长**: 50-55秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
网络运维的安全底线，容不得半点马虎。这就是平台最具特色的 P A M 受控审计功能。    系统会自动捕捉并记录下，任何人通过平台进行的所有会话行为。    在受控审计列表中，您可以查看到完整的连接历史和执行指令审计日志。    更令人惊叹的是，平台支持高清的‘会话录像回放’！    点击播放，您可以自由拖拽底部的精细化时间轴，逐字逐句地还原操作人员在终端输入的每一行命令和对应的实时返回结果。操作透明化、合规无死角，排障与安全复盘从未如此轻松。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 进入 PAM 受控审计列表，展示最近的会话日志，点击其中一条带有‘录像’标识的历史会话。  
2. 在弹出的黑色仿真终端回放弹窗中，点击播放，屏幕开始动态模拟当时操作者敲击键盘及终端实时回显的过程。  
3. 鼠标向后拖拽底部时间轴到 50% 进度处，展示跳跃回放，突出终端指令秒级跳转和高亮高危指令的效果。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
