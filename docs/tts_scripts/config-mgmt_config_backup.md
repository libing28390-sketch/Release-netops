# 🎙️ 配置管理 · 备份中心 功能演示与配音脚本

> **模块名称 (Module)**: 配置管理 (CONFIGURATION MANAGEMENT)
> **功能名称 (Feature)**: 备份中心 (Config Backup Center)
> **视频分镜预估时长**: 40-45秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
设备的配置文件，是网络最宝贵的数字资产。一旦设备损坏或配置丢失，备份中心就是您的‘时光倒流机’。    系统全自动连接网络设备并拉取最新配置，且支持生成 Git 增量历史版本。    在备份中心，您可以清晰地看到每台设备的备份成功率、最新备份大小以及备份历史树。    点击即可在线预览包含精美语法高亮的交换机原始 running config，安全可靠、尽在掌握。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 导航进入备份中心，列表项中绿色的‘备份就绪 (Ready)’和备份时间一览无余。  
2. 点击第一行交换机的‘查看配置版本详情 (History)’图标，打开历史快照弹窗。  
3. 在快照列表中点击最近的快照，展示高精度语法高亮的配置文本预览框，缓慢滚动展示命令段落的清晰排版。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
