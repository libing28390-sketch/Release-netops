# 🎙️ 资产与配置 · 标签管理 功能演示与配音脚本

> **模块名称 (Module)**: 资产与配置 (ASSETS & CONFIGURATION)
> **功能名称 (Feature)**: 标签管理 (Tags Management Editor)
> **视频分镜预估时长**: 30-35秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
如何跨机房、跨部门、跨业务线，对成千上万的网络设备进行精准分类？标签管理模块为您提供了极其灵活的维度抽象。    在这里，您可以自由设计各种颜色的多属性标签——比如划分‘核心层’、‘业务线A’或‘测试环境’。    支持自定义标签的背景色与字体色，并支持在资产列表中进行一键批量打标和标签过滤，让您的自动化脚本能够通过标签，瞬间选中特定的设备集群执行变更。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 打开标签管理页面，滑动展示不同色彩、圆角包裹的多样标签（如：Cyan 色的 Builtin，Emerald 色的 Production）。  
2. 点击‘创建新标签’按钮，选择优雅的亮橙色背景，命名为‘Core-Router’并保存。  
3. 在右侧列表中展示这个刚刚创建的标签，演示拖拽归类功能。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
