# 🎙️ 资产与配置 · 网络设备 功能演示与配音脚本

> **模块名称 (Module)**: 资产与配置 (ASSETS & CONFIGURATION)
> **功能名称 (Feature)**: 网络设备 (Network Devices Directory)
> **视频分镜预估时长**: 40-45秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
当网络设备数量庞大时，日常的查找、测试和配置工作往往效率低下。网络设备台账将设备生命周期的管理化繁为简。    系统提供包含主机名、管理 I P、厂商平台、硬件序列号 S N 的丰富数据列表。    支持便捷的一键联机连通性测试，绿色高亮即代表设备就绪。    点击设备，右侧展开抽屉，不仅支持快捷调用 Web S S H，更能直观管理其所在的机架 U 位和所属标签，彻底告别用 Excel 统计设备台账的落后方式。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 在设备列表页面点击搜索框，键入‘Cisco’，高亮检索出所有思科交换机。  
2. 点击第一行设备的‘连接测试 (Test Connection)’图标，列表项旁闪动绿色心跳气泡并弹出成功测试报告。  
3. 点击该行设备，右侧滑出侧边信息抽屉，向观众指出机架 U 位联动信息以及该设备的硬件序列号标签。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
