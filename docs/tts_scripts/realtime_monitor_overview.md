# 🎙️ 实时监控 · 运营总览 功能演示与配音脚本

> **模块名称 (Module)**: 实时监控 (REAL-TIME MONITORING)
> **功能名称 (Feature)**: 运营总览 (Dashboard Overview)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
欢迎来到 Net Sops 运营总览控制台！这里是……全网基础设施的监控中枢。    在大盘中，您可以通过极具科技美学的青色图表，实时掌控全网设备的在通率、最新告警收敛情况，以及自动化执行流水线的状态。    顶部醒目的状态卡片，直观地展示了当前设备总数、严重告警数量和计划任务的执行率。    鼠标悬停在资源状态监控图上，您可以查看最近 24 小时，C P U 与内存的动态负载曲线，确保网络底层架构，时刻保持稳健运行。这不仅是系统的首页，更是网络团队实现秒级态势感知的控制中心。
```

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 鼠标滑过屏幕顶部的状态统计卡片（如：在线设备数、活跃告警数、今日任务执行数）。  
2. 点击并悬停在 C P U/内存 24 小时趋势折线图的特定时间点上，展示动态数值 Tooltip。  
3. 滚动查看下方的‘最新工单待办’和‘近期安全审计动态’卡片，点击右侧的刷新按钮演示数据实时加载。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
