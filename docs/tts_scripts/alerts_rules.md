# 🎙️ 告警处置 · 告警规则 功能演示与配音脚本

> **模块名称 (Module)**: 告警处置 (ALERTS MANAGEMENT)
> **功能名称 (Feature)**: 告警规则 (Custom Alert Rules)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
如何做到比用户更早发现问题？这完全得益于告警规则引擎的自定义监控能力。    在规则编辑器中，网络工程师可以针对端口丢包率、物理板卡温度、C P U 水位等指标，设定多级规则阈值，并支持正则表达式过滤。    支持针对不同的规则组，配置精细化的通知路由——无论是邮件、Slack 还是即时通讯 Webhook，确保相关接口负责人能在第一时间收到精准推送，彻底告别无效的告警风暴。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 打开告警规则管理页面，展示预设的核心设备监测规则列表。  
2. 点击‘新建规则’按钮打开滑出式表单，填写规则名称、选择指标为‘Interface Discards’、输入阈值‘> 50’。  
3. 鼠标演示在通知配置下勾选“邮件”和“Webhook API 推送”，点击保存成功提示。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
