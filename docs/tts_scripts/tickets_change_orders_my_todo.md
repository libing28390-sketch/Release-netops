# 🎙️ 工单管理 · 个人待办 功能演示与配音脚本

> **模块名称 (Module)**: 工单管理 (CHANGE ORDERS & TICKETS)
> **功能名称 (Feature)**: 个人待办 (My Pending Tasks)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

```text
高效的团队协作需要每一个成员对自己的待办事项一目了然。新重构的‘个人待办’页面秉持了极致简洁的设计美学，将复杂归于优雅。    系统彻底抛弃了繁琐冗余的多级页签切换，而是智能地在单个精致的卡片列表中，集中呈现了需要您当前处理的全部待办工单。    无论是需要您作为审批人签字同意的初审或终审，还是由于不合规退回需要您修改的工单，亦或是已审核通过等待您确认实施的变更。    轻点工单号即可一键审批或流转，让日常沟通和工作效率倍增。
```

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 进入工单管理的‘个人待办’页面，首先向观众指出无二级标签的**“极简单卡片列表”**，向观众强调这种轻盈高级的 Nexora 原生视觉美感。  
2. 输入检索词‘路由调整’，检索出一条状态为‘初审中 (Initial Review)’的工单，点击它展开完整的高清工单详情视窗。  
3. 滑动查看详情面板中完整的申请描述、渲染出来的执行命令序列，并点击弹窗右上角‘同意并通过’绿色按钮，演示工单流畅移交终审的交互。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
