# 🎙️ 平台管理 · 授权管理 功能演示与配音脚本

> **模块名称 (Module)**: 平台管理 (PLATFORM ADMINISTRATION)
> **功能名称 (Feature)**: 授权管理 (License Entitlement Manager)
> **视频分镜预估时长**: 30-35秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
支持正版授权、获取官方最新的安全防护特征库和企业支持通道。授权管理页面是整个平台的‘合规服务保障卡’。    在这里，系统直观地呈现了当前 License 的有效期、授权的节点最大限制和已使用节点数量比。    运维主管可以清晰地获知当前授权启用的高级特性功能清单。    支持简单的一键上传新证书进行秒级在线激活续费，为您的智能化运维之旅提供坚不可摧的安全合规保障。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 点击打开‘授权管理’，页面呈现充满质感的银灰色盾牌图标和‘授权有效 (Licensed)’状态卡片。  
2. 指出下方的授权细节：如最大受控节点数 500 个、剩余天数 320 天。以及高亮勾选的激活功能列表（Monitoring, PAM, Auto-Exec等）。  
3. 点击‘更新 License 文件 (Upload License)’按钮，模拟上传新授权证书并重新计算节点额度的流程。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
