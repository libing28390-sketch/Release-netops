# 🎙️ 容量与报表 · 容量分析 功能演示与配音脚本

> **模块名称 (Module)**: 容量与报表 (CAPACITY & REPORTS)
> **功能名称 (Feature)**: 容量分析 (Capacity Planning Analyzer)
> **视频分镜预估时长**: 40-45秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
当网络带宽和存储负荷亮起红灯时才去买设备，往往为时已晚。    容量分析模块，为您引入了基于时序趋势的资源预警晴雨表。    系统自动监测并分析交换机骨干光口的带宽利用率曲线、核心服务器的存储水位上升斜率。    通过高精度的趋势拟合曲线，系统会科学预测某个网段的 I P 耗尽天数、或是某台数据库服务器的磁盘写满时间。    通过提前做好资源扩容规划，帮助您的网络运维团队从被动救火转型为科学的主动规划。
```

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 导航点击进入‘容量分析’，展示包含‘服务器存储预警天数柱状图’和‘光口带宽极限趋势图’的报表页。  
2. 鼠标悬停在一根红黄相间的柱状图上，气泡弹出提示‘Nexora-Data-Server-02 磁盘预计将在 18 天后写满’。  
3. 切换至‘带宽预测’，展示一条平滑上升的二次曲线与未来 30 天预测包络带，体现科学容量分析的高级算法深度。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
