# 🎙️ 自动化 · 执行计划 功能演示与配音脚本

> **模块名称 (Module)**: 自动化 (AUTOMATION PIPELINE)
> **功能名称 (Feature)**: 执行计划 (Execution Schedules Organizer)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
人脑难免有遗忘，但机器会永远忠诚执行。执行计划模块，让您的网络巡检作业，实现全自动定时跑批。    不论是每日凌晨三点进行的深度安全巡检、还是每个周末下午进行的环境指标监测，都可以在这里按标准的 Cron 时间格式进行简单编排。    您只需选择目标巡检模板和关联的设备组，剩下的工作，系统会在后台按时启动并保证精准执行。
```

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 进入巡检执行计划配置页，展示包含‘周期巡检’、‘每周配置对齐检查’在内的调度计划列表。  
2. 点击‘新建执行计划’弹窗，输入计划名称，选择巡检模版为‘Cisco & Huawei 核心路由巡检’，勾选运行周期为‘每天 03:00’。  
3. 勾选需要被覆盖的北京 IDC 和上海 IDC 核心设备群组，点击激活并关闭计划弹窗。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
