# 🎙️ 资产与配置 · IP/VLAN管理 功能演示与配音脚本

> **模块名称 (Module)**: 资产与配置 (ASSETS & CONFIGURATION)
> **功能名称 (Feature)**: IP/VLAN管理 (IPAM & Subnet Planner)
> **视频分镜预估时长**: 45-50秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
I P 地址规划混乱、地址冲突是每一个网络管理员的噩梦。    Net Sops 专业的 I P A M 智能管理模块，为您的地址资源建立起金字塔般的清晰骨架。    系统将复杂的网段、子网掩码、V L A N 标签划分得层级分明。    得益于极具创意的‘I P 地址网格地图’，每个子网下被占用的、空闲的或处于网关预留状态的 I P，都以红绿相间的网格形式直观展现。支持子网内并发 Ping Sweep 自动扫描发现，自动盘点存活地址，让地址资源管理，彻底告别手工记录。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 切换到 IPAM 页面，左侧网段树展开‘核心IDC骨干网段 -> 192.168.42.0/24’子网。  
2. 重点展示右侧炫酷的 **“IP 地址网格地图”**，鼠标滑过其中深绿色的已分配 IP 网格和灰白色的空闲网格，显示对应的绑定主机名与 MAC 地址。  
3. 点击右上角的‘扫描发现 (Scan subnet)’按钮，列表顶部弹窗呈现动态扫描进度与新发现存活设备的同步结果。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
