# 🎙️ 自动化 · 操作管理 功能演示与配音脚本

> **模块名称 (Module)**: 自动化 (AUTOMATION PIPELINE)
> **功能名称 (Feature)**: 操作管理 (Custom Operations Scripts)
> **视频分镜预估时长**: 40-45秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
每一个网络团队都有自己多年沉淀下来的 Ansible Playbook 或是 Python 实用脚本。操作管理模块就是您团队专属的‘脚本云端武器库’。    平台内置了代码预览和在线编辑器，支持团队成员安全地共享和维护自己的运维脚本。    配合系统安全的 RBAC 权限隔离机制，只有特定角色的操作员以上级别才能在此管理和发布脚本。    这些脚本在审核通过后，可作为标准的自动化变更原子步骤，直接嵌入流水线中，大幅降低管理开销。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 打开操作管理脚本库，选中名为‘Ansible 端口一键禁用脚本’条目，点击右侧的‘编辑代码’图标。  
2. 在右侧暗黑风格的代码编辑器里，修改第 15 行‘state: absent’的配置描述，并点击右上角亮绿色的‘保存更改 (Save)’按钮。  
3. 演示滑过页面上的“脚本审核状态”和“操作员权限隔离”提示标识，指出团队协作的规范 and 安全性。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
