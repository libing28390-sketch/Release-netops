# 🎙️ 配置管理 · 配置模板 功能演示与配音脚本

> **模块名称 (Module)**: 配置管理 (CONFIGURATION MANAGEMENT)
> **功能名称 (Feature)**: 配置模板 (Jinja2 Configuration Templates)
> **视频分镜预估时长**: 40-45秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
网络标准化、配置基线的基石在于配置模板化。配置模板模块，引进了强大的 Jinja 2 模板渲染引擎。    您可以使用带有逻辑判断和循环的变量占位符，来编写标准的基线配置模板——例如新建端口划入指定业务 V L A N。    运维人员只需输入目标变量数值，系统就会自动生成完全符合设备厂商语法的可执行命令序列，支持模板语法在线预览与预校验，彻底避免低级配置拼写错误。
```

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 导航进入配置模板页面，展示内置的标准交换机端口下发 Jinja2 模板。  
2. 点击编辑，向观众指出模板中的 {% for interface in interfaces %} 和 {{ interface.vlan_id }} 变量循环和控制占位符。  
3. 在右侧变量框内填入模拟 JSON 参数，点击‘试渲染 (Preview)’，下方瞬间生成标准思科命令‘switchport access vlan 10’，展示模板的自动化语法检查。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。
