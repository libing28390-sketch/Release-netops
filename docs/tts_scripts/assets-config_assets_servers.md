# 🎙️ 资产与配置 · 服务器 功能演示与配音脚本

> **模块名称 (Module)**: 资产与配置 (ASSETS & CONFIGURATION)
> **功能名称 (Feature)**: 服务器 (Server Resources Monitor)
> **视频分镜预估时长**: 40-45秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
网络运维不仅关注硬件连通性，更需要保障承载核心业务的服务器集群稳定运行。服务器管理模块让物理机与虚拟机管理得心应手。    系统提供了一站式的指标仪表盘，实时收集每台服务器的 C P U 开销、内存占用、以及各磁盘分区的容量警戒线。    一旦某台主机的系统进程数超载或者磁盘空间即将耗尽，系统不仅会即时告警，更能联动后台自动化清除日志文件，将业务隐患消除在萌芽状态。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 导航进入服务器管理页面，点击选中名为‘Nexora-Backend-01’的核心应用服务器。  
2. 展示其仪表盘中的‘CPU 占用率环形进度条’ and ‘内存水位卡片’，拖动查看下方的磁盘分区仪表盘比例（如：根分区已用 72%）。  
3. 鼠标悬停在系统关键进程列表上，展示关键服务（如 sshd, docker）的运行状态标记。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
