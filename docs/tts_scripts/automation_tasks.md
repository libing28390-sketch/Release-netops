# 🎙️ 自动化 · 自动化任务 功能演示与配音脚本

> **模块名称 (Module)**: 自动化 (AUTOMATION PIPELINE)
> **功能名称 (Feature)**: 自动化任务 (Playbook Tasks Execution)
> **视频分镜预估时长**: 45-50秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
传统的串行式逐台运维变更正成为历史。自动化任务模块，是 Net Sops 为您打造的高并发、流水线式的智能变更执行舱。    在这里，无论是批量端口 V L A N 划分，还是针对千百台路由器执行命令查询，平台都支持将这一系列操作编排为包含：前置检查、执行下发、后置验证和回退计划的四阶段规范流水线。    高并发多通道并发连接资产，状态秒级响应，执行进度条直观生动，让网络割接安全合规。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 进入自动化任务控制页，展示已有的自动化 Playbook，选择‘批量接口防环路下发’，点击启动。  
2. 选择目标设备组（如：核心交换机），点击‘立即执行 (Run Now)’。  
3. 页面展现炫酷的亮青色执行流进度条，各设备节点旁闪动‘连接中 -> 执行中 -> 验证中 -> 成功完成’的动画反馈，并流式输出执行日志。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
