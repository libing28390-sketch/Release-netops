# 🎙️ 实时监控 · 网络拓扑 功能演示与配音脚本

> **模块名称 (Module)**: 实时监控 (REAL-TIME MONITORING)
> **功能名称 (Feature)**: 网络拓扑 (Dynamic Network Topology)
> **视频分镜预估时长**: 45-50秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
传统的静态拓扑图，早已无法适应快速变化的网络环境。Net Sops 拥有令人惊叹的动态网络拓扑引擎！    系统通过 L L D P 和 C D P 邻居自动发现协议，自动发现并实时绘制全网的三层及二层网络拓扑。    当某个节点或链路发生故障、或者 O S P F 邻居中断时，拓扑图上会立即闪烁醒目的红色告警信号。    点击任意连线，即可查看两端接口的对接细节、运行状态和丢包证据链，让错综复杂的网络物理链路，瞬间变得清晰可视。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 打开网络拓扑页面，演示鼠标对拓扑画布的平移拖拽、滚轮无级缩放。  
2. 鼠标双击选定核心三层交换机节点，拓扑图将自动以其为中心高亮展示相邻接口连接关系。  
3. 点击两个节点之间的连接线，展开侧边栏‘链路详情’面板，展示接口对接名称、实时流量曲线及历史丢包证据链。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
