# 🎙️ 平台管理 · 用户管理 功能演示与配音脚本

> **模块名称 (Module)**: 平台管理 (PLATFORM ADMINISTRATION)
> **功能名称 (Feature)**: 用户管理 (RBAC User & Groups Mgmt)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
大型企业网络团队往往面临着复杂的组织架构和职责分工。    平台内置的 RBAC 用户及群组管理模块，让特权安全划分固若金汤。    在这里，超级管理员可以轻松定义和派发不同的系统角色——包括只读权限的观察员、执行日常巡检的操作员，以及拥有最高权限的系统管理员。    支持将用户归入不同的变更处理人组，与工单系统的认领和审批链逻辑紧密扣合，确保每一位员工只在授权边界内行使职责，坚决避免越权隐患。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 导航进入‘用户管理’控制台，展示当前系统的成员账户卡片和详细权限角色划分列表。  
2. 点击其中一个名为‘Operator-Li’的用户点击编辑权限，弹出抽屉式表单卡片。  
3. 鼠标重点展示在其 change_groups 选项下勾选‘Initial Reviewers (初审组成员)’，并将其系统角色由 Viewer 变更为 Operator 的权限操作交互。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
