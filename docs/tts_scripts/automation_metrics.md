# 🎙️ 自动化 · 巡检指标 功能演示与配音脚本

> **模块名称 (Module)**: 自动化 (AUTOMATION PIPELINE)
> **功能名称 (Feature)**: 巡检指标 (Inspection Metrics Analyzer)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
单一时间点的异常只是孤立的切面，我们需要长期趋势的积累才能做出科学预测。巡检指标分析，是为全网设备打造的‘健康指标时空胶囊’。    在这里，系统提取了历史巡检中沉淀出的设备 C P U 使用率、端口错包数等时序数据，为您绘制出极具参考价值的时序趋势分析图。    让网络工程师能够跨时间段地对比分析核心资产的性能损耗，在硬件故障发生前提前做好升级扩容方案规划。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 切换至巡检指标图表页面，在设备选择器中选择核心交换机，在指标中勾选‘CPU 动态指标趋势’。  
2. 时间窗口选择‘最近7天’，图表框内瞬间绘制出华丽精致的蓝色渐变面积曲线图。  
3. 鼠标沿折线曲线由左向右滑过，展示在每日 CPU 均值和峰值浮动变化中，气泡跟随移动展示实时解析参数的效果。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
