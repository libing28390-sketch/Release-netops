# 🎙️ 容量与报表 · 报表中心 功能演示与配音脚本

> **模块名称 (Module)**: 容量与报表 (CAPACITY & REPORTS)
> **功能名称 (Feature)**: 报表中心 (Unified Reports Center)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
如何向公司管理层或者客户证明我们运维团队的高质量劳动成果？这就需要一份规范的月度网络运维体检报告。    报表中心是您最专业的全自动出图报告师。    您可以自由勾选需要汇总的指标模块——如包含设备在线率、巡检缺陷占比、工单平均审批用时和安全审计事件。    点击一键生成，系统会在数秒内渲染出一份排版极其规范、图文并茂的专业 Excel 或 HTML 网络运行报告，为团队的工作成果建立完美的数字化汇报底气。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 打开报表中心页面，展示历史生成的‘网络月度运行体检报告’文件列表。  
2. 点击顶部‘立即生成新报表’，勾选指标项：‘设备在线率历史均值’、‘高危漏洞整改清单’、‘PAM 会话次数统计’。  
3. 点击确定渲染，界面弹出精致的 HTML 预览页面，包含五彩斑斓的统计数据占比图表，指出可一键导出 Excel 和 PDF 的操作图标。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
