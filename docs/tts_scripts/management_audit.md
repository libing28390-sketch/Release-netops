# 🎙️ 平台管理 · 审计日志 功能演示与配音脚本

> **模块名称 (Module)**: 平台管理 (PLATFORM ADMINISTRATION)
> **功能名称 (Feature)**: 审计日志 (Unified Audit Logs)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
全方位的安全管控，需要记录下系统内每一次管理操作的痕迹。    审计日志是整个平台底座的网络行为记录仪。    系统支持对用户的登录会话、配置变更指令下发、RBAC 角色变动等核心敏感操作，进行秒级精准捕获。    在审计日志中，每一条记录都详尽包含了操作人的账号名称、来源 I P、具体的动作类别和执行时间。    高精度的历史追溯数据库，让一切操作有迹可循，从制度和技术上严防内部特权滥用隐患。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 进入平台管理底座下的‘审计日志’管理页，展示全天候不断生成的系统用户操作明细列表。  
2. 在操作人（Actor）搜索框输入‘admin’，筛选出管理员近期所进行的所有敏感操作（如用户角色变更、高危脚本发布）。  
3. 点击某条审计日志展开，向观众指出里面包含的 JSON 格式‘动作细节 (Details)’快照，体现审计数据的严密底座特征。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
