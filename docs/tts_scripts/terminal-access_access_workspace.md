# 🎙️ 终端接入 · 操作工作台 功能演示与配音脚本

> **模块名称 (Module)**: 终端接入 (TERMINAL ACCESS)
> **功能名称 (Feature)**: 操作工作台 (Operation Workspace)
> **视频分镜预估时长**: 45-50秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
忘掉繁琐的本地客户端和不安全的明文连接吧！    Net Sops 打造的云端一体化‘操作工作台’，将 Web 终端的便捷性发挥到了极致。    无论是 Linux 服务器，还是各类品牌的网络设备，您都可以通过网页，一键发起安全的 S S H 或 Telnet 会话。    右侧内置的便捷工具箱，支持快捷发送自定义命令，让复杂的操作不再需要手动复制粘贴。    支持标签页多会话并行，鼠标轻轻拖动即可完美实现分屏比对。云端会话全程加密，让网络工程师在任何地方都能享受如丝般顺滑的操作体验。
```

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 在操作工作台设备列表中选择一台核心交换机，点击‘Web SSH 连接’，秒级唤醒下方嵌入式深黑终端窗口。  
2. 在终端内输入‘show ip interface brief’或‘display this’演示命令行快速响应。  
3. 鼠标划过右侧工具箱，点击‘快捷下发指令’，一键自动填充并执行命令。演示终端多分屏效果。

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
