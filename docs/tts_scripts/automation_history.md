# 🎙️ 自动化 · 执行历史 功能演示与配音脚本

> **模块名称 (Module)**: 自动化 (AUTOMATION PIPELINE)
> **功能名称 (Feature)**: 执行历史 (Execution History Details)
> **视频分镜预估时长**: 45-50秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
如何证明您的自动化流水线曾经安全、准确地执行过？执行历史模块以极具可读性的交互为您呈现每一步执行证据。    点开具体任务的历史日志，平台彻底颠覆了以往密密麻麻、难以阅读的命令行纯文本排版。    首创了 Raw 原始文本与 Parsed 结构化解析表格的无缝一键切换！    只需点击“解析”标签页，繁杂的接口速率、核心温度、丢包情况，瞬间被清洗转化为极其精美、支持二次检索的表格，体现工业级运维系统的精致质感。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 导航打开执行历史页面，点击最近的一条‘网络硬件温度大检查’执行历史，弹窗呈现详情。  
2. 在弹窗内点击第一台交换机节点，展示它当时返回的原始终端命令行输出（Raw View），并向下缓慢拖动滚动条。  
3. **关键操作：** 鼠标向上移动，点击切换至 **“解析视图 (Parsed Table View)”** 标签！瞬间，所有的温度数值被转换成了整齐精致、带有红色警告标记（表示超标）的结构化表格，体现极致易用性。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
