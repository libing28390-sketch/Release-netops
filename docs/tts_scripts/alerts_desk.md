# 🎙️ 告警处置 · 告警中心 功能演示与配音脚本

> **模块名称 (Module)**: 告警处置 (ALERTS MANAGEMENT)
> **功能名称 (Feature)**: 告警中心 (Alert Center Desk)
> **视频分镜预估时长**: 35-40秒
> **建议配音音色**: `Neural2-B` (男声/稳重专业) 或 `Neural2-F` (女声/温柔知性)

---

## 🎙️ 配音解说词 (TTS 转换文本)

```text
在海量的系统告警中，快速锁定核心威胁，是运维人长期的痛点。    告警中心为您提供了极致清晰的响应台。系统自动过滤并收敛网络告警风暴，根据告警级别，分类呈现。    每一个告警卡片，都包含了详细的触发源、设备 I P、以及异常日志片段。    在告警中心，您只需一键点击操作列，即可快速调用对应设备的 Web S S H，或者一键触发自动应急处置流水线，将网络故障响应时长从传统的数十分钟，缩短至秒级。
```

---

## 💻 屏幕具体操作指南 (录屏画面动作)

1. 打开告警中心，突出亮红色的‘严重告警 (Critical)’和亮黄色的‘警告告警 (Warning)’指标卡片。  
2. 点击其中一条交换机 C P U 过载的告警，展开其异常日志片段，指出受影响的持续时间。  
3. 点击右侧操作菜单，演示“快速连接设备”和“执行排障脚本”的一键式联动响应交互。  

---

## 🎨 剪辑与视觉提示 (视频后期精修)

1. **鼠标微动作**：在录屏时，鼠标指针需要保持匀速滑动，到达点击目标前建议略微停顿 0.5 秒，体现操作的平稳和自信。
2. **局部特写 (Zoom In)**：在配音讲解核心图表（如心跳延迟趋势折线图、IP网格地图、左右对比差异区）时，后期剪辑建议对核心卡片进行 1.2 倍的局部放大特写，聚焦注意力。
3. **视觉涟漪特效**：当配音说到关键动作词（如“一键点击”、“一键认领”、“启动轮换”）时，在点击鼠标的瞬间加上黄色或亮青色的光圈涟漪特效，强化交互动作。
4. **背景音乐配乐**：全篇建议搭配轻快、充满科技感节奏的低保真（Lo-Fi）电子环境背景音乐，音量维持在 -25dB 至 -30dB，突出人声配音。

---

> [!TIP]
> **TTS 转换小贴士**：在往配音软件或 API 黏贴配音文本时，可以在长短句之间多打两个空格（代表停顿 0.5 秒），这能让合成出来的语音听起来更加自然、抑扬顿挫。
