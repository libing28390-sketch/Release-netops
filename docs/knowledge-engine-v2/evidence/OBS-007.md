## Implementation

1. Import 状态机和数据库租约协调器记录低基数生命周期事件：入队、领取、失败、
   重试、租约获取/占用/丢失/过期/存储错误与成功。
2. Reindex worker 记录入队、文档失败、作业失败/成功及租约异常；不改变现有
   `scheduler_locks` 语义或 V1 文档/Chunk 数据。
3. 聚合器从进程内 Import 状态机和 PostgreSQL 的
   `ai_knowledge_reindex_job`、`scheduler_locks` 读取队列状态，检测 running
   作业缺失、格式错误或过期租约。
4. `/api/ai/metrics` 增加 `jobs.observability`，告警阈值可由
   `AI_JOB_QUEUE_BACKLOG_ALERT_THRESHOLD`、`AI_JOB_FAILURE_ALERT_THRESHOLD`、
   `AI_JOB_LEASE_ANOMALY_ALERT_THRESHOLD` 配置；默认分别为 100、1、1。
