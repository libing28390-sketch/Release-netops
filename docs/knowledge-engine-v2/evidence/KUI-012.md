实现内容：
- 新增 `/api/ai/assistant/documents/{document_id}/actions/{action}` 独立动作合同，动作包括 `delete`、`disable`、`enable`、`reparse`、`rechunk`、`reindex`。
- 所有动作服务端强制 `confirm=true`，请求模型 `extra=forbid`，权限统一为 `ai.knowledge.manage`，租户从认证用户取得，不接受客户端租户覆盖。
- `disable/enable/delete` 在 PostgreSQL 单事务内执行；删除同时删除 Chunk，但保留 metadata-only 动作 ledger。禁用保留 Chunk 与索引并提供 enable 恢复。
- `reparse`、`rechunk`、`reindex` 使用带 `operation` 与 `action_id` 的租户任务；Reparse 只更新解析 Metadata，Rechunk/Reindex 走现有事务性 Chunk/Embedding 替换和租约保护。
- 新增 `ai_knowledge_document_action` 记录确认、租户、操作者、影响计数、恢复方式、任务关联和安全错误码，不写正文、Chunk 内容、凭据或内部存储路径。
- 知识管理列表为每个文档提供独立的禁用/启用、Reparse、Rechunk、Reindex、删除按钮，每个动作单独弹出确认并显示影响与任务结果；批量删除也要求显式确认。
