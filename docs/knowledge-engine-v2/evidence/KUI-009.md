目标：实现官方知识与企业知识明显分区。

修改文件：backend/ai/services/knowledge_service.py；backend/ai/api/assistant.py；src/api/ai.ts；src/pages/ai/Knowledge/KnowledgeManagementTab.tsx；backend/tests/ai/test_kui_001_008_knowledge_admin.py；scripts/knowledge_engine_v2_kui_pg_probe.py。

执行命令：聚焦 KUI 测试；PostgreSQL KUI 探针；`py_compile`；`npm.cmd run lint`；`npm.cmd run build`；`git diff --check`。

测试结果：聚焦测试与 PostgreSQL 探针通过；官方 scope 只能返回官方来源，企业 scope 不泄漏官方文档；前端 lint/build 通过。

数据库影响：无新增 DDL；仅使用现有 PostgreSQL `ai_document.knowledge_source_type`。

安全影响：scope 仅接受固定枚举并在 SQL 参数中绑定；租户谓词和权限依赖保持不变，未知 scope 不扩大可见范围。

回滚方式：回退 scope 参数、分区卡片与契约改动，不删除知识数据。

已知限制：官方 Source Registry 的具体导入表单属于 KUI-010/KUI-015。
