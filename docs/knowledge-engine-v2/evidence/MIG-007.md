## 安全、数据库与回滚

- 只执行 PostgreSQL `BEGIN READ ONLY`；没有 job/document/chunk/embedding/index 写入，也没有外部 Provider/官方站点请求。
- 计划只保留 hash/计数/阶段，不保存正文、来源 URL、凭据、ACL、DSN 或异常原文；租户身份以 hash 形式存在。
- 解除阻断后仍必须使用现有 `KnowledgeReindexService` 的事务替换、维度校验、Compare-and-Set 和失败原子性；本 gate 不绕过这些边界。
- 回滚：停止 rebuild worker，继续读取 V1 projection；所有旧文档和旧 Chunk 保持不变。

3. 通过 Provider 维度、Chunk 原子替换、并发编辑和失败回滚的 PostgreSQL 探针后，才允许 apply。
