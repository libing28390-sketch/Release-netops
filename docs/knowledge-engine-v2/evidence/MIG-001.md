## 实现内容

- Document：V1 `ai_document` 原始内容/来源/hash 先做 PostgreSQL 只读 inventory，再追加 `kb_document`/`kb_document_version` 不可变版本；缺 hash、来源、租户或 ACL 证据的行隔离，不覆盖或删除 V1。
- Metadata：保留原始 JSON/typed columns 作为输入证据，按固定 parser/schema 解析、规范化厂商/产品/OS/版本/CLI platform，计算可复现 metadata hash；未知、冲突、Secret/ACL 越界行 quarantine，不得 active。
- Chunk：只从可信、已验证 Document Version 重建 append-only generation，保留 raw/embedding content、结构角色、父子关系、locator 和 hash；孤儿、重复、环、stale 或失败 generation 不得进入检索。
- Embedding：不盲拷 V1 JSON/TEXT 向量；锁定 provider/model/dimension/mode/contract 后，对验证过的 active Chunk generation 批量重算，校验 vector hash、维度、租户和 index generation，shadow 对比后才允许 feature flag 切换。
- 顺序冻结为 W0 inventory → W1 Document/version → W2 Metadata → W3 Chunk generation → W4 Embedding/index shadow → W5 retention cleanup；生产写入只允许 release-gated transaction。
