# OBS-003 Evidence

- Task ID: OBS-003
- 原始要求: `Trace 和日志写入前脱敏，限制原始查询保留。`
- 目标: 在 Trace、AI Gateway/Assistant 日志和统一日志处理器写入前执行脱敏，限制 raw query 只在请求作用域存在，避免密钥、Provider payload、私钥和异常正文进入可持久化面。

- 实现内容:
  - Trace `_text` 在 projection 前统一执行 bounded log sanitizer；raw query 仍只输出 captured/hash/length，normalized query、实体、过滤器和引用字段不会带出 secret assignment、Bearer 或私钥内容。
  - 新增 `sanitize_log_text`，覆盖 API key/token/password/secret/community/authorization/cookie/private-key assignment、Bearer token 和 PEM 私钥；Trace 文本保留既有 `<redacted>` 兼容标记。
  - AI Gateway/Assistant 不再把 Provider exception、fallback traceback 或原始错误字符串写入日志，只记录稳定 error code；根日志与 console/file handlers 均挂载 SanitizeFilter。
  - 为直接调用的 Source Registry 分页 API 规范化 Query 默认对象，并以 `checked_at` 作为刷新观察排序字段；摘要显式返回 `version_signal`，不返回正文/秘密。
