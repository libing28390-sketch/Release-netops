## 实现内容

1. 默认 `dry-run`：只消费 MIG-003 manifest，按 25 行 bounded batches 规划，零目标写入。
2. checkpoint 使用原子 temporary-file→replace，绑定 `manifest_sha256` 与 `batch_size`；绑定不匹配直接 fail-closed。
3. apply 引擎以 `(tenant_hash, legacy_id, v2_document_id, v2_document_version_id)` 为幂等键；已完成 checkpoint 会再次核验目标存在，全部存在则返回 idempotent noop，缺失则报错。
4. 每个 batch 独立 begin/commit/rollback；失败只回滚当前 batch，保留上一 checkpoint 的 cursor，状态为 `retry_wait`。
5. PostgreSQL rollback probe 仅创建临时表、写入一条探针记录、回滚 savepoint 和整笔事务；不触碰持久表，SQLite 禁止。
