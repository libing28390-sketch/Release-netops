- 实现内容:
  - `/api/ai/metrics` 的 `AIMetrics` 新增 Provider/Model 维度：requests、success、errors、error_rate、avg/P95 latency、input/output tokens、estimated_cost_usd。
  - Provider rate limit、concurrency timeout、circuit open 和 quota 事件进入 bounded limits counter；Fallback 记录 started/success/error。
  - Gateway request completion 统一调用 provider metrics；错误请求保留 provider identity 和稳定 error code；现有 `ai_usage_daily` 仍按日持久化 tokens、cost、success/error、avg latency。
  - `/api/ai/usage/summary` provider_breakdown 增加 success/errors/error_rate，并兼容缺少 additive success/error 列的旧表结构。
  - 所有指标只保存低基数标识、计数、时延、token 和估算成本，不保存请求正文、响应正文、异常原文或凭据。
