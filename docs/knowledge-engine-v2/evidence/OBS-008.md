## 实现

- PostgreSQL authoritative read-only catalog probes：relation bloat/index bytes、`pg_statio_user_tables` cache hit/read、database size/capacity budget。
- 慢查询优先使用 `pg_stat_statements`；扩展不可用时使用 `pg_stat_activity` 当前活跃查询时长 fallback，保证观测接口可用。
- API 继承 `ai.audit.view`，响应仅含低基数聚合；query text、参数、凭据、tenant id 和正文始终不出现在响应。
- 前端 Usage Dashboard 展示数据库观测摘要和 WARN 状态。
