- 实现内容:
  - assistant 在请求边界把原始 query、规范化 query、实体、服务端 filters、候选结果和最终 chunks 传给 trace store；这些字段不回写到 V1 conversation。

  - 候选与 Chunk 身份使用 opaque hash；不存储或返回原始 query、文档正文、Chunk 正文、URL、SQL、凭据或用户名。
  - 保留 KUI-017 的 `query_hash`、租户过滤和 redaction flags，跨租户 trace 仍返回空/404。
- 架构决策: 清单要求观察 raw query，但已冻结的 DB-012/RET-001 明确禁止 raw query 进入 debug/audit/storage。因此本任务记录“原始 query 已在请求边界捕获”的事件、哈希和长度，原文仅存在当前请求作用域，不进入 trace/API/数据库；这是在不破坏既定安全架构下的可行实现。
