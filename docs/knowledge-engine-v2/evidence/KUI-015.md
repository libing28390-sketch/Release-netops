### 实现内容

- 新增 tenant-scoped `GET /api/knowledge-v2/sources/{source_id}/refresh-status`，聚合最近 200 条追加式刷新观察，给出 healthy/failed/attention/never_checked/not_configured 状态、稳定错误码、结果计数和最新 source version 摘要。
- Source Registry 列表保留服务端状态筛选；详情按需读取刷新状态和观察历史；响应不返回正文、秘密、内部文件路径或原始异常。
- 知识库管理增加“文档与版本 / Source Registry / 刷新”视图切换，支持来源列表、校验、立即刷新、观察历史、错误状态、空态、失败态和窄屏自适应布局。
- 复用 CAT-003 CRUD、ING-018/019 采集和 m0120/m0121 append-only 观察事实，不改变 V1 `ai_document`。

### 安全、权限与审计

- 所有列表、详情和观察历史均由 Source Registry 服务执行 tenant scope 和 `knowledge_source.read`；刷新动作沿用 `knowledge_source.create`。
- 状态接口只输出哈希/计数/稳定错误码；不会回显 response body、headers、metadata 原文或凭据。
- 创建/校验/刷新仍写入现有 audit spine，观察证据保持 append-only。

### 回滚方式

回退 status read model、路由、类型和 Source Registry 面板即可；不删除 Source Registry 或刷新观察事实。freshness schema 未启用时安全返回 `not_configured`，保持 V1 可运行。

### 已知限制

“立即刷新”需要来源已启用且受 CAT-004 外发策略允许；面板不会在浏览器端执行网络请求，失败只展示稳定错误码。
