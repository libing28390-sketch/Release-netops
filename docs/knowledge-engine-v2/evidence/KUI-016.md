### 实现内容

- 新增 tenant-labelled `GET /api/knowledge-v2/evaluation` 和 `POST /api/knowledge-v2/evaluation/run`，只允许固定 `v1_baseline_postgresql` 套件。
- 复用 PostgreSQL V1 基线临时表/事务执行器；执行前后恢复检索器连接、PG 开关和 embedding 函数，避免污染在线进程。
- 返回 Recall/Retrieval Accuracy、Citation Accuracy/Recall、Wrong Vendor、Version Conflict、P50/P95 等指标和固定门禁；用例输出仅保留 Case、Query、布尔结果、精度和延迟，不返回 SQL、debug、文档 ID 或正文。
- Knowledge Management 增加 “RAG Evaluation / 回归” 视图，包含未运行、加载、失败、PASS/FAIL、门禁、延迟、用例表、窄屏横向滚动和 PostgreSQL 运行入口。
