# MIG-002 Evidence

- Task ID: MIG-002
- 原始要求：可信原始文档优先迁移；不可证明质量的 Chunk/Embedding 不直接迁移。
- 最终状态：PASS（策略与准入门禁完成；实际迁移未执行）。

## 目标

冻结 PostgreSQL 权威下的 source-first 迁移准入规则，确保只有可由原始文档、来源和 SHA-256 清单证明的文档进入后续迁移波次；Chunk 和 Embedding 不允许直接复制，必须在可信版本与固定模型契约下重建。

## 实现内容

1. PostgreSQL `BEGIN READ ONLY` 清点 legacy `ai_document`/`ai_document_chunk`，不执行生产 DDL 或写入。
2. 文档按原始内容、来源、声明 hash、原始内容 hash、normalized hash、租户、状态和排除标记分类。
3. 声明 hash 仅匹配 normalized 派生值而不能证明原始字节时，标记为 `conditional_reconciliation_required`，不提升为 trusted。
4. Chunk/Embedding 的 direct copy 永久禁止；后续必须从可信 document version 重建 chunk，并通过固定 provider/model/dimension/index 契约重新生成 embedding。
5. 报告只输出计数、状态和 hash，不输出文档 ID、原文、密钥、连接串或异常原文。
