### 实现内容

- 版本比较 API 仅返回租户内两版本的哈希、元数据 key、解析器、信任级别、大小和有界行数差异，明确不返回正文。
- 发布和替代沿用 CAS 生命周期服务，发布/替代在同一事务更新 `kb_document.current_version_id`，替代要求同文档且 replacement 已发布。
- 新增原子回滚服务：锁定文档及目标/当前版本，在一个事务中 supersede 当前版本、发布目标版本、移动 canonical pointer 并写生命周期事件；源版本事实不被改写，重复 request_id 幂等返回。
- API 使用 Pydantic `extra=forbid`，所有变更要求显式 `confirm=true`，服务端再次执行 `knowledge_source` 权限和 tenant 过滤。
- 前端版本历史显示比较、发布、替代、回滚按钮，所有危险动作显式确认，显示安全的比较摘要和成功/错误状态；无 V2 lineage 的旧 V1 文档不显示伪造管理动作。
- 生命周期审计改用受支持的 `target_type/target_id/request_id` 参数，并仅写 ID、状态和租户摘要。

### 安全、权限与审计

- 比较、列表和变更均 tenant-scoped；跨租户版本按稳定 Not Found 处理。
- 变更权限为 `knowledge_source.update`，读取为 `knowledge_source.read`；API 和服务双重校验。
- 比较响应不含 `original_content`/`normalized_content`；审计不含正文、URL、密钥或 ACL。
