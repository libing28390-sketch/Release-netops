- 实现内容:
  - m0146 以 additive columns/indexes 补齐旧 Agent、工具、证据和诊断记录的 tenant/user opaque scope，并执行可重复 backfill；不删除旧字段。
  - conversation/task API 在创建、读取、取消、反馈和消息上下文路径均先验证 tenant + purpose-bound opaque owner；任务不能引用其他用户的会话。
  - Agent runner 将 run、step、tool call、evidence 写入同一 scope，trace/cancel 只读取该 scope；返回的 tool/evidence 是有界元数据投影。
  - 诊断 case 不能绑定其他用户会话，case handoff、run、step 均按 case owner 过滤；旧 schema fallback 不改变已存在 V1 路径。
  - 原始工具参数、工具结果、证据正文不落入 API-008 新审计投影；只保存 key、状态、来源和 citation 等安全摘要。
