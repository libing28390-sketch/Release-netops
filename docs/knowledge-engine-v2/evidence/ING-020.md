## 实现内容

- Import Job API 支持 `execution_state`、`phase`、`job_kind`、`search`、`page`、`page_size`，页大小限制为 1～100，默认 20。
- 列表响应增加 `items/total/page/page_size/total_pages`，保留已有 `success/data/count` 兼容字段。
- 列表只返回有界摘要，不返回 tenant_id、idempotency_key、原始 errors、audit_events、phase_history 或 Worker fence 信息。
- 前端加入导入任务表格、状态/阶段筛选、搜索、服务端分页、进度条、成功/失败计数、错误详情按需加载和失败重试。
- 服务器继续执行 `knowledge_import.read`、`knowledge_import.retry` 权限和 tenant predicate；重试只允许失败或 retry_wait。
- 空列表、筛选无结果、加载失败、加载中和重试中均有明确 UI 状态。
