# DHCP租约功能介绍

- 所属模块：IPAM
- 英文名称：DHCP Leases
- 页面路由：`/ipam/dhcp`
- 导航 ID：`ipam-dhcp`
- 文档依据：当前代码、PDF 全量整改要求及对应专项建议书。

## 业务目标

DHCP租约为 IPAM中的正式子功能。它帮助具备相应权限的用户完成查询、判断、操作或审计，并通过清晰的状态和证据减少误判。

## 本次整改与核验重点

以 PostgreSQL 持久化数据为事实源，页面明确展示加载、空数据、未知、失败和成功状态，并保留来源与更新时间。

## 核心能力

1. 从统一侧栏进入并保持稳定路由。
2. 按当前用户角色展示允许查看或操作的内容。
3. 对关键对象提供检索、筛选、详情和必要操作。
4. 明确数据来源、更新时间以及无数据或采集失败原因。
5. 重要操作产生可追踪结果；高风险操作必须确认、审批或再次认证。
6. 后端事实数据持久化到 PostgreSQL，前端不以硬编码演示数据替代真实结果。

## 状态与证据模型

- 正常：存在足够的当前证据且符合规则。
- 异常：存在明确失败、冲突或越界证据。
- 未知：证据未采集、采集失败或不完整。
- 未配置：功能依赖尚未配置，与正常或异常均不同。
- 无数据：查询成功但当前范围没有记录，不得文案化为“一切正常”。

## 权限与安全

页面可见性不是唯一权限边界；后端 API 必须再次校验角色与资源范围。密码、令牌、MFA 动态码和敏感配置不得写入普通日志或导出文件。
