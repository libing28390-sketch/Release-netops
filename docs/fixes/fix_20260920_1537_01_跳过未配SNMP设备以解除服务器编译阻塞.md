# 修复记录：跳过未配 SNMP 凭证设备以解除监控编译阻塞

## 1. 问题现象
- 在宿主机上执行全量监控同步时报错：
  `services.monitoring_compiler.CompileError: AUTH_NOT_CONFIGURED: asset=asset-5c788264d2fc`
  导致编译失败中断，无法生成与发布 `linux_targets.yml`。

## 2. 根因分析
- CMDB 中部分设备未绑定 SNMP 凭证，在 `_load_compile_inputs` 加载设备时全部传入了 SNMP 编译流程，触发强校验报错崩溃，阻断了后续服务器目标的生成。

## 3. 解决方案
- 在 `_load_compile_inputs` 中：
  - 自动跳过 `role='server'` 的服务器设备；
  - 过滤掉未配置有效 SNMP 凭证或 Community 的设备，记录 warning 日志，防止单个未就绪设备阻塞整个监控系统编译。

## 4. 实际修改文件
- `backend/api/monitoring_v1.py`

## 5. 验证命令与结果
- `& "d:\nexora\nexora-private\.venv\Scripts\python.exe" -m pytest backend/tests/monitoring/test_monitoring_v1_compiler.py backend/tests/monitoring/test_domestic_and_wireless_monitoring.py`
  - 结果：`22 passed in 42.85s`。

## 6. 风险与回滚方式
- 风险：极低，仅跳过无效设备避免崩溃。
- 回滚：`git revert HEAD`。
