# 告警 Redis 凭据自动初始化

## 问题现象

首次 Docker 部署从 `.env.example` 创建 `.env` 后，`ALERT_NOTIFICATION_BROKER_PASSWORD` 为空；Compose required interpolation 随即失败，安装中断。

## 根因

环境模板刻意留空该密码，但部署脚本的 `initialize_env` 没有生成此项，也没有将其列入初始化变更记录。

## 解决方案

- 部署脚本在该值缺失或空白时生成 `nexora` 前缀、带随机十六进制后缀的 URL-safe 口令。
- 现有非空值保留；生成值写入目标 `.env`，沿用现有环境变更报告逻辑且不打印口令。
- 模板说明安装脚本会生成该口令，Compose 错误提示指出可运行的安装/更新命令。
