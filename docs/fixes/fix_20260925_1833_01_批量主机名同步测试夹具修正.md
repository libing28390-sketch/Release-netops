# 批量主机名同步测试夹具修正

## 问题现象

GitHub Actions 中 `test_batch_sync_hostname_mocked[asyncio]` 断言期望 `updated == 1`，实际为 `2`；同批次其他 2297 项通过，另有 1 项跳过。

## 根因

批量接口现在通过 hostname 同步服务返回的新旧名称判断是否更新。原测试仅模拟批量设备查询的 `fetchall()`，没有模拟同步服务按设备 ID 查询数据库的 `fetchone()`；未配置的 mock 返回 `MagicMock`，使测试无法提供真实旧 hostname。

## 解决方案

为批量接口测试 mock hostname 同步服务，根据设备 ID 返回样例中的旧 hostname 和规范化后的新 hostname，并断言服务被调用两次。生产逻辑无需修改。
