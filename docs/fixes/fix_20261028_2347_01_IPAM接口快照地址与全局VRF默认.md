# IPAM 接口快照地址恢复与全局 VRF 默认

## 问题现象

更新后 IP 地址页显示网段数量但地址列表为空，接口候选弹窗也显示 0。数据库中正式 `ip_addresses` 台账为空，但最近一次成功的 CMDB 接口快照仍有 IP 观察记录。

## 根因

IP 地址页查询固定要求 `registered_only=true`，只显示正式 IPAM 登记；接口候选服务只读取旧 `interfaces` 表，而当前 CMDB CLI 数据写入隔离快照表。两条页面读取源都没有跟随 CMDB 快照切换。另因接口快照没有 VRF 字段，原候选流程将这些网段全部阻塞在归属确认。

## 解决方案

- IP 地址页合并显示正式登记与只读接口观察，分开统计并保留只读行为。
- 候选读取每台设备最后成功的 CMDB 接口快照；没有成功快照的旧设备继续回退到 `interfaces`，避免同设备重复。
- 快照缺少 VRF 时，默认按全局/默认生成；精确 CIDR 在同租户、同站点唯一对应已有前缀时沿用已有 VRF。生成前可改选本租户 VRF，后端校验覆盖项与候选及租户匹配。
- 不改监控、ARP/MAC 采集、网络驱动或 TextFSM/解析模板，不把快照观察自动写入正式 IPAM 台账。
