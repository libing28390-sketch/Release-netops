# CI 收集阶段数据库初始化修复

## 问题现象

GitHub Actions 收集 `backend/tests/vendor_audit/test_network_access_limiter.py` 时，导入 `background_monitor_service.py` 查询 `alert_rules`，因 schema 尚未初始化报 `psycopg2.errors.UndefinedTable`。

## 根因

telemetry 状态初始化位于模块顶层，早于 pytest 的 PostgreSQL schema fixture。

## 解决方案

删除模块导入时的 `_init_telemetry_state()` 调用，改在 FastAPI lifespan 已执行 `init_db()` 后的 `_bg_init()` 中调用。

## 验证与回滚

- Python 编译和静态发布合同检查通过。
- CI 需要重新执行完整 pytest 收集与测试。
- 回滚本提交即可恢复原行为；不修改真实数据库。
