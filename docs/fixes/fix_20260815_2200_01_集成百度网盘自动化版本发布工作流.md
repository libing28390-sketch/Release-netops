# 集成百度网盘自动化版本发布工作流

## 1. 问题/需求背景
用户希望在发布 Windows 安装包（`NetOps.exe` 与 `NexoraTerminalAgent.exe`）时，能够全自动上传至百度网盘指定目录并归档版本，无需人工每次手动登录网页上传。同时需要精确控制上传触发时机，避免日常开发 push 产生过多碎片版本。

## 2. 解决方案
1. **GitHub Actions 集成 `bypy`**：
   - 在 `.github/workflows/release.yml` 的 `release-windows` 作业末尾添加 `Upload Windows Executables to Baidu Pan (百度网盘)` 步骤。
2. **严格版本与触发控制**：
   - 设定触发条件为 `if: startsWith(github.ref, 'refs/tags/') || github.event_name == 'workflow_dispatch'`，日常代码推送不会触发网盘上传。
3. **双轨制网盘目录结构**：
   - **最新稳定版（覆盖更新）**：固定上传至 `/NetOps_Release/最新稳定版/`，方便用户对外生成永久分享链接。
   - **历史版本归档**：以 Tag 名称（如 `v1.0.0`）及构建日期自动归档至 `/NetOps_Release/历史版本归档/${TAG_NAME}/`。
