# YunShan 测试文件收集错误修正记录

## 问题现象

GitHub Actions run `37410521721` 执行完整后端 pytest release gate 时，在收集两个 YunShan 测试模块阶段失败：文件末尾的反斜杠和字母 n 被解析为续行符后的非法字符。

## 根因

上一轮清理测试文件 EOF 空行时，命令的字节转义写错，把换行转义写成了普通文本。该错误由我引入。

## 解决方案

删除两个测试文件末尾的非法字符并保留标准换行。没有调整测试断言或产品逻辑。
