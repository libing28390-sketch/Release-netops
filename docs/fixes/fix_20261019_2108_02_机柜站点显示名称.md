# 机柜站点显示名称修复记录

## 问题现象

机柜页面显示的是默认站点内部代码，用户希望显示对应站点名称。

## 根因

机柜页面解析站点标签时优先选择 `site_code`，即使站点列表和机柜 API 都提供了更易读的 `site_name`，代码仍会盖过名称。

## 解决方案

新增站点标签解析 helper，优先显示关联站点目录名称，其次使用机柜 API 名称；只有名称缺失时才回退到站点代码、数据中心标签或站点 ID。机柜列表和复用该解析器的机柜视图使用相同规则。
