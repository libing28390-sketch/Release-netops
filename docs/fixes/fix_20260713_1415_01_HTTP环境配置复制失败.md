# HTTP 环境配置复制失败

## 问题

通过局域网 HTTP 地址访问配置备份页面时，点击配置查看弹窗中的“复制”按钮提示复制失败。

## 原因

页面仅调用 `navigator.clipboard.writeText`。该接口通常要求 HTTPS 或 localhost 安全上下文，通过 `http://192.168.18.1:5150` 访问时浏览器会拒绝调用。

## 修改

- 安全上下文中继续优先使用 Clipboard API。
- Clipboard API 不可用或被拒绝时，自动使用隐藏文本域和浏览器兼容复制命令。
- 根据复制命令的实际返回结果显示成功或失败提示。

## 结果

配置内容在 HTTPS、localhost 和局域网 HTTP 访问场景下均可复制。
