# 修复 CMDB 站点导入拒绝国内 11 位手机号与座机号问题

## 1. 问题现象
用户在 `http://192.168.56.1:5400/cmdb/sites` 导入站点时，表格中填写的电话号码为 `13111111111`，后端返回报错：
`contact_phone：contact_phone must include an international country calling code, for example +8613800000000`

## 2. 根因分析
- 后端 Pydantic 校验模型 `SiteCreate` 在校验 `contact_phone` 字段时，显式传入了 `international_required=True`，并且后置模型校验器只接受以 `+86` 开头的 11 位手机号。
- 前端 UI 与导入模板提示均为“例如 13800000000，支持 11 位手机、座机（010-12345678）或国际号码”，前后端契约存在不一致。

## 3. 解决方案
- 修改 `backend/schemas/schemas.py`：
  - `SiteCreate.validate_contact_phone`: 移除了 `international_required=True` 强制约束。
  - `SiteCreate.validate_phone_for_country`: 更新正则为 `r'^(?:\+86|0)?1[3-9]\d{9}$|^0\d{2,3}-?\d{7,8}$|^\+[1-9]\d{6,14}$'`，全面放行 11 位国内手机号、座机号及国际号码。
- 新增单元测试 [test_cmdb_sites_import_export.py](file:///d:/netops/netsops-main/backend/tests/configuration/test_cmdb_sites_import_export.py)。
- 重启端口 5310 上的 NetOps 后端应用。
