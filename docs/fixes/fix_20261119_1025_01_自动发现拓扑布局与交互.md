# 自动发现拓扑布局与交互

## 问题现象

较大的自动发现拓扑集中在画布中央，设备排成窄长多行。提高每行数量后，核心、汇聚、接入和无线设备仍难区分。拖动设备后可能跳位或在重绘时回到原行。导出的图带有窗口留白，端口标签可能重新出现，无线图标可能缺失。用户也需要用鼠标滚轮缩放画布。

## 根因

分层算法固定每行容量，渲染又按可视窗口限制横向坐标。自动布局与手动坐标共用状态，重绘时重新计算分层和适应视图。角色标题按物理行重复，所有链路同时绘制。导出沿用屏幕视角与外部图标地址，D3 缩放过滤器屏蔽了滚轮事件。

## 解决方案

- 支持输入每行容量，按角色和无线关系分组，并根据实际内容等比适应画布。大图默认显示主干，可按设备查看关联链路或切换到全部链路。
- 手动坐标单独保存，拖放期间保持视角，支持撤销和重做。设备名优先避让其它名称和设备图标。
- 鼠标在画布内以指针位置为中心缩放。PNG 和 SVG 按图形范围裁剪，保留图上链路和端口标签的显示状态，并嵌入同源图标。
- 提供含 60 台模拟接入交换机、2 台无线控制器和 12 台 AP 的本地演示。

## 风险与回滚方式

将每行容量设得很大时，适应画布会缩小设备和名称，可滚轮放大检查局部。若需回滚，通过 `git revert` 撤销本提交。
