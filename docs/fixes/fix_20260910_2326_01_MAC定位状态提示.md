# MAC 定位状态提示

## 问题现象

IP 定位在设备 MAC 表采集关闭、设备不支持 MAC 表、查询失败、已查询未命中和命中之间使用同一条提示；即使 H3C 交换机返回了有效 MAC/端口，用户也可能看到“未在 MAC 表中发现”。终端结果还直接展示内部 `PATH_TRACED` 枚举和冗长追踪备注。

## 根因

MAC 查询函数原先只返回记录列表，所有空结果原因均被压成 `[]`；前端没有状态字段，只能使用硬编码 ARP 降级文案。原始 MAC 表输出在部分平台注册/解析路径中也没有统一兜底。位置类型枚举没有经过用户界面标签映射。

## 解决方案

- 为 MAC 查询增加 `not_attempted`、`disabled`、`unsupported`、`query_failed`、`not_found`、`found` 状态，并用 list-compatible 结果包装保持旧调用方兼容。
- 对平台注册动作、定向命令和全表回退统一归因；解析器未产出记录时复用安全的原始 MAC 表行解析。
- 在定位响应中返回 `mac_lookup` 和多跳尝试记录；ARP-only 说明根据真实状态生成。
- 前端主定位页与复用面板显示状态标签，允许已有 MAC 结果强制实时刷新；隐藏冗长 `PATH_TRACED` 备注并将其映射为“已定位到接入端口”。
