# 今日主线改动

## 问题现象与提交目的

用户要求将 2026-10-14 在 `main` 工作区完成的代码修改推送到 `main`。当天工作涉及采集器自动同步可见性、系统运行时长采集周期、通知 Relay 启动依赖和服务器远程桌面资产导入；需要以单个可追溯提交交付。

## 根因与范围

这些改动分别对应此前确认的产品问题，不是同一运行时故障：采集器详情缺少自动发布状态说明，系统运行时长默认周期为 900 秒，Relay 可能早于数据库迁移完成启动，资产导入模板尚未支持远程桌面配置。

仅纳入当天上述实现及其配套计划、走查文档；未纳入 2026-10-13 发布文档修改、临时构建目录、部署/审计材料和运行日志。

## 解决方案

- 采集器详情显示现有配置发布状态、最近生效时间和自动同步说明，并将操作按钮标为手动操作。
- 新迁移将内置 `generic_system_std` 的旧默认周期从 900 秒调整为 300 秒；不覆盖自定义周期。
- `alert-notify-relay` 启动前等待 `netops` 健康，确保主服务迁移先完成。
- 资产导入模板及前后端导入流程支持为新服务器导入 RDP/VNC 配置，并继承资产凭据。
