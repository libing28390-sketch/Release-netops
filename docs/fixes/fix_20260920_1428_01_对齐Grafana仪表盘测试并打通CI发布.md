# 修复记录：对齐 Grafana 仪表盘完整性测试并打通 CI 发布流水线

## 1. 问题现象
- GitHub Actions CI 在 `backend/tests/monitoring/test_domestic_and_wireless_monitoring.py::test_dashboards_suite_completeness` 断言失败：
  `AssertionError: Dashboard file network-device.json missing`
- 由于 CI 失败，导致 GitHub Actions 自动发布工作流被中断，未向公有发布仓库 `Release-netops` 推送包含最新指标与 Grafana 修复的代码和镜像，宿主机拉取时代码停留在历史提交 `9bfc7e1`。

## 2. 根因分析
- 在清理旧的重复仪表盘文件时，移除了未带前缀的旧版文件（如 `network-device.json`），统一使用 `nexora-*.json`。
- `test_domestic_and_wireless_monitoring.py` 内部 `expected_files` 未及时对齐为规范的 `nexora-*.json` 文件名，导致测试找不到旧文件报错。

## 3. 解决方案
- 将 `expected_files` 中的仪表盘文件名列表更新为包含现存全部 8 个规范仪表盘：
  - `nexora-network-overview.json`
  - `nexora-network-device.json`
  - `nexora-network-wireless.json`
  - `nexora-network-interface.json`
  - `nexora-monitoring-health.json`
  - `nexora-network-outbound.json`
  - `nexora-linux-metrics.json`
  - `nexora-windows-metrics.json`

## 4. 实际修改文件
- `backend/tests/monitoring/test_domestic_and_wireless_monitoring.py`

## 5. 验证命令与结果
- `& "d:\nexora\nexora-private\.venv\Scripts\python.exe" -m pytest backend/tests/monitoring/test_domestic_and_wireless_monitoring.py`
  - 结果：`5 passed in 43.76s`。

## 6. 风险与回滚方式
- 风险：极低，仅同步测试断言与现有规范化仪表盘列表。
- 回滚：`git revert HEAD`。
