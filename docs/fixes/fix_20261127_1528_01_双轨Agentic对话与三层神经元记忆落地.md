# 修复与功能提交记录：AI Copilot 双轨混合路由、十二大模块工具化与三层神经元记忆落地

- **提交时间**：2026-11-27 15:28
- **目标分支**：`feat/cmdb-rack-3d-odf`（远端 `release/feat/cmdb-rack-3d-odf`）

## 1. 问题现象与提交目的
1. AI 中心 `/ai/usage` 展示内部模型/供应商 ID 而非真实名称，`/ai/health` 未覆盖 `embedding` 等全部已启用模型。
2. Copilot 此前存在纯正则静态大表劫持自然语言、单句查数（如“查一下我们有多少台设备”）走多轮 LLM 消耗 3,578 Token、4 步工具流偶发 1-Token 空流、只读 CLI（`display snmp-agent community`）误脱敏以及本地知识库示例命令拼入 `role="user"` 触发 `AI_SECURITY_UNSAFE_TOOL` 误拦截等问题。
3. 本次提交将全部 AI Copilot 优化（Usage/Health 修复 + 十二大模块只读总线 + 双轨混合路由 + 0-Token 实体预取证 + 三层运维神经元记忆系统 + 安全边界修复）统一合入并推送。

## 2. 根因与解决方案
- **Usage & Health 展示/探测**：后端补齐模型/供应商真实名称映射与全模型类型健康探测，前端同步修复展示与 Toast 类型。
- **十二大模块只读总线 & 实体工作记忆**：新增 `entity_context.py`、`module_bus.py`、`local_ops_queries.py`、`semantic_cache.py` 与 `local_router.py`，提供 RBAC 校验与零密钥列只读查询。
- **双轨混合路由（轨道 A 0-Token 极简事实快道 + 轨道 B 原生 LLM 推理）**：
  - 轨道 A：短句（≤ 36 字）单一客观事实查询（设备数量/在线状态、告警是非、单设备档案/机柜/登录/漂移/合规、站点/凭据/工单/IPAM/总览、`/slash` 指令）直接 0 Token 秒回极简摘要；
  - 轨道 B：新增 `copilot_tools.py`（9 个精简只读工具 + `prefetch_local_facts()` 0-Token 预取证单次流式直出），在 `assistant.py` 中实现多工具并行调用与多可能性推理，并通过 `_build_synthesis_messages()` 将只读工具/知识库证据隔离在 `role="assistant"` 消息中，彻底消除 Gemini 空流与 `AI_SECURITY_UNSAFE_TOOL` 误杀。
- **三层运维神经元记忆系统**：新增 `memory_graph.py`（PostgreSQL 幂等建表 `ai_memory_nodes` / `ai_memory_edges`），实现滑出窗口 0-Token 短期滚动摘要、2 跳实体突触扩散激活、时间衰减与赫布强化，并暴露 `/api/ai/assistant/memories` 管理接口与 `ops_memory_graph` 工具。
- **安全与脱敏边界**：修复 `classification.py` 与 `sanitizer.py` 对只读 `display snmp-agent community` 的误脱敏，保留对真实密钥赋值的严格脱敏；知识库片段返回模型前做前置脱敏。
