# Git Commit 修复记录：修复思科拓扑链路未显示

## 问题现象

在拓扑页面 `/monitor/topology` 对包含 `cisco_ios` 设备（如思科 IOL/IOU）的站点执行“Collect LLDP/CDP”发现时，发现结果全部为 Success，但拓扑观察记录（`topology_observations`）以及拓扑链路（`topology_links`）数目均为 0，导致前端页面仅展示节点，不展示任何物理链路（0 Links）。

## 根因

1. 针对 `cisco_ios` 平台定义的 LLDP 邻居发现指令为 `show lldp neighbors detail`。
2. 某些虚拟化或特定版本的思科 IOS（如 IOL）在其 `show lldp neighbors detail` 命令输出中**不包含**本地接口名（如 `Local Intf: ...`），仅包含对端信息。
3. 拓扑数据库填充和链路生成机制强制依赖 `local_interface`（本地端口）字段以在 CMDB 设备中进行邻居匹配。在 detail 输出中此项解析为空，进而导致所有采集到的邻居发现记录在清洗时由于 `source_port_raw` 为空而被全部过滤丢弃。

## 解决方案

1. 将 `cisco_ios` 平台的 LLDP 邻居采集命令修改为 `show lldp neighbors`（简表格式），简表格式中必定包含 `Local Intf` 字段。
2. 更新 Cisco 正常化解析器（`CiscoNormalizer.parse_neighbors`），使用 `show lldp neighbors` 模板进行 TextFSM 解析，并修改字段获取逻辑使其兼容简表输出中的 `interface`（本地端口）和 `remote_interface`（对端端口）字段。
3. 同步修改 `operational_data_service.py` 里的 `COMMAND_CATALOG` 配置，使日常运维数据查询指令与拓扑采集逻辑一致。
4. 更新单元测试 `test_h3c_cisco_quick_queries.py` 中的断言以适配修改后的 LLDP 查询指令。
