# 修复记录：新增中兴交换机 LLDP 邻居解析模板与 Playbook 命令修正

## 问题现象
系统在中兴交换机平台（`zte_zxros`）上缺少专用的 LLDP 邻居解析模板，导致拓扑发现任务和邻居展示均不可用。同时，前端快捷 Playbook 任务中的中兴邻居获取命令不正确。此外，中兴的 LLDP 邻居信息输出可能会折行（Port ID 过长时），导致 TextFSM 模板直接匹配失败。

## 根因
1. 未向中兴平台分配并注册 LLDP 解析规则；
2. 缺乏折行行合并的预处理逻辑；
3. 前端自动化任务中写错了中兴的 LLDP 获取命令。

## 解决方案
1. 创建 `data/textfsm_templates/zte_zxros_show_lldp_neighbor_brief.textfsm` 解析简表数据。
2. 在 `backend/core/textfsm.py` 增加对中兴折行邻居条目的智能自动合并逻辑。
3. 注册 `zte_zxros` 的拓扑及采集映射命令。
4. 修改前端页面 `src/pages/AutomationExecute/index.tsx` 的 Presets。

## 实际修改文件
* `data/textfsm_templates/zte_zxros_show_lldp_neighbor_brief.textfsm`
* `backend/core/textfsm.py`
* `backend/services/topology_service.py`
* `backend/services/operational_data_service.py`
* `src/pages/AutomationExecute/index.tsx`
* `backend/tests/test_topology_service.py`

## 验证命令与结果
运行 pytest 进行测试：
```powershell

```
测试通过。
且前端使用 `npm run build` 执行完整编译正常通过。

## 风险与回滚方式
* 风险：较低，所有变更仅限 `zte_zxros` 平台，不影响其他厂商。
* 回滚方式：使用 `git checkout` 撤销对这几个文件的修改，并删除新建的 textfsm 文件。
