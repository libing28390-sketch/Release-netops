# Git 修复记录：修复设备运行数据采集 NameError 与平台未支持报错

**创建时间**：2026-08-01 10:38
**修复问题名**：修复设备运行数据采集报错

---

## 1. 问题现象
1. 设备运行数据采集报错：`NameError: name 'logger' is not defined. Did you mean: '_logger'?`
2. 上游根因抛出异常：`services.neighbor_collection_contract.NeighborCollectionContractError: unsupported_platform:dptech_ios`

## 2. 根因
- `backend/api/devices.py` 内部仅定义了 `_logger`，未定义 `logger` 变量，部分函数误用 `logger.exception` / `logger.info`。
- `neighbor_collection_contract.py` 未注册 `dptech_ios` 和 `maipu` 平台的 `_PLATFORM_ALIASES` 与 `LLDP_COMMAND_WHITELIST`。

## 3. 解决方案
- `backend/api/devices.py` 添加 `logger = _logger` 别名并将调用规范化为 `_logger`。
- `backend/services/neighbor_collection_contract.py` 补齐 `dptech_ios` 与 `maipu` 平台别名与 `LLDP_COMMAND_WHITELIST`。
- `backend/services/topology_service.py` 补齐 `dptech_ios` 与 `maipu` 平台发现别名与命令。
- `backend/tests/vendor_audit/test_lldp_collection_contract.py` 补充契约断言测试。
