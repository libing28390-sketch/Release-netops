# 拓扑 Site 总览留白优化

## 问题现象
拓扑页只有少量 Site 卡片时，卡片集中在画布中间且下方留白很大；宽屏下卡片区域没有利用可用宽度。

## 根因
Site 总览内容容器和两站点卡片网格都限制了最大宽度；总览画布还复用了设备拓扑的固定大高度。

## 解决方案
- Site 总览容器扩大到可用宽度，两站点时使用两列铺开，更多站点按屏幕宽度自适应列数。
- 强化卡片状态、指标层级和键盘焦点反馈。
- 总览画布按视口高度使用紧凑尺寸，设备拓扑仍保留原有高度。
- 生产构建输出到独立目录后复制到本地 `dist`；本次不提交本地构建产物。
