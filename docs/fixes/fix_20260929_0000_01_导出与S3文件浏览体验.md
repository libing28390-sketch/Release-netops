# 修复记录：导出与 S3 文件浏览体验

## 问题现象 / 本次提交目的

- 告警表格导出使用了系统内置站点标识，资产 U 位出现重复 `U`，网络设备分页默认值与需求不符；凭据轮换界面信息层次不清。
- S3 新配置快照需要 `.cfg` 格式并按日期/厂商组织；原文件页不便于浏览、在线查看和下载。
- 本提交汇总以上已授权改动，并为本次代码校验、提交和推送留存记录。

## 根因

- 导出映射直接沿用了告警的站点值，未用站点目录解析内置 ID；U 位导出无条件拼接 `U`；分页 store 默认值为 15。
- 快照路径未包含完整日期和厂商，S3 内容写入 gzip 格式；文件页面将树与文件混排，查看/下载入口不够清楚。

## 解决方案

- 增加告警站点目录映射并阻止未知系统 ID 直接导出；规范化 U 位前缀；将网络设备初始分页改为 20 条；调整凭据管理布局。
- S3 新配置对象改写为纯文本 `.cfg` 并按日期/厂商归档；增加管理员专用内容 API 与 VS Code 风格双栏资源浏览器，以醒目的主按钮突出下载，并提供在线预览和路径复制。保留历史对象路径和旧压缩快照读取。
