# 修复Windows客户端监听本地回环 提交记录

本提交记录了将 Windows 客户端启动绑定地址从 `127.0.0.1` 调整为 `0.0.0.0` 的修复工作。

## 问题现象

Windows 客户端打包/运行后，启动的 FastAPI 后端服务只能在本地 `127.0.0.1:5010` 下被访问，局域网内的其他设备无法通过服务器的物理 IP 访问此接口，限制了跨主机客户端的连接。

## 根因

在 [desktop_tray.py](file:///d:/nexora/nexora-private/desktop/desktop_tray.py) 中，由 PySide6 进程代理拉起 Python 后端子进程时，命令行传参配置了硬编码的 `--host 127.0.0.1`。

## 解决方案

将 `--host` 传参从 `127.0.0.1` 修改为 `0.0.0.0`，使 `uvicorn` Web 服务器在宿主机的所有网卡和回环接口上同时开启监听；同步修改 UI 静态字段 `meta_addr` 的默认展示值，使其展示为 `0.0.0.0:5010`。

## 实际修改文件

* [desktop_tray.py](file:///d:/nexora/nexora-private/desktop/desktop_tray.py)

## 验证结果

1. 本地 `127.0.0.1:5010` 接口测试完全正常；
2. 局域网物理网卡地址 `192.168.42.1:5010` 成功建立连接并接收报文。
