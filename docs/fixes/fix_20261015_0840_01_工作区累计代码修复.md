# 工作区累计代码修复

## 症状

工作区积累了自动化、定时作业、SNMP 巡检和无线看板等多项已完成修改，涉及多个独立缺陷：巡检设备总数受默认 200 条分页限制；路由邻居状态依赖 CLI；批量备份历史按设备拆行；SNMP-only 巡检可能把未检查 SSH 显示为成功；定时作业审批与调度交互存在候选人、目标数量、系统内置作业和界面流程问题；无线 AP 下线后纳管总数可能减少且离线数未增加。

## 根因

- 页面统计使用单页设备数组长度，或未使用后端总数；快捷查询合并结果时逐设备解析及采集源元数据会被覆盖。
- 巡检结果将未执行的 SSH 检查写为成功；备份逐设备临时执行记录早于批次最终结果。
- SNMP 硬件、接口、邻居和告警已有采集数据，但巡检及告警路径未统一复用可信、新鲜、完整的快照；AP 统计依赖当前上报行，设备下线时身份行会消失。
- 定时作业候选人资格、审批范围、本人资料更新和作业 API 的不同授权路径没有完全对齐；页面也把目标选择、调度、审批和确认拆成过长的交互。

## 修复

- 使用完整分页总数展示巡检设备数；保留快捷查询的逐设备解析来源；未执行 SSH 检查保存为空状态。
- 将 OSPF/BGP 巡检和状态告警改为 SNMP 优先、CLI 回退；复用硬件与接口完整快照驱动巡检和告警；保留 AP 纳管身份并区分明确离线与完整清单未上报状态。
- 将批量配置备份历史按批次展示，详情保留设备结果，并为失败设备接入告警生命周期。
- 整理定时作业创建、编辑、审批与验证码交互，增加 CRON 未来执行时间预览；修正跨租户审批资格、自审批候选过滤、本人资料保存和系统内置作业只读行为；移除调度器对不存在的 `devices.is_active` 字段的引用。
- 本提交聚合工作区中已完成的独立修复，不包含部署或真实设备配置变更。
