# 实现期望公网IP校验与静态Override 提交记录

本提交实现了在互联网出口健康检测中对于期望静态公网 IP 进行校验以及在离线环境下直接 Override 公网 IP 的特性。

## 问题现象

1. 对拥有固定公网静态 IP 或静态网段的公司，当系统发生网络出口漂移或主备切换时，需要快速发现并告警。
2. 对政企等纯内网隔离的离线环境，探测引擎无法调用公网 IP 获取 API，会导致该状态持续为未知或报错。

## 解决方案

1. 支持在 `.env` 中配置 `OUTBOUND_PROBE_EXPECTED_EGRESS_IP` 环境变量，允许填入单个 IP、多个逗号分隔的 IP 或 CIDR 网段（如 `202.96.128.8,210.22.84.5` 或 `202.96.128.0/29`）。
2. 在后台拨测中，通过 `ipaddress` 库自动对比真实探测公网 IP 是否在此期望的白名单范围内，不一致时自动将探测运行状态降级为 `degraded`，并在 Reason 中展现详细的出口漂移中文警告。
3. 支持配置 `OUTBOUND_PROBE_STATIC_EGRESS_IP` 环境变量，配置后直接绕过外网网络请求，返回硬编码的公网 IP，适配离线局域网环境。
4. 新增 `test_outbound_expected_ip.py` 单元测试，完全覆盖各匹配场景。
