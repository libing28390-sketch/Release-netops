# H3C 硬件发现未入库

## 问题现象

F1090-9 的 SNMP 诊断可以读到硬件数据，但后台硬件发现 runs、capabilities、sensors 均无记录，Grafana 因此没有硬件序列。

## 根因

后台只按通用 SNMP 身份发现记录的有效期决定是否重新发现。线上身份快照字段匹配且仅 1 小时 47 分钟，因此被 6 小时 freshness gate 判定为新鲜；后台没有再检查硬件能力库存是否缺失。

## 解决方案

在通用身份快照仍有效时检查持久化硬件能力：能力记录缺失或 discovery version 过旧时，复用原 SNMP 发现和 `persist_discovery()` 入库流程。修复不按 H3C 厂商过滤，也不更改 dashboard 查询。
