# Grafana 接口描述字段对齐

## 问题现象
Grafana 接口流量与健康 Dashboard 的表格中，“接口全称”和“接口描述”字段含义混淆，接口描述显示成接口别名。

## 根因
生成器将 IF-MIB `ifAlias` 当作接口描述字段。用户期望接口全称对应 `ifName`，接口描述对应 `ifDescr`。

## 解决方案
- 将元数据查询中的接口描述标签由 `ifAlias` 改为 `ifDescr`，按 `instance` 和 `ifIndex` 关联。
- 错误数、丢弃数及 Top 利用率表格保留并映射 `ifDescr` 为“接口描述”。
- 重新生成接口流量与健康 Dashboard JSON，接口全称筛选和显示仍使用 `ifName`。

- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-interface.json`
- `docs/plans/plan_20260925_1901_01_Grafana接口名称与描述字段.md`

## 风险与回滚方式
- 不同设备对 `ifDescr` 的文本实现可能不同。若展示内容不符合预期，可核对设备实际采集标签。
- 回滚时恢复本次两个 Grafana 文件和对应记录文件的差异，或使用 `git revert` 撤销本提交。
