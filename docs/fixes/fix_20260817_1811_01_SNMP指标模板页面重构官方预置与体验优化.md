# SNMP 指标模板页面重构、官方预置与体验优化修复记录

- **修复编号**：`fix_20260817_1811_01_SNMP指标模板页面重构官方预置与体验优化`
- **创建时间**：2026-08-17 18:11 (UTC+8)
- **归档目录**：`docs/fixes/`

---

## 1. 问题现象与本次提交目的

1. **SNMP 模板管理单体组件臃肿与性能问题**：原 `MetricOidProfilesModal.tsx` 近 1900 行单体代码，状态和子模块高度耦合，输入公式时存在渲染卡顿。
2. **MIB 知识库厂商选择不全**：OID 拾取弹窗硬编码仅 5 个厂商，无法覆盖资产管理库中全量厂商字典及 MIB 库导入的扩展厂商。
3. **新建模板智能匹配采纳缺陷**：新建模板输入型号智能匹配到推荐规则后，点击“一键采纳”导致厂商丢失无法保存；编辑已有模板采纳导致 `editingId` 丢失无法就地更新。
4. **官方预置未在主列表直显且缺少一键复制**：运维人员无法在主列表中直观总览官方内置模板，且缺乏一键复制模板用于相近型号快速创建的功能。
5. **视觉主题与平台基调脱节**：部分模块采用了突兀的 Emerald 草绿色，与 Nexora 平台整体科技青蓝调不一致。

---

## 2. 根因分析

1. **架构设计**：列表、编辑抽屉、单指标行、接口流量 17 项 OID、SNMP WALK 实时探测器全部堆叠在单一文件中，缺少领域子组件拆分与 `React.memo` 优化。
2. **厂商字典割裂**：`OidPickerModal` 未接入 `NETWORK_VENDOR_GROUPS` 及 `/api/platform-registry/mibs/repository-stats` 动态厂商字典。
3. **状态赋值覆盖**：`MetricProfileEditor` 在一键采纳时直接用表单当前的空厂商覆盖了预置厂商；`handleApplyPreset` 内部硬编码了 `setEditingId(null)`。
4. **视觉与分页绑定**：分页组件固定绑定后端自定义模板总数；组件样式硬编码了 emerald 类名。

---

## 3. 解决方案与核心改动

1. **架构组件解耦与性能提升**：
   - 拆分为 5 个高内聚子组件至 `src/components/SnmpMib/components/`：`MetricProfileList`、`MetricProfileEditor`、`MetricRowItem`、`InterfaceConfigSection`、`LiveWalkInspector`。
   - 单指标行通过 `React.memo` 隔离重渲染，并提供常用倍数（`×1`, `×0.1`, `×0.01`, `×0.001`）快捷标签。
   - 接口流量模板提供“恢复标准 IF-MIB”一键重置。
2. **全厂商字典联动**：
   - `OidPickerModal` 动态合并资产管理主流分组与 MIB 知识库扩展厂商，选择未配置厂商的节点时自动反向填充主表单。
3. **智能推荐与一键采纳增强**：
   - 优化前后端模型前缀推导规则，仅输入精确型号即可即时触发智能匹配。
   - 一键采纳时智能回填预置厂商，编辑态套用时保留 `editingId` 支持就地更新。
4. **官方预置直显、一键复制与删除**：
   - 列表顶部增加 Tab（`全部模板` / `已配置型号` / `官方预置库`），官方预置直接呈现在列表中。
   - 提供 **“📋 复制”** 动作，一键克隆全部 OID、计算公式与接口流量模板，方便新型号快速创建。
   - 自定义型号操作栏提供 **“修改”** 与 **“🗑️ 删除”**，底部分页计数动态同步当前 Tab。
5. **平台统一科技青蓝视觉重塑**：
   - 全面剔除草绿色，统一对齐 Nexora 平台核心色调（科技青蓝 `#00bceb` / `#00a9ce` / `#008aad` / Slate）。
