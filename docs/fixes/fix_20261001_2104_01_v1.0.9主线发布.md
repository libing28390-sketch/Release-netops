## 问题现象与提交目的

用户要求将当前全部业务代码推送 main，覆盖 v1.0.9 标签，并确保 release.yml 向公有仓库同步相同版本。当前旧标签不包含最新平台绑定、MIB 缓存、拓扑发现与 CMDB 主机名统一改动。

## 解决方案

- 提交当前全部 backend/src 业务实现和回归测试。
- 维持 package、lockfile 和 backend 1.0.9，更新构建日期和公开 Release 说明。
- release.yml 共用发布并发组，并在发布前校验前后端/锁文件版本和触发标签。
- 沿用现有 github.ref_name 同步公有 tag、Linux Release 和 Windows Agent 附件。
- 保留公有树的现有私有资料过滤；临时输出和旧 dist/index.html 留在本地，不进入本次提交。
