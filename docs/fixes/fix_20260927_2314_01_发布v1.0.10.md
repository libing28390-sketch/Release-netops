# 发布 Nexora v1.0.10

## 问题现象

开发仓库 `main` 已包含监控采集、Grafana/cAdvisor 看板和审批验证方式更新，但公开 `Release-netops` 右侧仍显示 3 天前的 `v1.0.9`。

## 根因

公开 Release 由源仓库的 `v*` 标签触发。只推送 `main` 会同步发布树，不会创建新的 Latest Release；应用版本常量、前端 fallback 和部署说明也仍标为 `1.0.9`。

## 解决方案

将产品版本字段和展示 fallback 统一提升至 `1.0.10`，更新部署导航及 Release Notes，再以 `v1.0.10` 标签触发仓库现有的 Linux/Docker 与 Windows Workstation Agent 发布工作流。保留 `v1.0.9` 标签和制品作为回滚版本。

## 实际修改文件

- `package.json`
- `package-lock.json`
- `backend/core/version.py`
- `src/components/Sidebar.tsx`
- `src/components/ModuleSubNav.tsx`

- `docs/deploy/terminal-agent.md`

## 验证命令与结果

- `npm run lint`：通过。
- `npm run build`：通过，Vite 生产构建完成（4296 个模块）。
- `git diff --check`：通过。
- 标签触发的正式 GitHub Actions：提交本记录时尚未触发；最终结果及公开 Release 链接记录在对应 walkthrough。

## 未验证项

- 公开 Release 上传的 Linux/Docker 归档与 Windows Workstation Agent 尚待标签工作流完成后核对。
- 未在生产服务器执行升级；旧版本 `v1.0.9` 保持可用。

## 风险与回滚方式

正式标签只追加，不覆盖 `v1.0.9`。若发布门禁或制品上传失败，先按 Actions 日志修复；不移动已发布标签，必要时使用下一个递增版本号重新发布。部署回滚可继续使用 `v1.0.9`。
