# 拓扑可视化与出口拨测修复 提交记录

本提交记录了针对网络拓扑图可视化展示（包括接入层设备重叠遮挡、图标尺寸、留白、图例、避障等）以及互联网出口可用性拨测数据点丢失的深度修复工作。

## 问题现象

1. **思科拓扑链路未显示**：在拓扑图重构后，由于 LLDP 邻居解析与 PostgreSQL 重建冲突，导致思科设备的物理链路没有在前端渲染。
2. **接入层设备不见了/重叠**：新增 2 台 ACCESS 接入交换机后，由于历史位置缓存，导致新设备与 AGGREGATION 汇聚设备位置 100% 重合，新节点被遮挡隐藏。
3. **拓扑体验不佳**：设备图标过小、层间距留白大、Header 太厚且没有站点标识、图例颜色线太短、端口名称与设备卡片重合。
4. **出口拨测断线**：图表中出现大量的假性空值点与折线断开，虽然当时的互联网是正常的。

## 根因分析

1. **链路解析**：思科 LLDP 规范化映射的 platform 与 vendor 字段对齐问题阻碍了链路构建。
2. **位置重叠**：前端优先读取数据库布局位置，若历史记录中仅有 CORE/AGG 四个节点，新接入的 2 个 ACCESS 节点因缺少坐标回退为默认位置，从而与 AGG 的缓存坐标撞车。
3. **拓扑体验**：布局算法和渲染尺寸缺少精细调整。
4. **出口拨测断线**：拨测定时器因运行漂移，在 1 分钟等距网格内有时候落入 2 个点，导致下一个网格为 0 个点。`connectNulls={false}` 进一步将空点渲染为连线断开。

## 解决方案

1. **拓扑链路与重合**：
   - 修正思科 LLDP 发现映射，确保从物理接口中正确携带协商 speed。
   - 结构化布局下强行以最新的行/列规律覆盖分层轴坐标，完美防重叠。
2. **拓扑交互体验**：
   - 设备图标由 `38px` 增大至 `58px`；调整层级高度比，层间距压缩 22%。
   - 重构 Header pill 高度为标准的 `24px`，并加入 `🏢` 标识与 `·` 分隔符。
   - Hostname 加设统一 `112px` 的悬浮白底胶囊背景框，文字水平/垂直双向居中。
   - 分隔虚线颜色调淡为 `#E8EDF5`，并将带宽图例的线段长度拉长至 `24px`。
   - 将垂直/斜向链路的端口标签水平外扩至 `36px` 的侧边空隙，避开正下方的 Hostname 卡片。
3. **数据分桶校准**：
   - 将 OutboundHealth 历史折线的数据分桶修改为**最近邻窗格分桶** `[t - stepMs/2, t + stepMs/2)`。
   - 解决了由于任务执行几秒钟时延漂移引发的量化空值，同时保留真实停机断线。
