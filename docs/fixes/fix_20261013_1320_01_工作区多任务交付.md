## 变更范围

- 将 Guacamole 1.6.0 作为可选 Docker Compose 服务接入 PAM。Web 端支持 RDP/VNC 会话与录像回放；连接凭据从资产已绑定的普通/管理员凭据解析，不在远程桌面配置中另存密码。API、权限检查、JSON 认证、日志脱敏、录像归档和部署契约均有实现与测试。
- 录像先写入共享会话卷，再经现有 PAM 存储适配器归档；部署使用 S3 时归档目标是 S3。实际容器运行与 S3 对象验收待 Linux 部署主机执行。
- 移除配置备份的 FTP/SFTP/TFTP 文件归档路径及其专用服务、配置项和界面；新增 PostgreSQL 迁移处理旧字段。
- 合入本工作区其余已跟踪代码与任务材料，包括 CMDB 刷新/采集状态、资产手工新增后的异步识别、凭据中心排版、访问方式导出，以及相关 OpenAPI 计划和 walkthrough。
- 源分支保留 `.agents/`、`.codex/` 与 `handoff.md` 的协作修改；发布工作流会从公开发布树中排除这些内部材料。忽略的本地构建目录、`dist-*`、临时部署/审计目录和 `logs/` 未纳入。
