# AI 模块剩余改造收尾（审查报告批次 1–7）

日期：2026-11-22
范围：`Nexora AI 模块审查报告.md` 中的全部 7 个批次（1 安全收尾、2 Copilot 遗留问题、3 前端安全与功能、4 其余 AI 页面改版、5 代码治理、6 护栏、7 文档同步）。批次 6 护栏在其余批次之后补做完成。

## 决定

- M12 会话历史：落库时加密保存原文，令牌化只在发给 Provider 的那一次请求里做。
- 告警回答：保留明细（最新 20 条的主机名和告警标题）。
- 不拆超大文件（`services/assistant.py`、`KnowledgeManagementTab.tsx`），不做网关新能力，不改登录令牌存储。

## 改动

### 批次 1 安全收尾（M14 / M12 / M16）
- `backend/ai/security/crypto.py`：`aik:v2:<kid>:` 格式，HKDF 派生，provider_id 作为 AAD；多主密钥轮换；不再回退到 `SECRET_KEY`；解密失败报 `AI_KEY_DECRYPT_FAILED`；掩码只显示后 4 位。
- `backend/ai/security/field_crypto.py`（新）：会话内容字段加密 `afc:v1:`。
- `backend/ai/services/conversation_service.py`：写入时加密，读取时解密，搜索放到应用层；旧的 token 化行兼容读取。
- `backend/ai/security/tokenization.py`：vault 清理改为按过期时间的堆；新增带密钥的 `provider_user_id`。
- `backend/ai/api/providers.py`：增删改、启停都写审计；编辑时换密钥也走轮换流程；不再自动创建默认模型和路由；密钥历史接口；`retention_days` / `agreement_reviewed_at` 传 null 可以清空；只换密钥时也写 `ai_provider.updated` 审计。
- `scripts/ai_provider_key_reencrypt.py`（新）：一次把全部旧密文升级为新格式。

### 批次 2 Copilot
- 短追问按网络问题保留历史，不再只给 public 策略的短历史；跳过无法解密的历史占位行；本地会话的历史负载去掉错误气泡。
- 流式输出可以选中文字（`StreamingText.tsx` 按固定偏移分段渲染）。
- 去掉重复图标；代码块和标题在回答第一行时不再多出顶部间距；知识库 0 命中时给出明确提示，调试面板显示正确。
- 模型列表为空时不再显示写死的 DeepSeek 选项；测试连接不再默认 `deepseek-v4-flash`。
- 非流式截断返回 `truncated` / `finish_reason`。

### 批次 3 前端安全与功能（L6）
- `src/api/sseParser.ts`（新）按规范解析 SSE，`ai.ts` 已改用它。
- Provider 页：字段可以清空；换密钥只发一次请求；外发白名单编辑；作废密钥需要二次确认；密钥历史抽屉。
- AI 中心按角色权限显示子页；侧边栏 Copilot 入口加 `requiredRole: 'Operator'`。

### 批次 4 页面改版
- Prompt 中心、知识库（主页面和 7 个子面板）按 Provider 页的新风格改完；复核其余 8 个页面，修了健康页显示原始文案 key 的问题和安全页测试缺导入的问题。
- `src/components/ui/PageHeader.tsx`：ⓘ 提示移到 `<h2>` 外面，避免提示文字成为标题的可访问名称。

### 批次 5 代码治理（L1 / L2 / L4）
- 27 处 `except Exception: pass` 改为记日志并带固定错误码。
- 删除 `router.py` 中未使用的路由函数和写死的场景路由表。
- `llm_gateway.py`：`chat` 与 `chat_stream` 的准备阶段抽成 `_prepare_request`。

### 批次 7 文档同步（L7）
- `docs/ai/provider/deepseek-security-baseline.md`：按多 Provider 现状重写。
- ADR-006 / ADR-011 增加「现状（2026-11-22 同步）」小节；evidence 同步。
- 新增契约测试 `backend/tests/ai/test_adr006_adr011_contract.py`。

### 批次 6 护栏（M13 中文部分、中文个人信息、输出审核）
- `backend/ai/security/classification.py`：标识符正则统一使用 ASCII 单词边界，紧挨汉字的 IP、手机号、主机名能识别；新增 `find_cn_personal_info`（身份证、银行卡；输出侧严格模式另含手机号）、中文凭据写法 `CN_SECRET_ASSIGNMENT_RE`、中文注入 `PROMPT_INJECTION_ZH_RE`；英文注入新增 reveal system prompt / jailbreak / DAN mode。
- `backend/ai/security/tokenization.py`：身份证、银行卡令牌化为 `[[NXA_IDCARD_…]]` / `[[NXA_BANKCARD_…]]`；IP、邮箱、MAC、电话、站点、业务名改为直接复用分级规则，令牌化与 DLP 不再各维护一份。
- `backend/ai/security/gateway.py` / `backend/ai/services/conversation_service.py`：中文凭据写法在分级之前把值替换为 `<REDACTED>`，请求继续、会话只存脱敏文本（`redact_cn_secret_assignments`）。
- `backend/ai/security/dlp.py`：最终 DLP 检查身份证、银行卡，以及漏网的中文凭据原值。
- `backend/ai/security/output.py`：模型生成的身份证、银行卡、手机号打码；中文凭据值脱敏；流式跨 chunk 暂缓。令牌还原出来的用户自有值不打码。
- 联网检索查询拒绝含身份证或银行卡号；安全评测指标纳入中文注入与中文凭据。
- `scripts/ai_guardrail_impact_check.py`（新）：只读扫描知识库 chunk 和 Prompt 模板，按规则统计命中行数和 id，不输出原文。
- 测试：`test_batch6_input_guardrails.py`、`test_batch6_output_guardrails.py`、`test_batch6_impact_script.py`。

可以运行 `python scripts/ai_guardrail_impact_check.py` 查看知识库里有多少 chunk 会被脱敏或令牌化（只读，报告不含原文）。中文凭据写法不阻断，只脱敏，不需要上线前清理；只有 Prompt 模板里命中注入规则时报告为 REVIEW，需要检查模板。

## 行为变化（需要知道）

- DeepSeek 模型校验从 V4 两个代码改为 `deepseek-` 前缀。
- Operator 打开 AI 中心直接进入 Copilot；无权限子页显示说明而不是 403。Viewer 在侧边栏看不到 Copilot。
- 编辑 Provider 时清空的代理、标签、DPA、保留天数会真的清空。
- 被 kill switch 拦截的流式请求现在也写一条 `BLOCK` 安全审计（不产生 incident）。
- Prompt 列表从卡片改为表格；内容要点「查看」。
- 数据库长时间不可用时，只读工具和 IP/MAC 追踪会多出 warning 日志。
- 批次 6：用户消息或检索内容中出现「密码是…」「口令：…」这类带值的中文凭据，值被替换为 `<REDACTED>` 后请求照常继续，会话历史也只保存脱敏文本（原来完全不识别，原值会发给模型）。英文 `password=` 写法仍按原规则阻断。
- 批次 6：紧挨汉字的 IP、手机号、主机名、产品型号（如「华为CE6800-48S交换机」）、长数字（订单号、时间戳）现在会被令牌化，与英文空格分隔时一致；回答中会还原，用户可见内容不变。
- 批次 6：模型回答里自己生成的身份证、银行卡、手机号会被打码；中文注入写法会被标记为不可信数据（不阻断）。
