# CMDB接口采集顺带CLI VLAN

## 问题现象与提交目的

接口库存入口的 VLAN 域仍先读取 Q-BRIDGE SNMP；静态 VLAN 名称表在设备上可能缺失，页面所需 VLAN 清单因此不一定来自完整命令结果。本次让同一接口库存任务通过既有 CLI VLAN action 写入 CMDB 独立快照。

## 根因

共享库存编排把 VLAN 传给 SNMP 收集器，只有域不完整时才走通用 CLI fallback；成功的 Q-BRIDGE 数据会走共享表写入，而不是 CMDB generation 快照。

## 解决方案

- CMDB CLI collector 增加 VLAN-only 调用选项，复用现有会话、容量池、验证和快照 writer。
- 接口库存任务保留既有 IF-MIB/IP-MIB 逻辑，但不再请求 Q-BRIDGE VLAN 域；collection plan 开启 VLAN 时调用同一个 CMDB CLI collector。
- 更新 NSOT 采集预览中的 VLAN 传输说明。
- 未改监控调用、SNMP实现、共享解析器、TextFSM模板或共享事实表写入逻辑。
