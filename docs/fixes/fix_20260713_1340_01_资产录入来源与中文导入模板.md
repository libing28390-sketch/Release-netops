# 资产录入来源与中文导入模板

## 问题

- “设备来源”容易被理解为设备当前状态，用户会疑惑新设备投产后为何仍显示新设备。
- 中文界面下载的资产模板虽然列名为中文，但示例值仍混用 `new`、`legacy`、`staging`、`production` 等内部英文值。
- 模板填写内容与前端下拉框显示内容不一致，增加用户理解和录入成本。

## 根因

- `asset_origin` 的业务含义是首次录入方式，但页面文案没有突出其历史属性。
- 导入模板直接暴露数据库和接口内部枚举，缺少中文值到内部值的转换层。

## 解决方案

- 页面“设备来源”改名为“录入来源”，选项改为“新设备录入”和“存量设备补录”。
- 增加说明：录入来源记录首次录入方式，投产后不会改变。
- 中文模板使用“新设备、存量设备、待投产、已投产、在用、SSH”等中文业务值。
- 平台与设备分类使用前端可见名称，例如“Cisco IOS、Linux（通用）、机架式服务器、交换机”。
- 导入解析新增中文值标准化，自动转换为后端使用的 `new/legacy`、`staging/production` 等内部值。
- 保留旧中文列名、英文列名和英文内部值兼容，已有模板无需立即重做。

- `src/pages/AssetManagement/constants.ts`
- `src/pages/AssetManagement/index.tsx`
- `src/pages/AssetManagement/components/AssetModal.tsx`
