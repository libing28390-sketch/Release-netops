# Action 测试夹具字段不同步

## 问题现象

GitHub Actions 后端全量测试中，`test_cmdb_listing_does_not_append_inventory_alias_as_second_row` 报错：测试创建的 `interfaces` 表不存在 `interface_role`。当前 CMDB 查询还读取三个利用率阈值字段。

## 根因

该测试自建 PostgreSQL 表结构沿用了早期接口字段，但生产 schema 与迁移 `m0252` 已增加接口角色和利用率阈值字段。测试插入使用无列名的 `INSERT ... VALUES`，新增字段也会导致列数不匹配。

## 解决方案

在测试 schema 中添加 4 个字段，并使用与生产默认值一致的字段定义。4 处接口插入改用显式列名，新增字段由默认值填充。
