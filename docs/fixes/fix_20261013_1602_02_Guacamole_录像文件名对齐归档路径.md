# Guacamole 录像文件名对齐归档路径

## 问题现象

Ubuntu 实机确认 RDP WebSocket 隧道已到达 guacd，并启动了图形录像；会话结束后，PAM `storage_status` 为 `ERROR`，错误为 `PAM recording spool is missing`。共享卷内存在录像文件，但文件名没有扩展名。

## 根因

Nexora 为归档器登记的 spool 路径为 `<session_id>.guac`，但传给 Guacamole 的 `recording-name` 只有 `<session_id>`。Guacamole 按连接参数原样创建录像文件，不自动补 `.guac` 扩展名，导致实际路径和归档路径不一致。

## 解决方案

- Guacamole 连接参数构建时，将安全的录像名规范为 `<recording_name>.guac`；已经带 `.guac` 的名字不重复追加。
- 拒绝空录像名和路径分隔符/换行，避免录像名改变目标目录。
- 为 RDP/VNC 参数测试增加断言，验证录像名与 spool 格式一致。

## 风险与回滚

该改动只影响 Guacamole 录像文件名，RDP/VNC 网络连接与认证参数不变。若目标 Guacamole 版本拒绝带 `.guac` 的文件名，可回退 `recording-name` 规范化逻辑，并将归档器路径改为 guacd 的无扩展名文件名。
