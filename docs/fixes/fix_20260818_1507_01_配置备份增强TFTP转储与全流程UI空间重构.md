# 修复与功能增强记录：配置备份增强TFTP转储与全流程UI空间重构

- **提交目的**: 完善网络设备配置备份体系（SSH老旧算法兼容、本地时区显示、TFTP转储归档、启动配置采集、完成率统计修复），并对配置对比（`/config/diff`）与备份计划（`/config/schedule`）进行全流程空间压缩与高密度仪表盘重构。
- **记录时间**: 2026-08-18 15:07

---

## 1. 问题现象与需求背景

1. **SSH连接老旧算法兼容**: 老旧网络设备因使用 `diffie-hellman-group1-sha1`、`ssh-rsa` 等密钥交换算法无法连接；
2. **时区与时间显示**: 备份记录及快照时间轴显示为 UTC，与中国标准时间存在 8 小时偏差；
3. **备份任务完成率 0%**: 手动触发备份时未绑定任务结果计数，前端显示完成率为 0%；
4. **TFTP 归档与启动配置采集**: 用户需要将设备配置自动/手动转储到 TFTP 服务器，并支持采集设备的启动配置（Startup Config）；
5. **配置对比页面空间与流程优化**:
   - 原配置对比页面占用过多纵向高度，查看代码视窗狭窄；
   - 点击设备时直接跳转导致无法自定义选择快照；
6. **备份计划页面空间利用与对齐**:
   - 多层巨大横幅与空白卡片导致频繁滚动；
   - 右侧配置卡片底部与左侧执行记录底边未对齐。

---

## 2. 根因与解决方案

1. **SSH与时区**:
   - 在 `backend/drivers/ssh_compat.py` 中注入兼容性算法集合；
   - 后端统一以 ISO 8601 UTC 输出，前端统一转换为本地格式。
2. **TFTP与启动配置**:
   - 新增 `backend/services/tftp_service.py` 与数据库迁移 `m0152_config_backup_tftp_and_startup.py`；
   - 在 `BackupPolicyManager` 及前端手动备份中开放 TFTP 配置、连通测试与批次同步。
3. **备份完成率**:
   - 修复 `_finish_backup_run` 参数绑定，正确统计成功/失败/未观测数。
4. **配置对比与备份计划 UI 深度压缩**:
   - 移除冗余 `PageHero`，工具栏压缩为紧凑单行；
   - 对比视窗高度提升至 100% 满屏；
   - 修复跳步逻辑，提供「🚀 自定义对比」与「⚡ 对比最新」快捷通道；
   - 重构备份计划页面为通栏 4 指标卡 + 8:4 自适应等高网格，保存按钮像素级齐平。
