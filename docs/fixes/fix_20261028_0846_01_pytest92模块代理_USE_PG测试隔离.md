# pytest 9.2 `_USE_PG` 代理属性测试隔离

## 问题现象与提交目的

首次 Actions 全量复测已通过 3608 项并跳过 2 项，仅在 `test_rack_read_model.py::test_postgres_asset_check_uses_transaction_scoped_advisory_and_row_locks` teardown 时失败：`_DatabaseModule` object has no attribute `_USE_PG`。本次完成同类动态代理属性的最后一处测试替身修正。

## 根因

该测试直接对 `database._USE_PG` 使用 monkeypatch。pytest 9.2.0 从模块对象 `__dict__` 保存和恢复属性；`database` 代理通过 `__getattr__`/`__setattr__` 将 `_USE_PG` 映射到 `database.core`，实例字典中没有对应属性，故 teardown 误走删除分支并报错。

## 解决方案

将测试 patch 目标改为真实保存该值的 `database.core._USE_PG`。不修改生产数据库模块、CMDB、监控、SNMP 或解析逻辑。
