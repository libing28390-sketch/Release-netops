## 1. 任务背景与目的

响应用户关于：
1. `asset_id` 替换为 `hostname`、站点显示为人类可读名称、筛选支持级联厂商与角色、Top 20 字段瘦身；
2. 下线旧版 `/management/snmp-metric-templates` 路由并重定向至 `/monitoring`；
3. 新增 `06 互联网出口与 WAN` 大盘并在出口健康页面提供穿透入口；
4. 全面评估 `monitor` 下所有模块迁移 Grafana 的可行性与系统分层架构；
5. 新增第 7 套 `07 服务器与主机监控 (Server & Host Metrics)` 大盘并在服务器监控页面提供一键穿透入口；
6. 落地实现 Grafana 表格导出双层体系（Grafana 原生 Inspect 导出指导 + Nexora 基于 CMDB 与 VictoriaMetrics 深度融合的专业多工作表 XLSX / CSV 导出引擎）。

---

## 2. 解决方案与核心改动

1. **后端指标编译器与抓取配置**：
   - `backend/services/monitoring_compiler.py`：在 `Assignment` 中提取并透传 `site_name`，编译注入 `nexora_site_name`，配置 `labeldrop`；
   - `backend/api/monitoring_v1.py`：关联 `sites` 表获取站点真实名称。
2. **Grafana 7 套大盘自动化构建**：
   - `monitoring/grafana/generate_dashboards.py`：
     - 重构变量级联（site_name -> vendor -> role -> device）；
     - 实现 `clean_organize_transformation`，隐藏内部无用标签，表格只保留 4-5 个核心业务列；
     - 新增 `06 互联网出口与 WAN` 及 `07 服务器与主机监控` 大盘。
3. **权威网络监控报表导出引擎**：
   - `backend/services/monitoring_export_service.py`：
     - 结合 PostgreSQL CMDB 元数据与 VictoriaMetrics 5m 时序速率；
     - 使用 `openpyxl` 渲染多工作表专业工作簿（接口清单与状态、流量与利用率统计、高利用率预警、接口错误与丢弃排行）；
     - 注入 `\uFEFF` UTF-8 BOM，彻底解决 Windows Excel 打开中文乱码问题。
   - `backend/api/monitoring_v1.py`：暴露 `/export/interfaces`、`/export/devices`、`/export/outbound` 端点。
4. **前端交互与下线平滑过渡**：
   - `src/components/ExportTableModal.tsx`：开发独立的报表导出与 Grafana 原生导出指引工作台；
   - `src/pages/GrafanaDashboardPage.tsx`：注册新大盘，顶栏增加“📥 导出监控报表 (Excel/CSV)”操作按钮；
   - `src/components/ServerMonitoring.tsx` & `src/pages/OutboundHealthPage.tsx`：增加“📊 Grafana 专属大盘”穿透入口；
   - 下线旧 SNMP 指标模板菜单与路由，平滑重定向至 `/monitoring`。
