# pytest 9.2 数据库代理测试隔离

## 问题现象与提交目的

当前 VLAN CLI 变更提交后的 Actions 全量 pytest 在数据库代理 patch 的 teardown 处失败，并造成后续数据库测试级联失败。本次修复测试隔离，以完成当前采集变更的 CI 验证。

## 根因

CI 安装 pytest 9.2.0。pytest 对普通模块目标按实例 `__dict__` 获取恢复值；仓库 `database` 模块使用 `_DatabaseModule` 动态映射 `get_db_connection`，设置值会转发到 `database.core`，但代理的 `__dict__` 不持有该属性。清理时 pytest 因而试图从代理删除并报 `AttributeError`，模拟连接未恢复。

## 解决方案

测试直接 patch 实际保存连接工厂的 `database.core.get_db_connection`，使 pytest 保存并恢复真实模块字典中的原属性。不改变运行时代码。
