# Grafana 接口描述标签修正

## 问题现象 / 本次目的

Grafana 网络接口表格的“接口描述”使用了 `ifDescr` 字段映射，但查询实际只关联 `ifName`，导致描述列缺失或与接口全称重复。

## 根因

看板生成器没有把 SNMP `ifAlias` 描述指标按设备和 `ifIndex` 关联到接口名称查询；组织变换也映射了不匹配的标签名。

## 解决方案

- 生成器将 `ifName` 与 `ifAlias` 关联，并在表格中将 `ifAlias` 显示为接口描述。
- 重新生成目标 dashboard JSON。

- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-interface.json`
- `docs/plans/plan_20260925_1458_01_dashboard接口描述.md`

## 风险与回滚方式
