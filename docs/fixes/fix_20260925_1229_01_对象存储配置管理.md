# 增加对象存储配置管理与业务路由

## 问题现象

配置备份与 PAM 录像只能使用部署环境中的存储配置，无法在管理界面保存多个 S3-compatible profile，也无法分别指定业务用途的 Bucket 和对象前缀。

## 根因

存储服务原先只解析环境变量；对象记录未绑定数据库中的 provider profile，无法在默认配置调整后稳定读取原对象。

## 解决方案

- 增加 PostgreSQL S3 profile 与用途路由迁移、管理员 API 及对象存储管理页面。
- 加密保存访问凭据；对象写入后记录 provider ID、Bucket 和完整 object key，读取、重试和删除沿用对象记录的 provider。
- 为配置备份和 PAM 录像接入独立用途路由，并更新 Docker 部署文档。
