# 定时作业筛选参数默认值

## 问题现象

GitHub Actions 发布门禁 #739 的全量 pytest 中，`test_scheduled_jobs_cross_history_preserves_owner_system_read_only_and_actions` 失败，报错为 `AttributeError: 'Query' object has no attribute 'strip'`。同一轮另有 3306 项通过、1 项跳过。

## 根因

`list_scheduled_jobs` 新增参数将 `Query(...)` 元数据对象直接设为 Python 默认值。FastAPI 通过 HTTP 调用时会解析查询参数，但测试和内部代码直接调用该函数、未传这些参数时，会拿到 `Query` 实例；搜索代码随后调用 `.strip()` 抛错。

## 解决方案

改用 `Annotated[..., Query(...)]` 承载 HTTP 查询约束，同时使用 `None`、空字符串和 `None` 作为普通 Python 默认值。这样保留查询参数长度/范围校验，并兼容现有直接调用路由函数的测试和内部调用。

## 风险与回滚方式

- 变更仅调整查询参数声明，不改变 SQL 过滤条件或 API 响应格式。
- 如查询参数 HTTP 校验有回归，可回退 `Annotated` 声明并另行实现直接调用安全的参数归一化；部署问题则按主任务备份恢复应用镜像和源码，不动 `.env`、数据库或数据卷。
