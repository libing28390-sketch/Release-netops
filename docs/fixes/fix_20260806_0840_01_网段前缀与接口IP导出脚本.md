# Git 提交修复记录：网段前缀与接口 IP 导出脚本 (IPv4/IPv6 双栈全量支持版)

按照项目 Git 规范，每次代码修改提交必须在 `docs/fixes/` 创建记录。

## 1. 提交目的
强化 [scripts/export_network_prefixes_and_ips.py](file:///d:/nexora/nexora-private/scripts/export_network_prefixes_and_ips.py) 对 IPv6 的全量原生支持，确保交换机上的 IPv6 接口地址与 IPv6 网段前缀均能被精准抓取与换算。

## 2. 解决方案
1. **IPv6 CLI 命令强化**：对思科设备增加 `show ipv6 interface brief` 执行，对华为/华三设备增加 `display ipv6 interface brief` 执行。
2. **IPv6 正则与验证**：增加 IPv6 冒号十六进制正则表达式，并使用 Python `ipaddress.ip_address()` 进行准确性校验，排除不合法的 CLI 打印干扰。
3. **IPv6 掩码与前缀换算**：
   - 换算网段 CIDR（如 `2001:db8:1::1/64` $\rightarrow$ `2001:db8:1::/64`）
   - 环回口默认 IPv6 掩码为 `/128`
   - 设备互联自动识别 IPv6 `/126` 与 `/127`
