# 配置备份驱动类型映射修复

## 问题现象

`/config/backup` 在线网络设备批量备份时，所有网络设备都在连接前失败，错误为 `No driver found for asset_type: network_device`。

## 根因

CMDB 资产使用 `network_device` 表示网络设备；执行引擎注册表使用 `network` 作为 Netmiko 网络驱动类别。备份执行路径把 CMDB 类型直接传入驱动注册表，造成查找不匹配，尚未进入 Netmiko 厂商平台选择。

## 解决方案

在 `DriverRegistry` 边界将 `network_device` 规范为 `network`，然后保留 `vendor` 和 `platform` 供 Netmiko 选择具体平台。Cisco、Huawei、H3C 的平台和默认只读备份命令分派均由回归测试验证。
