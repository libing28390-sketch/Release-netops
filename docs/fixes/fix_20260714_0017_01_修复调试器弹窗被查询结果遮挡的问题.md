# Git 变更记录: 修复调试器弹窗被查询结果遮挡的问题

## 1. 变更背景与原因
当在执行结果面板 `QuickQueryResultOverlay` 点击“在线调试与创建解析模板”时，理应滑出 `TextFSMDebugger` 面板。
但因为 `QuickQueryResultOverlay` 采用了较高的层级设计（遮罩 `z-[70]`，内容框 `z-[80]`），而 `TextFSMDebugger` 之前的默认 z-index 为 `z-50`。
层级较低导致调试器面板被无情地渲染在查询结果弹窗的后面，造成了视觉遮挡、无法操作的问题。

## 2. 解决方案与实施步骤
我们修改了 [TextFSMDebugger.tsx](file:///d:/netops/netsops-main/src/pages/AutomationExecute/components/TextFSMDebugger.tsx) 组件：
1. **提升调试器层级**：将最外层的包裹容器类从 `z-50` 提升为 `z-[90]`；
2. **测试与回归**：这样一来，调试器弹窗便能顺利且完美地压在查询结果弹窗（`z-[80]`）的最上层，遮挡问题完美解决，点击保存并重新查询的交互链重归正常。
