## 1. 问题现象

对 AI 中心全部 12 个功能模块（Provider 供应商、Model & 路由、健康与 SLA、Prompt 提示词、AI Copilot 对话、Agent 注册表、知识库管理、检索测试、产品目录、AI 变更治理、Token 统计审计、AI 安全网关）开展深度代码审查后，发现存在以下三大类问题：
1. **P0 安全与数据缺陷**：AI 安全网关/脱敏/分类边界漏洞、SSRF/Provider 配置与密钥轮转缺陷、变更治理审批表字段不一致（`approved_at` 不存在）、多处后端分析服务和评测接口存在数据隔离与安全边界问题。
2. **P1 核心业务闭环缺陷**：Copilot 流式对话未持久化 citations 且前端缺少真实 `assistant_message_id`；`LLMGateway` 路由优先级倒挂（个人默认模型覆盖显式 `scene_route`）；`ToolRegistry` 超时阻塞线程；`tool_get_device_neighbors` 反向端口颠倒；`AgentRunner` 未读取 `ai_agent` 配置；`PromptRenderer` fallback 存在二次变量注入风险；安全策略 `max_payload_bytes`/租户开关/Kill Switch 持久化不完整；`ScopedTokenVault` 淘汰未同步清理反向映射；自定义产品型号厂商编码不对齐且别名插入在 PostgreSQL 事务中可能触发失败。
3. **P2 前端体验与产品知识库缺口**：12 个 AI 前端页面存在暗色模式缺失、原生 `alert()` 弹窗、模型编辑/路由重置/成本预算展示缺失、版本操作传参错用 `document_id`、上传前 1.2s 假延迟、分页冲突统计不准等问题；产品知识库仅覆盖少量交换机型号，缺少主流路由器/防火墙及锐捷、Juniper、Fortinet、Aruba 等厂商型号。

## 2. 根因

- AI 中心多个模块在快速迭代过程中分批建设，安全网关、路由网关、Agent/Tool、Prompt、知识库与前端页面之间的契约未统一收敛；
- 部分持久化写入与 SQL 查询未严格按 PostgreSQL 事务和约束语义（如 `ON CONFLICT`、`kb_product_alias` 枚举约束、行级状态保留）实现；
- 前端多页签沿用早期原型实现，未完整对接后端已提供的 `facets`、`conflicts`、`daily_estimated_cost_usd`、`GET /api/ai/agents`、`DELETE /api/ai/models/routes/{scene}`、`rotateAIProviderKey` 等能力。

## 3. 解决方案

- **P0 安全与数据修复**：加固 `classification.py`、`gateway.py`、`output.py`、`sanitizer.py`、各分析服务（`alarm_analysis`、`command_analysis`、`config_analysis`、`config_generation`、`diff_analysis`）、`change_governance.py`、`providers.py`、`usage.py`、`knowledge_evaluation_service.py` 与 `knowledge_baseline_pg.py`，补齐 12 项 P0 回归测试。
- **P1 核心业务闭环**：修复流式对话 citations 落库与 SSE `persisted` 事件、会话状态保留、ARP/MAC/告警 SQL 下推、`LLMGateway` 路由优先级、`ToolRegistry` 非阻塞超时、`tool_get_device_neighbors` 端口方向、`AgentRunner` 配置加载、`PromptRenderer` 单遍替换与 `PromptManager` 特异度匹配、安全策略/Kill Switch 持久化、`ScopedTokenVault` 淘汰清理、`AIRateLimiter` 并发安全、知识库目录治理、RAG 单次向量化，以及自定义产品型号 canonical 厂商码与 `kb_product_alias` PostgreSQL 冲突安全写入。
- **产品知识库扩充**：在 `official_product_catalog_service.py` 中补充华为、H3C、Cisco 主流路由器/防火墙/交换机，并新增 Ruijie、Juniper、Fortinet、Aruba 四大厂商 60+ 官方型号、别名及官方文档参考。
- **P2 前端优化与修复**：重构美化并修复 12 个 AI 前端页面和 `src/api/ai.ts`，补齐模型编辑/路由重置、Provider 合规字段与密钥轮转、日预算进度条、Dry-Run 原因与 `max_payload_bytes` 编辑、Agent 注册表展示、治理设备下拉与风险确认、检索测试暗色模式与结构化筛选、Prompt 全局 `facets`、知识库存储 ID 版本操作与去假延迟等。

- 风险：新增官方产品目录型号需在部署后触发一次官方目录同步写入生产数据库；本次推送至独立远端分支 `AI_DEV`，不影响 `main` 或其他发布分支。
- 回滚：可通过 `git revert <commit_sha>` 或直接删除/重置远端 `AI_DEV` 分支完整回滚。
