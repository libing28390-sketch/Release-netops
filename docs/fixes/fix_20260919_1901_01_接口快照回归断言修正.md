# 接口快照回归断言修正

## 问题现象

GitHub Actions 全量测试中，`test_interface_snapshot_clears_missing_current_rows` 断言缺失接口的 `oper_status` 被改为 `unknown`，以及 `test_interface_snapshot_uses_boolean_flags_for_postgresql_compatibility` 使用固定参数下标检查布尔值。两项断言均与当前接口采集实现不符。

## 根因

接口采集改为 SNMP 优先后，CLI/IP 快照只清除缺失接口的 IP/L3 投影，接口状态由 SNMP IF-MIB 维护并应保留。实现新增状态保护 SQL 参数后，旧测试的参数下标随之变化。

## 解决方案

- 更新缺失接口用例，确认 IP 字段清除且已有 admin/oper 状态保留。
- 通过 SQL 字段对应的占位符位置读取 `is_l3` 和 `ip_enabled` 参数，分别验证布尔值和整数类型。
