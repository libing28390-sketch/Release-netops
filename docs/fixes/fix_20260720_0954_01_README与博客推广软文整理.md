# Git 提交修复记录：README 与博客推广软文整理

## 问题现象
1. 项目根目录下冗余存在 `README.md` (旧版 44 KB 详细安装文档) 与 `README_v2.md` (新版 8.5 KB 精美产品展示页)，文档职责和版本混乱。
2. 属于技术推广博客性质的软文 `docker_deploy_guide.md` 被错误归档在 `docs/plans/` 目录中。

## 根因
1. 开发过程中新增了新版 `README_v2.md` 用于快速宣传展示，但未彻底完成新旧版本的交替替换。
2. 文档存放分类不够规范，博客类文章应有独立的 `docs/blog/` 归档。

## 解决方案
1. 将 `README_v2.md` 的内容完全写入并覆盖主 `README.md`，然后使用 `git rm` 删除冗余的 `README_v2.md` 物理文件，完成版本合并。
2. 在 `docs/` 下新建 `blog/` 目录，将推广软文从 `docs/plans/docker_deploy_guide.md` 移动到 `docs/blog/docker_deploy_guide.md`。
3. 修改 `.gitignore` 规则，追加加白项 `!**/docs/blog/**/*.md`，以便私有 Git 仓库能正常追踪并同步该博客文件夹下的 markdown 软文。
