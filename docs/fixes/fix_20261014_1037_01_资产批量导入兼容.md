# 资产批量导入兼容

## 问题现象

提交 `43d43459` 后，GitHub Actions 的资产导入回归测试出现 11 项失败。失败日志显示，既有测试直接调用 `import_assets()` 并传入 `AssetCreate` 实例，导入代码随后访问 `body.remote_desktop_profiles` 并抛出 `AttributeError`。一部分资产创建断言失败也是此异常导致。

## 根因

FastAPI 的 HTTP 请求校验会将 `/assets/import` 的 body 转换为 `AssetImportCreate`，该模型新增了 `remote_desktop_profiles`。测试和其他内部直接调用绕过 FastAPI 的模型转换，仍传入基础 `AssetCreate`，因此新字段不存在。

## 解决方案

在批量导入逐行处理入口检测基础 `AssetCreate`，将其序列化后校验为 `AssetImportCreate`，使新字段使用默认空列表。保留 HTTP 请求契约及已有资产导入语义。
