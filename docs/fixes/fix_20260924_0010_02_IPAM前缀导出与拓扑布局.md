# 修复记录：IPAM 前缀导出与拓扑布局

## 问题现象
- IPAM 前缀列表无适用的全量导出入口，当前列表有服务端分页。
- 拓扑详情工具栏覆盖绘图区；宽屏下站点卡片和角色分层图的比例不合适。
- 站点总览卡片分页打断了直接浏览。

## 根因
- 前缀页没有导出流程；图形 viewport 用外层画布测量，工具栏绝对定位覆盖 SVG；同层间距与相邻角色层距不匹配；站点少时固定多列并分页。

## 解决方案
- 新增 XLSX 默认、CSV 可选的前缀导出；按筛选条件服务端每页最多 100 条读取所有结果；计数/利用率标注导出快照，CSV 做 BOM、字段转义和公式前缀中和。
- 拓扑工具栏移到 SVG 画布上方正常流布局；用独立绘图区测量缩放及悬浮信息卡坐标；同层节点间距按相邻角色层距计算，布局 schema/key 升至 v8。
- 站点总览所有卡片直接展示，并按站点数自适应居中栅格。
