GitHub Actions 有 2,799 项通过、1 项跳过、1 项失败。唯一失败用例仍断言 V2 前的颜色，并检查没有经过 `build_dashboard_catalog()` presentation 覆盖的基础 builder，因而与实际发布 JSON 的语义不一致。当前 `main` 与远端已同步，但 v1.0.9 标签及公开 release 仍指向较旧代码。

- 根据用户要求，在提交后推送 `main` 并将现有 v1.0.9 标签重新指向新提交，触发公开发布 workflow。
