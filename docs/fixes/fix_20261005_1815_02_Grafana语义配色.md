# Grafana 面板高对比语义配色

## 问题现象

- 12 个 Grafana 面板已有方向色和状态色约定，但绿色、红色、蓝色等仍使用接近 Grafana 默认值的色号，整体识别度与产品视觉一致性不足。

## 根因

- Generator 中的健康、告警、严重、信息、辅助色分散地引用一组较保守的默认色值；生成出的 Stat、Gauge、Table 映射和趋势覆盖色因此缺少鲜明统一的 Nexora 视觉特征。

## 解决方案

- 在 Dashboard generator 集中定义高对比的 Nexora 语义色：薄荷绿表示健康/出向，亮蓝表示信息/入向，金色表示警告/广播，橙色表示高风险/错误，珊瑚红表示严重/丢弃，紫色用于组播，冷灰表示未知或中性。
- 重新生成全部 12 个 Dashboard JSON，保持现有指标语义、阈值顺序和健康状态映射不变，只更新这些配置引用的色值。
- 不在 Dashboard JSON 中强制主题背景；背景仍由 Grafana 用户主题设置决定。

## 修改文件

- monitoring/grafana/generate_dashboards.py
- monitoring/grafana/dashboards/nexora-*.json（12 个）
- backend/tests/monitoring/test_domestic_and_wireless_monitoring.py

- 仍需在目标 Grafana 中查看实际对比效果；开发机未安装 Docker，JSON 和测试验证不能代替页面渲染检查。
- 该配色面向 Grafana 暗色主题的高对比呈现；Grafana 背景主题是用户级设置，不随 Dashboard JSON 强制更改。
