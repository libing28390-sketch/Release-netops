# 修复记录：大盘端口名切换与服务器大盘拆分及网络监控迁移

## 1. 问题现象与需求背景
1. **大盘端口编号格式不全**：此前所有 Grafana 监控大盘（接口流量、出口网络、设备详情等）在展示端口时依赖 `ifIndex`（如端口 1、2、3），缺少交换机物理端口全称（如 `GigabitEthernet1/0/1`、`XGigabitEthernet0/0/1`），给一线网络工程师巡检与排障带来识别困难。
2. **服务器大盘粒度较粗未区分系统**：原有的 `07 服务器与主机监控 (Server & Host Metrics)` 将 Linux 与 Windows 主机指标混合在一个大盘中，展示不够精细专业。用户期望参考官方标准 Exporter 大盘规范，将服务器监控拆分为独立的 Linux 与 Windows 仪表盘，提升直观性与美观度。
3. **网络监控菜单冗余与功能分散**：左侧一级监控菜单中的 `/monitor/networks` 页面功能已被 Grafana 监控大盘覆盖，唯一保留的刚需功能是通过通用 SNMP MIB-II 批量同步网络设备真实主机名。用户建议移除该菜单，并将“SNMP 同步主机名”功能平滑迁移至 `/assets/network-devices`（网络设备台账）。

## 2. 根因分析
1. **SNMP 指标未关联 ifName**：SNMP Exporter 采集 `if_mib` 时未配置基于 `ifIndex` 到 `ifName` 的 label lookup，且 Grafana 生成脚本及 PromQL 查询按 `ifIndex` 聚合与标注，导致展示列与图例缺少 `ifName`。
2. **服务器大盘指标混用**：原 `server-metrics.json` 同时定义 `node_cpu_seconds_total` 与 `windows_cpu_time_total`/`hrProcessorLoad`，面板未能充分利用各自系统的专属核心指标（如 Linux 的 Load1/5/15、Swap利用率、IOPS，以及 Windows 的逻辑磁盘读写延迟、网络吞吐、RDP终端会话）。
3. **历史功能入口孤立**：原 `/monitor/networks` 仅作为旧版诊断页面保留，而设备台账操作场景集中在 `/assets/network-devices`，缺乏在资产列表直接触发 SNMP 主机名探测与更新的能力。

## 3. 解决方案与实施步骤
1. **SNMP Exporter 标签映射与 Grafana 大盘端口名切换**：
   - 在 `monitoring/snmp-exporter/snmp.yml` 中为核心 `if_mib` 指标（`ifAdminStatus`, `ifOperStatus`, `ifInOctets`, `ifOutOctets`, `ifHCInOctets`, `ifHCOutOctets`, `ifInErrors`, `ifOutErrors`, `ifInDiscards`, `ifOutDiscards`, `ifHighSpeed`）配置 `lookups: [{source_indexes: [ifIndex], lookup: ifName}]`。
   - 更新 `monitoring/grafana/generate_dashboards.py`：
     - `clean_organize_transformation` 隐藏 `ifIndex`，将 `ifName` 规范命名为「端口编号」并作为主要列显示；
     - 接口大盘与出口大盘中按 `(hostname, instance, ifName)` 聚合，图例从 `端口 {{ifIndex}}` 统一调整为 `{{ifName}}`；
     - 重新生成所有大盘 JSON，验证无报错。
2. **服务器监控拆分为 Linux 与 Windows 独立大盘**：
   - 将原 `build_server_dashboard` 拆分为：
     - `build_linux_dashboard()`：UID `nexora-linux-metrics`，文件名 `linux-metrics.json`，覆盖 Linux 主机总数、CPU/Load1/Load5、物理内存与 Swap、磁盘利用率 Top 10、磁盘读写 IOPS、网卡 bps 与 TCP 连接排行。
     - `build_windows_dashboard()`：UID `nexora-windows-metrics`，文件名 `windows-metrics.json`，覆盖 Windows 主机总数、CPU 使用率、物理内存与可用容量、逻辑卷使用率 Top 10、磁盘读写延迟 (s)、网卡 bps、RDP 活跃会话与 Uptime 清单。
   - 删除过期的 `server-metrics.json`。
   - 更新 `src/pages/GrafanaDashboardPage.tsx`，在左上角大盘选择器中注册 `07 Linux 服务器` 与 `08 Windows 主机`，并调整进程明细跳转按钮的激活逻辑。
3. **下线 `/monitor/networks` 并将 SNMP 同步迁移至 `/assets/network-devices`**：
   - 侧边栏 `src/components/AppSidebar/navConfig.ts` 移除 `network-monitoring` 选项；
   - 在 `src/utils/routeContext.ts` 中将 `/monitor/networks` 重定向映射至 `activeTab = 'inventory', subPage = 'devices'`；
   - 更新 `src/components/AppMainContent.tsx` 和 `src/pages/IPLocatorPage.tsx` 中的相关路由跳转；
   - 在 `src/pages/InventoryDevicesTab.tsx` 中新增 `handleBatchSyncHostnames` 方法：
     - PageHero 顶部工具栏增加「SNMP 同步主机名」按钮，支持一键探测同步；
     - 批量勾选设备时的浮动胶囊增加「批量同步主机名」按钮，支持按选中设备探测；
     - 配套半透明毛玻璃结果通知 Toast，并在同步完成后自动刷新设备台账与状态计数。
