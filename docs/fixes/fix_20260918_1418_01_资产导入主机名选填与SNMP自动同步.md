# 修复与功能记录：资产导入主机名选填与SNMP自动同步

## 1. 问题现象与提交目的
- **现象 1**：网络设备监控页面中之前未显示实时遥测 CPU / 内存指标数据。排查确认为 Cisco C2960 设备在纳管时未绑定对应的 SNMP 指标采集模板，后台遥测巡检调度触发安全约束跳过。
- **现象 2**：用户在通过 Excel 批量导入网络资产时，需要手工录入每一台设备的主机名。不仅操作繁琐，且容易出现与设备实际名称不一致的情况（例如将实际的主机名 `core-sw-01` 误录为代号 `R1`），导致 LLDP/CDP 拓扑推导匹配时出现未纳管邻居或设备割裂。
- **提交目的**：
  1. 为两台测试 Cisco 交换机绑定预设指标模板，恢复实时硬件遥测指标采集。
  2. 实现资产导入时主机名选填（支持留空），导入后自动通过通用标准 SNMP 读取实际设备名称并规范化同步。
  3. **标准约束保障**：严格遵循用户要求——“同步主机名这个是不需要绑定任何SNMP模板的，所有厂商都是这样的逻辑”。完全基于 RFC 1213 MIB-II `sysName.0` (`1.3.6.1.2.1.1.5.0`) 通用标准实现，彻底脱离任何特定厂商指标模板的绑定限制。
  4. 在【网络监控】页面详情卡片展示 `sysName` 差异徽标并提供【同步主机名】按钮；在【资产管理】新增/编辑弹窗提供【SNMP探测】快捷按钮。

---

## 2. 根因分析
1. **监控指标无数据**：
   采集链路架构中设定了 `snmp_metric_profile_id` 指标模板关联机制。当设备未指定模板时，为避免未知 OID 轮询造成设备负担，系统默认安全跳过。应用官方预置的 Cisco 模板后即可正常采集。
2. **导入强依赖手动主机名**：
   原有前端导入表头和后端入库校验中，`hostname` 属于强校验必填项，未提供基于网络管理 IP 和 Community 自动探测清洗的闭环能力。
3. **域名后缀污染**：
   许多物理网络设备通过 SNMP 返回的 `sysName` 带有企业域名后缀（例如 `core-sw-01.CCIE`），需要通过算法剥离域名后缀以统一为规范的主机名 `core-sw-01`。

---

## 3. 解决方案与实现说明
1. **RFC 1213 通用标准协议采集与零模板依赖**：
   - 在 [backend/api/devices.py](file:///d:/nexora/nexora-private/backend/api/devices.py) 中新增 `clean_system_hostname()` 与 `POST /api/devices/{device_id}/sync-hostname` 端点，以及即时探测端点 `POST /api/devices/probe-hostname`。
   - 所有接口统一使用 RFC 1213 MIB-II 标准 OID `1.3.6.1.2.1.1.5.0`，无论 Cisco、Huawei、H3C、Ruijie 或 Juniper 均天然支持，零模板依赖。
2. **资产导入放宽与异步自发现**：
   - 在 [backend/api/assets.py](file:///d:/nexora/nexora-private/backend/api/assets.py) 中，导入时若主机名留空，以管理 IP 临时入库；事务提交后由后台协程异步调用 SNMP 同步接口，自动完成设备实名化。
   - 在 [src/pages/AssetManagement/index.tsx](file:///d:/nexora/nexora-private/src/pages/AssetManagement/index.tsx) 中将“主机名”移出必填表头，更新说明为选填/支持留空。
3. **监控大屏与资产弹窗即时交互**：
   - [src/components/NetworkMonitoring.tsx](file:///d:/nexora/nexora-private/src/components/NetworkMonitoring.tsx)：头部展示 `sysName` 并增加【同步主机名】按钮。
   - [src/pages/AssetManagement/components/AssetModal.tsx](file:///d:/nexora/nexora-private/src/pages/AssetManagement/components/AssetModal.tsx)：主机名输入框右侧增设【SNMP探测】快捷按钮。

## 7. 风险与回滚方式
- **风险评估**：低风险。SNMP Get 探测属于只读操作，不更改设备运行配置；主机名留空时有 IP 兜底，不影响 CMDB 资产入库成功率。
- **回滚方式**：如需回滚，可通过 `git revert HEAD` 撤销提交，数据库中设备主机名仍保留为当前规范化名称或可通过界面重新手动编辑修改。
