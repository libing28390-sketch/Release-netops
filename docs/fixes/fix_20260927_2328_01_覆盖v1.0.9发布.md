# 覆盖 v1.0.9 发布

## 背景

当前代码已包含近期完成的监控面板、Grafana/cAdvisor 采集修正、告警成功率展示及定时作业安全审批多方式验证。用户要求继续使用公开仓库现有的 `v1.0.9`，直接更新该版本，不另发新版本。

此前一次操作误将应用元数据改成 `1.0.10`，并推送了源仓库 `v1.0.10` 标签。用户已取消对应 Actions 运行，并明确要求恢复使用 `v1.0.9`。公开仓库目前仍以 `v1.0.9` 为最新版本，未创建公开 `v1.0.10`。

## 修正内容

- 将后端版本、前端版本回退值、npm 包元数据和部署发布说明统一恢复为 `1.0.9`。
- 在 `v1.0.9` 发布说明中保留当前交付内容，包括审批验证方式、Grafana 内部指标抓取、容器观测、运行时间面板和告警成功率等更新。
- 将源仓库 `v1.0.9` 标签重新指向此次修正提交，并通过已有发布工作流覆盖公开仓库同名 Release 与附件。
- 删除误建的源仓库 `v1.0.10` 标签；不更改主分支既有提交历史。

## 验证

- `package.json`、`package-lock.json` 根包和 `backend/core/version.py` 均为 `1.0.9`。
- `npm run build`：通过，Vite 转换 4296 个模块并成功生成构建产物。构建后恢复被工具改动的跟踪文件 `dist/index.html`，不发布本地生成的构建产物。
- `git diff --check`：通过。
- `npm run lint`（TypeScript `tsc --noEmit`）：通过。
- 保留工作区内已有的两个未跟踪 `dist-*` 临时目录，不纳入提交。
