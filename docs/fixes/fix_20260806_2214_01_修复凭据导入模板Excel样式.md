# 修复 CMDB 凭据导入 Excel 模板表头背景网格纹理异常

## 1. 问题现象
用户在网页端 `http://192.168.56.1:5400/cmdb/credentials` 点击“模板下载”导出 Excel 模板时，用 Microsoft Excel 打开后表头单元格（凭据名称、类型、用户名等）填充背景显示为密集灰色/黑色点阵（dither grid pattern），遮挡白色文本。

## 2. 根因分析
1. 原先代码采用底层 zip 与手动 XML 字符串拼接构建 OpenXML 样式表 (`styles.xml`)，由于不同 Excel 软件版本对底层 `patternFill` 与 `fills` 索引映射逻辑处理差异，产生灰阶点阵遮罩。
2. 开发环境中后台 Python 服务运行在驻留进程 PID 11212 上，之前的代码修改未被热重启的后台应用加载，导致前端仍持续拉取到旧服务返回的模板文件。

## 3. 解决方案
1. **重构模板生成逻辑**：在 [credentials.py](file:///d:/netops/netsops-main/backend/api/credentials.py) 中全面采用 Python 标准工业级库 `openpyxl` 生成 Excel 文件，使用 `PatternFill(fill_type="solid", start_color="FF007D9D")` 显式设置纯色填充背景，`Font(color="FFFFFFFF", bold=True)` 设置白色加粗字体，并绑定数据校验下拉框。
2. **重构单元测试**：更新 [test_credential_import_template.py](file:///d:/netops/netsops-main/backend/tests/configuration/test_credential_import_template.py) 校验 `openpyxl` 导出的工作簿样式与结构。
3. **服务进程重载**：终止驻留旧进程 PID 11212，重启端口 5310 上的 NetOps 后端 API 服务，确保接口返回全新 openpyxl 生成的模板。
