# 修正 SNMP 模板绑定测试文案

## 问题现象

推送到 `main` 后，GitHub Actions 的前端测试有 3 项失败。失败用例都等待查找 `Hardware results use native LibreNMS collection`，但界面没有显示该旧文案。

## 根因

本次功能已将 SNMP 模板绑定流程的硬件采集说明更新为 Nexora 本地 SNMP 采集；对应 `MetricOidProfilesModal` 测试仍保留 LibreNMS 原生采集时期的固定文本断言。因此测试在完成绑定操作后因找不到过期文本而失败，其他流程断言未报告失败。

## 解决方案

将 3 处测试断言更新为当前界面实际显示的 `Hardware results are collected locally by Nexora over SNMP`。没有修改运行时代码或测试流程。

## 实际修改文件

- `src/components/DeviceList/MetricOidProfilesModal.test.tsx`
- `docs/fixes/fix_20261008_1621_01_修正SNMP模板绑定测试文案.md`

## 验证命令与结果

- `npm run test:frontend -- src/components/DeviceList/MetricOidProfilesModal.test.tsx`：1 个测试文件、10 项测试通过。
- 附件中的 Actions 汇总显示其余 125 个测试文件通过，失败集中在该文件的 3 项旧文案断言。
- 本次只修改测试和修复记录；完整前端套件未在本地重跑。

## 未验证项

修正尚未进入新的 GitHub Actions 运行；推送后由 CI 重新执行全量前端测试。未部署或修改真实运行环境。
