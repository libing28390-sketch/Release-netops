# 首页在线率精度断言修复

## 问题现象

Actions #775 后端 release gate 通过，但前端 Vitest 931 项中 1 项失败：`HomePage.test.tsx` 找不到 `75%`。DOM 实际显示 `75.00%`，其余 930 项通过。

## 根因

首页在非 100% 在线率时采用两位小数格式，测试仍保留精度调整前的整数百分比期望值。

## 解决方案

将首页测试的显示断言更新为 `75.00%`。不修改在线率计算、页面显示或精度逻辑。

## 实际修改文件

- `src/pages/HomePage.test.tsx`
- `docs/plans/plan_20261111_1414_01_Actions后端门禁失败修复.md`
- `docs/walkthrough/walkthrough_20261111_1414_01_Actions后端门禁失败修复.md`
- 本修复记录

## 验证

- `npx vitest run src/pages/HomePage.test.tsx`：1 passed。
- `npm run lint -- --pretty false`：通过。
- 浏览器核对的 Actions #775：后端 pytest 已通过；前端检查由该断言失败，完整 workflow 尚未通过。
