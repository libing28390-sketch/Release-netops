# Git 变更记录: 重置/清空快速查询弹窗的上次输入命令

## 1. 变更背景与目的
当用户选择设备并开启快速执行面板（`QuickQueryOverlay`）后，在自定义命令输入框中输入并执行了命令。但如果关闭弹窗、重新选择其他设备或再次拉起快速查询面板时，发现该输入框中仍保留着上次执行的脏数据，降低了交互体验并可能导致用户误操作。

## 2. 解决方案与实施步骤
我们升级了 [QuickQueryOverlay.tsx](file:///d:/netops/netsops-main/src/pages/AutomationExecute/components/QuickQueryOverlay.tsx) 组件：
1. **添加重置钩子**：引入了 React `useEffect` 钩子，以弹窗显示状态 `hasTargets` 为依赖项；
2. **状态自动重置**：当 `hasTargets` 从 `false` 变为 `true`（表示弹窗被重新拉起/打开）时，立即调用 `setCustomCommand('')` 重置清空输入框内容，确保每次打开时输入框都是干净的。
