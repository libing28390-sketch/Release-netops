# Grafana 接口看板隐藏旧字段

## 问题现象

GitHub Actions run `#605` 在用户要求推送 CMDB 夹具修复后仍失败：`test_dashboards_suite_completeness` 的接口看板遍历断言发现某个 `organize.excludeByName` 缺少 `ifDescr`。该 run 有 1 个失败、2308 个通过、1 个跳过。

## 根因

失败断言遍历设备、接口、出口三份看板。设备清单 panel 8 已有 `ifDescr = true`，但接口看板 panel 6（利用率）、panel 9（错误/丢弃比例）、panel 12（Flap 次数）的生成器配置漏掉该字段。先前只核对 panel 8，因此没有发现接口看板中的缺项。

## 解决方案

在 `build_interface_dashboard()` 中为三个表格的 organize transformation 添加 `excludeByName.ifDescr = true`，并用生成器重建对应 JSON。
