# 修复记录：资产管理模块支持绑定已有凭据

## 问题现象
用户在“凭据管理”手动新建了凭据，但“资产管理”录入资产时无法直接绑定已有凭据，只能手动录入，给凭据集中化管理与轮换带来不便。同时，Excel 资产导入模板中缺乏绑定凭据的列，无法进行批量凭据关联。

## 根因
`physical_assets` 表和 API 层没有提供 `credential_id` 属性及入库绑定逻辑。在前端录入表单中也未设计已有凭据的选择与模式切换机制。

## 解决方案
1.  **数据库与后端**：
    *   在 `physical_assets` 表结构中添加 `credential_id` 列。
    *   在 `AssetCreate` / `AssetUpdate` 模型中加入 `credential_id` 参数。
    *   新增 `_pre_resolve_credential` 预解析逻辑，若录入或导入资产时指定了已存凭据（支持通过凭据 ID 或名称指定），则提前将该凭据的用户名、密码、SNMP社区名等解密并缓存至本地列以供后续底层采集兼容使用。
    *   在设备与资产更新同步时，限制仅对自动生成的凭据（`cred-{hostname}-`）进行覆盖修改，而防止在资产更新时意外覆盖、改写或污染全局共享凭据。
2.  **前端 UI 与模板**：
    *   在 Excel 导入导出模板和说明页中增加“绑定凭据”/“Credential”字段列。
    *   在 `AssetModal` 中增加“手动录入新凭据”和“绑定已有凭据”模式切换 Tab。
    *   在绑定模式下渲染凭据下拉框以选择关联已有凭据。
