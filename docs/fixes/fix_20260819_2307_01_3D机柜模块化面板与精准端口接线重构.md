# 修复记录：3D机柜模块化面板、精准端口接线与防遮挡重构

## 问题现象

1. **端口灯虚亮**：未插线的端口全部亮绿灯，与物理实际不符
2. **端口数量错误**：S6850-54HF 等48口交换机仍按24口渲染
3. **缺少管理口/控制口/USB口**：面板未展示 MGMT、CONSOLE、USB 模块
4. **线缆遮挡设备信息**：3D跳线从正面直穿面板铭牌区域
5. **线缆过粗**：默认线缆粗度远超真实光纤/Cat6规格
6. **选中设备全蓝**：选中后整个机箱变蓝色发光体，丢失细节
7. **PWR/SYS 指示灯缺失**：面板无电源和系统状态 LED 灯珠
8. **鼠标在端口间隙闪烁**：悬停在端口间触发反复刷新

## 根因

- `getSwitchFrontTexture` 未接收 `connectedPortNumbers`，默认所有端口亮灯
- 端口布局硬编码24口，未根据设备型号自适应
- 线缆路径直线绘制，未设计下挂走线和避让逻辑
- 选中效果使用整机 emissive 材质替代线框指示
- 面板纹理未包含管理区域模块

## 解决方案

### 核心修改

1. **动态端口 LED 绑定真实跳线** (`textures.ts`, `SwitchFaceplate.tsx`, `RackDeviceItem.tsx`, `RackScene.tsx`)
   - `getSwitchFrontTexture` 新增 `connectedPortNumbers: number[]` 参数
   - 仅当端口号存在于 `connectedPortNumbers` 中才亮绿灯
   - 缓存 key 包含排序后的端口列表确保不同设备独立纹理

2. **48口/24口自适应物理面板** (`textures.ts`)
   - 检测型号名 (S6850/6800/48/54/56) 渲染 48 ports (2×24) + 6 QSFP28
   - F1090 等小型设备渲染 24 ports (2×12) + 4 QSFP28

3. **MGMT/CONSOLE/USB 模块化物理呈现** (`textures.ts`, `DevicePortMatrix.tsx`, `RackDeviceTooltip.tsx`)
   - 面板左区渲染黄色 MGMT RJ45、青色 CONSOLE RJ45、蓝色 USB 3.0
   - HUD 面板新增独立管理口状态栏

4. **精准端口 3D 接线与下挂防遮挡理线** (`RackCableLayer.tsx`)
   - `getPortPhysicalCoordinates` 解析接口名映射到精确3D坐标
   - 8点 CatmullRom 样条，线缆先前出15cm、下挂至底部理线架、水平走线至竖直线槽
   - 标牌移至 X=-3.8 离格左区
   - 线缆细化至 2.5mm 光纤 / 5.0mm Cat6

5. **选中效果改为线框+微拉出** (`ProceduralChassis.tsx`)
   - 取消整机发光，改用青色线框边缘 + 6cm 前拉

6. **PWR/SYS LED 灯珠** (`SwitchFaceplate.tsx`, `ServerFaceplate.tsx`)
   - 3D 圆柱体 emissive 材质灯珠
