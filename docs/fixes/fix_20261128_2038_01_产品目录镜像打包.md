# 修复 Docker 部署后产品目录不可用

## 问题和根因

Docker 部署访问 `/ai/catalog` 时返回 `Reviewed catalog seed is unavailable`。后端读取仓库内 `docs/knowledge-engine/catalog/` 的产品目录和别名 YAML，最终镜像漏掉了该目录。

## 修改

在 `Dockerfile` 的最终阶段将种子目录复制到后端读取的 `/app/docs/knowledge-engine/catalog/`。部署配置和数据库无需调整。

## 验证

- 按镜像目录结构复制种子目录，调用后端加载器验证全部 5 个必需的 YAML 可读取并解析。
- 部署机执行 `docker compose up -d --build --no-deps netops` 成功。随后执行 `docker compose exec -T netops ls -l /app/docs/knowledge-engine/catalog/`，确认所需文件全部位于运行容器内。
- 运行容器的产品目录页面和接口结果未直接复核。

## 回滚

如需撤销本次打包修复，回退对应提交并重建 `netops` 镜像。回退后产品目录可能再次缺少种子文件。
