# 拓扑画布移除视图切换按钮

## 问题现象
拓扑画布右上角同时提供“Site 总览”和“设备拓扑”两个切换选项，入口与 Site 卡片总览、站点筛选重复；此前源码调整也没有更新本地 `dist` 构建产物。

## 根因
页面保留了可切换全站点总览和设备拓扑的双按钮，且本地生产构建产物比源码旧。

## 解决方案
- 移除画布右上角的双视图切换按钮。
- 默认显示 Site 卡片；点击卡片进入该 Site 拓扑，现有 Site 筛选器选择“全部站点”返回卡片总览。
- 将生产构建输出到临时目录，再复制更新后的入口和资源到本地 `dist`，避免 Vite 清理原有静态数据目录。

## 实际修改文件
- `src/pages/TopologyPage.tsx`
- `docs/plans/plan_20260930_1552_01_拓扑默认Site卡片视图.md`
- `docs/walkthrough/walkthrough_20260930_1552_01_拓扑默认Site卡片视图.md`
- `docs/fixes/fix_20260930_1653_01_拓扑画布移除视图切换按钮.md`
- 本地构建输出：`dist/index.html` 和 `dist/assets/` 中生成的资源（不提交）

- 检查本地 `dist/index.html`：所有入口和 preload 引用资源均存在。

## 风险与回滚方式
当前默认流程中，点击 Site 卡片进入拓扑后通过 Site 筛选的“全部站点”回到卡片列表。若需恢复双按钮，可恢复 `TopologyPage` 的画布切换组及原视图处理。
