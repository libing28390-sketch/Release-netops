# Dashboard 语义配色与无线终端统计口径

## 问题现象

- 多个 Dashboard 对入/出流量、错误、丢弃和告警严重度使用不一致的颜色；普通数量与异常状态难以区分。
- 网络总览和无线专页使用不同的终端计数来源和回退路径，造成一页显示缺数据、另一页显示 0。
- Stat 使用 range query + lastNotNull，最新序列消失后可能继续保留窗口内旧值。
- 部分磁盘百分比和采集耗时表没有应用预期单位，通用 `instance` 字段曾被标成设备管理地址。

## 根因

- 生成器为方向流量、健康阈值和告警严重度混用了颜色；普通 Stat 默认蓝色，0 值异常也可能高亮。
- 无线总览仅组合原始厂商 SNMP 序列；无线专页还使用平台控制器/SSID 回退，并按设备标签避免重复汇总。
- 单位 override 使用字段名匹配，但表格转换后的最终列名不同；`instance` 标签没有稳定代表设备管理 IP。
- 当前状态 Stat 没有使用 instant query。

## 解决方案

- 统一语义色：入蓝、出绿、错误橙、丢弃红；告警按严重度配色；普通 Stat 中性显示。
- Stat KPI 使用 instant query，避免源序列消失后仍显示较早的样本。
- 让总览和无线专页共用设备级 controller→SSID 无线客户端统计表达式，区分指标缺失与真实 0，不增加零值回退。
- `instance` 显示为“采集目标”，修正磁盘百分比与 SNMP 耗时单位字段匹配，改善接口趋势图例与详情页空白布局。
- 生成器写出前检查 Dashboard 数量、UID、面板 ID 和网格碰撞。
