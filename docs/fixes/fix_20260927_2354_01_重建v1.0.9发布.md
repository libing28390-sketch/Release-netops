# 重建 v1.0.9 Release 并更新发布说明

## 背景

用户确认需要把 GitHub 上的 `v1.0.9` Release 重建，以刷新 Release 首次发布时间，并再次更新 Release notes。版本标签仍保持 `v1.0.9`。

## 本次发布说明调整

- 标注发布内容更新日期为 2026-09-27。
- 按监控平台/Grafana、告警处置/通知、定时作业安全审批、S3 对象存储分节说明当前版本内容。
- 说明 cAdvisor 容器 CPU、内存工作集、磁盘读写速率的采集改进及无数据排查线索。
- 说明告警成功率把 `retrying` 记为失败尝试，并区分暂无已完成投递与指标源不可用。
- 说明 MFA、邮箱、飞书验证选项及 SeaweedFS S3 的配置备份/PAM 录像用途。

## 发布步骤

- 更新 `docs/deploy/release-notes.md` 并创建修正记录。
- 运行文档格式检查及发布门禁所需的本地检查。
- 提交并推送 `main`，将源仓库 `v1.0.9` 标签移动到该提交。
- 按用户确认删除公开仓库 `Release-netops` 中旧的 `v1.0.9` Release 对象，保留标签。
- 等待 v1.0.9 工作流通过后，确认同名 Release 重新创建，发布日期为重建完成当天，正文与下载附件来自最新构建。

删除旧 Release 会清除该 Release 对象及其下载计数；公开标签仍保留，随后由发布工作流重建同名 Release。
