# 修正网络总览设备总吞吐单位显示

## 问题现象

01 网络总览的“设备总流量 Top10”表格只显示 `23897` 这类无单位的原始数字，使用者无法判断其代表速率还是累计数据量。

## 根因

查询用 `rate(if*Octets[5m]) * 8` 后按设备求和，结果为 bit/s 吞吐速率，不是字节累计量。生成器把表格 `Value` 改名为“总流量”，但 `table_panel` 未收到相同的 `value_col_name`，于是单位 override 仍匹配默认列“数值”；转换后的列名不匹配，Grafana 没有应用 bps 格式化。

## 解决方案

- 将面板标题改为“设备总吞吐速率 Top10”，列头改为“总速率 (bit/s)”并增加说明，明确 5 分钟窗口、入向 + 出向汇总和速率语义。
- 让 `table_panel.value_col_name`、organize transformation 的列名和 field override matcher 完全相同，保留 `bps` 单位使 Grafana 自动缩放显示。
- 同步 generator 生成的 Overview JSON；没有改 PromQL 统计口径。
