# NSOT退役与调度回归测试契约

## 问题现象
本地后端9文件组合94项中82通过、12失败，失败均在本轮新增/更新的退役或路由作业回归测试，而不是重新开放功能的理由。

## 根因与方案
- 已注销的API没有业务处理器。GET返回404，根SPA静态挂载会先拒绝其他方法并返回405；无静态挂载时仍可能404。退役契约检查同时验证仅bulk-options注册、请求拒绝和设备策略不变，避免把特定静态构建布局当业务接口约束。
- 旧NSOT作业执行体标记retired并停用，外层执行器将终态归一写为skipped；验证持久化状态及停用和零设备采集，不改执行器。
- 新路由作业测试曾把sync_routing_neighbors_job mock到错误模块；修正为scheduler_service的真实调用位置，确保测试不访问设备。
