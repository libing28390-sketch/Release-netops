# 拓扑默认 Site 卡片视图

## 问题现象
打开 `/monitor/topology` 时默认显示设备拓扑画布，用户需要手动切换才能按 Site 查看分组卡片。

## 根因
`TopologyPage` 的 `canvasView` 初始值设为 `site`，而 Site 卡片总览对应 `overview`。

## 解决方案
将拓扑页面初始视图改为 `overview`。卡片点击进入所选站点拓扑的行为保持不变。
