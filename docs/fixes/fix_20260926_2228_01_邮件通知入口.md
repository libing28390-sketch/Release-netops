# 修复记录：SMTP 邮件设置入口放错模块

## 问题现象
- 用户在平台管理中找不到“邮件告警 SMTP 通道”，页面导航内没有邮件配置入口。
- 浏览器实查发现 SMTP 表单被放在“配置管理 → 配置模板”页面中，和平台管理设置的归属不一致。

## 根因
- SMTP 表单挂载在 `PlatformSettingsTab`（配置模板中心实现）中；平台管理导航、路由上下文和主内容区均未定义 SMTP 设置页。

## 解决方案
- 新增独立邮件通知设置页 `/management/notifications`。
- 在平台管理导航中添加“邮件通知”入口，补充路由解析和页面标题。
- 从配置模板中心移除 SMTP 表单与相关状态逻辑，避免重复入口。
- 保留 SMTP 加载/保存/测试 API、权限反馈、校验和密码安全行为，并调整为更易读的页面布局。
