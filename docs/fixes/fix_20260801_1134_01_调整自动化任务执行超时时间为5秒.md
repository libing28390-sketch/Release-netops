# Git 修复记录：调整自动化任务执行超时时间为 5 秒

**创建时间**：2026-08-01 11:35
**修复问题名**：调整自动化任务执行超时时间为5秒

---

## 1. 问题现象
在 `http://192.168.96.1:5400/automation/tasks` 下发自动化任务或脚本时，当设备不可达或响应卡住时，默认超时时间较长（20~30秒），等待时间过长。

## 2. 根因
驱动层默认配置的 SSH 建连超时 `timeout` 设为 20 秒，`blocking_timeout` 与 `read_timeout` 设为 30 秒/120 秒。

## 3. 解决方案
将 `netmiko_driver.py` 中的 `timeout`、`blocking_timeout` 和 `read_timeout` 默认值统一调降为 **5 秒**，同时保留按设备或任务传入自定义超时的扩展能力。
