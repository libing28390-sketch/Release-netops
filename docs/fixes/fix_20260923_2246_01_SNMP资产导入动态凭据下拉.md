# SNMP 资产导入动态凭据下拉

## 问题现象

资产模板的 SNMP 凭据列没有凭据选择项，静态示例 `snmp-ro` 在其他凭据中心中不存在时会令导入失败；普通/特权凭据样例也可能被误当成真实绑定值。需要让登录后的下载模板直接列出当前可用 SNMPv2 凭据。

## 根因

静态公开 XLSX 不含用户当前的凭据中心数据，页面此前优先直接下载该文件，因此无法生成环境专属的凭据下拉列表。

## 解决方案

- 新增 Operator 鉴权的 `/api/assets/import-template`，按凭据中心实时生成隐藏选项工作表和 SNMPv2 凭据名称数据校验列表。
- 只列出 SNMPv2 且 Community 已配置的凭据；凭据名称以文本写入，避免类似公式的名称被 Excel 执行。
- 页面优先下载动态模板；端点不可用时回退到静态文件，再回退到浏览器生成模板。
- 更新静态模板字段、清除虚构 SNMP 名称，并说明精确名称、Community、本地凭据和重复资产跳过规则；保留旧表头兼容。

## 风险与回滚方式

- 没有可用 SNMPv2 凭据时，动态模板仍可下载，但不会生成 SNMP 凭据列表；留空仍允许使用资产本地 Community。
- 回滚可恢复上述 API、前端、静态模板和测试改动，并一并移除本修复记录；不涉及数据库迁移。
