# Actions 监控测试回归修复

## 症状

GitHub Actions 后端回归为 3,242 passed、5 failed、1 skipped。失败涉及监控指标来源断言、硬件巡检指标、接口状态错误信息，以及 BGP/OSPF/BFD 邻居告警的批量状态写入。

## 根因

- BGP 邻居告警已按设计改为 SNMP 优先、CLI 回退，集合目录正确返回 `snmp_cli_fallback`；原测试仍断言旧的 `ssh_cli`。
- 内存巡检现在只接受 `memory_usage_percent` 传感器，旧夹具省略了 `sensor_type`，与真实诊断快照结构不符。
- `_collect_snmp_for_inspection` 对所有 SNMP 巡检项都读取 IF-MIB 快照，并把接口快照错误混入硬件指标，即使当次没有接口状态检查。
- 接口 Down 巡检已改用完整 IF-MIB CMDB 快照，旧测试仍用“没有 LibreNMS 行”的错误文案契约。
- 邻居批处理测试没有设置新采集计划和凭据解析器，因而采集函数按设计没有进入 BGP/OSPF/BFD 分类处理。

## 修复

- 只有当巡检项包含接口 Down 检查时才读取 IF-MIB 快照；其他 SNMP 指标不再附带无关接口错误。
- 更新测试夹具和断言，使其匹配当前传感器类型、SNMP 优先来源、IF-MIB 错误语义，并为邻居批处理测试显式配置采集许可和 CLI 凭据。
- 未放宽业务校验或告警断言。
