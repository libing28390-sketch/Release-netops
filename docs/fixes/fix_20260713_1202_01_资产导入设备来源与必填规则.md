# 资产导入设备来源与必填规则

## 问题

- 资产导入模板缺少设备来源和免上收投产原因字段。
- 批量导入接口未持久化设备来源，手工增加模板列也会被忽略。
- 资产新增页面没有集中说明必填规则。

## 根因

- Excel 模板、前端列映射和后端批量写入 SQL 没有随 `asset_origin` 业务字段同步升级。
- 表单仅通过保存按钮状态限制“主机名/资产编号至少一项”，用户无法直接理解规则。

## 解决方案

- 服务器与网络设备模板新增 `设备来源/Asset Origin`、`免上收投产原因/Takeover Exemption Reason`。
- 增加 `new`、`legacy` 可选值说明和可直接使用的示例行。
- 模板第一张工作表增加“填写说明”，设备来源列标题明确标注 `new=新设备、legacy=存量设备`，避免将参考页误认为没有该字段。
- 批量导入统一执行资产来源规则：新设备强制待投产；存量设备直接投产必须提供普通账号、普通密码和至少 5 字的原因。
- 导入时同步写入资产和关联设备的投产、豁免、托管状态。
- 新增资产弹窗集中展示必填规则，缺少资产标识时给出明确错误。

## 风险与回滚

- 存量设备直接投产的批量导入校验比旧版本严格，缺少必要字段的文件会返回具体错误。
- 回滚时需同时撤销模板列、前端映射和后端导入逻辑，避免前后端契约不一致。
