# Grafana 看板展示与数据语义

## 问题现象

设备详情看板身份表被裁切且缺少站点/厂商/角色筛选；接口运行状态需要用背景色表达；部分看板暴露内部索引和发现来源字段；查询无样本时被补零误显示为真实的 0；告警持续时长卡片过窄。告警 Outbox 查询成功但没有队列行时也需要显式输出 0，查询失败时则应保持无样本。

## 根因

看板生成器中的变量、表格映射、默认空值文本、PromQL 回退和面板布局未完整表达这些展示语义；Outbox exporter 只为有状态行输出指标，不能区分空队列与查询失败。

## 解决方案

- 调整设备详情筛选变量和身份表高度；Up/down 状态单元格以绿色/红色背景填充。
- 隐藏不面向用户的硬件索引、rule/source 元数据；使用“暂无采集数据”表达无样本，对有采集基线且统计为零的查询保留真实 0。
- 调整告警持续时长卡片宽度。
- Outbox 查询成功时为允许状态输出汇总值（包括 0）；查询失败时省略该指标族。
