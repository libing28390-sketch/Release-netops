# 修复记录：发布测试耗时观测与依赖缓存

## 问题现象

Release workflow 的后端全量测试约耗时 8 分钟，日志没有慢测试排行；Python 依赖安装步骤约 31 秒且未启用 pip 缓存，难以确认并优化真实瓶颈。

## 根因

workflow 使用裸 `pytest`，未显示慢测试信息；`setup-python` 没有启用依赖缓存。Redis 集成用例因安全授权跳过不是耗时根因。

## 解决方案

- 开启 `actions/setup-python@v5` pip 缓存，依赖键为 `backend/requirements.txt`。
- 用 `pytest --durations=25` 替代裸 `pytest`，测试数量、覆盖范围和 Redis 授权策略保持不变。
- 暂不启用并行，避免 PostgreSQL 隔离 fixture 和共享测试数据库产生竞态。

## 风险与回滚方式

- pip 缓存不可用时会回退到正常安装。
- pytest 慢项参数不改变测试结果；可从 workflow 移除此参数恢复原命令。
- 若缓存配置遇到 Action 兼容问题，可删除 `cache` 与 `cache-dependency-path` 两项设置。
