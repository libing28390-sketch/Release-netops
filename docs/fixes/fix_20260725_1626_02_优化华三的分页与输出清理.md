# Fix Record - 优化华三的分页与输出清理

## 问题现象
当在包含多页数据的 H3C 等设备上执行 `display interface brief` 等长命令时，查询速度非常缓慢（耗时约 8 秒），且最终输出中夹杂许多长空格行（`               `）和换行格式错误，影响显示和表格对齐。

## 根因
1. 原 `drain_paged_output` 在读取每个新分页的数据时使用了基于静默延时超时的 `read_channel_timing`。即使已经加载完新数据，由于底层仍在等待信道静默，也会产生不必要的等待时间（可达数秒）。
2. 部分设备通过发送回车符 `\r` 及一串用于擦除 `---- More ----` 标识的空格行来进行换页擦除。在 python 依据行边界切分后，由于回车符被剥离，这些包含特定数量空格的抹除行作为独立行遗留在输出结果中。

## 解决方案
1. 重构 `drain_paged_output`：优先调用 Netmiko 的 `read_until_prompt_or_pattern` 配合 `paging_pattern` 精准检测页底及命令结束状态，直接实现无静默等待读取。
2. 过滤提取残留：在返回的行序列中检查并剔除含有字符但仅包含空白/空格的抹除残留行，并移除 `\r` 符号。

2. 在基准测试中，S6850-1 上的长输出命令读取速度缩短了 50 倍以上（只需 0.16s 即可回显 3 页完整数据），输出内容整洁有序，无残留空格行。
