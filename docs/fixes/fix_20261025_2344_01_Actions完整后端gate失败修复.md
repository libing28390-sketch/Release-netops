# 修复记录：Actions 完整后端 gate 失败

## 问题现象

Actions #751 在后端 pytest 全量执行后返回失败：3487 passed、1 skipped、4 failed。由于后端 gate 失败，前端构建、知识引擎评估和发布树同步没有运行。

## 根因

1. `RESOURCE_ACTIONS['Operator']` 仍包含通用 `approve`，与变更/发布审批职责分离策略矛盾。普通 Operator 被错误允许审批 playbook，也导致 PAM 审批请求在资源查询前未被拒绝，最终返回 404 而非 403。
2. 两个 scheduled-job 测试夹具没有提供新契约要求的有效同租户 bounded grant。manifest 因缺授权而正确拒绝；NSOT snapshot job 因缺少 active grant 被 claim 为 denied，采集器 mock 未运行。

## 解决方案

- 从 Operator 粗粒度 action 集合移除 `approve`；管理员通配权限与 Release Manager 等显式 role profile 授权保持不变。
- 为 scheduled-job manifest 测试补充同租户 incident ticket 与 bounded grant。
- 为 NSOT snapshot job 测试补充 grant ID、active grant row、scope 与 manifest hash 一致的授权快照；不放松生产授权校验。
