# 修复接口采集布尔类型不匹配 修复记录

## 问题现象

在接口页面点击“立刻采集接口”报错，接口采集任务失败，后端日志抛出：
```
psycopg2.errors.DatatypeMismatch: 错误:  字段 "is_l3" 的类型为 boolean, 但表达式的类型为 integer
LINE 5: ...ysical', 'routed', '192.168.96.102', '192.168.96.102', 1, 1)
                                                                  ^
HINT:  你需要重写或转换表达式
```

## 根因

在将核心数据库从 SQLite 变更为 PostgreSQL 后，`interfaces` 表中的 `is_l3` 列的类型变更为 `boolean`。
1. 在 `backend/services/interface_collection_service.py` 内部 `UPDATE` 和 `INSERT` 语句中，对 `is_l3` 部分分别硬编码写入了整数值 `1`。
2. 在 `backend/services/scheduler_service.py` 调度同步物理接口时，将 `is_l3` 的值强制转换为了整型 `1`/`0` 进行占位符填充。
这两种整型向布尔型的隐式转换动作直接导致 PostgreSQL 报错。

## 解决方案

1. 将 `interface_collection_service.py` 中的 `is_l3 = 1` 替换为标准 SQL 的布尔关键字 `is_l3 = TRUE`。
2. 将 `scheduler_service.py` 中的 `is_l3` 三元表达式从数值 `1` / `0` 修改为返回 Python 布尔型 `True` / `False`。
