# 修复 PostgreSQL 迁移中断

## 问题现象

新部署环境拓扑采集和设备匹配成功，但 `managed_links=0`。数据库 `schema_migrations` 只有 1～18，日志提示 `aggregation_protocol` 不存在。

## 根因

第 19 号迁移使用 `COALESCE(created_at, CURRENT_TIMESTAMP)`，而基线中的 `sites.created_at` 是 TEXT。PostgreSQL 类型推断失败后，迁移框架停止执行后续迁移。

## 解决方案

在 `m0019_site_timestamps.py` 中保持 TEXT 字段契约，并将 PostgreSQL 回填值显式转换为 `CURRENT_TIMESTAMP::text`。修复后服务启动会自动继续执行 19～23 号迁移，创建 `aggregation_protocol`、`name_display` 等字段。

## 验证

- Python 编译通过。
- `test_schema_migrations.py`：5/5 通过。

## 部署

```bash
docker compose build netops
docker compose up -d netops
```

不需要删除镜像缓存以外的数据库数据，也不要使用 `docker compose down -v`。
