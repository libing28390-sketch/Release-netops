# 稳定 SSH 兼容算法测试

## 问题现象 / 本次提交目的

提交 `18e1592a` 对应的 GitHub Actions 后端 pytest 中，唯一失败是算法回归测试要求运行器的 system OpenSSH 输出 `ssh-dss`。

## 根因

生产代码会按 `ssh -Q key` 过滤本机 OpenSSH 未实现的算法。GitHub runner 未报告 DSA 支持；测试把当前主机能力误当成所有 SSH 客户端都支持。

## 解决方案

保留 legacy 策略包含 `ssh-dss` 的断言；以 mock 能力覆盖本机支持和不支持 DSA 的参数生成行为，避免测试依赖 runner 安装的 OpenSSH 版本。

## 实际修改文件

`backend/tests/pam/test_ssh_compat_algorithms.py`；本次计划、走查和修复记录。没有修改 SSH 生产代码。
