# 拓扑链路响应测试契约修正

## 问题现象

release.yml 对 ea49dbcc 的完整后端门禁结果为 2599 passed、1 skipped、1 failed。失败的机架范围拓扑路由测试断言链接仅含 `id`，与当前 API 补充链路证据方向和两端采集状态后的响应不符。

## 根因

`backend/api/topology.py` 会对每条拓扑链接附加 `evidence_directions`、source/target collection evidence 和 `evidence_status`。既有机架范围测试在响应契约扩展后仍保留旧的完整对象比较。

## 解决方案

更新测试预期，验证无采集证据的兼容链接保留 `unknown` 两端采集状态、空方向和 `not_applicable` 关系状态；生产逻辑不变。

- `docs/plans/plan_20261001_2059_01_v1.0.9主线发布.md`

- 本修复记录。
