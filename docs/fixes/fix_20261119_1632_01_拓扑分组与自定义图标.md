# 拓扑分组与自定义图标

## 问题

较大的单行上限会将接入层拉得过宽，并压缩全图文字。设备选中后多条上联难以追踪，正式页面缺少 Demo 的上联分组。站点摘要靠近第一层设备。自定义图标目录及保存出错提示也随本次发布补齐。

## 变更

- 站点页面支持完整拓扑和上联分组切换，包括全屏，继续使用实际站点数据。
- 完整拓扑按可用宽度换行，默认每行上限 60。保留手工坐标，突出选中设备的全部关联链路，并改进缩放和站点摘要布局。
- 支持按设备类型上传多套 PNG 或 SVG 图标，选择系统默认、类型默认或单设备覆盖。后端使用现有存储配置，并在迁移 m0326 中维护图标元数据与分配。
- 图标更新只替换 SVG 节点图形。上传失败时区分存储连接、文件写入和元数据保存。

## 文件与验证

涉及 `src/components/TopologyGraph.tsx`、`src/pages/TopologyPage.tsx`、上联分组组件、角色布局、图标前端与相关测试，以及图标 API、服务、迁移和 `backend/main.py` 路由注册。

原工作区的 TypeScript 校验、相关前端测试与生产构建通过。Edge 用 50 台设备样本验证三行接入、双上联高亮、缩放、旧手工坐标以及普通和全屏的视图切换。图标使用隔离 PostgreSQL 测试验证，现场对象存储受部署配置影响。

## 回滚

回退本次应用发布即可恢复旧页面。图标元数据迁移新增独立数据表，应用回退无需删除已上传文件或新表。
