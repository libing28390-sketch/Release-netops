# Git 变更记录: 增加自定义查看命令输入与实时 TextFSM 调试入口

## 1. 变更背景与目的
为了解决预设命令在某些设备上不支持、或用户需要灵活执行任意查看指令（如各种 `show` / `display` 命令）的问题，我们支持了在快速执行弹窗中输入自定义命令。同时，将其与我们开发的在线 TextFSM 调试及模板自动生成沙箱完美结合，实现完整的数据提取闭环。

## 2. 解决方案与实施步骤
1. **输入框增加**：在 `QuickQueryOverlay.tsx` (快速查询弹窗) 中增加了自定义命令的输入框与执行按钮。支持键盘 Enter 键直接触发；
2. **后端流重定向**：在前端 React state (`useAutomation.ts` 的 `runQuickQuery`) 中，当识别到执行的是 `custom_command` 时，不再将其路由到无解析功能的 `/api/execute` 接口，而是将其定向至 `/api/devices/{id}/parsed-command`。这样可以在后端实时对自定义指令进行在线解析尝试；
3. **状态及设备回填**：在前端收集数据结构时，自动将后端的解析状态 `parse_status` 及具体单设备平台 `platform` 回填至 `mockStructured` 对象中。这使得在命令不支持、或无模板时，下方能够准确弹出“该命令无匹配模板，是否在线调试与创建解析模板”的 Banner，并能一键带入正确的设备平台和回显上下文至调试器。
