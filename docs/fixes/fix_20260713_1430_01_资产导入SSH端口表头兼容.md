# 资产导入 SSH 端口表头兼容

## 问题

资产导入仅识别“管理端口”表头。用户将表头填写为“SSH端口”或使用旧模板中的“端口 (SSH/Mgmt)”时，该列会被忽略，后端因未收到 `management_port` 而使用默认端口 `22`。

## 修改

资产导入新增以下表头兼容映射：

- `SSH端口`
- `SSH 端口`
- `SSH管理端口`
- `端口 (SSH/Mgmt)`
- `端口(SSH/Mgmt)`
- `SSH Port`
- `ssh_port`

以上表头与现有“管理端口”“Mgmt Port”“management_port”均统一映射为 `management_port`。

## 结果

表格中填写的非标准 SSH 管理端口可以正确写入资产表和关联设备表，不再因表头差异静默回落为 `22`。
