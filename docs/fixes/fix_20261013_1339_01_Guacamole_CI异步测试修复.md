# Guacamole CI 异步测试修复

日期：2026-10-13
关联计划：[Guacamole RDP/VNC 纳管](../plans/plan_20261013_0958_01_Guacamole_RDP_VNC纳管.md)

## 原因

首次推送触发的 GitHub Actions 在后端 pytest 阶段失败：3,227 passed、1 skipped，只有 Guacamole service 测试的两个异步用例失败。它们标记为 `pytest.mark.asyncio`，但 CI 依赖只提供项目已有的 AnyIO pytest 插件，没有安装 pytest-asyncio。

## 修复

- 将这两个用例改为仓库其余异步测试使用的 `pytest.mark.anyio`，不新增测试依赖，也不改变运行时代码。

## 验证

- `backend/tests/pam/test_remote_desktop_guacamole_service.py`：7 passed。
- 后端全量 Actions 的其余 3,227 个测试在首次运行中通过；修复后的完整 Actions 运行 `38352587455` 成功。
- Windows 本机未运行 Docker。Actions 成功后已在授权的 Linux 部署主机更新；Guacamole/guacd 容器运行及基础服务检查结果见 Guacamole walkthrough。尚无 RDP/VNC 测试目标，未进行真实会话联调。
