# Fix Record - 修复华三ARP解析与分页超时

## 问题现象
1. **ARP 模板解析 State Error**：当执行 `display arp all` 收集 ARP 表项时，华三设备的某些系统版本输出的 ARP 类型图例（Legend）含有空格或换行，触发了 TextFSM 模板中极其严格的 `^. -> Error` 规则导致崩溃。
2. **低权限 SSH 连接超时（Pattern not detected）**：在普通只读用户（如 `user` 登录）下，Netmiko 连接初始化时执行 `screen-length disable` 关闭分页失败（返回 `Permission denied.`），导致分页实际启用。随后执行 `display interface brief` 等长命令时，设备在 `---- More ----` 暂停，导致 Netmiko 读超时崩溃。

## 根因
1. TextFSM 模板匹配要求过苛，且加入了对未知行抛出 Error 的逻辑。
2. 收集任务在后台以普通用户连接时，不支持分页关闭命令。原底层驱动未在所有 `send_command` 交互中实现对分页响应的全局匹配与自动翻页（`drain_paged_output`）。

## 解决方案
1. 优化 `data/textfsm_templates/h3c_comware_display_arp_all.textfsm` 模板，放宽图例和表头行的正则匹配规则，并移除了 `^. -> Error` 以兼容所有行输出。
2. 全局 monkeypatch 注入 Netmiko 的 `BaseConnection.send_command`：在未指定 `expect_string` 时，自动在期望正则中追加可能出现的分页匹配项（如 `---- More ----` 等），并在命令返回后统一调用 `drain_paged_output` 自动发送空格翻页，防止连接挂起超时。
