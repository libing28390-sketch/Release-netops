# Guacamole 录像分辨率与回放比例

## 问题现象
RDP 与 VNC 录像在宽屏播放器中以源画幅等比显示。旧 RDP 录像源尺寸为 1024×768（4:3），完整适配时两侧留有黑边；VNC 源画幅和后续新 RDP 录像均为 1920×1080（16:9）。

## 解决方案
- RDP Guacamole 参数启用 resize-method=display-update，后续修正又增加 1920×1080 初始尺寸。
- 客户端优先协商 16:9 尺寸，上限 1920×1080；服务端最终决定接受的分辨率。
- 播放器显示源分辨率和比例，提供完整适配与按宽度等比放大。按宽度模式可纵向滚动，不拉伸画面。

## 历史录像与回滚
历史录像不会重新编码，旧 RDP 源尺寸仍为 1024×768。按宽度放大模式只改变查看尺寸，超出窗口高度时需要滚动。回滚时撤销分辨率协商和播放器改动并重新部署。
