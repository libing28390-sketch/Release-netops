# Guacamole 录像分辨率与回放比例

## 问题现象
RDP 与 VNC 录像在宽屏播放器中以约 4:3 尺寸居中显示，两侧留有较大黑边。录像画面未被拉伸；回放源分辨率本身较窄。

## 根因
录像播放器按源显示尺寸等比缩放以完整展示桌面。RDP 连接未设置动态分辨率更新方法，客户端发送的新尺寸可能不被服务端应用；VNC 是否能改变桌面尺寸取决于目标 VNC Server。已有录像保留原始分辨率。

## 解决方案
- RDP Guacamole 参数启用 `resize-method=display-update`。
- 连接端将请求尺寸限制到 16:9 比例及 1920×1080 上限，且由 RDP/VNC 服务端实际决定是否支持。
- 录像播放器显示源分辨率和比例，提供完整适配与按宽度等比放大两种视图；按宽度模式允许纵向滚动，不拉伸画面。

## 风险与回滚方式
VNC Server 可忽略动态尺寸请求；历史录像仍维持录制时画幅。按宽度模式会在内容高度超过窗口时显示滚动条。回滚方式为撤销本次提交并重新部署上一版。
