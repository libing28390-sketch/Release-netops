# V1.0.10 远程桌面体验与版本发布

## 问题现象 / 本次目的
RDP/VNC 配置区在非 Windows 资产编辑窗口中也出现；Access Center 的远程桌面表格显示管理端口而非目标端口，RDP 登录和服务管理按钮分成多行。当前发布版本仍为 1.0.9，发布工作流不接受用户指定的大写 `V1.0.10` 标签。

## 根因
远程桌面配置区没有按 Windows 服务器平台条件渲染；共享资产单元格固定取 management_port；RDP 操作容器允许换行。发布版本散落于 package、lockfile 和 backend 元数据；release workflow 只匹配 `v*` 并只校验小写 `v<version>`。

## 解决方案
- 仅在 Windows server 资产编辑窗口展示 RDP/VNC 配置；新建资产提示同样受条件控制。
- RDP/VNC 分类展示其配置 profile 的目标端口，RDP 普通/管理员/服务管理操作维持单行。
- 将 package、lockfile 和 backend 版本同步为 1.0.10；更新部署导航及 Release Notes。
- 让 release workflow 同时触发和校验小写 `v<version>` 与大写 `V<version>`，保持旧标签格式兼容。
