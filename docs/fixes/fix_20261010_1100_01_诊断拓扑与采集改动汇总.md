# 诊断、拓扑与采集改动汇总

## 问题现象与本次目的

工作区包含多项已完成但尚未合入 `main` 的 SNMP 诊断、拓扑读取、PostgreSQL 看板与硬件采集变更。本次按用户要求将这些源代码和配套项目记录合并提交并推送到 `main`，同时不纳入构建缓存、日志或内部协作文件。

## 根因与解决方案

这些改动分别对应近期完成的工作：SNMP 诊断页缺少系统信息和 LLDP 展示且拓扑数据读取有行数上限；SNMP 运行时间展示格式不统一；PostgreSQL 看板入口与版本化采集配置需要保留；硬件详情看板包含空白及低价值的传感器/诊断面板。代码已按各项 walkthrough 中记录的方案完成，本次统一提交到主线。
