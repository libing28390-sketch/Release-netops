# Fix Record: RAG 统一中间格式 (Normalized Markdown) 与智能解析管道

## 1. 问题现象与需求
需要建立规范的 RAG 解析底座，将原始格式 (PDF/DOCX/HTML/CHM/TXT/MD) 先解包转码为统一中间格式 (Normalized Markdown)，并实施 Heading 与 CLI 标题感知的智能切片 (Smart Chunking)。

## 2. 根因与设计
固定字数盲目切片会导致网络 CLI 命令、语法说明、回显示例与排障建议被硬性打断，引发 RAG 召回断章取义。

## 3. 解决方案
1. 在 `knowledge_service.py` 中引入 `smart_chunk_markdown()` 函数，基于 Markdown 标题树与代码块边界进行高质切片；
2. 在 `KnowledgeManagementTab.tsx` 展现推荐格式等级指南与 6 步解包转码解析 Stepper。
