# 知识库管理中心支持多文件/ZIP包上传与单条/批量删除功能

## 问题现象 / 提交目的
1. **多文件 & ZIP压缩包上传**：原知识库文件上传仅支持单文件选择与粘贴，用户在导入多个 SOP 手册或 ZIP 压缩包时操作繁琐。
2. **删除功能补充**：知识库缺少文档单条删除与批量删除能力，无法清理历史弃用或重复导入的知识库切片。

## 根因与改进方案
1. **多文件 & ZIP客户端解压**：
   - 引入 `jszip` 库，支持在浏览器端安全解压 `.zip` 压缩包并过滤出标准文本文件（`.md / .html / .txt / .json / .yaml / .csv / .xml` 等）。
   - 上传弹窗采用双模式（批量文件上传队列 vs 手动录入），支持文件队列管理、独立移除、来源压缩包标识以及批量解析索引进度条。
2. **单条与批量级联删除**：
   - 在 `backend/ai/services/knowledge_service.py` 添加 `delete_document` 和 `batch_delete_documents` 方法，同步清理 `ai_document` 与关联的 `ai_document_chunk` 切片。
   - 在 `backend/ai/api/assistant.py` 暴露 `DELETE /api/ai/assistant/documents/{doc_id}` 与 `POST /api/ai/assistant/documents/batch-delete` 接口。
   - 前端增加 Checkbox 选择、全选/取消全选、批量删除二次确认弹框与行内单条删除按钮。
