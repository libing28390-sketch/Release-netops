# Windows 资产远程桌面配置与 Access Center 表格

## 问题
资产编辑表单对所有资产显示 RDP/VNC 配置。Access Center 的 RDP 端口列显示管理端口 22，而配置的 RDP 目标端口为 3389；普通、管理员与 Windows 服务管理操作分成两行。

## 本地修改
- AssetModal 仅在 server 类型且平台为 windows 或 windows_server 时显示远程桌面配置区和新资产提示。
- Access Center RDP/VNC 分类显示启用 profile 的目标端口；其他协议分类保留 management_port。
- RDP 普通、管理员与服务管理操作改成同一行。

## 保留行为
隐藏非 Windows 资产的编辑器不会删除既有 RDP/VNC 配置。资产改回 Windows 后仍可继续查看或管理。
