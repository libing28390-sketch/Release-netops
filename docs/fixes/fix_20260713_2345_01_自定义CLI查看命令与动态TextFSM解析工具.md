# Git 变更记录: 自定义 CLI 查看命令与动态 TextFSM 解析工具

## 1. 问题现象与本次提交目的
- **提交目的**：由于不同网络设备厂商（特别是华三、锐捷等）的很多 show/display 指令没有内置的 TextFSM 解析模板，导致用户输入自定义指令时前端无法结构化展示。
- **功能描述**：本次提交实现了“用户自定义输入查看命令 -> 在线编写/智能生成 TextFSM 模板 -> 实时测试解析 -> 一键保存并过滤列”的完整闭环。

## 2. 解决方案与实施步骤
1. **自动生成骨架**：在 [textfsm_builder_service.py](file:///d:/netops/netsops-main/backend/services/textfsm_builder_service.py) 中，编写算法自动匹配表格列头并输出基础 TextFSM 匹配语句；
2. **新增 API**：在 [textfsm_templates.py](file:///d:/netops/netsops-main/backend/api/textfsm_templates.py) 中增加 `/api/textfsm/auto-generate` 接口并升级在线解析测试路由；
3. **前端调试器**：实现 [TextFSMDebugger.tsx](file:///d:/netops/netsops-main/src/pages/AutomationExecute/components/TextFSMDebugger.tsx)，包含规则文本编辑器、Raw Output 编辑框、测试解析和字段勾选过滤器；
4. **前端融合**：修改 [QuickQueryResultOverlay.tsx](file:///d:/netops/netsops-main/src/pages/AutomationExecute/components/QuickQueryResultOverlay.tsx) 和 [index.tsx](file:///d:/netops/netsops-main/src/pages/AutomationExecute/index.tsx)，如果执行自定义命令未匹配解析器，则提示并允许一键拉起在线编辑器。保存模板后自动触发重新运行查询，使用新模板秒出结构化数据表格。
