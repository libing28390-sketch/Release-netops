# 采集器运行状态部署验收

## 本次提交目的

记录全站列表与表单统一、`.env.example` 参数差异提示、采集器本地运行状态修复、定时作业查询默认值修复及目标环境验证结果。

## 现象与根因

- 本地采集器被显示为“心跳未上报”，尽管本地 Docker 服务由 vmagent 与 SNMP Exporter 承载。
- 配置发布曾把配置应用成功误当成采集器在线；远程/边缘没有心跳协议时仍可能显示错误状态。
- 定时作业筛选参数曾将 FastAPI `Query(...)` 对象作为 Python 默认值，直接调用路由函数时搜索 `.strip()` 出错。
- Docker update 备份 `.env` 却没有说明新版环境模板新增、变更或废弃参数。

## 解决方案

- 本地采集器按 vmagent `/health` 和 SNMP Exporter `/metrics` 的实际响应检查；远程/边缘无心跳时显示未知；配置发布不再修改运行状态。
- 使用 `Annotated[..., Query(...)]` 保留 API 校验并提供普通 Python 参数默认值。
- Docker update 比较升级前后的 `.env.example` 并只报告变量名和变化类别，不读取或覆盖真实 `.env`。
- 统一列表工具栏、表格选择态、操作按钮、列设置、搜索回车提交、表单和对话框体验。
