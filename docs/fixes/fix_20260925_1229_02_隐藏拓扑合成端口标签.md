# 隐藏拓扑图中的合成端口占位标签

## 问题现象

拓扑图显示 `Port-数字` 作为端口标签，但这类名称是采集失败时产生的占位值，对查看拓扑没有帮助。

## 根因

SNMP 邻居采集在无法将 LLDP/CDP 端口映射到 IF-MIB 接口名时会生成 `Port-{索引}`；图形格式化逻辑此前将它当作真实接口名展示。

## 解决方案

在拓扑图公共端口标签格式化入口过滤严格匹配 `/^port-\d+$/i` 的占位值；保留链路与原始邻居数据，并继续显示真实接口名。
