# Git 修复记录：修复国产设备 Command Catalog 缺失与 Playbook 迪普凭据解析

**创建时间**：2026-08-01 11:00
**修复问题名**：修复国产设备命令目录与Playbook凭据解析

---

## 1. 问题现象
1. 中兴 (ZTE)、迪普 (DPTech)、迈普 (Maipu) 设备在全量数据采集时红字报错：`NO command catalog found for category in platform ...`
2. 迪普防火墙在 Web 终端正常，但 Playbook 执行时提示 SSH 认证被拒绝。

## 2. 根因
1. 当某些非必选分类在国产设备平台上无命令定义时，原代码将其记为 `success=False` 并带上报错，且 `platform_utils.py` 误将 `dptech` 归一化为 `dptech_conplat`。
2. `playbooks/engine.py` 解密凭据时仅读取 `normal_username` / `normal_password`，对单账号设备提取为空字符串，导致传入驱动的密码为空引发 SSH 拒绝。

## 3. 解决方案
- `platform_utils.py` 修正迪普平台归一化为 `dptech_ios`。
- `playbooks/engine.py` 增加 `username` 与 `password` 回退。
- `base_driver.py` 增加密码空值时的自动解密兜底。
- `operational_data_service.py` 将无命令分类标为非适用状态，避免记为采集失败。
