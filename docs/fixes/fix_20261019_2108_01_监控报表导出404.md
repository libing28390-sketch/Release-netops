# 监控报表导出 404 修复记录

## 问题现象

在 `/monitor/dashboards` 导出监控报表时，浏览器提示 `Export failed with HTTP status 404`。

## 根因

共享导出弹窗请求 `/api/monitoring/v1/export/...`，但 FastAPI 的 `monitoring_v1` router 前缀实际为 `/monitoring`，再由主应用添加 `/api`，所以注册地址为 `/api/monitoring/export/...`。线上匿名只读检查中，错误地址返回 404，真实地址返回 401，证明路由已存在且 Viewer 鉴权有效。

## 解决方案

新增集中管理的监控报表 URL 常量，将仪表盘报表弹窗与网络监控接口导出入口统一切换到后端已注册地址。
