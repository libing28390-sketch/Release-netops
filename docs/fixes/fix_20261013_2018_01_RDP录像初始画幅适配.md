# RDP 录像初始画幅适配

## 问题现象
部署播放器比例改进后，VNC 录像源为 1920×1080，但新 RDP 会话仍记录为 1024×768（4:3）。RDP 服务端未应用连接后的动态尺寸更新，导致新录像依旧偏窄。

## 根因
虽已请求 `resize-method=display-update`，Guacamole 连接没有固定初始宽高；该 Windows RDP 服务端在首帧及后续尺寸更新中继续使用 1024×768。

## 解决方案
给 RDP 参数增加显式 1920×1080 初始分辨率，并保留 `resize-method=display-update` 以支持兼容的服务端后续自适配。VNC 参数继续依赖服务端桌面尺寸能力。

## 风险与回滚方式
RDP 服务端可能不接受请求的尺寸，届时录像会继续使用服务端协商结果。若出现兼容问题，撤销宽高参数并重新部署；已有录像不受修改。
