# RDP 录像初始画幅适配

## 问题现象
播放器已支持完整适配和按宽度放大，但新 RDP 会话仍记录成 1024×768（4:3），导致完整适配时在宽屏播放器中出现较宽侧边留黑。

## 根因
RDP 参数虽启用了 resize-method=display-update，但此 Windows RDP 服务端仍使用默认的 1024×768 初始桌面。后续尺寸更新没有改变录像源分辨率。

## 解决方案
给 RDP 连接增加显式 1920×1080 初始尺寸，并保留 resize-method=display-update。VNC 不增加固定尺寸，继续由 VNC Server 协商显示尺寸。

## 实际修改文件
- backend/services/guacamole_service.py
- backend/tests/pam/test_remote_desktop_guacamole_service.py
- src/components/access/GuacRecordingPlayer.tsx
- src/components/access/RemoteDesktopClient.tsx

## 备注
本次 RDP 会话由用户手动关闭，因此 UI 显示 Gateway 521 属于用户主动结束，不是连接失败。连接建立后已显示宽屏 Windows 登录画面，录像源尺寸也确认是 1920×1080。

## 风险与回滚方式
RDP 服务端可能忽略请求尺寸，届时录像仍会使用实际协商结果。回滚时撤销宽高参数并重新部署；已有录像的分辨率不受影响。
