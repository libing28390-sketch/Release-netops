# 调整对象存储管理界面与连接测试

## 问题现象

对象存储配置页面需要更清晰地展示 profile 列表和用途路由；编辑现有 profile 时，如果不重新输入凭据，连接测试不能复用已保存的 S3 配置。

## 根因

页面原先把配置列表、用途路由和表单集中在一屏，缺少清晰分区；未输入凭据的编辑草稿直接调用未保存配置测试接口，而该接口要求完整凭据。

## 解决方案

- 按“对象存储 / 用途路由”页签分开列表与路由配置。
- 将新建和编辑表单改为分组右侧抽屉，更新页面标题。
- 编辑时若连接设置未变且凭据留空，改为测试已保存 profile；连接设置变化时要求输入凭据，只输入一项凭据时直接提示。
- 同步对象存储计划与 walkthrough，说明当前无独立命令存储 API，不展示没有后端契约的占位配置。
