# AC 无线看板与终端明细

## 问题现象与目的

无线专网监控缺少 AC 数量和 AC 筛选；站点、厂商、角色、设备选项来自全网 `up` 指标，可能混入交换机、防火墙等设备。AP 表把采集控制器名称显示成通用“设备名称”，且没有逐终端明细查询。

## 根因

- 无线看板复用了全网设备变量定义。
- 看板只有 AP/控制器客户端汇总查询，没有 AC 在线状态卡片。
- H3C 探针已保存终端 MAC、IP、SSID 等属性，但没有把关联 AP、Radio/WLAN、VLAN 信息组合成可查询的 Prometheus 样本。

## 解决方案

- 无线筛选变量只从 `role="wireless_controller"` 的采集目标取值；设备变量命名为 AC 控制器。AC 总数按控制器身份去重，在线 AC 只计 `up == 1`，目标存在但全部离线时显示 0。
- AP/Radio/SSID/BSS/终端查询由选择的 AC 标签过滤；AP 表明确标示“所属 AC”。新增终端明细表，字段限定为 MAC、IP、AP、SSID、Radio、WLAN、VLAN；不导出用户名。
- H3C 探针采集官方 Station AP Relation 表并按 APID 关联已发现 AP；关系字段缺失时保留未知值。指标只包含当前 `good/present` 的终端数据。
