# 资产列表类型与子类字段修正

## 问题

资产管理列表中的“类型”实际优先显示了设备角色，“角色”列又显示 `device_role`，与资产录入表单中的“资产类型”和“设备子类”含义不一致。

## 修改

- “类型”调整为“资产类型”，固定展示录入字段 `asset_type`。
- “角色”调整为“设备子类”，展示录入字段 `device_category`。
- 为服务器和网络设备子类增加中英文显示映射。
- 普通表格与分组视图使用相同字段和显示规则。
- 未识别的历史子类值保留原值显示，空值显示为 `—`。

## 结果

资产列表现在与新增、编辑资产时填写的“资产类型”和“设备子类”完全对应，不再混用设备角色字段。
