# Nexora 终端接入模块使用手册

## 功能入口

- 操作工作台：`/access/workspace`
- 我的收藏：`/access/favorites`
- 我的历史记录：`/access/history`
- 受控审计：`/access/pam-audit`

## 使用流程

在操作工作台搜索设备并选择连接协议，连接后可执行命令、查看实时输出和保存会话记录。常用设备可点击星标加入“我的收藏”；已结束的本人会话在“我的历史记录”中按设备、权限、方式和风险筛选，受控审计页面则聚焦活跃会话与实时处置。

## 权限与安全

连接前系统会校验用户、站点和设备授权；敏感命令按策略拦截或要求二次确认。审计记录不可由普通用户修改，导出前应确认筛选条件和脱敏范围。
