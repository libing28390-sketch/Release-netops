# Nexora 实时监控模块使用手册

## 适用范围

实时监控模块覆盖运营总览、监控中心、互联网出口、服务器监控、网络监控和拓扑视图。

## 使用流程

1. 从左侧进入“实时监控”，先在页面顶部选择 Site、设备类型和时间范围。
2. 在运营总览查看设备在线率、接口健康度和告警摘要；点击指标卡可下钻到设备列表。
3. 在监控中心按设备/IP 搜索，切换 CPU、内存、接口流量和可达性指标。图表悬停可查看采样时间和值。
4. 在拓扑页先选择 Site，再点击刷新。多 Site 场景下节点按 Site 分组，链路只在两端节点都可见时绘制。

## 运维建议

- 发现数据延迟时先检查设备凭据、采集任务和时间窗口，再使用“刷新”。
- 大规模设备建议按 Site 和分页查看，避免一次加载全部节点。
- 拓扑异常时确认设备具有唯一管理地址，并执行一次资产同步。
