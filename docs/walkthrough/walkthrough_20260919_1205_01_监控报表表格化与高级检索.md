## 1. 完成摘要

针对用户反馈原监控报表页面“不咋好看”、“想要表格方式展示”以及“支持高级选项来搜索，更人性化”的需求，本次完成了全栈重构：

1. **全新交互式表格展示（Table View）取代静态卡片**：
   - 将原先单一的 3 张下载卡片升级为**现代专业数据大表**；
   - 支持 Tab 维度切换：
     - 🚀 **全网接口流量与利用率**（接口名、描述、状态、速率、实时入出向速率、带宽利用率动态彩色进度条、错包数、处置建议）；
     - 🖥️ **网络设备运行与资源**（设备名、IP、厂商平台、在线状态、CPU 负荷进度条、内存负荷进度条、温度、风险评估）；
     - 🌐 **互联网出口与 WAN 链路**（探针目标、运营商、类型、激活状态、延迟 ms、丢包率 %、健康评级）。
   - 表格支持表头列点击排序（按主机名、利用率、CPU、内存等升序/降序）、分页器切换（每页 10/25/50/100 条）。
2. **多维人性化高级搜索与筛选（Advanced Filters）**：
   - **快捷搜索栏**：支持实时模糊检索设备名、IP、接口名、描述、厂商等关键词；
   - **快速状态与阈值下拉**：一键切换 UP/DOWN、在线/离线、利用率 ≥50%/≥70%/≥85%；
   - **折叠式高级筛选面板（带激活条件小红点计数）**：
     - 🏢 站点筛选（动态加载全网站点列表）；
     - 🏷️ 厂商筛选（Huawei、Cisco、H3C、Ruijie 等）；
     - 🛡️ 角色筛选（Core、Distribution、Access、Firewall 等）；
     - ⚡ 专项过滤（“仅看物理错包/丢包端口”、“仅看高负荷设备”、“运营商分类”）；
   - 提供【清空重置】按钮与无匹配数据时的友好提示。
3. **顶置 KPI 态势概览卡片（Metrics Summary）**：
   - 顶部实时渲染 4~5 个指标卡片（总数、UP数、超负荷预警数、错包端口数、全网平均利用率等），直观展示当前报表态势。
4. **按当前筛选导出与全量多工作表导出并存**：
   - 提供 **【导出当前筛选 (Excel)】** 与 **【CSV】**：导出的表格完全遵循用户在界面上的高级筛选条件；
   - 保留 **【官方权威多工作表导出下拉菜单】**：一键直接下载原 4-Sheet / 2-Sheet 完整工作簿；
   - 导出 CSV 全部带 `\ufeff` UTF-8 BOM，彻底解决 Windows Excel 中文乱码。

## 3. 关键实现与架构细节

### 3.1 统一数据流设计
```
[PostgreSQL CMDB + VictoriaMetrics 5m Telemetry]
                      │
                      ▼
  [fetch_*_report_data(filters=...)]
       ├── summary KPI 统计计算 (高负荷、错包、平均利用率)
       ├── options 动态筛选字典 (vendors, sites, roles, isps)
       └── items 结构化记录 (含格式化文本与原始数值供排序)
           ├── /api/monitoring/reports/data -> 前端表格交互、分页与动态图表
           └── generate_*_report(filters=...) -> 按当前筛选条件生成 XLSX / CSV
```

### 3.2 带宽利用率动态色阶标准
- `< 30%`：健康墨绿 (`bg-emerald-500`)
- `30% ~ 70%`：标准平稳天蓝 (`bg-cyan-500`)
- `70% ~ 85%`：负荷预警琥珀黄 (`bg-amber-500`)，标签标明“预警”
- `≥ 85%`：严重过载猩红 (`bg-rose-500`)，带红色闪烁点与“严重”标签
