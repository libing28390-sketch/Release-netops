# 5. IPAM 地址管理产品使用手册 (IPAM)

IPAM 地址管理模块是保证企业网络地址不重叠、按需规划和精细分配的核心工具，支持 IPv4 与 IPv6 的双栈层级展示。

![IPAM地址管理](file:///e:/data/netsops/docs/images/ipam_prefixes.png)

## 1. 核心功能概述

本模块包含以下子菜单：
1. **网段前缀 (Prefixes)**：全局大网段与明细子网网段的包含树状拓扑图。
2. **IP 分配明细 (IP Addresses)**：每个子网网段内所有主机的 IP 分配表。
3. **IPAM 统计与对账 (Utilization & Reconciliation)**：分析网段地址的真实使用状况，对账排除未记录的“幽灵 IP”。

---

## 2. 详细操作步骤

### 2.1 网段前缀划分与分级
* **层级嵌套自动识别**：
  进入 **IPAM地址管理 -> 网段前缀** 页面。您录入的网段会根据 IP 前缀和掩码长度自动推导父子级。
  * 例如录入 `10.0.0.0/8`（根容器），再录入 `10.100.0.0/16`（数据中心大网段），接着录入 `10.100.1.0/24`（业务子网），系统界面会显示缩进的层级网段树。
* **利用率展示**：子网右侧的百分比和进度条表示该网段中已分配的 IP 比例（例如子网可用 254 个 IP，已分配 127 个，利用率则显示 50%）。

### 2.2 IP地址的精准分配与关联
* **自动分配空闲 IP**：当用户需要在特定子网内分配 IP 时，可以点击网段内的“空闲 IP 分配”。IPAM 模块会自动计算该段内所有尚未使用且不在保留状态的第一个可用 IP，防止管理员手动查表引起的主机 IP 冲突。
* **设备接口绑定**：在分配 IP 时，可以直接关联设备名和设备接口名（如 `Core-SW-01` 的 `Vlanif100`）。当接口流量或状态有变时，IPAM 地址库能随时反查关联资产。
* **逻辑对账**：通过读取网络中核心交换机的 ARP 表和路由表，与 IPAM 中的静态记录进行定期对账，标识出“已在物理网络运行但未在 IPAM 中录入”的 IP。
