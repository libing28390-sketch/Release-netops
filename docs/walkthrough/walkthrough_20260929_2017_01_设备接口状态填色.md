# 设备接口状态填色

## 完成摘要

设备详情的“设备端口实时状态清单”现使用状态颜色填充单元格背景：`Up` 为绿色，`down` 为红色。映射值和查询不变。

## 实际修改文件

- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-device.json`（由生成器生成）

## 关键实现说明

- 将目标表格的 `custom.cellOptions.type` 从默认 `color-text` 改为 `color-background`。
- 复用现有状态值映射（`1 → Up/green`、`2 → down/red`），与 `04 接口流量与健康` 的运行状态填色方式一致。
- 生成器输出的 12 个 dashboard JSON 中，只有设备详情 JSON 内容变化；上一轮筛选器与面板布局修改均保留。
