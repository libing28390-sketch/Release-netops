# Comware CPU 与内存发现适配走查

## 结果

将 Comware CPU/内存与光模块硬件发现接入硬件库存采集，并审查通用 LibreNMS 规则解析、OS 特例、传感器持久化及指标导出。当前行为按各条规则的真实 OID 与索引执行；不能解析的转换、缺失依赖或不完整 walk 会保留为 partial/unsupported，不伪造百分比或零值。Comware 光模块表关联 IF-MIB 接口身份，以接口索引保存实体数据。

LibreNMS 硬件传感器类型的枚举不表示每个 OS 都实现全部类型。当前实际覆盖以固定上游规则和已经适配的 OS handler 为界；本任务另外为 H3C Comware 增加 CPU、内存与 transceiver 特例。工作区新增代码期间发现并修复了 transceiver 调用未传 identity，以及缺值导致的错误传感器问题。

## 验证

最终命令与通过数统一记录在 [多厂商无线监控与主线交付走查](walkthrough_20261005_0107_01_多厂商无线监控与主线交付.md) 及本次 `docs/fixes/fix_*.md` 记录。此前计划中“只做静态核验”的限制已被用户后续要求完成实现、验证、push 和关机的明确指令取代。

## 边界

没有真实设备可用于 SNMP 运行验证。CPU/内存和 transceiver 型号差异、固件返回值及实际数据库历史仍需在用户部署设备上按监控状态检查；本走查不代表所有厂商/机型达到硬件监控完全等同。
