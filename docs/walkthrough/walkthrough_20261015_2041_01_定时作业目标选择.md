## 根因与关键实现
- 原父窗口为 `z-[80]`，候选弹窗为 `z-[70]`，导致目标列表在父窗口后方。
- 候选弹窗通过 React portal 放到 body，层级为 100；限定动态视口高度，标题、全选与操作栏保持可见，列表独立滚动。
- 原候选框依赖整行 onClick，复选框 onChange 为空；现在用 label 和真实 onChange，支持键盘操作、部分勾选、焦点范围限制和关闭后焦点恢复。
- 合并基本信息与动作卡片，用双栏利用横向空间；备份/NSOT 使用紧凑说明，命令与脚本审批提示仅在对应动作出现，审批校验逻辑保持原契约。
- IP 查询显示明确的查找按钮、批量输入说明、已选目标计数和可移除的设备行；已有 IP 搜索和添加回调不变。
- 主 Agent 维护 JobModal、集成与文档；前端 Luna 子 Agent 独占 CandidateModal；验证 Luna 子 Agent 执行公共类型检查与构建。
