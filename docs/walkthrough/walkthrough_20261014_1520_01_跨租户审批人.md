# 定时作业跨租户审批人 — 执行记录

## 完成摘要

- 移除了配置验证码审批中“审批人与申请人必须同租户”的硬性判断，覆盖候选人列表、验证码发起、验证码校验和审批令牌消费四个阶段。
- 候选人目录现在查询所有启用用户，并按 PAM 审批权限、可用验证方式和资源授权范围筛选；响应包含 `tenant_id`。
- 定时作业、作业删除、执行计划和告警规则的审批人选择器统一使用该候选人目录，并显示用户所属租户。
- 申请人仍必须绑定有效租户；自审批仍禁止；审批人仍必须启用、有 PAM 审批权限并配置 MFA、邮箱或飞书验证方式。
- 对显式受限审批人，继续执行资源范围校验：其可以审批已授权的申请人租户；跨租户审批需全局授权。未受限的 PAM 审批角色可跨租户使用。

## 剩余说明

- 具备 tenant-only 显式资源范围的审批人仍不能审批范围外的租户；需授予全局 PAM 审批范围后才能跨租户审批。
- 审批人下拉项会显示租户标识，便于确认跨租户候选人的身份。
