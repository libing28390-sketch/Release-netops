# 资产列表字段自选展示走查

## 完成摘要

资产总览、网络设备和服务器列表现在默认突出关键字段，其他字段可通过“列设置”复选框按需显示。列偏好保存在浏览器本地；操作列始终保留，服务器列表的操作列固定在右侧。

## 关键实现说明

- 资产总览默认显示设备、资产类型、状态和管理 IP；其余资产字段可勾选显示，并可恢复默认列。
- 网络设备沿用已有列设置菜单，默认显示设备名称、管理 IP、在线状态和健康状态；已有自定义偏好继续生效，恢复默认时采用精简列。
- 服务器新增列设置菜单，默认显示主机名、管理 IP 和状态；原表格字段可勾选显示，行操作列固定在右侧。
- API、导出数据和后端契约未改变。`AssetManagement/index.tsx` 中既有 SNMP 导入相关改动予以保留。

## 剩余风险与回滚方式

- 网络设备列表会保留用户已有的自定义列选择；此前未自定义或仍使用旧默认的浏览器会采用精简默认列。
- 如果用户勾选大部分字段，服务器表格仍可横向滚动；操作列保持在右侧。
- 如需回滚，撤销三个列表对应的列默认值、选择菜单和动态列显示即可；无需数据回滚。
