# 告警范围与通知规则优化

## 完成内容

- 告警规则范围现在与 `/automation/scheduled-jobs` 的资产筛选概念对齐：全部设备、站点、角色、复合条件、指定 IP、标签表达式和接口；历史设备范围仍可编辑。
- 站点、角色、设备类型和平台从当前租户的设备目录加载。复合条件可组合站点、角色、类型、平台和接口，所有已填写条件必须同时满足（AND）。站点/角色/复合条件支持精确和模糊（包含）匹配；指定 IP 使用精确匹配。标签规则复用嵌套 AND/OR/NOT 条件表达式。
- 前端不再把复合范围原始 JSON 展示在规则列表，而是生成简洁摘要。标签条件以条件项数量概览。
- 通知区域改名为“通知规则”，只展示 Webhook 和邮件两个勾选项；新建网络规则必须明确至少选一种。个人偏好不再作为规则渠道选项或网络规则的新写入渠道。宿主机规则原有系统通知路径保持不变。
- 编辑器移除 24 小时告警、恢复和重复键统计展示及对应请求。
- 后端按告警设备真实上下文匹配新范围。标签映射短暂缓存；设备站点 ID 转成站点名称后匹配。非法、空或无法读取的复合/标签条件 fail closed。
- 新增租户范围目录 API，并补充范围匹配、目录租户隔离、通知渠道校验及运行时标签上下文测试。
