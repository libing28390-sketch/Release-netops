# 硬件采集精简与设备看板

## 完成摘要

已停止周期轮询和 Prometheus 指标导出 `voltage_volts`、`current_amperes`、普通硬件 `sensor_value` 三类无当前业务依赖的读数。设备详情 Grafana 看板由 38 个面板缩减为 27 个，移除空的电压/电流面板、未归一化通用传感器读数表及复杂发现/质量诊断区。

温度、风扇转速、风扇与电源部件状态、CPU、内存、功率和光模块功率仍保留。无线 `wireless_sensor_value`、硬件发现状态与 AP 覆盖完整性逻辑也保持不变。

## 关键实现说明

- 轮询器候选加载、采集到期预检查及 `poll_hardware_inventory` 直接入口均过滤三类测量类型，避免常规轮询和直接调用绕过过滤。
- 指标渲染在输出传感器元数据、质量、最近成功时间和数值前过滤三类读数；旧值不会继续作为当前指标暴露。
- 数据库内已发现传感器与历史样本没有删除，按需诊断接口仍可读取；VictoriaMetrics 旧时间序列按既有保留策略自然过期。
- 看板移除面板 ID `20`、`21`、`22`、`24`、`29`–`33` 以及 row ID `903`、`905`；同步从 V2 样式清单移除对应项。接口诊断 row ID `904` 保留。
- “发现状态/采集质量”属于已有状态的展示，不会额外发 SNMP 请求；能力状态指标仍保留，因为无线看板使用 AP 发现覆盖完整性。设备详情仍可通过诊断接口查看采集库存状态。
