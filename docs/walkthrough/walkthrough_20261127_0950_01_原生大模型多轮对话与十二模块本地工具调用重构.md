## 1. 完成摘要

已将 Nexora AI Copilot 的自然语言主链路重构为与 ChatGPT / Claude / Gemini / DeepSeek 对齐的 **原生 LLM 多轮连续对话 + 本地 12 模块 & 本地知识库并行工具调用（Function Calling）** 架构：

1. **9 个标准只读本地工具（`backend/ai/services/copilot_tools.py`）**：
   - 将全部 12 大模块与本地厂商知识库收敛为 `get_network_overview`、`query_cmdb_devices`、`query_alarms`、`query_monitoring_topology`、`query_pam_sessions`、`query_config_and_compliance`、`query_tickets_and_automation`、`search_local_knowledge`（以及受控条件挂载的 `search_public_web`）。
   - 全量通过 `AISecurityGateway` 的 `_tool_is_unsafe` 与 `_has_credential_field` 静态校验，保留 RBAC 角色控制与零明文密钥列。
   - 内置 `parse_and_resolve_tool_args` 通过 `ai_security_gateway.resolve_output()` 自动还原脱敏标识符 Token（如 `[IP_1]` → `10.254.0.1`），单工具返回硬截断 ≤ 1,800 字符并支持 `asyncio.gather` 并行取证。
2. **原生 LLM Tool-Calling 对话主循环（`backend/ai/services/assistant.py`）**：
   - 保留高危写命令本地只读拦截（0 Token）与显式 `/slash` 快捷命令（0 Token），取消对自然语言的死板正则截胡（`local_router.py` 仅在 `AI_COPILOT_AGENTIC_CHAT_ENABLED=False` 时启用旧自然语言路由）。
   - 同时支持非流式（`_run_agentic_chat`）与 SSE 流式（`_run_agentic_chat_stream`）：最多 2 轮并行工具调用，通过 `_progress_event` 实时展示调取了哪些本地模块，最后流式合成多可能性推理结论，并精准累加多轮 `input_tokens` / `output_tokens` / `cached_tokens`。
   - 静态 System Prompt 引导模型：先查本地工具、再结合 CMDB 厂商/型号/版本检索本地知识库、按「已排除项 → 多种可能性排序 → 本机只读核查命令」输出研判；若底层模型不支持 `tools`（400），自动平滑降级为普通对话。
