## 完成摘要

按项目 netops-itsm-design、netops-frontend 和 quality-gate 检查并调整工单呈现层。保留现有侧栏、接口、审批/执行权限、状态机和默认每页 10 条及条数选择器。没有修改后端、数据库或已有工单，没有进行设备命令下发、提交、推送或部署。

## 实际修改文件与关键实现

- `src/components/tickets/TicketUI.tsx`：以现有 FormDialogShell、ActionButton、useEscapeClose、useFocusTrap 组合领域公共弹窗、事实字段和空态，统一固定底部操作、最上层 Escape 和焦点返回。
- `src/components/tickets/TicketReviewerDialog.tsx`：初审/终审共用候选人选择器，搜索、组内候选、选择后确认；保留原候选资格和后端校验。
- `src/pages/ChangeOrder/index.tsx`：统一审批选人及原因输入弹窗、复用 ToastNotification，纠正新建/列表标题。
- `src/pages/ChangeOrder/components/ChangeOrderList.tsx`：公共搜索/操作按钮、六列信息、突出当前处理人和实施窗口、分页紧接表格，保留查询参数和默认条数。
- `src/pages/ChangeOrder/components/ChangeOrderEditor.tsx`：公共表单分区和操作栏；基本范围、机器命令/回退、必填控制表三个分区；控制表默认显示待补全计数，可展开填写，正式提交校验不变。目标设备去除重复窗口和人员信息。集成检查补回预检失败分支使用的 XCircle 图标导入。
- `src/pages/ChangeOrder/components/ChangeOrderDetail.tsx`：顶部回答状态、处理人、下一步；首屏展示窗口、设备、命令和回退，责任分工与验证移到变更内容之后；模板快照、活动记录按需展开；时间窗口展示未开始/窗口内/已结束，未伪装为 SLA。
- `src/pages/ChangeOrder/components/ControlSheetPanel.tsx`、`ChangeOrderWorkflowPanels.tsx`：控制表聚焦检查/人工步骤/验证；职责、结果验证、交接与历史记录层级整理，保留操作权限和回调。
- `src/pages/ChangeOrder/constants.ts`：状态及风险配色的主题处理。
- `src/pages/Tickets/index.tsx`：故障与服务工作台公共搜索、按钮、详情及责任组弹窗，成员维护/保存/关闭一致。
- `src/pages/Tickets/ServiceRequestComposer.tsx`、`ServiceRequestDetails.tsx`：统一申请/详情弹窗、下一步动作与信息层级，无目录时紧凑空态。
- `src/pages/Tickets/ServiceCatalogManager.tsx`：目录/字段/履约分区、中文字段类型、公共固定操作栏；修正字段 key 编辑触发 React 行重建而丢焦点的问题。
- `src/pages/Tickets/TicketSlaSettingsPanel.tsx`、`TicketSlaSummary.tsx`、`TicketSummaryPanel.tsx`：策略与工作日历统一布局，保留全部配置字段与快照含义，不补造默认 SLA。
- `src/components/AppSidebar/navConfig.ts`、`src/hooks/usePageTitle.ts`：故障/服务与变更入口名称明确。
- 相关测试：公共弹窗、选人器、ChangeOrder 父页/列表/流程面板、服务详情及页面标题断言。

两个前端执行者分别负责变更内容组件和服务/SLA组件；主 Agent 负责公共组件、父页面、列表、最终审查和公共验证，未让两个执行者同时修改同一文件。
