# 单组织模式与租户限制下线走查

## 完成摘要

关闭 Nexora 面向用户的多租户管理入口以及以 `tenant_id` 作为用户访问边界的限制。历史 `tenant_id` 保留作为记录身份和审计信息；新建记录使用 `tenant-default`。显式角色/动作、站点、设备组、所有者、审批、MFA 和对象 ID 校验仍然执行。

## 核心改动

- 新增统一单组织 tenant policy，集中定义历史 tenant 查询范围和新记录写入标签。
- 隐藏租户管理 UI 和创建/修改/删除接口；旧路径不再提供多租户维护能力，内部兼容读取使用默认组织。
- 设备/资产、用户、告警、监控、配置、IPAM/IP 定位、变更单、拓扑、PAM、脚本/定时作业、知识库和目录等读取及授权不再按当前会话 tenant 隐藏历史记录。
- 保留站点和设备组资源范围，并补齐 SQL 范围过滤、缓存范围键和执行动作校验。
- 修复因不再传入 tenant 过滤而生成空 SQL 条件的配置快照和告警规则目录查询。
- 修复知识文档生命周期中的 `_CONTROL_RE` 残留引用，以及产品解析候选合并对已审查 OS 家族补全的影响。
