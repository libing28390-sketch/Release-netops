# 多厂商 CLI 智能结构化解析引擎重构验证报告（第十次更新）

本报告记录了在自定义模板编辑测试页中，为避免因输入其他平台或不支持的指令格式导致测试报错，从而实现“系统内置参考回显样本”与“我实际输入的测试样本”双显示与对比功能的更新。

## 完成摘要

1. **模板详情 API 支持返回默认参考样本**：
   - 在 [textfsm.py](file:///e:/data/netsops/backend/core/textfsm.py#L24) 中定义了 `TEMPLATE_DEFAULT_SAMPLES` 默认命令采集样本映射表（包含华为、华三等厂商的内存、CPU、设备插槽、风扇等日常高频查询命令的标准回显样本）。
   - 修改了模板获取端点 [api_get_template](file:///e:/data/netsops/backend/api/textfsm_templates.py#L71)。当获取单个模板详情时，系统会自动在映射表中查找该模板名。若有匹配的系统内置参考样本，则以 `default_sample` 字段一并返回给前端。
2. **前端编辑弹窗实现双展示与“一键填充”对比**：
   - 优化了 [TextFSMTemplatesTab.tsx](file:///e:/data/netsops/src/pages/TextFSMTemplatesTab.tsx#L463) 模板编辑器弹窗：
     - 当加载的模板具有系统内置参考样例时，会在右侧测试模块的“样本输出”上方渲染一个精致的 **「系统内置参考回显样本」**（Builtin Reference Example Output）展示区，显示正确的设备回显长文本。
     - 该参考展示区提供一个 **「一键填充到测试框」** 的高亮操作按钮。用户点击后，可瞬间将正确的系统样例填充进下方的“样本输出（我实际输入的测试样本）”编辑框中。
     - 通过将内置标准回显与用户输入的样本上下分层显示，用户可立即对比两者的格式差异（如空行、单位后缀、大小写拼写），秒级排除“回显指令与模板语法不兼容”的问题。
3. **回归验证顺利通过**：
   - `pytest` 与 TypeScript 类型检查无任何遗留错误。

## 调试页双展示测试功能核对

当你在 `http://192.168.42.1:5150/automation/textfsm` 中点开任一常用的内置/自定义模板（例如 `huawei_vrp_display_memory_usage.textfsm`）时：

1. **系统内置参考回显样本**：弹窗右侧上方会自动渲染浅蓝色框，内含官方推荐的内存 bytes 格式回显参考数据。
2. **一键填充**：点击右上角 **「一键填充到测试框」**，参考回显会直接加载到下方的文本框中，你可以随时修改其中的数值或比对你手头设备的数据。
3. **我实际输入的测试样本**：文本框的标题已被更新为 `样本输出 (我实际输入的测试样本)`。用户可以在这里自定义任何调试内容并点击 `测试解析` 产出最终 JSON，极大提升了测试 and 纠错效率。
