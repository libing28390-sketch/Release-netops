## 关键实现说明

- `/config-approval/approvers` 从认证会话读取 `user_id`（兼容 `id`），缺少稳定 ID 时返回 401。
- `list_approvers_with_methods` 要求申请人 ID；若 ID 为空则返回空列表，并在候选项中排除 ID 与申请人相同的用户。
- `_get_approver_for_request` 的“申请人不能审批自己的请求”校验仍保留，列表过滤之外还有创建阶段保护。
