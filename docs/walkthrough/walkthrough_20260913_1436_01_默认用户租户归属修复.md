# 默认用户租户归属修复走查

## 完成摘要

- 默认管理员创建时显式绑定 `tenant-default` / `role-admin`，已有默认管理员的空归属也会在 bootstrap 中修复。
- 新增 PostgreSQL migration `m0228_admin_tenant_assignment`，安全回填已部署数据库里的默认管理员空租户/角色字段；不修改其他空租户用户，也不覆盖管理员显式租户。
- 用户管理创建账号时写入认证管理员的 `tenant_id`；管理员没有租户时 fail closed，忽略客户端请求体提供的租户值。
- 未操作用户的 Docker 主机；该修复随本次调度锁/时区修复一同走 Release workflow 发布。

## 关键行为

- Migration 只处理 `username='admin'` 的空 `tenant_id` / `role_id`，多次执行幂等；其他用户必须由有权限的管理员明确分配，避免自动把未知账号提升到默认租户。
- 新用户继承已认证 actor 的租户，而不是信任客户端可伪造的 `tenant_id`。
- 新测试覆盖默认 admin 创建与空字段修复、migration 幂等与既有显式租户保留、用户租户继承/tenantless 拒绝/未认证拒绝。
