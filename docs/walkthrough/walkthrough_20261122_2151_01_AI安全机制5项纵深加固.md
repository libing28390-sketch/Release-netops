## 2. 实际修改文件

- `backend/ai/security/classification.py`：增强 `_REDACTED_ASSIGNMENT_PHRASE_RE` 覆盖 `snmp-agent/snmp-server`、`radius-server`、`tacacs-server` 前缀的已脱敏配置行。
- `backend/ai/security/gateway.py`：移除 6 个只读分析场景对 `credential_request` 的整类豁免，恢复自然语言索密意图的严格拦截，同时依靠 `_credential_request_probe` 放行已脱敏配置片段。
- `backend/ai/security/field_crypto.py`：为 `_KEY_CACHE` 增加 `threading.Lock` 并发保护与容量 16 的有界保留策略，消除多 `kid` 轮转期交替解密时的反复清空与 HKDF 重算抖动。
- `backend/ai/security/sanitizer.py`：在 `sanitize_text` 中接入 `redact_cn_secret_assignments` 并补全 CLI 密码/密钥修饰符（`8|9`、`radius-server key`、`tacacs-server shared-key`、`pre-shared-key simple`），同时保留 `[[NXA_...]]` 未知 Token 占位符不被误改。
- `backend/ai/api/security.py`：`update_security_policy` 写入新 `active` 策略前，在同一事务中将同租户旧 `active` 行更新为 `superseded`。
- `backend/ai/security/dev_passthrough.py`：新增 `_boot_at` 启动时间基准与 `sync_peer_expiration()`，支持跨 Worker 同步临时黑名单模式到期时间且保持重启自动失效语义。
- `backend/tests/ai/test_ai_p0_security_and_data_fixes.py`：新增 `test_security_5_hardening_items` 回归测试覆盖上述加固点。
