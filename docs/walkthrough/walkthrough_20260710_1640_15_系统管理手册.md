# 11. 平台管理产品使用手册 (Platform & Audit)

平台管理模块是 Nexora 平台的“安全底座”，负责对内部团队成员进行多角色 RBAC 访问控制、MFA 校验生命周期管理、以及系统级配置和高安全级别的操作审计日志记录。

![平台管理](file:///e:/data/netsops/docs/images/management_audit.png)

## 1. 核心功能概述

本模块包含以下子菜单：
1. **审计日志 (Audit Log)**：详尽记录平台内所有用户的每一笔操作事件（如登录、凭据查看、设备删除、配置备份发起等）。
2. **用户与角色管理 (Users & RBAC)**：配置运维人员账户，划分多级角色权限（Administrator、Operator、Viewer）。
3. **安全与 MFA 设置 (MFA Security)**：配置用户的全局多因子校验开关，重置二次认证二维码。
4. **系统级配置 (System Config)**：数据库类型切换（SQLite 与 PostgreSQL 同步逻辑）、外部 API 接口密钥配额等。

---

## 2. 详细操作步骤

### 2.1 全方位的安全审计日志 (Audit Logs)
* **不可篡改性**：所有的操作都会在后端触发 [log_audit_event](file:///e:/data/netsops/backend/services/audit_service.py) 函数进行异步写盘，无论成功还是失败，都会被永久记录，防止运维人员私自误操作后进行日志擦除。
* **审计检索**：
  进入 **平台管理 -> 审计日志**，支持输入用户名、目标设备、时间范围以及高危关键字进行流水检索。日志内容会显示原始 IP 地址、操作状态（成功/失败）和详细说明。

### 2.2 用户管理与多角色授权
1. 切换至 **用户与角色** 标签。
2. 点击“添加用户”，录入用户名并指定权限角色：
   * **Administrator（管理员）**：拥有全系统权限，可配置凭据和删除资产。
   * **Operator（操作员）**：可发起备份、执行自动化脚本、创建变更单，但无删除设备资产的权限。
   * **Viewer（只读审计）**：仅可浏览监控、拓扑、查看配置和 IPAM 数据。
3. **MFA 安全强关联**：
   管理员可以为任意用户重置或重新生成 MFA 二维码。用户在手机端绑定 Google Authenticator 之后，不仅在登录时需要输入动态验证码，在终端提权、高危命令执行时也必须进行 MFA 二次确认，确保关键核心网络节点不受单点安全漏洞威胁。相关账户注册与认证逻辑可参考 [users.py](file:///e:/data/netsops/backend/api/users.py) 模块代码。
