# 完成摘要

资产默认 auto 和旧 legacy_compat 仅启用了有限的旧算法，而资产页面已无策略选择入口。兼容策略现现代优先，开放底层库支持的完整旧算法；保留显式 modern 的严格行为。维护期创建请求漏带 Bearer token，现复用共享 apiRequest。常规配置备份查询补读设备 SSH 策略，避免静默忽略已保存策略。

- backend/api/pam.py：同步算法策略说明；没有修改 PAM 鉴权。
- backend/tests/pam/test_ssh_compat_algorithms.py：兼容集合、严格模式、算法排序和本地真实 SSH 握手回归。
