# 走查记录：资产管理绑定已有凭据

## 完成摘要
实现了资产管理模块直接绑定凭据库中已有凭据（如全局共享凭据）的功能，支持手动录入与绑定已有凭据的模式切换。避免了在资产表上重复录入密码而导致无法实现凭据共享、凭据编辑及自动轮换时产生冲突的问题。

## 实际修改文件

*   [assets.py](file:///d:/netops/netsops-main/backend/api/assets.py)：
    *   在 `AssetCreate` 和 `AssetUpdate` Pydantic 模型中添加 `credential_id` 属性。
    *   在 `_create_linked_device` 关联设备创建函数中支持已有凭据关联，并把关联凭据的账户和口令解密同步回设备和资产本地列。
    *   在 `_sync_device_from_asset` 中添加凭据绑定/解绑逻辑，并且通过过滤自动生成的凭据（如 `cred-{hostname}-`）来防止修改共享凭据时污染凭据库。
    *   增加 `_pre_resolve_credential` 预解析凭据辅助函数，使得在 `create_asset` 与 `import_assets` 插入资产前能提前解析并解密出正确的用户名、密码、SNMP 社区名等字段存入本地列。

## 关键实现说明
1.  **凭据解密与本地列同步**：为了确保与原有底层网络采集和 SSH 登录逻辑兼容，当选择绑定已有凭据时，后台在保存资产和设备时会自动通过 `_pre_resolve_credential` 解密出凭据库中的口令同步回资产/设备的本地加密口令列。
2.  **免受共享凭据污染**：当资产绑定了共享凭据（非 `cred-{hostname}-` 自动生成格式）时，在更新资产的本地密码时不会改写 `credentials` 凭据库表的行数据，从而规避了密码覆盖污染其它关联资产的安全隐患。
