# 终审与命令执行权限解耦

## 完成摘要

变更单终审通过不再校验实施人的设备命令执行权限。管理员终审组和 `command.execute` 授权保持独立：终审人按终审身份完成审批；实施人在实际进入实施阶段时仍必须通过明确的命令执行权限和设备范围校验。

## 关键实现

- 删除 `approved` 状态分支中对指定实施人调用 `assert_explicit_execution_profile` 和 `enforce_resource_scope(command, execute)` 的检查。它们导致终审动作因实施人尚未配置执行权限而失败。
- 保留实施人指派接口的资格检查，以及进入 `implementing` 状态时对执行人、设备范围和 `command.execute` 的校验。因此这次不会给任何管理员新增设备执行权限，也不会放行未授权命令。
- 增加回归测试：未配置 `command.execute` 的管理员实施人不阻止终审；该实施人随后开始实施仍被拒绝。
