# 全站表单与列表体验统一走查

## 完成摘要

- 新增通用列表工具栏、搜索框、表头复选筛选、齿轮列设置弹窗和列偏好辅助方法。列设置弹窗支持搜索可用字段、添加/移除、恢复默认、取消和确定；操作列保持必选，至少保留一个数据列。
- 将通用列表外观应用到 `DataTable`，增加 hover 与 `data-selected`/`aria-selected` 行状态样式。主要资源列表接入统一搜索与列设置：网络设备、资产、服务器、告警工作台、定时作业、CMDB 资产。
- 将共享表单分区和操作栏接入存储配置、定时作业、资产新增/编辑、设备编辑；存储配置进一步使用统一对话框壳，表单主体独立滚动，测试/取消/保存操作留在底部。
- 定时作业搜索现在通过分页 API 匹配任务名称、脚本 ID、命令和目标范围；类别与启停筛选也在服务端分页前执行，过滤总数和分类计数随筛选返回。现有租户与作业查看权限条件保持原样。
