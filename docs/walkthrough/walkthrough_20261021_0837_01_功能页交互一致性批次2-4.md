## 实施结果

把共同的交互预期落到具体业务页面，同时保留页面原有布局、查询约定和危险操作边界：

- **Monitoring / Capacity**：补上键盘可操作的摘要下钻、可读的筛选和图例状态、焦点样式；容量趋势区分权限、加载、错误、空数据和重试，避免把缺少数据显示成 0%。
- **Alerts / IPAM**：告警列表和详情明确呈现加载失败、权限拒绝及重试；切换/关闭详情后忽略过期响应。IP 定位支持 Enter 和显式按钮共用提交路径，并标出工具视图选择和异步状态。
- **CMDB / Config**：导入弹窗复用 `ActionButton`、`ActionIconButton`，补充对话框语义、Escape、焦点循环和触发按钮焦点返回。配置日期筛选统一主题 tokens，日期和快捷范围暴露选择状态，并支持本地化标签和 Escape 关闭。
- **Operation Workspace / Automation**：补全设备级操作名称、搜索名称、类别/视图选择状态和 RDP/VNC 加载错误提示；自动化设备抽屉和确认/结果/调试弹窗按层关闭并保持现有命令执行边界。
- **Tickets**：列表、详情和时间线明确显示权限、加载失败、过期内容和重试；请求竞态不再覆盖新列表/详情。执行中的特权命令仍不能通过 Escape 或遮罩关闭；审批选择关闭时清除临时选择。
- **Platform / AI Center**：审计筛选使用主题 tokens、可访问名称和焦点样式；AI Center 懒加载使用本地化、可访问且支持减少动态效果的等待状态，并检查默认 Provider 子页现有测试。
- **共享焦点处理**：新增 `src/hooks/useFocusTrap.ts`。最上层弹窗接收焦点，Tab/Shift+Tab 在其内部循环，关闭后返回触发控件；已用于 MFA、CMDB 导入、自动化确认/查询/调试和工单审批/命令弹窗。`useEscapeClose` 仍负责逐层关闭，不与业务关闭逻辑冲突。

未新增 API/schema、依赖、路由、状态库或组件库；没有修改认证、RBAC、审批状态机、凭据脱敏、命令范围、回滚流程或真实设备操作契约。
