# 拓扑隐藏合成端口标签

## 完成摘要

确认画布上的 `Port-数字` 来自 SNMP 采集器的本地端口索引回退：LLDP 的 `lldpLocPortId` 和 IF-MIB `ifName` 都无法映射时，采集器生成 `Port-{索引}`；CDP 路径在缺少 IF-MIB 映射时也有相同回退。图形组件此前把此值当作正常接口名显示。

现在拓扑图统一标签格式化入口会隐藏严格匹配 `Port-数字` 的占位值，包括端点标签和悬浮信息。邻居数据和真实接口名称仍按原样保留。

## 关键实现

在 `getFullInterfaceLabel` 中识别 `/^port-\d+$/i` 并返回空标签；该 helper 被画布接口标签、SVG 标题和链路悬浮信息共用。`Port-channel`、`Port-Channel1` 等真实接口格式不匹配此表达式。
