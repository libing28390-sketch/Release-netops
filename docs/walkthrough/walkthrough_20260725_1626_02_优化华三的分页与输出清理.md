# Walkthrough - 优化华三的分页与输出清理

## 完成摘要
优化了 SSH 长回显输出的分页读取机制，极大缩短了翻页等待时间（时延从 8 秒下降至 0.2 秒以内），并自动清除了残留的清屏空格。

## 实际修改文件
- [ssh_compat.py](file:///d:/netops/netsops-main/backend/drivers/ssh_compat.py)

## 关键实现说明
1. **基于模式的分页读取**：将 `drain_paged_output` 内的 timing 静默判定（`read_channel_timing`）重构为优先使用 Netmiko 的 `read_until_prompt_or_pattern` 来匹配分页标识（如 `---- More ----` 等）。只要出现标识或最终提示符，立即进入下一页，使得等待完全零延迟。
2. **清除擦除空格**：部分设备换页发送空格后会产生一整行用作擦除原提示符的空格行。在读取合并后，检测并过滤掉了那些“只包含空格但长度不为零”的擦除残留行，并移除了内含的 `\r` 回车符。
