# 资产管理健康度过滤逻辑与统计对齐走查报告

## 1. 修复摘要
成功修复了资产管理（`/assets/dashboard`）顶部 4 联严重程度 / 健康度状态卡片（P1 严重故障、P2 重要问题、P3 需要关注、运行正常）与表格数据过滤条件不一致的问题。

## 2. 根因与修复说明

### 2.1 根因定位
1. **临期保修计算不一致**：
   - 后端 `/assets/summary` 的 `warranty_expiring_soon` 仅计算未来 90 天内到期的设备；
   - 前端 `severityOf` 之前的判断条件为 `new Date(a.warranty_expiry) <= Date.now() + 90d`，未加上 `>= Date.now()` 下限限制。
   - 当资产维保已过期（如样例数据中的 `2026-06-01`，早于当前系统时间 `2026-08-20`）时，前端 `severityOf` 将这 8 台历史过保设备全部判定为 `warning`，导致卡片统计显示 `0 (0%)`，但点击进入过滤时表格却展示全部 8 台设备；点击“运行正常”（统计为 8）时反而显示 0 条。
2. **状态与级别映射口径不齐**：
   - 卡片 1（P1 严重故障）统计了 `inactive`，但 `severityOf` 之前仅将 `decommissioned` 判定为 critical；
   - 过滤激活时，表头右侧总数统计展示的是后端无过滤的 `total`，而非当前视图的实际条数。

### 2.2 修复措施
1. **修正 `src/pages/AssetManagement/helpers.ts`**：
   ```ts
   export const severityOf = (a: Asset): 'critical' | 'major' | 'warning' | 'healthy' => {
     const onlineStatus = a.online_status || (a.status === 'active' ? 'online' : a.status === 'inactive' ? 'offline' : 'pending');
     if (onlineStatus === 'offline' || a.status === 'inactive' || a.status === 'decommissioned' || a.lifecycle_status === 'decommissioned') {
       return 'critical';
     }
     if (a.status === 'maintenance' || a.lifecycle_status === 'maintenance') {
       return 'major';
     }
     if (a.warranty_expiry) {
       const exp = new Date(a.warranty_expiry).getTime();
       const now = Date.now();
       if (!Number.isNaN(exp) && exp >= now && exp <= now + 90 * 86400000) {
         return 'warning';
       }
     }
     if (a.status === 'in_storage' || a.lifecycle_status === 'staging') {
       return 'warning';
     }
     return 'healthy';
   };
   ```
2. **对齐统计指标与重置逻辑**（`src/pages/AssetManagement/index.tsx`）：
   - `criticalCount = (summary?.by_status?.['inactive'] ?? 0) + (summary?.by_status?.['decommissioned'] ?? 0)`
   - `majorCount = (summary?.by_status?.['maintenance'] ?? 0)`
   - `warningCount = (summary?.warranty_expiring_soon ?? 0) + (summary?.by_status?.['in_storage'] ?? 0)`
   - `healthyCount = summary?.by_status?.['active'] ?? 0`
   - 工具栏总数动态显示当前视图条数（`severityFilter !== 'all' ? displayAssets.length : total`）；
   - 在表格筛选为空时，增加“重置所有筛选”一键恢复按钮。
