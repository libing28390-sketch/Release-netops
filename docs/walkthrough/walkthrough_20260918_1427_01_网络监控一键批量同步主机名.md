# 网络监控一键批量同步主机名验证报告

## 1. 任务概述与完成摘要
在网络监控页面已支持单台设备通过 RFC 1213 标准 SNMP MIB-II `sysName.0` 校准主机名的基础上，新增**一键批量同步主机名**功能：
1. **零模板标准保证**：批量同步严格遵循通用 RFC 1213 标准 OID `1.3.6.1.2.1.1.5.0`，完全不绑定、不依赖任何厂商指标采集模板，所有网络设备厂商统一处理。
2. **后端受控并发与全表联动**：提供 `POST /api/devices/batch-sync-hostname`，通过 `asyncio.Semaphore` 限制最大并发量为 10，自动读取凭据、并发探测、清洗剥离域名前后缀，并原子同步更新 `devices`、`physical_assets` 和 `topology_observations`。
3. **前端直观交互**：在【网络监控】页面左侧设备列表“X 台在管网络设备”右侧提供【批量同步】按钮，同步过程显示旋转动画，完成后展示详细统计 Toast 并自动刷新设备列表与监控大屏数据。
4. **用户约束遵守**：按照用户明确指示：“**然后先不要push**”，本次变更仅在本地完成修改与全流程验证，未执行任何 `git push`。
