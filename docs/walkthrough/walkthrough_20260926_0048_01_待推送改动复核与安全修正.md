# 待推送改动复核与安全修正

## 完成摘要

对当前 `main` 工作区的 Grafana 方案 A、CMDB 接口监控画像和 S3 存储改动做集成复核，修正迁移配置覆盖风险和配置快照越权读取，并补齐接口 PPS 方向曲线。此次变更将与工作区原有相关改动统一提交推送。

## 关键修改

- m0253 对空的内置 IF-MIB 配置完整 seed；对非空运维配置只追加缺失的 `ifLastChange`，保留现有 metric/OID 和其他字段，并基于最终 JSON 更新 hash。
- Grafana 04 接口看板和 09 接口详情页的 PPS 图分别展示入向、出向、单播、组播、广播。
- 接口状态表把 `1` 显示为绿色 `Up`、`2` 显示为红色 `down`，不展示原始数字。
- 配置快照内容和下载接口通过资产 tenant/site scope 查询；非管理员缺少 tenant、设备/站点 tenant 不一致、重复的 legacy site name 均拒绝读取；对无权限和不存在的 snapshot 使用相同 404。
- SNMP 目录和 exporter 增加只读 IF-MIB `ifLastChange` OID `1.3.6.1.2.1.2.2.1.9`，用于计算接口状态变化时间；没有向设备写入配置。
