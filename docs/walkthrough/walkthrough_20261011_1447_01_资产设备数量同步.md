## 数据口径说明

数量对齐的是资产台账中的网络设备与服务器总数。没有关联到可操作 `devices` 记录的物理资产仍会计入台账总数，但不会因此出现在工作台设备列表。本次没有修改数据库关联或执行数据回填。

资产 API 的新建和导入路径会为网络设备/服务器创建关联 `devices` 记录；旧资产更新时，如果找不到关联设备，当前同步逻辑会跳过，不会自动补建。旧接口的 200 行上限意味着还不能判断台账与真实设备行数是否相等；本地分页代码部署后，工作台会显示设备 API 的真实总数。若仍小于台账总数，再按权限范围和关联关系做只读核对，本次不自动生成连接凭据或可操作设备。

本地修改尚未提交或部署，所以生产页中的在线分母仍显示旧的 200；本次也未对生产数据做修改。
