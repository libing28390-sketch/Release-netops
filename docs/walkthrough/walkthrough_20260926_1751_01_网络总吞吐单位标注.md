# 网络总览设备吞吐单位标注走查

## 完成摘要

01 网络总览“设备总流量 Top10”实际计算各设备所有接口 5 分钟入向和出向字节速率，乘 8 后合计，语义是吞吐速率，单位 bit/s（bps），不是累计流量。原表格没显示单位，是因为列重命名为“总流量”后，Grafana unit override 仍匹配默认列名“数值”，名称对不上导致 formatter 未应用。

现已将标题改为“设备总吞吐速率 Top10”，数值列为“总速率 (bit/s)”，说明中解释速率窗口、入+出汇总及 Grafana 自动缩放；并让单位 matcher 与转换后的实际列名一致。

## 关键实现说明

PromQL 保持原样：对 `ifInOctets` / `ifOutOctets` 及兼容指标计算 5 分钟 `rate()`，分别乘以 8 转为 bit/s，再按设备把入向和出向速率相加并取 Top10。Grafana 的 `bps` unit 会把数值可读地显示为 kb/s、Mb/s 等。该总和是所有接口读数合计，不能理解成去重后的业务流量。
