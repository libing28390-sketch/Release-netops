# 凭据绑定与改密安全收口 Walkthrough

## 本次完成内容

1. 凭据中心支持管理员按设备替换绑定或解除绑定。
2. 解除绑定只清除设备与凭据的关联，不删除凭据，也不修改设备硬件密码。
3. 绑定设备禁止从设备级密码轮换接口、资产投产口令上收流程和批量轮换流程单独改密。
4. 凭据密码同步任务的每台设备执行阶段不再写回凭据中心；只有所有目标设备成功验证后，才执行一次中心提交。
5. 密码轮换页面调整为状态查看入口，密码修改应从凭据中心发起。

## 操作验证

### 替换或解除绑定

1. 进入「凭据中心」。
2. 在关联设备列表中点击设备右侧的「普通/特权」管理入口。
3. 选择「替换为新凭据」或「解除绑定」。
4. 替换必须选择不同且角色兼容的凭据；解除后设备进入独立凭据管理。

### 绑定凭据改密

1. 在凭据中心编辑凭据并输入旧密码。
2. 提交新密码，系统创建凭据密码同步任务。
3. 任务会按设备记录成功、失败、重试和回滚结果。
4. 所有关联设备验证成功后，凭据中心才更新权威密码；部分失败时权威密码保持不变。

## 风险边界

- 替换绑定不会自动验证新凭据能否登录设备，也不会自动修改硬件密码；替换前应确认新凭据已在设备生效。
- 绑定设备的单台改密请求会被后端拒绝，并提示从凭据中心发起全量同步。
- 解绑后如需修改设备本身密码，应在设备/资产的独立凭据管理流程中操作。
