# 定时作业授权拒绝记录与脚本摘要修复 walkthrough

## 变更

- 定时作业授权失败时，在同一事务中新增 `denied` 执行历史，记录作业创建人、所属租户、拒绝原因和空设备列表；该路径不连接设备或启动作业内容。
- 执行历史列表和导出显示“权限拒绝”；打开详情可读到授权校验的具体原因。
- 数据库迁移完成后，重新计算标准、已发布系统脚本的 SHA-256 摘要，修复启动更新脚本内容而摘要滞后的情况。
- 审批接口将脚本快照校验失败作为 HTTP 409 冲突返回，避免触发未处理异常堆栈。
- 定时作业编辑、候选预览、作业详情、删除审批、采集计划及停用确认弹窗去除背景模糊；列表禁用态只屏蔽交互，不再模糊底层页面。
