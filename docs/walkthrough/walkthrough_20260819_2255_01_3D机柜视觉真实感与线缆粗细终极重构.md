# 3D机柜视觉真实感与线缆粗细终极重构 走查报告

## 任务完成摘要

针对用户指出的“选中设备被大面积高亮泛蓝/泛紫破坏外观”、“静态端口灯全为绿色”、“线缆与标牌遮挡设备面板信息”、“电源灯未展示”以及“跳线管径过粗”五大核心体验问题，进行了深度重构与精细打磨：

1. **彻底修复选中设备全机泛蓝/泛紫发光缺陷（`ProceduralChassis.tsx`）**：
   - 移除了破坏冷轧钢质感的全机身发光色（Emissive 归零）；
   - 无论是选中状态、还是切换至“角色/健康/功耗”热力模式，机箱本体始终保持真实高档的 **冷轧枪灰/深灰金属质感（Gunmetal Cold-rolled Steel）**；
   - 选中效果收敛为清爽干练的 **细线青蓝线框边沿高亮（Wireframe Outline）** 与 6cm 前向微抽拉，设备面板文字与铭牌清晰如初。
2. **端口状态灯与静态真实度重构（`textures.ts`）**：
   - 彻底修复静态贴图 24 口全亮的假象：仅点亮真实连通的前几个 UP 端口（绿色高亮 `#22c55e`），其余未连通端口均为深色暗态未点亮（Dark Slate `#334155`）；
   - 符合数据中心真实交换机与防火墙的前面板工作形态。
3. **增加 3D 物理电源灯与系统运行灯（`SwitchFaceplate.tsx` / `ServerFaceplate.tsx` / `GenericFaceplate.tsx`）**：
   - 在前面板左侧耳朵与铭牌处增加了 **3D 物理圆形 PWR（电源指示灯）** 与 **SYS（系统运行指示灯）** 珠粒；
   - 通电时呈现清晰的发光绿灯（`#22c55e`），断电时呈现暗灰（`#334155`），并在丝印层附带清晰文字标记 `PWR ●  SYS ●`。
4. **重构线缆物理走向与标牌位置，彻底杜绝遮挡（`RackCableLayer.tsx`）**：
   - 将走线路径彻底移至机柜立柱外侧的 **标准垂直理线槽（$X = -2.15$）**，横向不跨越机柜正前方，设备面板文字与铭牌 100% 无遮挡；
   - 将 3D 悬浮链路标牌移至机柜左侧外延空白区域（$X = -3.2$），既清晰醒目，又绝不挡住机架上的任何设备。
5. **大幅精细化跳线管径（`RackCableLayer.tsx`）**：
   - 将原本过粗的管径缩细为符合真实机房比例的超细光纤/网线：
     - 光纤跳线半径精细至 `0.013`（约 2.5mm LC 纤细光跳线）；
     - 双绞线/DAC 铜缆半径精细至 `0.017`（约 5.0mm 标准跳线）；
   - 画面呈现工业级专业理线效果，规整纤细，高级美观。
