# CAT-014 Product Catalog Browse and Version Filter Walkthrough

1. Open **AI Center → Product Catalog** and keep the **型号目录** panel selected.
2. Choose a Vendor, then Family and Series. The Model table narrows to the selected hierarchy.
3. Choose `17.9.x` to show the three Cisco Catalyst 9300 rows, or choose `V300R024C10SPC500` to show the three Huawei CE6800 rows.
4. Verify each row shows the primary and compatibility versions and still labels the model as draft/read-only.
5. Enter a model substring such as `48P` and press Enter; the result combines the hierarchy, version, and model filters.
6. Use **清除筛选** to return to all reviewed rows. If a combination has no match, the table remains empty without guessing another model or driver.
