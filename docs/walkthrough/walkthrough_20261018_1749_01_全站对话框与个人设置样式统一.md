# 全站对话框与个人设置样式统一

## 完成摘要
- 全局把 cyan 强调色映射到标准蓝，并把浅色强调底色调整为更淡的蓝色；正文/辅助文字继续走现有语义色变量。
- 扩展共享 `FormDialogShell` 的样式契约，统一表单对话框的文字层级、字段边框、占位文字、禁用状态和蓝色焦点；错误输入保留红色，安全提示保留低调的琥珀色标记。
- 资产和设备表单减少渐变、背景模糊、重阴影和过大圆角；说明区、PAM 和账户凭据区使用中性表面，主操作统一为标准蓝。
- 个人设置的基本资料、安全、通知和终端页面统一使用浅色表面与细边框。Fixed PIN 卡片采用普通底色和窄琥珀色边缘，MFA/通知状态保留原语义。
- CMDB 凭据、设备、接口、站点、VRF、VLAN、VLAN 业务等共用的新建/编辑记录弹窗，改用公共中性表单样式；新增入口统一为标准蓝色“新建”，放在左侧，搜索与导入导出工具靠右，去掉模糊遮罩、缩放动画和重阴影。
- 机柜管理的新建机柜、安装设备、设备型号管理/新建入口接入同一中性弹窗样式和标准蓝色主按钮；新建按钮放左，机柜工具放右。
- 公共 `ActionIconGroup` 强制操作组保持可见，不再受调用方遗留的 `opacity-0` 影响；`TableActionCell` 复用传入的操作组，不再生成嵌套分组。CMDB、IPAM 和机柜等使用公共组的行操作因此不必悬停即可看到。
- 未修改表单验证、字段值、保存请求、凭据和 MFA 行为。

## 关键实现说明
- `:root` 将 cyan 色阶映射到 blue 色阶，因此全站依赖 cyan Tailwind 色阶的强调元素同步采用蓝色。
- `.nx-form-dialog-shell` 和 `.nx-form-dialog-surface` 统一字段标签与输入控件色彩，并在深色主题下继续使用语义变量；错误态输入通过 `aria-invalid` 或红/玫瑰边框类排除在普通焦点覆盖之外。
- 资产表单的说明卡、PAM 区、保存栏和二级对话框，以及设备表单的 SNMP/PAM 区和底栏均改用共享样式类。
- 个人设置去掉强模糊、大阴影、渐变和弹窗缩放动画，导航选中态改成浅蓝；Fixed PIN 的安全语义仅通过图标和左侧细边标识。
- CMDB 多实体复用 `CmdbManagementTab` 的同一创建表单，因此凭据、设备、接口、站点、VRF、VLAN、VLAN 业务等入口一起得到统一样式；机柜表单和设备型号管理也使用公共 `nx-form-dialog-surface` 与语义操作按钮。
- 新建按钮统一显示“新建”，使用标准蓝色并与搜索、导入导出控件分列左右；页面记录字段、提交逻辑和权限判断保持原样。
- `ActionIconGroup` 在共享组件内追加 `!opacity-100`，以公共行为覆盖遗留的 hover-only 类；`TableActionCell` 将现有 `ActionIconGroup` 展开后重新包装，避免辅助技术重复读到嵌套 group。
