# 拓扑发现性能修复 Walkthrough

## 变更结果

- `backend/services/topology_service.py` 将设备级发现从串行循环改为默认 6 路有界批处理。
- 同一设备的 SSH/CLI 并发限制保持为 1，避免 VTY、交互提示符和连接状态互相干扰。
- 同一设备的 LLDP 与 Eth-Trunk 复用一个 `PlatformActionSession`，每条命令仍按独立平台注册动作做模板解析、字段契约校验和审计。
- 长批次通过租约心跳续租。
- 解析模板不匹配、认证失败、凭据不完整和不支持动作不再盲目重试；仅明确的 SSH 不可达/超时错误保留重试。
- `docs/architecture/device_credential_connection_standard.md` 增加拓扑性能约束，防止后续通过提高同设备并发解决问题。
