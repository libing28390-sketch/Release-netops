# 资产导入提示增加进度指示记录

## 完成摘要

在资产批量导入提示中增加主题适配的动画进度条。进度条只在导入进行中显示，以循环移动表示任务仍在处理；不展示无法从当前接口准确取得的百分比或已完成行数。

## 实际修改文件

- `src/pages/AssetManagement/index.tsx`
- `docs/plans/plan_20261011_2014_01_资产导入进度条.md`
- `docs/walkthrough/walkthrough_20261011_2014_01_资产导入进度条.md`

## 关键实现说明

- 进度条位于现有导入提示的辅助说明下方。
- 使用浅色/深色主题对应的轨道和蓝色移动段。
- 仅当 `importInProgress` 为真且提示类型为 `info` 时渲染；导入结束后随提示状态更新而隐藏。
- 后端导入接口和列表刷新机制没有改动。

## 验证命令与结果

- 静态检查了导入请求、列表轮询和提示组件：当前后端接口在整批结束后返回汇总，列表轮询受当前筛选条件影响，因此没有使用它们计算百分比。
- 人工检查了条件渲染、动画参数、明暗主题样式和 `aria-hidden` 标记。

## 未执行验证及原因

- 未运行测试、lint 或构建；用户请求是增加 UI 指示，且没有要求执行验证命令。
- 未重新导入设备，避免对用户资产数据产生重复写入。

## 剩余风险与后续建议

- 当前进度条是无百分比的循环指示器。若后续需要真实百分比，应由后端提供可轮询或可流式读取的逐行任务进度，再由前端展示确定性进度。
