# 发现终端证据分级执行记录

## 完成摘要

发现终端页现默认显示全部当前 IP 观察，原始 ARP/ND 行数与按当前范围去重后的 IP 数分开统计。每条观察依据当前设备三层接口、已管理设备、虚拟网关 MAC 和同设备同 VLAN 的 FDB 接入口证据标为基础设施地址、接入口主机候选或待核主机候选。判定只属于当前观察投影，不写正式 IP 台账。

## 实际修改文件

- `backend/services/ipam_discovery_service.py`、`backend/api/ipam.py`：当前证据分级、去重摘要、分类筛选和详情一致性。
- `src/pages/IPVlan/DiscoveredEndpointsTab.tsx`、`src/pages/IPVlan/ipamDiscoveryPresentation.ts`：默认范围、分类计数、列表/详情/导出说明和筛选。
- `backend/tests/ipam/test_current_endpoint_classification.py`、`src/pages/IPVlan/DiscoveredEndpointsTab.test.tsx`、`src/pages/IPVlan/ipamDiscoveryPresentation.test.ts`：针对当前证据分级及页面契约的聚焦回归。

## 关键实现与现网结果

- 基础设施判定先于接入口判定：当前三层接口 IP、同站点已管理设备 IP、已管理设备跨站点同 IP、VRRP/HSRP 虚拟 MAC 都不计入主机候选。`192.168.56.1` 的设备登记站点是 WH-DC-03，而当前 ARP 来自 WH-DC-01；按用户要求排除终端候选，同时保留站点不一致提示。
- 接入口主机候选必须有近期且完整的 ARP 与 FDB，设备、MAC、VLAN 和原始上下文一致，FDB 路径唯一且为显式 Access 端口。Trunk、聚合、拓扑邻居、缺失或过期证据保持待核。未知 VRF 不自动推断 Global，接入口证据不等于资产身份或正式登记。
- 浏览器最终在 2026-11-11 13:34（Asia/Shanghai）显示 49 条 ARP/ND 观察、32 个不同 IP、28 个基础设施地址、2 个接入口主机候选、2 个待核主机候选。`172.16.5.10` 匹配 `S6850-5 / VLAN 7 / GigabitEthernet1/0/2`；FDB 更新后 `172.16.6.10` 也满足接入口判定。全部 49 条观察的 SNMP 地址空间仍待确认。
- 页面“主机判定”筛选已在浏览器验证；筛选结果随当前 FDB 代次更新，不固定使用上一次观测数量。最终浏览器刷新后默认范围和 49/32/28/2/2 分类均正常。

## 未执行验证与剩余边界

- 当前分类不确认终端资产名称、使用人或在线状态；还需 DHCP、准入、主机代理或人工登记等独立证据。
- 思科设备按用户要求暂缓；本次没有连接、配置或改动设备，也没有修改当前观察原始行与正式 IP 台账。
- FDB 收集代次会变化，接入口候选数量应随当前证据实时变化，不能固定写为 2。
