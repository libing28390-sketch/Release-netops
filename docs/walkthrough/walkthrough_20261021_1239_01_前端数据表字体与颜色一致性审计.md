# 前端数据表字体与颜色一致性审计

- 日期：2026-10-21（Asia/Shanghai）
- 对应计划：`docs/plans/plan_20261021_1239_01_前端数据表字体与颜色一致性审计.md`

## 完成摘要

按用户追加要求对全站业务表格进行源码级清点，并以 `/assets/dashboard` 的资产表作为视觉基准。浏览器对照后发现 NSOT 的局部放大覆盖了共享样式，现已移除局部字号覆盖；常规正文、表头、加粗主标识和圆角标签都与资产表使用同一层级，状态色仍保留语义。

## 审计范围与结论

- 静态清点 `src/` 中 64 个含 `<table>`/`<DataTable>` 实现或封装的非测试 TSX 文件，覆盖监控、接入、告警、资产/CMDB、IPAM、自动化、配置、工单、管理、AI 等页面族；不把终端和命令输出的表格当普通业务表格判断。
- 共享表格规则将正文设为 13px、表头 12px；紧凑表格正文 12px、表头 11px。多数直接写在 `td`/`th` 上的较小 Tailwind 字级已被共享规则覆盖。
- 真正偏小的异常集中在嵌套元素：NSOT 次要字段、巡检指标字段、IPAM 利用率和状态徽标、WAN 专线辅助字段，以及告警/巡检/监控/PAM/作业执行等页面内的关键状态徽标。其他审查到的表头和常规单元格没有发现跨页面的公共低对比根因。

## 实际修改

- `src/pages/NSOTCollectionOperations.tsx`：取消 NSOT 专属字号覆盖，复用共享表格的表头 12px、正文 13px；模板名 12px 加粗，平台代码 12px 等宽加粗，模板 ID 10px 辅助色，模板类型标签采用资产表相同的浅蓝底/蓝字圆角填充。颜色按资产表使用深色正文与灰色表头，状态色保留语义。表格最小宽度由 2400px 降至 2100px，保留容器内横向滚动、粘性表头、导出、分页与现有操作，并增加表格可访问名称和长值 title。
- `src/index.css`：所有普通业务表格的圆角标签统一 10px、600 字重；在线、告警、模板类型等语义色保留，终端表格不受影响。
- `src/pages/NSOTCollectionOperations.test.tsx`：验证表格可访问名称与系统模板的浅蓝底/蓝字类别样式；原有模板/平台筛选和分页测试继续通过。
- `src/pages/InspectionItemsTab.tsx`：名称、厂商、采集方式、脚本、OID、阈值、描述、编辑控件和展开详情从 10px 提升到 12–14px，辅助文本使用 `--ui-fg-muted`。
- `src/pages/IPVlan/index.tsx`、`src/pages/IPVlan/IPPoolTab.tsx`：放大利用率、子网标识、数据类型与状态徽标，弱化普通数字使用主题 muted token；健康/故障颜色语义保留。
- `src/components/wan-circuits/WanCircuitTable.tsx`：线路号、运营商、次要带宽提升到 12px，状态/共享接口徽标提升到 11px。
- `src/components/NetworkMonitoring.tsx`、告警桌面/历史/规则/维护、`src/pages/InspectionTab.tsx`、`src/pages/ExecutionSchedule/components/ExecutionDetail.tsx`、`src/pages/PAMAuditTab.tsx`、`src/pages/ScheduledJobs/index.tsx`：关键状态和严重度徽标统一至少 11px，不改变状态语义。
