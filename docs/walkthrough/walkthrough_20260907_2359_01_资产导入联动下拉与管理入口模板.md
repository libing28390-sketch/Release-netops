# 资产导入联动下拉与管理入口模板 Walkthrough

## 完成摘要

根据截图反馈，资产导入模板和资产编辑/导入链路已完成修正：资产类型会先过滤厂商，厂商会再过滤平台；厂商与平台下拉只保留一套规范英文显示值，历史中文/代码仍可被导入归一化；凭据列按 `绑定凭据 → 绑定特权凭据 → SNMP凭据` 排列；管理入口现在有 Web管理示例，协议和入口显示名称都是真正的 Excel 原生下拉。

## 剩余风险与后续建议

- 动态 Security Vault 凭据名称不写入静态下拉，模板仍要求填写已有凭据名称或 ID。
- 如果用户使用不支持命名区域联动的旧版表格软件，前端导入预检仍会拒绝服务器厂商/平台错配，但下拉本身可能退化为不可联动列表。
- 资产类型、厂商和平台的业务校验仍以导入链路和后端规范化为最终边界，Excel 客户端校验不是唯一安全控制。
