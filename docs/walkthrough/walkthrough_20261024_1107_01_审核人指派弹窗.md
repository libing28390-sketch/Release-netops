# 审核人指派弹窗

## 完成摘要

简化脚本“指派审核人”弹窗，并修复审核人搜索结果遮挡“发送审核申请”按钮的问题。弹窗只保留标题、搜索、结果、提交和取消，结果列表进入正常布局流。

## 实际修改文件

## 关键实现

- 移除装饰图标和额外说明文案，使用紧凑、朴素的弹窗样式。
- 搜索结果以内嵌列表显示，限制列表高度并允许滚动；结果不再覆盖操作按钮。
- 为弹窗设置视口最大高度和内部滚动，搜索控件与结果列表补充可访问性标签。
- 保留现有审核人选择状态与提交处理逻辑。
