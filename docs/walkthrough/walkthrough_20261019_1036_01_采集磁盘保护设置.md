- 采集器表单已移除无运行时消费者的“队列磁盘上限（MB）”；旧数据库字段和旧 API 继续保留，兼容已有数据。

- API 不持有 Docker socket。VictoriaMetrics supervisor 从持久运行卷读取值，配置变化时优雅停止进程并让 Docker 重启 VictoriaMetrics 容器。
