# 远程桌面默认启用

## 完成摘要

- 删除后端 `NETOPS_REMOTE_DESKTOP_ENABLED` 门控，旧 `.env` 值 `0` 不再阻断 RDP/VNC profile、会话和 WebSocket 接口。

## 剩余风险与后续

- 默认启动 Guacamole/guacd 会增加约 1.8 GiB 容器内存上限和最多 3 个 CPU 的配置容量；是否可连接仍取决于资产的 RDP/VNC 服务、网络可达性和凭据/profile 配置。
- 本次部署只验证了工作台读取远程桌面 profiles 与 Guacamole 服务可达，没有向具体资产发起 RDP/VNC 会话；单台设备连通仍取决于服务、网络、凭据和访问配置。
- 服务器部署前备份位于 `/root/nexora-remote-desktop-default-20261016-1213/pre-change.tar.gz`；静态资源旧 owner 清单位于同目录。没有推送或提交代码。
- 回滚路径见 [实施计划](../plans/plan_20261016_1213_01_远程桌面默认启用.md)：恢复旧代码与 Compose 定义，在旧版重新部署前将原开关设为 `0`，保留数据库和录像卷。
