# 快捷操作分页条数选择

## 完成摘要

已在快捷操作页分页栏恢复“每页条数”选择器。冷启动默认保持10条；可选10、20、50、100条。切换每页数量后回到第1页，设备 API 请求、列表内容和总页数同步更新。

## 实际修改文件

- `src/pages/AutomationExecute/components/DeviceSelectionStep.tsx`
- `src/pages/AutomationExecute/components/DeviceSelectionStep.test.tsx`（更新必需 props 夹具）

## 实现说明

- 父组件以 `DEVICE_PAGE_SIZE`（10）初始化 `devicePageSize`，请求参数 `page_size` 和最后页计算均使用当前选择值。
- 分页组件接收 `onItemsPerPageChange`，因此展示条数选择器；切换时同步回到第1页。
- 表格只有在当前页数据填满所选条数时才撑满列表容器，少量结果保持自然高度。
- 未修改通用分页器或其他页面。
