# 首页在线率精度显示

## 完成摘要
修正首页在线率的百分比显示。435 / 436 将显示为 99.77%，不再因整数四舍五入而显示为 100%。

## 实际修改文件

## 根因与实现
首页沿用正确的在线数和总数口径，但通过 Math.round 将百分比取整。当前改为保留两位小数；精确全在线时显示 100%，只要在线数低于总数，就把最大显示值限定为 99.99%。在线数和总数仍来自同一份资产汇总，后端统计未修改。
