# 1. 操作工作台产品使用手册 (Operation Workspace)

操作工作台是网络工程师进行日常设备直连操作、特权命令行调试以及安全会话审计的核心场所。

![操作工作台](file:///e:/data/netsops/docs/images/access_workspace.png)

## 1. 核心功能概述

操作工作台提供以下子功能菜单：
1. **终端接入与登录 (WebSSH & Telnet)**：支持在 Web 浏览器内直接发起 SSH/Telnet 会话连接至网络设备，无需使用第三方客户端（如 SecureCRT 或 Putty）。
2. **多因子身份验证 (MFA) 阻断校验**：对于特权或高风险会话，后端将强行阻断连接，直至操作员通过 MFA 二维码验证。
3. **PAM 会话审计与操作录像**：记录所有用户在终端内的输入输出历史，支持会话命令集检索、安全策略审计，并对会话交互进行实时审计记录。

---

## 2. 详细操作步骤

### 2.1 Web 终端登录与连接
1. 进入 **操作工作台 -> 终端接入** 页面。
2. 页面左侧会列出当前在线且支持直连的网络设备列表。
3. 选择目标设备，点击 **“开启终端会话”**。
4. 系统将在右侧生成一个嵌入式终端窗口。后端服务会自动从**凭据中心**拉取加密密码（相关逻辑在 [vault_service.py](file:///e:/data/netsops/backend/services/vault_service.py) 中，由安全算法自动解密），为用户自动填入完成登录，直接展示设备命令行界面（CLI）。

### 2.2 特权会话与 MFA 校验
当接入核心设备或需要进入特权配置模式（如 Cisco 设备的 `enable` 或 Huawei 设备的 `system-view`）时，系统可能会触发安全校验限制：
* **阻断式 MFA**：系统会自动弹出 MFA 验证框。操作员必须使用绑定的 Authenticator App 扫描并输入一次性动态密码 (TOTP) 才能释放凭据。
* 这样能有效避免由于工程师账户被盗导致的非授权操作风险。

### 2.3 PAM 终端行为审计
网络安全审计员可前往 **操作工作台 -> PAM会话审计**：
1. **指令流水记录**：所有执行过的命令均会被记录在审计日志中（例如输入了 `undo shutdown` 或 `configure terminal`），并附带精准的时间戳和操作人。
2. **审计日志检索**：可通过关键字搜索谁在何时执行了高危指令。
3. 代码逻辑请参考会话流审计控制器 [pam.py](file:///e:/data/netsops/backend/api/pam.py)。
