# 业务网段 IP 利用率

## 完成情况
- 利用率页默认请求并展示 `network_scope=business`；页面增加“业务网段 / 全部网段”切换。
- 服务端按 `prefixes.network_type` 在任何利用率/聚合计算之前筛选。业务白名单为 `server`, `user`, `user_access`, `dmz`, `wireless`, `voice`, `storage`, `container`, `vpn`, `vip`；历史 `user` 归一为 `user_access`。
- 业务模式排除 `transit`, `p2p`, `wan`, `loopback`, `management`, `network_service`, `unclassified`、空值和未知类型。UI 显示互联段及其他非业务段排除数；Top 5 显示每段的network_type标签。
- “全部网段”包含已分类和未分类网段。API 不带范围参数时保留历史全量口径，前端通过显式参数默认聚焦业务段。
- 总利用率、容量网段数、分配/剩余 IP、Top 5、站点分组、分配趋势全部使用同一网段范围。原全局Pools/VIPs卡片替换为所选范围内的剩余可分配IP。

## 修改文件
- `backend/services/ipam_service.py`：business用途白名单、范围筛选、范围/互联排除计数、forecast范围一致性、Top 5返回用途。
- `backend/api/ipam.py`：`GET /api/ipam/analytics?network_scope=business|all`；无参数仍为`all`。
- `src/pages/IPVlan/IPUtilizationTab.tsx`：默认业务范围切换、中英文范围说明和用途标签。
- `backend/tests/test_ipam_capacity_and_reconciliation.py`：PG驱动业务/互联/管理/基础设施/未知用途测试。
- `src/pages/IPVlan/IPUtilizationTab.test.tsx`：测试初始业务请求和切换全部后重取数据。
- 配套计划：[plan_20261029_0950_01_业务网段IP利用率.md](../plans/plan_20261029_0950_01_业务网段IP利用率.md)。
