# 关键实现说明

- GLB LED 节点按元数据与节点名识别电源、系统、告警、端口及前后面板；端口灯按物理 `port_index` 和链路状态渲染，正常系统灯保持绿色呼吸，告警由 ALM 灯以琥珀/红色闪烁承载。
- 3D 线缆使用接口运行态着色：UP/光纤为设备本色蓝、UP/铜缆为本色金黄、降级为琥珀、DOWN 为红色；降低发光强度、收窄端点粒子并隐藏未知链路的假流量粒子。
- 同一端点的多条线现在走确定性的微型线束通道；LAG 成员按顺序做轻微高度偏移，悬停单线时其余线降亮度，避免用大量颜色破坏整柜观感。
- 修正 S6800 族 `XGE/FGE/FortyGigE/HGE` 的原生端口号解析：保留 49–54 后缀，紧凑 `QSFP+1..6` 才转换为 49–54，避免 49/53/54 全部落到端口 48。
- `topology_links` 的聚合行展开为真实成员端点（例如 `XGE1/0/49–52`、`GE1/0/1–4`），标签显示 `LLDP · LAG n/m`；缺少成员证据的聚合父接口不再猜测映射到物理端口。
- 拓扑 API 在兼容读模型为空但证据图已有 LLDP 物理边时使用只读物理图回退；同时合并 `interfaces.oper_status`，使线路可反映 UP/DOWN。
- 没有已验证链路时取消 3D 默认示例线缆；底部明确显示“无已验证链路”。
- 修复选中设备打开 Inspector 后抽屉改变 Canvas 尺寸导致镜头跳回整柜的问题；设备近景按设备尺寸计算并保持在机柜外侧。
- 修正监控设备列表分页参数（100，符合 API 上限），恢复 Inspector 的真实 IF-MIB 接口读取。
- Windows 开发后端热重载排除 `backend/tests`，避免测试文件编辑触发 PostgreSQL 初始化期间的 Uvicorn 重启。
- QSFP28 不再直接显示为实心灰色保护盖：保留 GLB 的编号与 anchor，隐藏会遮住腔体的源 cage/slot/lane 层，在前端叠加有深色 cavity、四条内触点、金属四边框和 A/B link 灯的端口组件；只有已验证的 49–54 端口点亮。
- 公共线束改为“真实端口短引 → 面板下沿 clearance → 安装轨内侧汇线”，水平段不再穿越设备面板；端点仍保留精确端口坐标和确定性的 lane offset。线路拆成后方连续段与前方三段式理线段（源端/侧槽/目标端），汇线槽固定在 `x≈±2.5`，面板下沿预留 `0.10` 间隙，避免跑到柜体外侧，其他设备的链路在全线视图仍可见。
- 已验证的 SFP/SFP+ 端点增加插入式模块壳体、拉环和介质色 receptacle；空端口保持开放。同步修正 S6800 双排 SFP 的行序（01–08 下排、09–16 上排），模块、线缆与 GLB cage 共用该坐标。
- 线缆端点从 cage 内部前移到 receptacle，并增加小型深色 boot 与短应力释放段；SFP 光模块用双 LC 孔，QSFP 用窄型端口 boot，避免蓝色方块遮住腔体。
- SFP 光纤端点再细分为两根并行纤芯，分别对准双 LC 孔；普通铜缆/DAC 仍使用单 boot，不会伪装成双芯光纤。
- 跨 U 位线缆在端口短引后立即切换到设备面板后方深度；公共水平段不再从中间设备前面穿过，并将光纤线径收窄以保留端口边框。
- 机柜 GLB 顶盖/状态条的材质不再写入深度缓冲，U41/U42 的设备与线缆不会被顶盖遮掉；顶盖仍保留外观和标签。
- 无显式介质字段时，S6800/S6850 的 1–48 号 SFP 笼依据资产布局归类为光纤；若发现结果明确提供 `copper`/`dac`，仍优先保留显式介质。
- 配线架作为独立被动设备接入：`RackDeviceItem` 对 `patch_panel/配线架` 使用已批准的 CAT6 24 口 GLB，GLB 加载失败时回退到 24 个 RJ45 腔体的 `PatchPanelFaceplate`；当前 JG-02 的 9 台设备清单没有 `patch_panel` 行，因此不会在 3D 中凭空生成一台配线架。
- 机柜用途分类抽成 `rackProfiles.ts`：网络（核心/汇聚/接入/Leaf-Spine/高密度）、服务器、存储、安全、综合、布线、电源/UPS、传输；3D 工具栏显示自动识别的用途标签。JG-02 按现有交换机/防火墙占比识别为“网络设备柜 · 高密度交换机”，不会为了套模板而篡改 U 位或设备角色。

# 剩余风险与后续建议

- 端口活动/速率灯仍以 IF-MIB 与拓扑数据为依据；没有真实接口采样时保持暗态，不生成模拟流量。
- 浏览器控制台仍有历史遗留的重复 key 警告和 THREE.Clock 弃用提示，未扩大本次机柜灯效范围处理。
- 若需要进一步逼真，可在后续资产版本中为不同厂商补充各自端口灯颜色/速率语义映射，并继续保持 LLDP 成员证据优先。
- 新增设备时按 [3D 设备新增经验手册](../rackvision/3d_device_onboarding_playbook.md) 执行资产元数据、端口坐标、灯效、线束和浏览器验收清单。
