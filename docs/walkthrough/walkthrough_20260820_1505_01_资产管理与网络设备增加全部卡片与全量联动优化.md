# 资产管理与网络设备增加“全部”总览卡片与全量联动走查报告

## 1. 任务概述
为 **资产管理**（`/assets/dashboard`）与 **网络设备**（`/assets/network-devices`）两个核心页面的顶部 Bento KPI 卡片组统一增加首位的 **「全部」总览卡片**，实现了未筛选时的默认高亮状态与一键恢复“全部”视图的能力，并彻底解决了底栏 Pagination 分页总数与过滤结果联动不一致的问题。

## 2. 核心修改与实现说明

### 2.1 升级为 5 联 Bento KPI 状态卡片
在资产管理与网络设备页面均升级为 5 列自适应 Bento 卡片布局（`grid-cols-2 md:grid-cols-3 lg:grid-cols-5`）：
1. **「全部资产 / 全部设备」**（`filterVal: 'all'`）：
   - 显示全量资产/设备总数与 100% 比例；
   - **默认激活高亮**（带蓝色微发光选中细外边框与轻底色）；
   - 点击可一键切回“全部”视图；
2. **「P1 · 严重故障 / 离线设备」**（`filterVal: 'critical'` / `'offline'`）；
3. **「P2 · 重要问题 / 告警异常」**（`filterVal: 'major'` / `'warning'`）；
4. **「P3 · 需要关注 / 待投产 / 维护」**（`filterVal: 'warning'` / `'staging_maintenance'`）；
5. **「正常 · 运行正常」**（`filterVal: 'healthy'`）。

### 2.2 状态切换与高亮联动交互
- **状态同步**：
  - 当处于全部视图时，「全部」卡片高亮；
  - 当点击某个特定状态卡片时，对应状态卡片高亮，表格精准过滤；
  - 再次点击当前已高亮的状态卡片，或点击「全部」卡片，立即恢复为全部视图并高亮「全部」卡片。

### 2.3 底栏分页条数精准联动
- 修复了之前过滤后表格仅显示匹配项但 Pagination 依然显示数据库全量条数的问题：
  - 资产管理：`totalItems={severityFilter !== 'all' ? displayAssets.length : total}`
  - 网络设备：`totalItems={quickFilter !== 'all' || tagFilterIds.length > 0 || (inventoryLifecycleFilter && inventoryLifecycleFilter !== 'all') ? displayRows.length : inventoryTotal}`
