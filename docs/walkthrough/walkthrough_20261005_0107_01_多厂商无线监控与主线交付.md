# 多厂商无线监控与主线交付走查

## 结论

按用户要求，本阶段完成 H3C（华三）与 Huawei（华为）无线 AC 的采集、库存与指标链路补齐。H3C 的 Wireless 适配依据厂商官方 HH3C-DOT11 MIB，属于 Nexora 的官方 MIB 扩展；固定 LibreNMS Comware 实现并没有对应 Wireless discovery handler。Huawei 对齐固定 LibreNMS `Vrp.php` 的 AP、Radio、VAP 与 SSID 采集行为，并补入其官方 MIB 的列和索引语义。对信锐官网资料的追加核验找到了 NAC 控制器 OID 汇总表及 SNMP 指南；该资料支持部分标量采集，但不包含完整表列 OID，因此尚未据此宣称信锐明细采集适配完成。

工作区也包含之前已授权的 Comware 硬件发现、资产网络设备列表及专线表单改进；这些改动与无线采集共享服务、测试和 Grafana 集成，本次统一审查交付。未纳入构建输出与临时验证目录。

## 无线覆盖

- H3C：AC 计数；AP 标识、状态、型号/序列号、客户端数、CPU/内存/温度；Radio 状态、信道、发射功率等级、利用率、模式位图、类型与运行代码、绑定 SSID 文本、平均/最大/最小原始信号强度、客户端数及文档定义的错误计数；BSS 客户端数；Station 表的 MAC 索引、IP、用户名、TxRateSet 与 SSID。逐客户端身份与射频绑定属性保存在库存原始值/metadata，不作为高基数 Prometheus 标签。
- Huawei：AP 数；AP 名称、序列号、类型、CPU、内存；Radio 类型位图、信道、接口 MAC、利用率、干扰率、Actual EIRP；按 AP MAC + radio index + WLAN ID 采集 VAP 在线终端数；按 2.4 GHz / 5 GHz SSID 表采集客户端数。SNMP trap 节点不当作 pollable 表。
- 空表、无效哨兵值和不完整 walk 按缺失/partial/failed 处理，不以 0 冒充有效遥测。Huawei Radio MAC 是值字段，行身份使用 AP MAC + Radio ID；H3C AP、Radio、BSS 与 Station 分别按对应 MIB 索引关联。
- 已同步 OID 配置、内置目录迁移、硬件库存轮询和 Wireless Grafana 面板。迁移以 additive/幂等方式并保留管理员对非内置字段的编辑。
