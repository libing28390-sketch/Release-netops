# 服务器删除遥测外键修复走查

## 完成摘要

已修复服务器资产删除因遥测外键阻塞的问题。删除关联设备前会清理服务器遥测明细和小时汇总；新建数据库及已有 PostgreSQL 安装均使用 `ON DELETE CASCADE`。资产管理页单条删除失败会保留确认弹窗并展示安全错误，批量删除会汇总失败项。

## 关键实现说明

1. `_delete_linked_device` 在删除 `devices` 前清理 `device_telemetry_samples` 和 `device_telemetry_hourly`，与现有健康采样清理保持同一事务。
2. `m0218_device_telemetry_delete_cascade` 查询并替换现有设备遥测外键，支持旧约束名称、重复执行和已有真实数据；降级不撤销级联语义，避免回滚应用后重新产生不可删除设备。
3. 基线 schema 同步为级联外键，保证新安装行为一致。
4. 资产管理页改用统一 `apiRequest`，单条删除错误显示在确认弹窗，批量删除错误显示在反馈面板；不直接展示数据库异常细节。
