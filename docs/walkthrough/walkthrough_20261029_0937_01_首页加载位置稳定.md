# 首页加载位置稳定

## 完成摘要
本轮处理用户确认的“电脑浏览器首页卡片轻微上下移动”。修改仅追加到 `src/pages/HomePage.tsx`，保留前轮粒子、宽度与淡入修改，未触及认证、真实数据、部署或其他用户文件。

根因：资产统计加载提示作为额外段落，成功后卸载，导致 4px margin + 16.5px 行高消失。下方 KPI、模块入口、平台和快捷操作实际向上移动 20.5px；在 1440×900 时还使内部滚动条消失，内容横向重新居中 7.5px。上一轮只核对宽度和 transform，未覆盖这一真实布局回流，本轮明确补测几何 x/y。

修正：加载、汇总和错误使用同一个描述段落，窄屏预留两行文本高度；主机/数据库徽标行预留最小高度，避免异步徽标到达时增高。错误文字沿用公共 warning 语义色。无需修改全局滚动或其他页面。
