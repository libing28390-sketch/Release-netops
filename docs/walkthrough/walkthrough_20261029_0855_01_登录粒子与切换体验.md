# 登录粒子与切换体验

## 完成摘要
- 登录背景改为泊松分布的彩色短胶囊粒子，GPU 双缓冲纹理维护位置、尺寸和亮度，鼠标控制带惯性与轻微扰动的双环场。
- 用户指出第一版屏幕空间密集点阵与官网差异大，该版本已撤换。最终采用官网的透视视野、mesh scale、采样间距、粒径比例、蓝红黄色团与双环响应机制，避免尘雾和过密的完整圆环。
- 复现了首页内容宽度随延迟主机资源到达而扩张的问题，补充根容器 `w-full`，同时移除 6 组首页入场位移，保留淡入。
- 无新增依赖；没有改动认证、MFA、验证码、API、浏览器缩放或部署配置。

## 实际修改文件及协作
- `src/components/home/ThreeCyberNetwork.tsx`：登录背景组件入口及不支持 WebGL 时的装饰降级。
- `src/components/home/loginParticleRenderer.ts`：泊松采样、透视相机、GPU ping-pong 模拟、帧率无关的追随、事件与 GPU 资源回收；隐藏页暂停、减少动画偏好静态帧、浮点帧缓冲不支持时的静态场。
- `src/components/home/loginParticleShaders.ts`：模拟与绘制 shader；Luna 提供初稿，主 Agent 修正尺寸范围、双环函数、位移方向与颜色场并集成。
- `src/pages/HomePage.tsx`：Luna 移除首页入场 y 位移；主 Agent 通过浏览器对照发现并修复 flex 子项自动宽度的问题。
- 对应计划：`docs/plans/plan_20261029_0855_01_登录粒子与切换体验.md`。
- 保留用户已有 `.agents/`、`.codex/`、`handoff.md` 和历史构建产物；未提交或推送。

## 关键证据：官网与实现
- 参考页面：https://antigravity.google/ 。读取实际加载的 `MainParticlesComponent.astro_astro_type_script_index_0_lang.BBRcXE3Z.js` 和其共享依赖，确认 Three.js r180、浮点状态纹理、鼠标追随、双环尺寸响应以及短胶囊点绘制。
- 最终没有远程运行时依赖，也没有直接载入官网压缩脚本。项目内独立实现粒子场，噪声采用局部连续 value noise；随机分布与噪声细节并非逐像素复制。
- 原背景 284 个三维几何与连线；最终参考域泊松采样后通过透视视野呈现稀疏粒子，避免第一版向屏幕直接铺满上万个可见点的错误。

## 首页内容扩张：复现与修正
使用实际改前/改后 HomePage 组件，在与 AppMainContent 相同的 flex-column 父布局中挂载；模拟资产汇总与延迟 150ms 到达的主机资源数据，不创建真实会话。

| 观测 | 改前 | 改后 |
| --- | --- | --- |
| 首页首帧宽度 | 852.875px | 1280px |
| 主机资源到达后宽度 | 1023.390625px | 1280px |
| 最大宽度变化 | 170.515625px | 0px |
| 单层入场位移 | 8px | 0px |
| scale 偏离 1 | 0 | 0 |

根因是 flex 子项根容器只有 `max-w-7xl mx-auto`，宽度由内容撑开，主机资源增加后重新布局；不是 browser zoom 或整页 scale。`w-full` 使首页从首帧就占满可用宽度并保持 max-width 限制。清除入场位移后，父子分组也不再从不同起点回位。
