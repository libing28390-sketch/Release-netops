# 关键实现说明

- 移除了 `snmp-exporter` 对 `current_version.json` 的启动等待。
- 默认 `snmp.yml` 增加 `bootstrap_disabled_v2` 占位认证。它不是真实凭据，且默认 target 文件为空，不会向设备发起请求；满足 snmp_exporter v0.26 要求至少存在一个 auth 定义。
- 对已有但尚未发布的旧 runtime 卷，如果仍是 `auths: {}`，后端启动脚本会刷新为新的 bootstrap 配置；带有 `current_version.json` 的已发布配置不会被覆盖。
- 更新部署文档和契约检查，防止未来重新引入阻塞等待或空 auth 配置。

- 如果部署服务器的持久化 runtime 已有损坏且带 `current_version.json`，脚本不会覆盖它；应查看 `docker compose logs --tail=200 snmp-exporter vmagent`，按现有 artifact 回滚流程处理。
- 需要把代码同步到服务器并重建/重建容器；不需要删除 `nexora-monitoring-artifacts` 或数据库卷。
