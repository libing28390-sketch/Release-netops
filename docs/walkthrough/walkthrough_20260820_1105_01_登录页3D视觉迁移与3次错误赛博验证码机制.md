## 3. 核心实现与关键逻辑

### 3.1 赛博暗黑霓虹矢量验证码（方案 A）
- **高颜值矢量 SVG 生成**：
  - 字符集去除易混淆字符（`0/O/1/I`），生成 4 位高对比度字母数字组合；
  - 配备 Cyan（`#06b6d4`）、Indigo（`#818cf8`）、Emerald（`#10b981`）、Sky（`#38bdf8`）四色微发光滤镜；
  - 动态叠加背景暗调网格、2 条贝塞尔光流曲线与 24 颗随机辉光粒子点；
- **安全核销机制**：
  - 内存短期缓存 `_captcha_cache`，有效期 5 分钟（300s）；
  - 单次验证后立即 `pop()` 核销，防止重放攻击。

### 3.2 输错 3 次拦截与成功清零
- 在 `POST /api/login` 中：
  1. 密码验证前先查询该用户在 `login_failures` 中的历史失败次数；
  2. 若 `count >= 3`，必须提供 `captcha_id` 和 `captcha_code` 并通过 `_verify_captcha()`，否则直接返回 HTTP 400 与 `X-Captcha-Required`；
  3. 验证码通过且密码正确后，立即调用 `_clear_login_failures(safe_username)`，彻底清除数据库中的锁定与失败计数；
  4. 若密码依然错误，则递增计数并继续要求验证码。

### 3.3 登录页 3D 视觉展示
- 登录页面左侧区域由原先的静态 SVG 连线升级为完整的 3D 赛博网络视界，包含可拖拽交互的三维地球、节点探针与星环；
- 登录成功后的主控制台（`HomePage.tsx`）保持整洁高密度的指标卡和 12 宫格模块导航，兼顾登录前的视觉震撼与登录后的运维操作效率。

## 5. 剩余风险与后续建议
- **内存清理**：当前验证码使用带有 TTL 的内存字典 `_captcha_cache`，在单节点及小型集群上性能极高且无依赖；若后续进行多副本分布式部署，可无缝对接 Redis 缓存。
