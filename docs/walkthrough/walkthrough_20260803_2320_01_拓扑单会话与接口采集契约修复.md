# 拓扑单会话与接口采集契约修复 Walkthrough

## 变更结果

- `PlatformActionSession` 在 `backend/services/platform_registry_service.py` 中持有一个 Driver 上下文；`execute_platform_action` 仍以动作粒度加载发布版本、校验命令和模板、解析回显、写入审计，只把网络发送切换到共享会话。
- `backend/services/topology_service.py` 在同一设备上先复用会话执行 LLDP，再复用该会话执行 Eth-Trunk；拓扑不再额外执行 `display interface brief`。
- `backend/database/migrations/m0094_repair_huawei_eth_trunk_command.py` 将 Huawei SYSTEM 发布动作的旧缩写修复为 `display eth-trunk`，并重算动作及发布版本校验和，迁移可重复执行。
- `backend/services/interface_collection_service.py` 和 `src/pages/CmdbManagementTab.tsx` 恢复有 IP 接口投影契约；无 IP 物理端点不再冒充 CMDB 的 L3 接口记录。
- `src/App.tsx` 与 `src/pages/AlertMaintenanceTab.tsx` 的共享用户查询统一携带认证头，登录状态未就绪时不再发匿名请求。
- `docs/architecture/network_collection_session_reuse_standard.md` 固化后续采集、巡检和自动化任务的会话复用边界。

## 运行时预期

对绑定平台注册的拓扑设备，日志应表现为每台设备一次登录、连续执行 `display lldp neighbor brief` 和 `display eth-trunk`，而不是每条动作各自重新连接。动作仍分别记录命令耗时、解析状态和审计信息；若单条命令失败，后续只读动作按策略继续执行。
