### 硬件导出合成测量

专用 PostgreSQL 中创建5,296条 active sensors，分布在17台合成设备上；执行30次 `/hardware-metrics` 完整处理。handler wall time 的 p50/p95/max 为 **1,057.63 / 1,245.80 / 1,248.33 ms**，响应 **8,364,096 bytes**，30次输出完全一致。该环境 `EXPLAIN (ANALYZE, BUFFERS)` 执行时间 **24.72 ms**；分段日志显示耗时主要在指标文本渲染，传感器 SQL 查询明显更短。

这个数据集验证了当前代码在本机隔离环境中处理该数量级传感器的输出正确性和耗时，不代表生产机器的冷缓存、CPU 或真实传感器标签结构。不能拿它与此前生产 p95 4.10 秒直接作性能提升结论。
