# 仪表盘平台分布统计完成记录

## 完成摘要

总览页的平台图现与资产 KPI 使用同一份 `/api/assets/summary` 数据：总数按网络设备和服务器计算，平台计数来自同口径的 `by_platform`。解析时校验各平台计数之和与总数一致；不一致时保留资产总数，并显示平台分布不可用，避免再呈现被 200 条列表上限截断的数据。

环图使用实际平台台数绘制，平台明细显示台数和一位小数百分比。标题计数改为“台纳管”，不再把未按在线状态筛选的数组长度说成“台在网”。平台清单仅为已知网络设备平台保留设备列表跳转。

## 关键实现说明

- 新增平台汇总解析，拒绝非安全整数、负数及合计不等于总量的响应。
- Zustand store 在载入、重置和旧式总数 setter 路径中同步管理平台计数和解析错误状态。
- AppMainContent 将平台编码映射为显示名、颜色、台数、比例，并仅将已知网络平台设为可跳转项。
- DashboardTab 的图中心总数使用资产汇总的 `assetsTotal`，切片使用原始数量；空数据、加载中和汇总错误均有明确显示。
