# 移除网络设备新增功能

## 完成摘要

已从 `/assets/network-devices` 移除“添加设备”入口，并删除只服务于该入口的创建弹窗、POST 提交处理、创建表单状态和新增专用的生命周期确认分支。首页“添加网络设备”快捷入口现在进入资产台账；资产台账自身的“新增”功能保留。设备编辑仍可用。

- `src/pages/InventoryDevicesTab.tsx`
- `src/pages/HomePage.tsx`
- `src/components/AppMainContent.tsx`
- `src/contexts/AppDomainContext.tsx`
- `src/App.tsx`
- `src/components/modals/AppModals.tsx`
- `src/components/DeviceFormModal.tsx`
- `src/components/DeviceFormModal.test.tsx`
- `src/hooks/useDeviceFormActions.ts`
- `src/hooks/useDeviceFormActions.test.ts`

## 关键实现说明

- 页面不再接收新增弹窗 setter，顶部操作区中的新增入口删除；筛选行里的刷新和列设置仍保留。
- `DeviceFormModal` 收窄为编辑模式，`useDeviceFormActions` 不再提交 `POST /api/devices`。
- 清理新增状态的上下文传递与投产确认分支；编辑请求和管理员绑定错误提示保持原行为。
- 首页快捷入口从网络设备列表移到资产台账，用户仍可通过统一的新增资产流程创建网络设备。

## 剩余风险与回滚方式

- 后端 `/api/devices` 创建接口未删除，以免改变接口层契约；前端此页面和旧全局弹窗已不再调用它。
- 若需要恢复旧入口，可从该任务改动恢复 `InventoryDevicesTab` 按钮及 `useDeviceFormActions` 新增分支、弹窗状态传递；其他编辑逻辑无需回滚。
