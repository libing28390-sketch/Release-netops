## 1. 核心问题与解决方案

### 1.1 修复跳过快照选择页面的业务流程 Bug
- **原问题**: 原代码在设备列表中点击设备时，错误地在后台设置了 `autoCompare = true`，自动用最新的 2 份快照直接跳入 Diff 对比视窗（图二），用户无法看到快照时间轴（图三），必须点击“重选”才能挑选。
- **解决方案**:
  - `loadSnapshots` 与 `handleSelectDevice` 默认改为 `autoCompare = false`；
  - 用户点击设备行时，正常进入「Step 2 快照选择页面（图三）」，并在 A / B 槽位中**默认预填最新两份快照**，用户既能自由查看/切换所有历史快照、也能一键选择「启动配置 vs 运行配置」或「最新两次」，点击「开始对比 (A vs B)」进入对比；
  - 并在设备列表右侧额外提供 `[⚡ 对比最新]` 快捷按钮，满足老用户 1 步直达对比的需求。

### 1.2 Step 1（设备选择页）空间压缩与扁平化
- 移除上方占高 ~100px 的独立 `PageHero`；
- 移除占高且信息冗余的 3 个空旷指标卡（“可审计设备”、“当前页结果”、“对比方式”）；
- 整合为高度仅 ~42px 的极简工具条（设备总数胶囊、搜索框、模式切换、资产树折叠）；
- 资产树与设备表格高度全面撑满屏幕，可视设备行数提升 300% 以上。

### 1.3 Step 2（快照选择页）空间压缩与扁平化
- 顶栏精简为 ~40px 紧凑栏（返回设备列表、设备元信息、启动vs运行、快速对比最新、开始对比主按钮）；
- A / B 槽位由原先的大卡片收敛为 ~42px 的紧凑胶囊槽位条；
- 快照时间轴撑满剩余全部可用高度。
