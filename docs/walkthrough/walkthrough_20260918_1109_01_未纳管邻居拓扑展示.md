# 未纳管邻居拓扑展示与告警分级走查报告

## 1. 完成摘要
针对本地网络拓扑中存在未纳管邻居（如 `R1 <-> core-sw-02`、`R2 <-> core-sw-01`）导致页面 `links = 0`、错误将未纳管设备计入告警造成流水线显示为 `degraded（需要关注）` 的问题，已完成全链路端到端闭环修复：
1. **后端告警分级**：将未纳管邻居标记为 `severity: 'info'` 与 `blocking: False`，流水线在仅存在未受管邻居时保持 `healthy（证据正常）`，不再误报拓扑故障。
2. **前端数据模型打通**：前端正式接入 API 返回的 `unmanaged_nodes` 和 `unmanaged_links`，将未纳管外部设备加入画布，并分别统计 `managedLinkCount`（管理链路）与 `externalLinkCount`（外部链路）。
3. **指标栏与告警分层 UI**：
   - 顶部指标栏细分呈现“管理链路”与“外部链路”，使运维人员清楚看到实际发现到的外部邻接链路（例如管理链路 0、外部链路 2）。
   - 流水线提示区域使用信息态（`<Info />`）灰色徽章展示 `未纳管邻居 · 2`，替换原先的红色/黄色故障感叹号。
4. **画布视觉与详情抽屉**：
   - 未纳管外部链路渲染为柔和中性色（`#94a3b8`）与 `4,3` 虚线，避免与高带宽内部受管链路混淆。
   - 未纳管节点统一标注“外部”徽标与状态，点击节点抽屉清晰提示该设备由 LLDP 发现但尚未录入 CMDB，避免误点设备详情或监控中心触发异常。

## 3. 关键实现说明
### 3.1 后端服务：告警分级与健康度计算
在 `get_topology_generation_status` 中为未匹配邻居标记非阻塞信息：
```python
if unmatched_observations:
    warnings.append({
        'code': 'unmanaged_neighbors',
        'count': unmatched_observations,
        'message': 'Some neighbors are not present in managed device inventory.',
        'severity': 'info',
        'blocking': False,
    })
blocking_warnings = [item for item in warnings if item.get('blocking', True)]
# 仅当存在真实阻塞型 warning（如链路陈旧等）时才判定为 degraded
'health': 'empty' if total_observations == 0 else ('degraded' if blocking_warnings else 'healthy')
```

### 3.2 前端数据接入与指标分层
- 在 [src/hooks/useTopology.ts](file:///d:/nexora/nexora-private/src/hooks/useTopology.ts) 中将外部节点与虚拟链路注入渲染模型，计算 `managedLinkCount` 和 `externalLinkCount`。
- 在 [src/pages/TopologyPage.tsx](file:///d:/nexora/nexora-private/src/pages/TopologyPage.tsx) 指标栏明确区分：
  - `管理链路`（数值为 `managedLinkCount`，本场景下为 0）
  - `外部链路`（数值为 `externalLinkCount`，本场景下为 2）
- 顶部警告条识别 `warning.blocking === false`，以优雅的 `<Info />` 徽章展示 `未纳管邻居 · 2`。

### 3.3 画布渲染与抽屉交互优化
- 在 [src/components/TopologyGraph.tsx](file:///d:/nexora/nexora-private/src/components/TopologyGraph.tsx) 中，未纳管链路使用 `#94a3b8` 与 `4,3` 虚线，未纳管节点使用“外部”层级色调与状态标识。
- 在 [src/components/TopologyInspectorPanel.tsx](file:///d:/nexora/nexora-private/src/components/TopologyInspectorPanel.tsx) 中，选中未纳管节点时友好展示“此设备由 LLDP 邻居发现观测到，尚未录入 CMDB”的指引卡片。
