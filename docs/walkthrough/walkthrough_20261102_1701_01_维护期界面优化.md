# 维护期创建与列表视觉优化

## 改动

- 创建、资源选择和详情弹窗统一使用 `FormDialogShell`；表单使用 `FormSection`、`TextField`、`SelectField`、`ActionButton`。
- 列表工具栏使用 `ListToolbar`、`ListSearchInput`，与 `AlertDeskTab` 使用相同的页面骨架和共享样式。
- 表格和分页铺满面板；操作按钮使用告警中心相同的 `TableActionCell` / `ActionIconGroup`，移除维护期专有的图标组外框。
- 列表按用户要求拆为八列：维护期、描述、执行目标、开始时间、结束时间、状态、创建人、操作；保留详情、复制、删除、搜索、状态筛选、导出和分页。
- 创建成功后关闭创建弹窗并刷新列表，不再自动打开新建维护期的详情弹窗。
- 只调整 `src/pages/AlertMaintenanceTab.tsx` 的维护期呈现。接口、验证、权限和业务操作保持原有行为。
