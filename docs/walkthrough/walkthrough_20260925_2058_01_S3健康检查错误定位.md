## 关键实现说明
- 对 Botocore 错误只输出通过字符白名单校验的错误码及 100–599 状态码；不返回异常正文、服务端原始消息或凭据。
- S3 连接测试 API 原样保留健康检查返回的脱敏说明，便于管理页面展示。
- 移除 S3 区域环境变量；仅 Environment 配置固定使用 `us-east-1`。数据库存储配置仍保留既有 region 属性兼容性。
