## 平台与命令契约核对

表格标签按现有代码别名归一如下：

| 表格标签 | canonical platform | 核对结论 |
|---|---|---|
| `ruijie_os` | `ruijie_rgos` | 别名链路存在；表格含 `show interface status`，注册表同时有 `show interface brief`/`show interfaces status`，需确认是否按别名兼容或补充动作契约。 |
| `DPTech` | `dptech_ios` | 别名链路存在；基础 ARP/VLAN/接口/日志/时钟模板可见，BGP/OSPF/运行配置等表内命令不在当前发布动作集合。 |
| `MyPower` | `maipu` | 别名链路存在；基础接口/邻居/MAC/光模块/环境/风扇/电源模板可见，BGP 使用 `neighbors` 还是平台注册的 `summary` 仍需确认。 |
| `中兴 ZXROS` | `zte_zxros` | 别名链路存在；LLDP、MAC、路由、光模块、温度、日志等模板可见；表内 `show environment` 和 `show running-config` 不在当前发布动作集合。 |

需要单独决策的命令差异（不等同于代码缺陷）：

- 锐捷/迪普/迈普的 MAC 命令在表格中使用连字符形式（如 `mac-address`），平台注册动作/模板命名存在空格形式或别名形式；应由平台契约明确规范化规则。
- 锐捷表格包含 `show clock`、`show environment`、`show ip nat translations`、`show running-config`，但这些并非当前 `ruijie_rgos` 发布动作的完整集合。
- 迪普表格包含 BGP、OSPF、CPU-usage、接口 counters、running-config；当前动作目录只发布基础采集项，不能直接从 Excel 推导为已开放动作。
- 迈普表格包含 BGP/OSPF、设备信息、温度告警、日志、running-config；当前动作目录的 BGP 命令是 `show ip bgp summary`，需确认设备族差异后再决定是否纳入。
- 中兴表格的 `show temperature detail`、`show opticalinfo brief`、`show logging buffer almlog` 与当前目录一致；`show environment` 是未支持行且有一行空回显，应继续保持禁用。
