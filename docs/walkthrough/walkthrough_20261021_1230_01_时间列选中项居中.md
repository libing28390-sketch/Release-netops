# 日期时间选择器选中项居中

- 日期：2026-10-21（Asia/Shanghai）
- 对应计划：`docs/plans/plan_20261021_1230_01_时间列选中项居中.md`

## 完成摘要

修复小时/分钟选中项错位与切换时间时整列突然跳动的问题。首次打开时即时精确居中，切换时间时平滑滚到中心；首尾值仍可居中。

## 根因与修改

- `TimeColumn` 原先按固定 32px 行高推算位置；窄屏全局规则将按钮最小高度提高至 36px，导致选中值错位。曾为修正对齐问题而直接赋值 `scrollTop`，使列表整列跳动。
- `src/components/DateTimePicker.tsx` 现在依据选中按钮和滚动容器的真实 DOM 几何计算目标位置。首次定位使用即时滚动，后续时间变化使用 `scrollTo({ behavior: "smooth" })`，同时遵从 `prefers-reduced-motion`。列表上下留白让首尾值也可居中；选中按钮只过渡颜色。
- `src/components/DateTimePicker.test.ts` 覆盖 32px/36px 行高与首、中、尾值；`src/components/DateTimePicker.interaction.test.tsx` 验证首次打开即时定位及切换小时、分钟后平滑居中。
