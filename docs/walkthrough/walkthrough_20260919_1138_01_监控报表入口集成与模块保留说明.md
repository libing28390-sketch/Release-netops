## 2. “生成报表”功能入口迁移与落地

生成报表作为企业级网络运维的核心场景，现已作为**一等公民功能**正式迁移并集成到用户最常用、最核心的入口中：

1. **左侧侧边栏【实时监控】菜单组**：
   - 正式上线【监控报表】（`Monitoring Reports`）独立菜单项，位于【监控大盘】后。
   - 路径为 `/monitor/reports`，图标采用清晰直观的 `FileSpreadsheet` 绿色工作表图标。
2. **【运营总览】(Overview / DashboardTab) 页面**：
   - 在 PageHero 顶部快捷操作栏中，新增了墨绿色主题的【📥 生成报表】按钮。
   - 无论运维主管或值班人员在查看总览时，均可一键直达报表导出中心。
3. **报表中心能力升级 (`MonitoringReportsPage`)**：
   - 提供 3 套权威企业级多工作表报表：
     - 《全网接口流量与利用率报表》（含接口清单、流量统计、高负荷预警、错包丢弃排行 4 个 Sheet）
     - 《网络设备运行与资源负荷报表》（含设备运行清单、高负荷告警 Top N 2 个 Sheet）
     - 《互联网出口与 WAN 链路运行报表》（出口链路与探针健康）
   - 支持一键导出 `.xlsx` 格式（带深海蓝商务表头、斑马纹底色、冻结首行、自适应列宽）和 `.csv` 格式（注入 `\uFEFF` UTF-8 BOM，彻底解决 Windows Excel 中文乱码）。
   - 内置“Grafana 原生临时排障数据导出指引”，为高级时序指标排查提供操作参考。
