# 3D机柜模块化面板、精准端口接线与防遮挡重构 走查报告

## 任务完成摘要

针对用户提出的“线缆与名称遮挡面板”、“端口数量与实际不同且未区分管理口/业务口/USB口/Console口”、“线缆插入的端口位置与实际不符”等问题，进行了工业级面板物理结构重构与精准三维走线算法升级：

1. **三维真实端口精准定位与下挂理线算法（`RackCableLayer.tsx`）**：
   - 根据接口名称自动精准解析其物理位置：
     - `10GE1/0/20` 精准定位在第 10 列上排端口（$X = +0.65$）；
     - `10GE1/0/5` 精准定位在第 2 列下排端口（$X = -0.15$）；
     - `MGMT` 精准插入左侧带黄色标贴的带外网口（$X = -1.05$）；
     - `100GE1/0/1` 精准插入右侧 QSFP28 高速上联笼（$X = +1.25$）；
   - **下挂理线防遮挡**：跳线出端口后向前探出 15cm，垂直下落至机箱下沿线槽（$Y - 0.16$），横向走线均在设备字符下方通过，彻底杜绝横穿遮挡设备名、厂商名和铭牌。
2. **企业级 3 模块真实物理面板重构（`textures.ts` / `SwitchFaceplate.tsx`）**：
   - **模块 1：控制与带外管理区（左侧）**：
     - 铭牌区：主机名、厂商、型号、3D 物理发光 PWR（电源）与 SYS（系统）指示灯；
     - 专属端口：带黄标与绿灯的 **MGMT RJ45 管理口**、带青色标的 **CONSOLE 控制口**、蓝芯 **USB 3.0 接口**；
   - **模块 2：业务流量端口区（中间）**：
     - 24 个业务端口按照 4 口一组（Quad-Block）呈现真实两排阵列，仅真实 UP 口亮绿灯；
   - **模块 3：高速上联区（右侧）**：
     - 4 个 40G/100G QSFP28 笼位带拉环与专属编号。
3. **悬浮 3D 标牌外延与交互 HUD 升级（`RackCableLayer.tsx` / `RackDeviceTooltip.tsx`）**：
   - 3D 链路信息标牌固定在机柜左侧 $X = -3.8$ 的安全空白区域，不再与机柜本体发生任何视角重叠；
   - 右下角设备看板独立展示【MGMT / CONSOLE / USB】状态模块与【24× 业务端口矩阵】，数据与真实 SNMP (IF-MIB) 完全对应。
