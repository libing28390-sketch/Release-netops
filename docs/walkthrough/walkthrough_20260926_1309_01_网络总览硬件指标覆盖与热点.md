## 完成摘要

01 网络总览不再把 CPU、内存和温度作为全设备时间趋势呈现。原三块替换为在线设备中 CPU、内存、温度指标覆盖设备数；新增逐设备 CPU 使用率和内存使用率 Top10 即时表。CPU/内存仍使用已有的多厂商归一化查询，按设备列值，不计算跨设备平均值。

## 剩余风险与后续建议

- CPU/内存覆盖数为 0 表示当前在线设备没有匹配到现有标准指标样本；具体是设备不支持还是采集缺失，需结合厂商和设备型号继续核查。
- CPU/内存 Top10 展示相对排行，不等于故障；如需红黄告警，应按设备类型制定有依据的阈值。
- 不同设备温度传感器和阈值语义不同，当前总览不做统一温度异常判断。
- 回滚时恢复 Overview 原三个资源时间序列面板和位置，再运行生成器。
