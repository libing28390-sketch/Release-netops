# 告警主机站点信息走查记录

## 完成摘要

告警中心与历史告警的列表和详情现在都通过 CMDB 站点目录把告警记录中的站点标识映射为 `site_name`。无法解析时显示“未分配站点”，不会回显内部站点 ID。主机名和 IP 沿用告警 API 原有字段。

## 关键实现说明

- 告警列表和详情响应增加 `site_id`，不在告警 SQL 中重复查询站点名称。
- 前端 `AlertRecord` 增加 `site_id`；共享 hook 复用 `listSites()`，表格和详情按 `site_id/site/site_code` 查目录中的 `site_name`。解析失败时显示中英文占位文案，不回退显示标识符。
