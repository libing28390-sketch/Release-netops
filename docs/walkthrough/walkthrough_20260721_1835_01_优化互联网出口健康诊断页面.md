# 优化互联网出口健康诊断页面 验证报告

## 完成摘要

本次优化针对用户反馈的 10 个核心痛点进行了全方位整改，修正了监测语义和数据表达，完成了页面从“视觉上完成”到“监控逻辑可信”的提升。

### 核心改进

1. **6 栏高密度摘要卡片**：
   - 将顶部卡片重构为 6 栏紧凑布局（综合状态、网络连通性、公网出口 IP、IP 合规状态、时延指标、检测状态），相比原 5 卡片压缩了 20% 高度，大幅提升页面信息密度。
   - IP 合规状态卡片：支持在规则有多条时点击展示详细期望白名单规则对话框。
   - 检测状态卡片：集成动态倒计时组件，精确至秒（如：`下次检测: 42 秒后`）。若监测中断（如后端离线超过 3 分钟），将高亮渲染 `数据中断 Xm` 警告。

2. **状态一致性与合规解耦**：
   - 区分显示“综合状态”与“网络连通性”以及“IP合规状态”。即使在防抖确定的 1st 周期（`public_ip_changed = False`）也能在卡片上及警告横幅中实时呈现“不匹配”的具体细节，避免状态矛盾。

3. **双轴图表高级视觉表现与去燥**：
   - **空洞断线表示**：增加数据空洞自动填充机制（大于 3 分钟自动补 `null`），使折线在断档处**物理断开**，且时间轴等距分布。
   - **隐藏常态点 (Hover 显现)**：默认隐藏折线上的所有圆圈采样点，鼠标悬浮时仅通过 hover 状态下的活跃点定位，使界面清爽度大幅提升。
   - **异常 ReferenceArea 区间**：可用率低于 100% 时，自动在该时间戳对应的 X 轴区间渲染一条淡黄色（总体图）/淡红色（单指标图）透明背景指示带（`<ReferenceArea>`），方便运维人员一眼定位故障发生时段，代替原本杂乱的红色圆圈点。
   - **避免 100% 曲线贴顶**：将可用率/结果 Y 轴最大值 domain 设为 110%，但 Y 轴 ticks 固定保留 `[0, 25, 50, 75, 100]`，使 100% 可用率折线在顶部留出 10% 高度的 Padding。
   - **蓝/紫色面积透明度调优**：渐变面积图的不透明度从 25% 减淡到 12% 左右，展现更加干净、专业的高端 APM 软件（如 Datadog）质感。
   - **富图例与 Tooltip 单位详情**：
     - 图例增加单位：`平均时延(ms)`、`可用率(%)`。
     - Hover 框不仅有毛玻璃模糊效果，还会显示当前节点的 `成功目标数 / 总数` 详情（如 `9 / 10`）。

4. **高级指标返回**：
   - 后端 `get_outbound_status` 计算最近一次拨测的 `p95_latency_ms` 与 `max_latency_ms`，并提供状态维持时长 `status_duration_seconds` 的计算。

5. **配色优化与中文化**：
   - 彻底将后端的 "X of Y targets available" 翻译为 "X / Y 个目标可用"。
   - 将“降级 (Degraded)” 状态配色由深橙色细调为黄色（`text-yellow-600 bg-yellow-50/40 border-yellow-200`），保证视觉告警级别的准确性。

## 剩余风险与后续建议

- 客户端实时倒计时取自本地时钟与 API 倒计时，若本地时钟存在明显偏差可能导致倒计时略微抖动。建议在极严格的生产环境中使用 NTP 同步服务器时间。
