# 凭据轮换页面密度改版完成记录

## 完成摘要

- 凭据轮换页从 20 列宽表调整为凭据组、设备、平台和账号类型摘要；完整状态、轮换日期、到期时间和管理 IP 按需展开。
- 账号类型筛选会同步收窄可见列；查看、复制、轮换、导出、分页和管理员权限仍沿用原有逻辑。
- 关联设备摘要最多展示两个名称，更多设备显示 `+N`；完整清单改为独立抽屉，支持名称/IP 搜索、平台筛选和分页，默认每页 20 条。
- 共享凭据设备清单通过管理员只读 API 在服务端搜索和分页，每次只返回一页设备元数据；未绑定的设备本地组仍只包含单台设备。
- 统计卡改为低饱和度摘要样式，临期或过期数量大于零时才使用警示色；顶部说明压缩为单行提示。
- 应用栏标题与页面标题统一为“凭据轮换”。

## 关键实现说明

- 主表保留分组摘要和账号操作卡片；展开行提供各账号类型的用户名、设备数、状态、最近轮换、到期时间和设备摘要。
- 设备抽屉只渲染当前页，默认 20 条、最多 100 条；共享凭据的关键词、平台和分页参数由后端 SQL 处理，关闭或切换查询会取消前一请求。
- 新增的设备查询接口仅返回 `id`、设备名、管理 IP、平台和分页元数据，不返回密码、Token 或凭据字段；接口沿用管理员鉴权。
- 共享凭据和设备本地凭据继续调用原有查看、复制、更新/轮换处理函数；没有触发任何查看秘密、复制秘密或真实密码轮换操作。
- 导出仍使用完整 `rotationExportData`，不受屏幕摘要列变化影响。
