# IPAM 网段与地址池合并走查

## 完成摘要

- 地址池管理已嵌入网段管理：在网段列表或层次视图中可打开该网段的地址池弹窗，列表与新建表单固定在当前网段。
- 地址池 API 支持按 `prefix_id` 过滤；创建和修改时校验所属网段、地址族、起止顺序、CIDR 范围和同网段范围重叠。
- 侧栏不再展示独立地址池或 DHCP 租约入口。旧页面路由、DHCP 租约数据表和 CRUD API 保留。
- DHCP 租约没有接入 IP 清单、地址池使用量或容量统计；本次没有增加数据库字段、迁移或租约回填。

## 实际修改文件

- `backend/api/ipam.py`：地址池查询接受可选 `prefix_id`；创建和更新时将范围校验错误映射为 HTTP 409。
- `backend/services/ipam_service.py`：增加地址池范围校验、按网段筛选及地址池内已登记 IP 使用量统计。
- `src/components/AppSidebar/navConfig.ts`：移除独立地址池和 DHCP 租约导航项，保留地址空间与工作台分组。
- `src/pages/IPAMManagementTab.tsx`：在地址相关页面共享当前网段上下文，并继续保留旧地址池和 DHCP 页面路由渲染。
- `src/pages/IPVlan/PrefixManagementTab.tsx`：在网段行操作中增加“分配范围 / 地址池”入口和网段范围弹窗。
- `src/pages/IPVlan/IPPoolTab.tsx`：支持嵌入网段弹窗、固定当前网段、按网段过滤列表与导出；原独立页面兼容入口仍可使用。

## 关键实现说明

- 地址池仍是网段内的一段连续地址范围，不与整个 CIDR 网段混成同一条记录。
- 地址池必须关联已存在的网段。起止地址必须与网段同为 IPv4 或 IPv6、顺序有效并且都落在该网段内；同一网段中的地址池不能互相重叠。
- 地址池使用量从该网段内有效的 IPAM 地址记录计算；人工 DHCP 租约不参与计数或自动分配。
- 隐藏 DHCP 菜单仅影响导航展示。租约历史数据、`/api/ipam/leases` CRUD API 和旧页面渲染分支保留，未来接入 DHCP 服务器时仍可继续使用。

## 剩余风险与回滚方式

- 既有地址池如果包含越界或重叠范围，修改这些池时会被新校验拒绝，需要先整理冲突数据。
- 未来若要把 DHCP 租约用于地址库存或利用率，必须先接入 DHCP 服务器同步并明确租约有效期、来源和冲突优先级。
- 若需恢复菜单入口，可在 `src/components/AppSidebar/navConfig.ts` 中恢复相应导航节点；本次没有删除数据库记录或 API，代码回退无需数据迁移。
