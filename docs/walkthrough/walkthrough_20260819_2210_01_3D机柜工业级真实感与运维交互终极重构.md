# 3D 机柜工业级真实感与运维交互终极重构 走查报告

## 任务完成摘要

全面贯彻**“第一眼像真的，第二眼看得懂，第三步能操作，第四步能排障”**（70% 工业真实 + 20% 运维信息 + 10% 科技感）的工程准则，完成了 3D 机柜孪生模块的工业级重构：

1. **真实工业金属机柜与精准比例**：
   - 严格遵循 EIA-310-D 标准与 1U = 44.45mm 物理比例，机柜外形与内部 19 英寸导轨比例协调真实。
   - 彻底摒弃粗暴的游戏/赛博朋克大屏风格与全身通体刷色，采用深炭灰/枪灰冷轧钢（`#1e293b` ~ `#283344`），搭配柔和冷白顶棚主光与微弱环境漫反射，呈现拉丝金属、棱角倒角与导轨方孔质感。
2. **前后物理面板真实分流 (Front vs Rear)**：
   - **正面**：交换机密集 RJ45/SFP+ 万兆接口阵列、服务器 SAS/SATA 热插拔硬盘仓、电源按键、左右金属挂耳与简洁设备铭牌。
   - **背面**：双冗余热插拔 PSU 交流电源模块（带拉手与 AC 插座）、风扇排风蜂窝格栅模块、Rear MGMT/Console 维护口及接地铜螺栓。
3. **精准克制的状态指示灯与选中微拉出 (Micro Pull-Out)**：
   - **小而准的状态 LED**：正常绿灯（`#22c55e`）、警告橙灯（`#f59e0b`）、严重红灯（`#ef4444`）、离线灰灯（`#64748b`）。
   - **选中抽拉**：点击设备后，设备沿 Z 轴**向前平滑拉出 6cm**，同时未选中设备亮度轻微降低至 75%，并附带细线青蓝轮廓高亮，凸显工业滑轨质感。
4. **文字克制与信息分级架构**：
   - 3D 表面仅保留大号设备名与型号标牌（如 `CORE-SW01` / `CE6885`），坚决不做“3D Excel”；
   - 鼠标悬停展示紧凑 4 行卡片（设备名、型号、U位区间、健康状态、管理 IP/功耗）；
   - 点击设备联动滑出右侧 CMDB 资产与网络运维 Drawer。
5. **门默认打开 100°**：
   - 默认打开 100°，确保第一眼清晰看到内部所有设备与空 U 层次，支持一键关门查看全貌。
6. **设备快捷搜索飞镜头**：
   - 顶部搜索框支持模糊查找设备名、IP、型号，选择后相机平滑飞至目标设备前方微俯视角并触发拉出。
7. **纯净 3D 视口与底部健康状态条**：
   - 3D 画布保持干净无干扰，底部常驻设备健康统计栏（`● 正常 36   ▲ 警告 2   ■ 严重 1   ○ 离线 0`）。
