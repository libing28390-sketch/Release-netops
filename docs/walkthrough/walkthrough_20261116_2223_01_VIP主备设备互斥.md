# VIP 主备设备互斥走查

## 完成摘要

- 备用设备候选会排除当前主设备；主设备改选为当前备用设备时，备用值自动清空。
- 表单提交时再次检查主备设备 ID，重复时显示“绑定控制主设备和备用设备不能选择同一台设备”。
- `create_vip` 与 `update_vip` 服务层共用相同校验，防止 API 或其他调用路径写入相同设备组合；API 已将 `ValueError` 映射为 409。
- 编辑时可清除可选主/备用设备；空字符串在服务层写为 SQL `NULL`。
- 没有修改 API 字段或数据库结构。

## 实际修改文件

- `src/pages/IPVlan/VIPManagementTab.tsx`：过滤备用设备选项、自动清空冲突选择并在保存前拦截。
- `backend/services/ipam_service.py`：创建/更新 VIP 时验证主备设备不同，并规范化被清除的设备字段。
- `docs/plans/plan_20261116_2223_01_VIP主备设备互斥.md`。
