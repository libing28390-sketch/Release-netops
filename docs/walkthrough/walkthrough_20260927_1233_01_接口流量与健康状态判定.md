# 接口流量与健康状态判定

## 完成摘要

04 接口流量与健康仪表盘已区分流量统计与接口状态：流量及利用率只计算管理启用、运行 UP 的接口；状态表展示管理状态与运行状态，默认隐藏明确的管理员停用端口。管理启用但运行 DOWN 的端口仍会列出并作为异常候选。状态表保留 UP 绿色、down 红色背景填充。

状态表增加“接口范围”选项：默认“隐藏管理停用”，选择“显示管理停用”时可查看 ifAdminStatus=2 的端口。Flap 和最近状态变化视图也过滤掉管理员停用接口。
