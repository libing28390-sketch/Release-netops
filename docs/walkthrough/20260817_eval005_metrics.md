# EVAL-005 评测指标

## 目标

定义并实现后续评测共用的 Recall@K、Precision@K、MRR、NDCG@K 和 Entity Resolution Accuracy，避免每个质量门禁自行解释指标。

## 定义

- Recall@K：`|unique(topK) ∩ Gold| / |Gold|`。
- Precision@K：`|unique(topK) ∩ Gold| / K`，即使返回少于 K 条也使用 K 作分母。
- MRR：第一个唯一相关结果的倒数排名。
- NDCG@K：二值相关性 DCG / 理想 DCG，重复结果只保留首次出现。
- Entity Resolution Accuracy：每条 Query 的所有期望/预测实体字段在规范化后完全相等的比例；预测未知字段算错误。

对于 Gold 为空的 no-match Query，空结果得分 1，返回任意文档得分 0。空案例集指标为 0。所有聚合均为按 Query 的宏平均。

## 实现与验证

实现位于 `backend/ai/services/evaluation_metrics.py`，不连接数据库。`scripts/knowledge_engine_v2_eval_metrics_check.py` 用固定正向、no-match 和实体规范化案例验证公式和边界；专项测试 1 passed。

这是离线指标库，不是持久化测试：数据库为 `none`，SQLite 为 `not_used`。后续如果从数据库读取评测样本，连接必须是 PostgreSQL。

## 结果

五项指标和空结果/重复结果/未知实体行为均已冻结并通过验证。
