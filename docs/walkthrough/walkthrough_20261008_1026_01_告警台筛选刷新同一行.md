# 告警管理工具栏与缩放适配

## 完成摘要

告警台、告警规则、历史告警和维护窗口四个页面的搜索、筛选与手动刷新现在位于同一行；手动刷新使用无文字图标按钮。四个页面的搜索框宽度为 240–360px，历史告警展开后的起止时间输入宽度为 200–240px，时间面板按内容宽度收拢，两个日期输入与快捷范围固定在同一行，窄屏时只在面板内横向滚动。四个表格使用内容宽度并禁止单元格换行，缩放后由表格区域横向滚动承载列宽。告警台默认减少列并提供持久化的列设置；历史告警和告警台较长的标题/信息截断显示，并可悬停查看全文。

## 关键实现说明

- 告警台状态筛选、告警规则类别筛选与其他筛选项均并入一行工具栏；刷新图标在加载时旋转。
- 历史告警高级时间范围仍可展开到下一行，起止输入框采用受控宽度；维护窗口与规则的新建入口、告警台自动刷新开关保持原有位置。
- 历史告警时间筛选展开后按控件内容收拢，不再用整行空白底色；快捷范围与清除动作对齐日期输入。
- 四个表格外层负责横向和纵向滚动，导出菜单容器不再拦截 sticky 表头；历史告警的长文本使用省略号和 `title` 提示。

## 剩余风险与回滚方式

- 内容宽度会使窄屏表格出现横向滚动，这是保留单行字段时的预期行为；长历史告警标题和信息可以悬停读取完整内容。
