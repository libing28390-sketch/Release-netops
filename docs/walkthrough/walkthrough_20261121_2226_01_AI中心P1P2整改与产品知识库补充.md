## 2. 实际修改文件

### 2.1 后端 P1-P2 与产品知识库扩充
- `backend/ai/api/assistant.py`：流式对话落库携带 `citations`，落库后推送 SSE `persisted` 事件返回真实 `assistant_message_id`；统一批量删除文档的租户范围。
- `backend/ai/services/conversation_service.py`：允许 `local_sensitive_identifier` 与 `local_security_block` 执行模式；重命名/归档/清空消息时保留 `selected_model_id` 与 `clarification_state`。
- `backend/ai/services/ip_troubleshooting.py`、`mac_troubleshooting.py`、`natural_query.py`：补全 ARP 关联接入设备信息；MAC 规范化比对下推 SQL；告警查询下推设备与时间条件。
- `backend/ai/gateway/router.py`、`llm_gateway.py`：新增 `resolve_route_policy(scene)` 返回分类策略；修正 `chat()` / `chat_stream()` 优先级使显式 `scene_route` 优先于个人默认模型。
- `backend/ai/api/models.py`、`backend/ai/services/model_health.py`、`metrics.py`：消除 `ai_model_acl` N+1 查询；新增 `DELETE /api/ai/models/routes/{scene}`；健康历史默认保留提升至 90 天；延迟采样列表限制上限 1,000。
- `backend/ai/tools/registry.py`、`read_only_tools.py`：工具超时使用 `executor.shutdown(wait=False, cancel_futures=True)` 避免阻塞并立即释放并发槽位；修正 `tool_get_device_neighbors` 反向查询时本端/对端端口颠倒；MAC 工具下推 SQL 规范化；复用配置 Diff。
- `backend/ai/api/agents.py`、`backend/ai/agents/runner.py`：新增 `GET /api/ai/agents`；`AgentRunner` 从 `ai_agent` 读取 `system_prompt`、`allowed_tools`、`max_steps`、`timeout` 并过滤可用工具；返回结果还原 Vault Token。
- `backend/ai/prompts/renderer.py`、`manager.py`、`api/prompts.py`、`schemas/prompt.py`：复用沙箱 Jinja2 环境，fallback 改为单遍正则替换防二次注入；新增按厂商/平台特异度匹配的 `get_prompt_for_scene`；分页接口新增全局 `facets`。
- `backend/ai/api/security.py`、`security/dev_passthrough.py`、`tokenization.py`、`rate_limit.py`：持久化与加载 `max_payload_bytes`；合并租户开关防覆盖；`ai_kill_switch` 改为 `ON CONFLICT DO UPDATE`；Dry-Run 阻断返回准确 `max_data_level` 与可读 `reason`；`dev_passthrough` 联动策略状态；`ScopedTokenVault` 插入后强制执行 `max_entries` 淘汰并同步清理 `_reverse`；`AIRateLimiter` 内存限流加锁、Redis 使用原子 `incr` + `expire`。
- `backend/ai/services/knowledge_service.py`、`product_resolver.py`、`rag_retriever.py`：目录重命名同步更新文档路径元数据，禁止删除系统目录；收窄产品解析 SQL 列；RAG 检索单次向量化消除重复 Embedding。
- `backend/services/product_catalog_service.py`：自定义型号查询关联规范 `v.code`；创建自定义型号时以 PostgreSQL `ON CONFLICT DO NOTHING` 安全写入 `exact`/`canonical` 别名至 `kb_product_alias`；合并自定义型号别名到解析链路。
- `backend/services/official_product_catalog_service.py`：扩充产品知识库覆盖华为、H3C、Cisco 主流路由器/防火墙/交换机，并新增 **Ruijie（锐捷）**、**Juniper**、**Fortinet**、**Aruba** 四大厂商型号、别名与官方文档参考映射（总计 60+ 官方型号条目）。
- `backend/tests/ai/test_ai_p1_p2_fixes.py`：新增 10 项覆盖 P1-P2 核心改动与产品知识库扩充的回归测试。
