# 3D端口防抖、规整理线、缩放与灵敏度交互重构 走查报告

## 任务完成摘要

针对用户提出的“端口缝隙悬浮屏幕不停刷新抖动”、“连线线路不规整”、“缩放不方便”以及“选择设备操作不灵敏”四大交互与渲染问题，进行了深度重构与全面闭环：

1. **彻底消除端口悬浮抖动与高频重渲染死循环（`RackDeviceTooltip.tsx`）**：
   - 彻底移除了破坏 CSS 布局盒模型的 `scale-110` 放大动画，采用无回流的 `ring-2 ring-cyan-500/60` 与 `brightness-125` 高亮效果；
   - 固定端口看板与详情区域为硬编码高度（`h-[68px]`），杜绝因内容字数变化导致的卡片尺寸抖动；
   - 增加悬停状态持久记忆，鼠标在端口微小缝隙间滑动时保持平稳，不会触发任何屏幕闪烁或刷新。
2. **数据中心标准垂直理线架走线重构（`RackCableLayer.tsx`）**：
   - 严格遵循 EIA-310-D / TIA-942 标准，将跳线约束在机柜两侧 **垂直理线槽（$X = -1.78, Z = 1.35$）** 内；
   - 路径按照 `端口前伸 -> 90°横入理线槽 -> 槽内垂直上升/下降 -> 90°水平引出 -> 插入目标设备` 生成规整优美的 3D 管线，告别空中杂乱飞线；
   - 在“按需”模式下，只保留当前选中设备的垂直规整跳线，并在正中央悬浮呈现 1 个高对比度 3D 链路标牌，彻底解决标牌遮挡堆叠问题。
3. **顶栏快捷缩放与平滑阻尼升级（`RackScene.tsx` / `CameraController.tsx` / `Rack3D/index.tsx`）**：
   - 在顶部浮动控制栏直接增加了 **`[ 放大 (+) ]`** 与 **`[ 缩小 (-) ]`** 快捷操作按钮；
   - 调优了 OrbitControls 鼠标滚轮缩放阻尼（`zoomSpeed: 1.4, dampingFactor: 0.12`），使得视图推拉更加丝滑可控。
4. **设备点击与悬浮 100% 秒级灵敏度响应（`RackDeviceItem.tsx` / `ProceduralChassis.tsx`）**：
   - 移除了 `ProceduralChassis` 与 `RackDeviceItem` 内部两层重复的 Z 轴 `useFrame` 抽拉动画，统一下沉至单层管理，避免射线检测在运动中脱靶；
   - 为每个设备增设了一层全包围的隐形碰撞体（Raycast Hitbox），并在指针进入时即刻变更鼠标手型（`cursor: pointer`），保证从任何俯仰角度点击均能秒级选中。
