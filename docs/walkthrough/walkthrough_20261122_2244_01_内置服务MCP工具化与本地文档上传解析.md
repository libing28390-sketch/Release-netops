- 目标仓库：`D:\netops\netsops-main`

## 1. 完成摘要
1. **内置服务 MCP 工具化**：
   - 新增 [registry.py](file:///D:/netops/netsops-main/backend/ai/mcp/registry.py)，将 8 项内置能力（`/ip`、`/mac`、`/neighbors`、`/alarms`、`/sop`、`/config`、`/troubleshoot`、`/web`）统一封装为标准 MCP Tool 定义（`name`、`slash_command`、`description`、`inputSchema`、`risk_level`），其中 6 项只读工具支持直接 `tools/call` 调用。
   - 在 [assistant.py](file:///D:/netops/netsops-main/backend/ai/api/assistant.py) 新增：
     - `GET /api/ai/assistant/tools`：向 Copilot 前端动态下发工具与斜杠指令目录；
     - `POST /api/ai/assistant/mcp`：标准 MCP JSON-RPC 2.0 端点（支持 `initialize`、`tools/list`、`tools/call`），受 `ai.assistant` 权限与只读脱敏边界保护。
2. **Copilot `/` 快捷指令动态化**：
   - [AssistantTab.tsx](file:///D:/netops/netsops-main/src/pages/ai/Copilot/AssistantTab.tsx) 启动时自动调用 `getCopilotTools()` 拉取后端注册的服务目录并传入 [CopilotComposer.tsx](file:///D:/netops/netsops-main/src/pages/ai/Copilot/CopilotComposer.tsx)；输入 `/` 时动态展示后端注册的全部服务与参数提示（请求失败自动降级到内置默认列表）。
3. **本地 Word / Excel / PDF 上传与解析**：
   - 新增 [document_parser.py](file:///D:/netops/netsops-main/backend/ai/services/document_parser.py)，纯本地解析 `.docx`（优先 `python-docx`，无依赖时原生 OOXML ZIP 解析）、`.xlsx`（`openpyxl`）、`.pdf`（`pypdf`）及 `.txt`/`.md`/`.csv`/`.log`/`.json`（上限 10MB、提取文本上限 24,000 字符）。
   - `POST /api/ai/assistant/attachments/parse` 强制经过 `scan_document_security` 安全预检（高敏拦截、中敏自动脱敏）。
   - 前端 [CopilotComposer.tsx](file:///D:/netops/netsops-main/src/pages/ai/Copilot/CopilotComposer.tsx) 新增回形针上传按钮与附件标签（支持移除），发送时自动将解析后的文档内容随本轮提问提交。
