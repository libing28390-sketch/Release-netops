已成功完成对个人设置弹窗 (`src/components/ProfileModal.tsx`) 的现代化重构。

## 1. 完成摘要

1. **双栏架构重构 (Master-Detail)**：
   - **左侧个人名片与分类导航**：
     - 常驻身份卡片：大头像、真实姓名/用户名、角色徽章（`管理员` / `操作员` / `只读用户`）、MFA 动态防护状态以及上次登录时间。
     - 纵向精致 Tab：👤 基本资料、🔐 登录安全、🔔 告警通知、💻 终端工具，带活跃指示胶囊与右侧微箭头。
   - **右侧独立设置面板**：
     - 彻底消除了原界面连续 4 层重复的“基本资料/头像与联系方式”套娃横幅，视觉清爽开阔。
2. **头像选择器 6x2 对称与交互升级**：
   - 12 个预设头像升级为 **6 列 × 2 行** 对称排列，消除原 5 列排版的底部孤立留白问题。
   - 增加当前选中头像的 Cyan 呼吸外光环、右上角高亮圆点与 `hover:scale-105` 微动效。
   - 上传图片按钮与文件格式限制说明（PNG/JPG/WebP ≤ 2MB）紧凑整合。
3. **表单语义化与视觉精致度**：
   - 用户名增加锁定只读徽章（`Lock` 图标与浅色底）。
   - 真实姓名、手机号、邮箱增加左侧语义图标前缀（`UserRound`, `Phone`, `Mail`）与流畅的 Focus 光晕效果。
   - 密码修改区增加新密码与确认新密码的一致性即时校验报警。
   - 保持了 MFA 扫码绑定、TOTP 验证码录入、固定 PIN 码、钉钉/飞书/企微 Webhook 及终端 Agent 下载等全部底层业务能力。
