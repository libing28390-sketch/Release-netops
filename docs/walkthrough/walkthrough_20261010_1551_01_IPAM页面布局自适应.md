# IPAM 页面布局自适应走查

## 完成摘要

- IPAM 内容承载层和页面根容器增加宽度收缩约束，宽表不会把主内容区域向外撑开。
- IP 定位页的 ARP 表改为固定页面工作区布局：筛选和采集操作保持可见，结果表独立滚动，分页留在结果卡底部；窄窗口可横向查看完整列。
- IP 地址页的筛选区拆成站点/网段摘要行与筛选/搜索行，窄屏可整齐换行。
- IP 地址表设置了明确列宽并禁止徽标逐字换行；资产编号和序列号合并显示为“资产信息”，长文本截断并可通过悬停查看完整内容。
- 未修改 API、地址数据或采集行为。

## 实际修改文件

- `src/pages/IPAMManagementTab.tsx`：为共享 IPAM 根容器和内容区补充 `w-full min-w-0`、`min-h-0` 约束。
- `src/pages/IPLocatorPage.tsx`：固定 ARP tab 的内部布局；控制区不收缩，表格拥有独立的双向滚动容器，分页不随表格滚动；为列设置最小尺寸和文本截断。
- `src/pages/IPVlan/IPAddressTab.tsx`：重排筛选器、限制表格最小宽度及列宽、固定表格布局、徽标不换行；合并资产显示列并为截断内容保留 title。
- `docs/plans/plan_20261010_1551_01_IPAM页面布局自适应.md`：本次计划。
- `handoff.md`：记录跨 Agent 分工和完成状态。

## 关键实现说明

- ARP 表滚动区使用 `min-h-0 flex-1 overflow-auto`，确保它在父级 flex 布局中收缩；工具区和分页不进入表格滚动区域。
- IP 地址表 14 列总宽度约 1613px。视口不足时仅结果区出现横向滚动，标签和徽标保持单行；完整字段仍保留在 DOM 文本或悬停 title 中。
- 地址清单的数据查询、分页、筛选和导出没有改变。合并“资产信息”只影响表格展示，单独的资产编号和序列号仍分别包含在导出数据中。

## 剩余风险与回滚方式

- 可视宽度小于约 1613px 时，IP 地址结果表仍需横向滚动，这是保留所有字段且避免竖排的折中。
- ARP 表在非常低的窗口高度下会压缩结果区，但工具栏和分页保持可见；可按目标窗口高度调整内边距或表格区最小高度。
- 回滚时仅撤销这次新增的 `min-w-0`、表格滚动和列布局调整；不要恢复或覆盖同一文件中此前已有的网关、前缀、矩阵和数据逻辑。
