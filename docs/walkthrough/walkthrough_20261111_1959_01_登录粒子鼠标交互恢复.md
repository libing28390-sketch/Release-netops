# 登录页粒子鼠标交互恢复走查

## 完成摘要

修复了登录页两个粒子可见性问题：不支持 `EXT_color_buffer_float` 时粒子停在静态画面；指针移入账号/密码卡片后，跟随光标的粒子环被卡片遮住。回退路径现在使用顶点着色器动画；指针位于卡片内时，粒子响应移到最近的可见卡片外沿。保留现有 GPU 模拟路径和减少动态效果偏好。

## 关键实现

- 动画是否运行不再由浮点颜色缓冲扩展决定。没有该扩展时启用着色器回退动画，避免静态背景。
- 回退路径通过鼠标跟随的 `ringCenter` 计算粒子轻微位移、亮度和尺寸，粒子位置在 GPU 顶点阶段更新，不在 CPU 上逐帧复制粒子数组。
- 登录卡片标记为粒子遮挡区。鼠标进入卡片时，渲染器把粒子响应中心平滑引导到最近且未被卡片遮住的位置；表单控件仍在粒子层之上，不会被粒子盖住。
- 尊重 `prefers-reduced-motion`：偏好减少动画且指针空闲时保持静态；指针移动时恢复显式交互。

## 11 月 2 日前后代码对比

- 11 月 2 日提交 `18e1592a` 将旧版 `ThreeCyberNetwork.tsx` 中的单文件 Three.js 实现拆成渲染器和着色器。旧版有 120 个远景、150 个中景、14 个近景粒子；每帧在 CPU 上更新轨道、弹簧回复和鼠标排斥，并要求浏览器支持 WebGL。
- 新版改为 Poisson 采样、点精灵和 GPU ping-pong 模拟，粒子外观更稀疏。它增加了 `EXT_color_buffer_float` 能力门槛；不支持时会停止动画帧，仅保留静态粒子。这是旧版不会触发的降级行为。
- 11 月 11 日提交 `03bea6c2` 调整了减少动态效果偏好下的鼠标交互，但 `!canSimulate` 仍会让不支持扩展的设备停在静态状态。本次补上顶点着色器动画回退，并解决新环形响应被登录卡片遮挡的问题。
