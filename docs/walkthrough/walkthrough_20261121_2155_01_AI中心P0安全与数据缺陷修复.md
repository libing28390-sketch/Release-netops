## 3. 关键实现说明

- **P0-1**：在 `RAGRetriever._filter_sql` 对 `request.applicability` 字典键名增加严格正则 `^[A-Za-z0-9_]{1,64}$` 校验，并将 PostgreSQL JSONB 查询从 f-string 插值改为参数化 `COALESCE(d.metadata_json -> ?, '[]'::jsonb) @> jsonb_build_array(?)`，同时为 `_search_once` 异常捕获补充 `logger.exception`。
- **P0-2**：
  - 修复 `sanitizer.py` 中 `password`、`secret`、`key-string`、`pre-shared-key`、`authentication-password`、`snmp-agent community` 的双必填 `\s+` 缺陷，补充华为 VRP `irreversible-cipher` / `level \d+` 与通用 PKCS#8 `BEGIN [A-Z0-9 ]*PRIVATE KEY` 脱敏；
  - 将 `classification.py` 的 `IPV6_RE` 升级为完整支持 `::` 压缩格式且不误判 MAC/时间戳的正则，并在 `tokenization.py` 与 `dlp.py` 中共享同一正则；
  - 移除 `output.py:sanitize_output` 中无条件的 `html.escape(clean, quote=False)`，保留危险标签/协议剥离与凭据脱敏，避免破坏正常文本、CLI 命令、JSON 响应及 `<REDACTED>` 占位符。
- **P0-3**：
  - 在 `AISecurityGateway.protect()` 与 `LLMGateway.chat/chat_stream` 透传 `scene` 参数；对只读配置/差异/命令/告警分析及配置草案生成场景（`config_explain`、`config_diff`、`command_explain`、`alarm_analysis`、`change_plan`、`config_generation`）豁免不含真实凭据的 `change_command`、`full_configuration_or_topology` 与 `credential_request` 误判，真实未脱敏凭据与跨租户请求依然严格阻断；
  - 为 5 个分析/配置生成服务补充 `sanitize_text` 预脱敏、`tenant_id`/`roles` 透传、LLM 畸形 JSON 类型容错（如 `risk_level: null`、百分制 `confidence`、非字典列表项）及更完善的高危命令检测（含回滚命令）。
- **P0-4**：
  - `ChangeGovernanceService.create_change_draft` 改用 `LOCK TABLE change_orders IN SHARE ROW EXCLUSIVE MODE` + `services.change_order_service.create_change_order()` 真实落库（生成 `order_number`，保存 `target_devices_json`、`commands_json`、`rollback_plan`、`requester_id`、`requester_username`、`tenant_id`），彻底移除 `except Exception: pass`；
  - `approve_change` 改用 `SELECT ... FOR UPDATE` 行锁，校验工单存在性、租户隔离、合法审批状态、申请人与审批人职责分离，并更新 `approver_id`/`approver_username`/`final_approver_id`/`final_approver_username`/`updated_at`；路由层将异常准确映射为 404/403/409，并为 `generate-config` 补充 `ai_rate_limiter` 限流。
- **P0-5**：
  - `LLMGateway._log_request` 改用 PostgreSQL 原子 `INSERT INTO ai_usage_daily (...) VALUES (...) ON CONFLICT (date, provider_id, model_id, scene) DO UPDATE SET ...`，消除并发丢失更新与首单 `UniqueViolation`；
  - `LLMGateway._budget_exceeded` 改为校验当日总消耗；`usage.py:get_usage_summary` 新增 `daily_estimated_cost_usd` 并以当日消耗对比 `AI_DAILY_BUDGET_USD`，将 `provider_breakdown` 延迟改为按请求量加权平均。
- **P0-6**：
  - `providers.py:update_provider` 在更新云端 Provider `base_url` 且未显式提交 `approved_endpoint_patterns` 时，自动将新 HTTPS URL 同步到 `approved_endpoint_patterns_json`，防止更新后运行时被出向白名单阻断；
  - 重构 `AzureOpenAIProvider._get_endpoint(model)` 移除对 `self.base_url` 的就地修改，使 `chat()` 与 `chat_stream()` 均无状态、并发安全地拼接部署端点。
- **P0-7**：
  - 为 `RAGRetriever.__init__` 增加实例级 `connection_factory` 与 `embedder` 依赖注入；改造 `scripts/knowledge_baseline_pg.py` 与 `knowledge_evaluation_service.py` 不再 monkey-patch 模块全局属性；
  - 将 `POST /api/knowledge/evaluation/run` 的权限由 `("knowledge_source", "read")` 收紧为 `("knowledge_source", "update")`。
