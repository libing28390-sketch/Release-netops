# 走查与验证报告：大盘端口名切换与服务器大盘拆分及网络监控迁移

## 1. 任务完成摘要
按照用户要求，本次变更完成了三项关键升级：
1. **大盘端口编号格式切换**：所有 Grafana 监控大盘（网络接口流量、互联网出口、设备详情等）全量摒弃单纯数字 `ifIndex`，全面切换为交换机物理端口全称（如 `GigabitEthernet1/0/1`）。
2. **服务器大盘精细化拆分为 Linux 与 Windows**：废弃混合型 `07 服务器与主机监控 (Server & Host Metrics)`，参考官方 Node Exporter 与 Windows Exporter 大盘架构，拆分为：
   - `07 Linux 服务器监控 (Linux Server Metrics)`（UID: `nexora-linux-metrics`）
   - `08 Windows 主机监控 (Windows Host Metrics)`（UID: `nexora-windows-metrics`）
3. **下线 `/monitor/networks` 并迁移 SNMP 批量同步至 `/assets/network-devices`**：
   - 侧边栏彻底移除 `/monitor/networks`（网络监控）菜单；
   - 访问历史路径 `/monitor/networks` 自动平滑重定向至 `/assets/network-devices`；
   - 在网络设备管理页面 [InventoryDevicesTab.tsx](file:///d:/netops/netsops-main/src/pages/InventoryDevicesTab.tsx) 的顶部工具栏及批量勾选浮动胶囊中分别新增「SNMP 同步主机名」与「批量同步主机名」按钮，一键或按需批量调用 `/api/devices/batch-sync-hostname`，配合动态 Toast 状态反馈与列表无缝自动刷新。
