## 关键实现说明

- 投产预检发现网络设备或服务器缺少关联设备记录时返回 HTTP 422，不再静默放行。
- 投产请求不再立即更新 `physical_assets.lifecycle_status` 和 `devices.lifecycle_status`。
- 上收开始时只设置 `rotation_status=rotating`，资产保持原生命周期状态。
- 单台和批量上收成功后，同时将物理资产与关联设备更新为 `production`、`is_managed=1`。
- 上收失败时保持或恢复原生命周期状态，并写入 `takeover_error`。
- 前端轮询仍以 `rotation_status` 判断结果，成功后刷新列表，此时才显示“已投产”。
