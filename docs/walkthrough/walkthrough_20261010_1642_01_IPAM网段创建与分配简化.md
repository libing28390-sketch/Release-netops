# IPAM 网段创建与分配简化执行记录

## 结果摘要

本轮整理了接口采集生成、人工新增网段、IP 分配和地址池的职责与表单。接口候选改成分页查看，避免把数千条候选一次渲染成报表；新增网段表单先呈现 CIDR 和常用字段，规划工具及其余属性按需展开。

## 行为变化

- 接口候选预览按精确 CIDR、租户、站点、VRF 分组，默认只列待创建项，每页显示 25 项；切换到已存在项后可选择并补登记接口 IP。页面只展示接口样例，不返回整批接口明细。
- “生成全部待创建项”先显示数量和范围确认，调用时使用明确的 `all_pending: true`。选中项使用显式 `candidate_ids`。空列表不再触发全量生成；未知或过期候选会要求刷新。
- 保持原有精确 CIDR 归并规则，不自动合并相邻网段。采集器的自动网段发现只创建/更新前缀；手动生成还会登记接口 IP，两者职责不同。
- 网段名称解释为可选展示别名；默认网关 IP 会参与可分配地址排除；网关设备是可选 CMDB 设备关联。错误类型的网关接口自由文本输入已去掉；已有接口 ID 只读保留，新建时留空。
- IP 分配表单优先呈现网段、用途、IP 和主机名；设备、接口、MAC、角色、状态、到期时间和备注折叠在“其他信息”。
- 地址池表单从所属网段继承租户；它只记录连续地址范围和利用率，不会下发 DHCP 租约，也不限制手工 IP 分配。地址池仍作为网段下的子级管理。
- 新增网段弹窗固定高度与内部滚动区域，规划器不再随 CIDR 输入自动插入；弹窗使用淡入而不缩放。网段、IP 清单及地址池在已有数据后刷新时保留当前列表，避免清空后重新出现。
