# 监控审查问题修复完成记录

## 完成摘要

完成监控审查报告中的主要修复，并追加用户明确提出的服务器拓扑隔离：

- 报表和事件读写增加租户范围；overview 缓存按租户键隔离。
- 接口、设备和出口报表改为真实样本语义，去除出口虚构数据；缺失样本显示 `NO_DATA/STALE`，不参与正常/高负荷判断。
- 接口指标关联使用资产与 ifIndex/ifName 稳定键，避免同设备端口值串用。
- 采样告警不再把缺失、计数器重置或异常 delta 当成恢复；错误/丢弃/包计数使用位宽和 uptime 感知的计数器 delta。
- 维护窗口到期自动解除 suppressed，写审计活动并入队通知；通知改为 PostgreSQL outbox，支持幂等、租约、退避和最终失败保留。
- 报表筛选竞态、健康下钻 offset/total 及前端错误/空态处理完成。
- 服务器设备从拓扑发现选择、站点汇总、证据图持久化/读取、legacy metadata 和前端绘图输入全部排除；已有服务器节点或链路不会再显示在网络拓扑图中。

- workspace outbox 使用 at-least-once 语义；多个渠道部分成功后重试可能产生重复通知，后续可按渠道拆分 outbox delivery row。
- `outbound_probe_targets.target_name` 仍为全局唯一；如需不同租户使用同名目标，需单独迁移为租户内唯一约束。
- 监控 overview 的部分运行队列统计仍是平台级汇总，不含设备明细；不返回跨租户资产标识。
