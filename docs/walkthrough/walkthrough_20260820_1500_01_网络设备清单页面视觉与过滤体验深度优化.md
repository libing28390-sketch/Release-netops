# 网络设备清单页面视觉与过滤体验深度优化走查报告

## 1. 任务概述
对 `/assets/network-devices`（网络设备清单页面，对应 `InventoryDevicesTab.tsx`）进行了深度视觉与交互重构，全面采用与 `/assets/dashboard` 统一的高级 SaaS Bento Grid 设计规范，并实现了 4 联状态 KPI 卡片与表格数据过滤的精准对齐。

## 2. 核心修改与实现说明

### 2.1 4 联 Bento 状态卡片升级
- 将原有的微小文本标签（`QuickTag`）全面升级为现代 Bento Grid 状态卡片：
  1. **离线设备 (P1)**：柔和深红微徽章（`bg-rose-50 text-rose-700`）、粗体 Mono 计数与占比、流体微进度条；
  2. **告警异常 (P2)**：琥珀黄微徽章（`bg-amber-50 text-amber-700`）、指标告警计数；
  3. **待投产 / 维护 (P3)**：科技蓝微徽章（`bg-blue-50 text-blue-700`）、待投产与维护状态计数；
  4. **运行正常 (正常)**：翡翠绿微徽章（`bg-emerald-50 text-emerald-700`）、正常在线设备统计；
- 卡片支持点击高亮并即时联动下级表格过滤，再次点击取消过滤。

### 2.2 工具栏与高级筛选 Bento 容器化
- 搜索框与下拉筛选器（平台、角色、在线状态、生命周期状态、标签）封装在 Bento 容器中；
- 增加搜索内容一键清除小图标（`X`）；
- 激活任意筛选或 KPI 卡片过滤时，显示一键 **「重置筛选」** 按钮；
- 工具栏右侧动态展示当前筛选匹配的实际设备数（`共 N 台设备`）。

### 2.3 批量操作栏胶囊化与操作体验
- 选中多台设备时，工具栏下方平滑滑出蓝色高亮批量操作栏：
  - 展示已选中设备总数；
  - **批量连通检查**：调用快速探测；
  - **批量配置变更**：快捷导航至自动化配置编排；
  - **批量标签**：弹出标签分配面板；
  - **取消选择**：一键清除当前多选。

### 2.4 表格与分页容器
- 表格容器统一为 `rounded-2xl`，底栏内嵌 `<Pagination />`，支持每页条数切换与页码跳转。
