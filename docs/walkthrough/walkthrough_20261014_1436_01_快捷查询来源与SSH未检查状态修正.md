# 批量快捷查询来源与巡检 SSH 未检查状态走查

## 完成摘要

- 批量快捷查询为每台设备保留请求状态、设备平台、解析器、parser_platform、采集来源、command_source、adapter、模板、模板来源、解析状态、命令、记录数及错误码。
- 汇总结果只有在所有设备的来源元数据一致时才显示单一值；平台版本、模板或解析器不同会显示“多种解析器（按设备）”。逐设备来源可在结构化表格和终端结果中展开查看，Excel Meta 工作表也包含逐设备来源行。
- 网络设备巡检默认将 ssh_ok 设为 null；没有 CLI 检查项且没有发生 CLI 回退时，SSH 显示“未检查”。真实 CLI 检查及 BGP/OSPF 的 CLI 回退仍记录实际结果。
- inspection_results.ssh_ok 是可空列，无需数据库迁移。现有导出状态格式会把 null 显示为 —。
- 按用户要求未改历史 Playbook TextFSM 重解析路径。

## 剩余风险与建议

- 旧巡检记录中的 ssh_ok=0/1 保持原显示；只有新记录的未检查状态使用 null。
- 快捷查询失败设备没有解析器/模板信息时，逐设备明细会显示请求失败，汇总解析器会标为混合或未报告。
