# 型号字段移除厂商前缀执行记录

## 完成摘要

- 增加通用型号规范化：当型号以厂商字段对应的 canonical 厂商名和空格开头时，去掉该前缀；型号代码、产品系列和后缀保留。例如 `H3C S6850` 变成 `S6850`，`H3C SecPath F1090` 变成 `SecPath F1090`。
- ENTITY-MIB 读取结果、H3C `sysDescr` 解析、人工填写型号和旧的已保存型号都经过规范化；手动同步结果、`devices`、`physical_assets` 及机柜关联使用一致的无厂商前缀型号。
- 型号字段不再重复保存厂商；厂商仍保存在单独的 `vendor` 字段。未匹配到精确厂商前缀的型号保持原值。
