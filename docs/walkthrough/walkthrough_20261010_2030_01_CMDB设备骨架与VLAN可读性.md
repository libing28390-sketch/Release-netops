# CMDB 设备骨架与 VLAN 可读性走查

## 变更

- `/cmdb/devices` 后端列表基于物理资产和设备表中可用的分类字段排除服务器资产；兼容缺少可选分类列的旧数据库结构。
- `/cmdb/vlans` 移除默认行展开，摘要区收敛为 VLAN、网关、当前页设备/端口三组信息。
- VLAN 主表调整为 9 个摘要字段：VLAN ID、名称、设备/站点、网段/网关、描述、VRF、SVI、状态、端口/设备数。
- 操作列使用共享详情图标按钮，打开完整详情视图；接口、ARP/MAC 终端和业务属性仍可在详情中查看。原筛选、分页、导出、编辑和删除入口保留。
- 当前页设备数按唯一设备 ID/主机名去重，避免 API 按设备与 VLAN 组合返回时重复计数。
