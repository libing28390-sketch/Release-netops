# 拓扑筛选布局保存

- `src/pages/TopologyPage.tsx` 将设备范围传给完整拓扑组件。`src/components/TopologyGraph.tsx` 恢复三种范围的保存按钮，按范围保存和读取坐标、缩放及布局设置。
- 全图使用原浏览器存储键和服务端同步。有线和无线各用一个独立的浏览器存储键，重置只清除当前范围。
- Edge 使用四台设备的合成拓扑验证三个范围的按钮、拖动保存、刷新恢复和重置隔离。模拟接口收到全图布局保存请求，两个筛选视图未写入全图接口。
- `npm run lint`、`git diff --check`、临时目录 Vite 生产构建通过。验证范围为本地浏览器与模拟接口。
