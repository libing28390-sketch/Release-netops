# 7. 配置管理产品使用手册 (Config Backup & Diff)

配置管理模块负责全网设备配置的自动备份、增量差异比对、配置合规性审计以及配置漂移告警。

![配置管理](file:///e:/data/netsops/docs/images/config_backup.png)

## 1. 核心功能概述

本模块包含以下子菜单：
1. **备份作业控制台 (Config Backup)**：手动或定时触发全网配置拉取，记录备份状态和版本历史。
2. **配置差异比对 (Config Diff)**：可视化对比任意两个历史版本配置文件的异同。
3. **配置搜索 (Config Search)**：全文搜索所有配置文件中的关键字（如查找包含 `ip route-static 0.0.0.0 0.0.0.0` 的所有交换机）。
4. **合规性审计与漂移检测 (Compliance & Config Drift)**：定义规则模板审计配置，自动捕获设备本地被人工私自修改后的“漂移”差异并报警。

---

## 2. 详细操作步骤

### 2.1 自动与手动配置备份
* **备份作业发起**：
  进入 **配置管理 -> 配置备份**。页面上方提供“立即执行全网备份”按钮。
  点击后，后台会拉起多线程作业引擎。作业会依次解密凭据，通过 SSH 登录设备执行备份指令（例如 Cisco 设备的 `show running-config` 或 Huawei 设备的 `display current-configuration`）。
  备份完成后，将生成全新的版本历史，并在列表中展示每个设备的备份成功/失败状态。

### 2.2 多版本差异比对与漂移审计
* **可视化差异分析**：
  在设备的历史版本列表中，勾选两个不同的时间版本（如 `2026-07-09` 与 `2026-07-10`），点击 **“差异比对”**。
  系统会呈现类似 Git diff 的红绿行内/双栏对比视图，红色代表删除的配置，绿色代表新增的配置。
* **漂移审计**：
  当网络发生了不符合预期的手动修改，合规引擎在备份后会自动比对“基线版本”与“当前运行版本”。如果检测到有非官方授权的变更行，合规控制台会将其标识为“配置已漂移 (Drifted)”，并发出严重警告。
* 核心备份逻辑及差异对比可以参考 API 实现 [configs.py](file:///e:/data/netsops/backend/api/configs.py)。
