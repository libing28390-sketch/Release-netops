# 个人资料保存权限修复走查

## 完成摘要

- 个人中心改为调用 `PUT /api/users/me/profile`；后端从已验证会话读取用户 ID，不再依赖客户端指定目标 ID。
- 本人资料保存不要求 `user.update` 管理范围；管理员管理其他账号仍使用原路径并执行租户及资源范围校验。
- 自助更新保留数据库中的用户名、角色、角色配置、分组和资源范围；只有管理员管理其他账号时才执行原有租户及资源范围校验，并写入账号管理字段。
- 全局通知通道保留创建者、全局管理员及经范围授权的账号管理员的编辑能力。
- 个人中心遇到结构化 API 错误时提取 `detail.message`，不再显示 `[object Object]`。
