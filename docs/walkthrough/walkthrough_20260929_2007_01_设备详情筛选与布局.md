# 设备详情筛选与布局

## 完成摘要

- `02 网络设备详情` 的“设备身份与 SNMP 连通性”面板从 3 个网格单位增加到 4 个，身份表隐藏 `site_id`、`tenant_id` 内部字段，保留设备名称、资产 ID、管理地址、站点、厂商、系统平台、角色和 SNMP 状态。
- 设备身份表下方的 KPI、硬件趋势、明细和接口诊断面板整体顺延一格，避免与加高后的表格重叠。
- 顶部新增级联的站点、厂商、角色筛选。原设备选择器继续单选，并按上述条件筛选设备，硬件统计仍限定于一个 `asset_id`。

## 实际修改文件

- `monitoring/grafana/generate_dashboards.py`
- `monitoring/grafana/dashboards/nexora-network-device.json`（由生成器生成）

## 关键实现说明

- 复用参考看板的 `site`、`vendor`、`role` 查询和全选行为；现有 `asset_id` 设备变量查询按三个父筛选器收窄，并保留设备名、管理地址、站点组成的显示标签。
- 身份表查询仍以设备选择器产生的 `asset_id` 为范围，没有启用设备“All”，以免单设备详情面板把多个设备的硬件采样混在一起。
- 生成器输出的 12 个 dashboard JSON 中，只有 `nexora-network-device.json` 出现内容差异。
