# Walkthrough: Nexora RAG 统一中间格式 (Normalized Markdown) 与智能解析管道

## 完成摘要
成功在后端和服务层落地了 **统一中间格式 (Normalized Markdown + Metadata JSON)** 解析与 **Heading/CLI-Aware 标题感知智能切片 (Smart Chunking)** 机制。同时在知识管理中心 (`KnowledgeManagementTab.tsx`) 引入了文件格式解析效能评估指南与可视化中间转码 Stepper。

---

## 关键实现说明

### 1. 标题与 CLI 结构感知切片器 (`smart_chunk_markdown`)
在 `backend/ai/services/knowledge_service.py` 中实现了 `smart_chunk_markdown` 解析器：
- 自动提取 `#`, `##`, `###` 标题树结构，保证 Section 名称透传至每个 Chunk 的 Metadata JSON 中。
- 完整保留 ````huawei / ````cisco 等命令行回显块，避免硬性按固定字数从中间截断命令参数或故障建议。

### 2. 格式推荐等级指南与可视化解析流水线 (`KnowledgeManagementTab.tsx`)
- **格式效能 Banner**：
  - 🟢 **最佳**：Markdown (`.md`), HTML, TXT, JSON
  - 🟢 **推荐**：DOCX (`.docx`), CSV/XLSX
  - 🟡 **支持**：文字型 PDF, CHM
  - 🔴 **不推荐**：扫描型 PDF / 图片 (提示字符歧义风险)
- **解码流水线 6 步可视化 Stepper**：
  `原始文件解析/提取 → 转换为标准 Markdown 中间格式 → Heading 标题 & CLI 结构抽取 → Metadata JSON 提炼 → Heading-Aware Smart Chunking → Embedding 向量与 FTS 就绪`
