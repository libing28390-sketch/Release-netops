## 关键实现说明

- `actions/setup-python@v5` 通过 pip cache 减少重复下载安装依赖的时间。截图中约 31 秒的依赖安装有机会缩短，但缓存命中与节省量由 GitHub Actions 运行环境决定。
- pytest 使用原完整套件，仅增加 `--durations=25` 报告。单凭报告参数不会直接缩短当前约 8 分钟的测试执行时间，但能为下一步做基于证据的优化提供热点与 setup/call/teardown 耗时。
- PostgreSQL fixtures 会创建独立测试数据库。未把数据库 fixture 改成共享，也未在没有 worker 隔离保障时并行执行。

## 剩余风险与后续建议

- pip 缓存对首次运行或缓存失效的运行无明显收益。

- 对比下一次 Release 的 pytest 时长与最慢项后，再实施测试代码或 workflow 分片优化。
