# 告警范围选项弹层美化

## 变更摘要

- 将浏览器原生 `datalist` 替换为应用内的范围候选输入框，候选弹层与字段同宽，显示匹配值和设备数量。
- 站点、角色以及组合范围中的站点、角色、类型、平台统一使用该控件。
- 支持键盘上下选择、回车确认、Esc 关闭及自由输入；不改变原有范围 API、保存值和匹配逻辑。

## 关键文件
