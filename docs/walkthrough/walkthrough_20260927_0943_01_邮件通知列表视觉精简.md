# 邮件通知列表视觉精简

## 完成摘要

`/management/notifications` 的 SMTP 通道表格已改为响应式列表行。页面主体与标题区对齐并使用可用宽度；通道状态、SMTP 发件信息和收件人摘要更容易扫读；测试操作保留文字，其余操作收敛为带无障碍名称的图标按钮。精简了列表说明和空态文案。

## 关键实现说明

- 用自适应 CSS 网格替换固定最小宽度的宽表格，小屏自动改为纵向信息块。
- 合并通道名、启用状态、更新时间；SMTP 主机与发件人并列呈现；收件人改为简短人数摘要并显示有限名称。

- 第 3 步点击“仅保存”时，仅在保存请求成功后清空临时测试收件人并返回通道列表；配置校验或接口失败时保留向导和错误提示。发送测试仍使用单独的“保存并发送测试邮件”操作。
