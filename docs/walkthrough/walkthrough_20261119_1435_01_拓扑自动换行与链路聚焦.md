# 拓扑自动换行与链路聚焦

- `src/utils/topologyRoleLayout.ts` 按视口宽度和设备名称长度提前换行。每行上限默认仍为 60，可手动调整。接入设备按已观测到的上联组合排列，待确认的接入设备单独排在后面。有线接入层内部行距收紧，无线分区和角色层之间仍保留间距。
- `src/components/TopologyGraph.tsx` 接入新布局，保留保存的手工坐标和行上限。首次读取旧布局时重新适应视野。选中设备后突出关联链路和直接邻居，支持鼠标滚轮、点击百分比回到 100% 及「适应全图」。
- `src/pages/TopologyPage.tsx` 和 `src/components/TopologyUplinkGroups.tsx` 在正式站点画布增加「完整拓扑 / 上联分组」切换。两种视图共用筛选后的设备和链路，模式切换保留选中设备，也可在全屏下切换。分组视图列出各个物理上联及两端接口，支持 AP 有线父设备与无线控制器分区。

## 验证

- 角色布局和无线布局测试通过 21 项，分组组件测试通过 3 项，名称标签、链路、图标与导出测试通过 14 项。
- `npm run lint`、隔离目录中的 Vite 生产构建和 `git diff --check` 通过。
- Edge 实测站点页面使用 50 台设备样本。每行上限设为 60 时自动安排三行接入，自动行最多 12 台；设备名称边框没有重叠。旧版手工坐标在改成每行 10 台后仍保留。选中的接入设备同时突出两条上联，切到分组后显示两台汇聚及其端口。滚轮缩放、恢复 100%、适应全图和全屏切换均通过。
