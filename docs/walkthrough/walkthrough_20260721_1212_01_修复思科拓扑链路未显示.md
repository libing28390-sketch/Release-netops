# 修复思科拓扑链路未显示：执行记录

## 完成摘要

已确认并修复了在 `cisco_ios` 平台（如思科 IOL/IOU 设备）上进行拓扑发现时，由于 `show lldp neighbors detail` 输出缺少 `Local Intf:` 字段导致无法提取本地接口，进而使得所有邻居观察记录被丢弃、拓扑链路展示为 0 的问题。

通过将采集指令变更为 `show lldp neighbors`（简表），并适配其 TextFSM 解析出的 `interface` 和 `remote_interface` 字段，我们成功重新提取了完整的本地接口与对端接口对。经过验证，拓扑发现任务正确生成了全部 5 条链路，所有的测试用例也已全部通过。

## 实际修改文件

* `backend/services/topology_service.py`：修改 `DISCOVERY_COMMANDS` 中 `cisco_ios` 的 `lldp` 查询命令为 `show lldp neighbors`。
* `backend/services/discovery_service.py`：修改 `COMMAND_PROFILES` 中 `cisco_ios` 的 `neighbors` 查询命令为 `show lldp neighbors`。
* `backend/services/normalizers/cisco.py`：更新 `parse_neighbors` 方法，使用 `show lldp neighbors` TextFSM 平台参数解析，并兼容匹配 `interface` (本地端口) 与 `remote_interface` (对端端口)。
* `backend/services/operational_data_service.py`：更新 `COMMAND_CATALOG` 中 `cisco_ios` 平台的邻居查询指令为 `show lldp neighbors`。
* `backend/tests/vendor_audit/test_h3c_cisco_quick_queries.py`：更新测试断言中对 `cisco_ios` 的解析命令预期。
