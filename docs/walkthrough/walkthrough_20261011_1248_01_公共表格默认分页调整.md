# 公共表格默认分页调整 Walkthrough

## 变更摘要

- 将公共表格和列表的默认每页数量从 20 调整为 10，覆盖使用共享 `Pagination` 的受控状态、固定分页参数、全局资产列表 store，以及 WAN 专线等自定义分页列表。
- 保留用户手动切换到 20、50、100 条的选项；只把分页默认值和相应最小值改为 10。
- 未调整导出、搜索预加载等非表格分页请求的批量大小。
- 同步更新资产列表页大小默认值的既有测试断言。

## 验证

- `rg` 扫描 `src` 后，未发现表格默认分页仍使用 `useState(20)`、`itemsPerPage={20}` 或 20 条的最小分页约束；残余 `Math.max(20, ...)` 仅用于 Rack 3D 场景几何参数。
- `git diff --check` 通过；Git 仅提示部分已有文件下次写入时会规范 CRLF 行尾。
- 未运行测试或构建。

## 影响与风险

- 首次加载分页列表会显示最多 10 条，用户仍可从分页控件选择更大页数。
- 不涉及数据库、API 契约或部署配置。
