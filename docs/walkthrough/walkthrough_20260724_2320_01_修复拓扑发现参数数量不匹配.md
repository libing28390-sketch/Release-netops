# Walkthrough / 验证报告: 修复拓扑发现 INSERT 与 UPDATE 参数不匹配

## 完成摘要

修复了在执行拓扑发现保存到 `topology_observations` 表时，因为 SQL 语句中占位符数量与 Python 传入的参数元组长度不匹配，导致保存新记录（INSERT 路径）与更新已有记录（UPDATE 路径）时，分别抛出 `TypeError: not all arguments converted during string formatting` 和 `IndexError: tuple index out of range` 异常并导致任务标记为 `topology_discovery_failed` 的 Bug。

## 实际修改文件

* [backend/services/topology_service.py](file:///d:/netops/netsops-main/backend/services/topology_service.py)

## 关键实现说明

1. **INSERT 修复**：在 SQL 的 `VALUES` 子句尾部中已经硬编码了 `0` 和 `1`，但 Python 传参元组的末尾也传入了 `0` 和 `1`，造成参数比 `?` 占位符多出两个。移除了 Python 元组尾部的多余参数。
2. **UPDATE 修复**：移除原来有缺陷且不对齐的 `values` 临时元组定义，将 `UPDATE` 语句的 18 个参数全部以 inline 的方式显式传入，保证参数个数与更新语句的 18 个占位符严格一一对应且顺序正确。
