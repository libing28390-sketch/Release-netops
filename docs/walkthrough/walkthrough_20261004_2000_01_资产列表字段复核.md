# 网络设备列表字段精简与机柜名称交接记录

## 完成摘要
已调整 `/assets/network-devices` 默认列并去掉表格强制 2200px 最小宽度；低频诊断字段仍可由用户自行打开。列偏好按版本写入 localStorage，并支持安全回退和恢复默认。列表与导出均只显示机柜名称 `rack_name`，没有名称时使用 `—`，不会显示机柜代码或内部 ID。
