# Nexora Project AI Skills & Capabilities

This document defines the specialized skills and tools available for this project.

## 1. Network Automation Skill
- **Tools**: Netmiko, Scrapli, TextFSM.
- **Capability**: Analyze device configurations, execute multi-vendor commands, and parse structured data using TextFSM templates located in `backend/core/textfsm/`.

## 2. Premium UI Skill
- **Tools**: TailwindCSS v4, motion/react, Lucide icons.
- **Capability**: Generate and refine high-end, animated dashboard components following the project's glassmorphism and dark-mode aesthetic.

## 3. Log Analysis Skill
- **Tools**: `scripts/startup_logger.cjs`, Python logging.
- **Capability**: Deep analysis of startup sessions, troubleshooting concurrent process failures, and monitoring long-term system health through compressed log archives.

## 4. MCP Integration
- **Playwright**: Used for automated UI testing and capturing visual snapshots.
- **Postgres**: Used for schema analysis and complex query optimization.
